# useColorScheme 色彩方案

`ColorSchemeProvider` 会将保存的色彩方案应用到文档，并提供给
`useColorScheme`。该钩子返回选中的 `light`、`dark` 或 `auto` 模式、Bootstrap
当前为页面解析出的亮色或暗色色彩方案，以及一个用于应用并持久化选择结果的设置
函数。它读取 `<html>` 元素上的 `data-bs-theme`；当该属性缺失或为 `auto` 时，
回退到浏览器的 `prefers-color-scheme` 设置，与 Bootstrap 解析颜色变量的方式
一致。

选中的 `light`、`dark` 或 `auto` 模式会通过
[`@guoyunhe/react-storage`](https://github.com/guoyunhe/react-storage) 保存在
`localStorage` 的 `colorScheme` 键中，因此刷新页面后仍然有效，并会在多个浏览器
标签页之间保持同步。该键通过 `colorSchemeStorageKey` 导出。

在应用根部渲染一次该 Provider。由于应用保存方案的效果由 Provider 负责，只要
Provider 挂载，即使没有组件调用 `useColorScheme` 或渲染色彩方案切换按钮，保存的
偏好也会生效。

## Provider

```tsx
import { ColorSchemeProvider } from 'react-bootstrap-pro';

export function App() {
  return (
    <ColorSchemeProvider>
      <Routes />
    </ColorSchemeProvider>
  );
}
```

`useColorScheme` 必须在 `ColorSchemeProvider` 内调用，否则会抛出错误。

实际渲染结果一致。

## API

### ColorSchemeProvider

| 属性       | 类型        | 说明                                      |
| ---------- | ----------- | ----------------------------------------- |
| `children` | `ReactNode` | 应用内容。Provider 自身不会增加任何标记。 |

Provider 读取保存的方案并应用到文档元素，同时跟踪 `data-bs-theme`、
`prefers-color-scheme` 以及保存值的变化。

### useColorScheme

该钩子不接受参数，返回一个 `ColorSchemeState` 对象：

| 属性                  | 类型                  | 说明                                                  |
| --------------------- | --------------------- | ----------------------------------------------------- |
| `colorScheme`         | `ColorScheme`         | 选中的 `'light'`、`'dark'` 或 `'auto'` 模式。         |
| `computedColorScheme` | `ResolvedColorScheme` | Bootstrap 为页面解析出的 `'light'` 或 `'dark'` 方案。 |
| `setColorScheme`      | `SetColorScheme`      | 将方案应用到文档并持久化。                            |

`setColorScheme` 接受 `'light'`、`'dark'` 或 `'auto'`。设置为 `'light'` 或
`'dark'` 时会在 `<html>` 上写入 `data-bs-theme`；设置为 `'auto'` 时会移除该属性，
让 Bootstrap 重新跟随浏览器偏好。

`colorScheme` 反映保存的选择，可能为 `'auto'`。`computedColorScheme` 永远不会是
`'auto'`：它反映实际的 `data-bs-theme` 属性；该属性缺失时则反映浏览器偏好。

## 行为

- `<html>` 上的 `data-bs-theme='light'` 与 `data-bs-theme='dark'` 优先于浏览器偏好。
- 未设置该属性，或设置为 `data-bs-theme='auto'` 时，`computedColorScheme`
  跟随 `prefers-color-scheme`；除非保存了其他模式，否则 `colorScheme` 保持
  `'auto'`。
- Provider 挂载时会恢复保存的 `'light'` 或 `'dark'` 选择，无论是否有组件调用
  `useColorScheme`。如果页面已经设置了 `data-bs-theme`（例如通过内联脚本），则
  保留该值并优先使用它。
- 其他标签页修改 `colorScheme` 键后，当前标签页会同步应用新的方案。
- 如果 `localStorage` 不可用，`setColorScheme` 仍会更新当前页面的文档，但不会
  持久化选择。
- Provider 在客户端读取存储。服务端渲染时 `computedColorScheme` 为 `'light'`，
  首次客户端渲染会读取实际数值。
