# Floating labels

`FormFloating` wraps a `<label>` and a `.form-control` element to build a
floating label. Put the label first so screen readers announce it before the
value, and give textual controls a non-empty `placeholder`: the CSS-only
implementation uses `:placeholder-shown` to detect an empty field. The
placeholder stays transparent until the control is focused.

## Textareas

Textareas match the height of inputs by default. To change the height, override
the `--bs-form-floating-height` custom property on the wrapper instead of using
`rows`, so the label floats correctly at any height.

## API

### FormFloating

Renders a `div` by default. Its own prop is `always`; it inherits native props
for the selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

| Prop        | Type          | Description                                                      |
| ----------- | ------------- | ---------------------------------------------------------------- |
| `always`    | `boolean`     | Keeps the label floated and the placeholder visible.             |
| `component` | `ElementType` | Selects the rendered element; defaults to `div`.                 |
| `...props`  | `BoxProps<C>` | Native props for the selected element and all Box utility props. |

Validation classes can be passed through `className`: add `is-invalid` to the
wrapper and the control, then render feedback below the field.

### FormControl

Renders an `input` by default. Its own props replace the native `size` prop
with Bootstrap control sizing; it inherits other native props for the selected
element and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

| Prop         | Type                   | Description                                                      |
| ------------ | ---------------------- | ---------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap form-control size.          |
| `plaintext`  | `boolean`              | Renders the control with the `.form-control-plaintext` style.    |
| `ghost`      | `boolean`              | Renders the control with the `.form-ghost` style.                |
| `adorn`      | `boolean`              | Adds the input-group adornment styling.                          |
| `adornEnd`   | `boolean`              | Adds adornment styling at the end of the control.                |
| `validation` | `'valid' \| 'invalid'` | Applies the corresponding server-side validation class.          |
| `component`  | `ElementType`          | Selects the rendered element; defaults to `input`.               |
| `...props`   | `BoxProps<C>`          | Native props for the selected element and all Box utility props. |

### FormLabel

Renders a `label` by default. Its own `col` prop adds horizontal-form label
styling; it inherits native props for the selected element and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

| Prop        | Type                      | Description                                                      |
| ----------- | ------------------------- | ---------------------------------------------------------------- |
| `col`       | `boolean \| 'sm' \| 'lg'` | Adds `.col-form-label`, optionally sized to match the control.   |
| `component` | `ElementType`             | Selects the rendered element; defaults to `label`.               |
| `...props`  | `BoxProps<C>`             | Native props for the selected element and all Box utility props. |

## Accessibility

Render the `<label>` before the control and bind it with `htmlFor`. A non-empty
`placeholder` is required for textual controls, but it is not an accessible
name, so keep a visible label.
