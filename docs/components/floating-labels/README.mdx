# Floating labels

`FormFloating` wraps a `<label>` and a `.form-control` element to build a
floating label. Put the label first so screen readers announce it before the
value, and give textual controls a non-empty `placeholder`: the CSS-only
implementation uses `:placeholder-shown` to detect an empty field. The
placeholder stays transparent until the control is focused.

## Textareas

Textareas match the height of inputs by default. To change the height, override
the `--bs-form-floating-height` custom property on the wrapper instead of using
`rows`, so the label floats correctly at any height.

## API

### FormFloating

Renders a `div` by default. Its own prop is `always?: boolean`; it inherits
native props for the selected element and all [`Box`](../box/README.mdx#api)
props through `BoxProps<C>`.

| Prop        | Type          | Description                                        |
| ----------- | ------------- | -------------------------------------------------- |
| `always`    | `boolean`     | Keeps the label floated and shows the placeholder. |
| `component` | `ElementType` | Renders a `div` by default.                        |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.            |

Validation classes can be passed through `className`: add `is-invalid` to the
wrapper and the control, then render feedback below the field.

### FormControl

Renders an `input` by default. Its own props are `size?: 'sm' | 'lg'`,
`plaintext?: boolean`, `ghost?: boolean`, `adorn?: boolean`,
`adornEnd?: boolean`, and `validation?: ValidationState`; it inherits native
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### FormLabel

Renders a `label` by default. Its own prop is `col?: boolean | 'sm' | 'lg'`; it
inherits native label props and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

## Accessibility

Render the `<label>` before the control and bind it with `htmlFor`. A non-empty
`placeholder` is required for textual controls, but it is not an accessible
name, so keep a visible label.
