# Floating labels 浮动标签

`FormFloating` 包裹 `<label>` 与 `.form-control` 元素，构建浮动标签。标签必须写在
控件之前，屏幕阅读器才会先朗读标签再朗读值；文本控件需要非空 `placeholder`，
因为纯 CSS 实现依赖 `:placeholder-shown` 判断空值。控件未聚焦时占位文本是透明的。

## 文本域

文本域默认与输入框等高。若要调整高度，请覆盖容器上的
`--bs-form-floating-height` 自定义属性，而不要使用 `rows`，这样标签在任意高度下
都能正确浮动。

## API

### FormFloating

默认渲染为 `div`。自有属性为 `always`；继承所选元素的原生属性及通过
`BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

| 属性        | 类型          | 说明                                      |
| ----------- | ------------- | ----------------------------------------- |
| `always`    | `boolean`     | 标签始终浮动，且占位文本保持可见。        |
| `component` | `ElementType` | 指定渲染元素，默认为 `div`。              |
| `...props`  | `BoxProps<C>` | 所选元素的原生属性及全部 Box 工具类属性。 |

校验样式可通过 `className` 传入：为容器和控件添加 `is-invalid`，再在字段下方渲染
反馈信息。

## 无障碍

`<label>` 必须写在控件之前，并通过 `htmlFor` 绑定。文本控件需要非空
`placeholder`，但它不能作为可访问名称，因此请保留可见标签。
