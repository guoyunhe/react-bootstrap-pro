# Tooltip 工具提示

`Tooltip` 使用 `@floating-ui/react` 处理定位和交互。它不会初始化 Bootstrap
JavaScript 插件，也不会读取 `data-bs-toggle` 属性。通过 `trigger` 传入单个触发元素，
子节点作为提示内容渲染。

## 概览

悬停或聚焦按钮，即可在触发元素上方查看提示。

<DemoContainer>
  <TooltipBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

使用此组件时请注意：

- Tooltip 使用 Floating UI 定位，并通过 portal 渲染到 `document.body`。
- 空内容不会显示。
- 隐藏的触发元素无法可靠定位。
- 禁用控件无法接收焦点或鼠标事件；请使用可聚焦的包装元素作为触发元素。
- 重要信息应同时在 Tooltip 之外提供。

## CSS 变量

可在自定义类上覆盖 Bootstrap Tooltip 变量：

```css
.custom-tooltip {
  --bs-tooltip-bg: #563d7c;
  --bs-tooltip-color: #fff;
}
```

## API

### Tooltip

默认渲染为 `div`。自有属性为
`delay?: number | { close?: number; open?: number }`、`instant?: boolean`、
`onShowChange?: (show: boolean) => void`、`placement?: Responsive<TooltipPlacement>`、
`show?: boolean`、`trigger?: ReactElement` 和 `triggers?: TooltipTrigger[]`；继承所选
元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

| 属性           | 类型                                                                | 说明                                             |
| -------------- | ------------------------------------------------------------------- | ------------------------------------------------ |
| `trigger`      | `ReactElement`                                                      | 触发元素；传入后启用交互模式。                   |
| `placement`    | `TooltipPlacement \| Partial<Record<Breakpoint, TooltipPlacement>>` | 首选放置位置或响应式放置位置，默认为 `top`。     |
| `triggers`     | `('hover' \| 'focus' \| 'click')[]`                                 | 触发方式，默认为 `['hover', 'focus']`。          |
| `delay`        | `number \| { open?: number; close?: number }`                       | 鼠标悬停显示/隐藏的毫秒延迟。                    |
| `show`         | `boolean`                                                           | 交互模式下控制显示；静态模式下用于添加显示样式。 |
| `onShowChange` | `(show: boolean) => void`                                           | 交互请求改变显示状态时调用。                     |
| `instant`      | `boolean`                                                           | 禁用淡入淡出动画。                               |
| `component`    | `ElementType`                                                       | 更换提示表面的元素。                             |
| `...props`     | `BoxProps<C>`                                                       | 提示表面的原生属性及所有 Box 工具类属性。        |

`TooltipInner` 设置内部文本样式。可使用 `className`、Box 工具类属性或 Bootstrap Tooltip
CSS 变量自定义外观。

### TooltipInner

默认渲染为 `div`，没有自有属性。继承原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

## 无障碍访问

提示通过 `aria-describedby` 与触发元素关联。建议使用可键盘聚焦的交互元素作为触发元素，
并提供清晰的无障碍名称。重要说明不应只存在于 Tooltip 中。若提示中包含链接或其他控件，
请同时检查键盘和触屏操作。
