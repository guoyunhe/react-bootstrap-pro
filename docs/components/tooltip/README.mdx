# Tooltip

`Tooltip` provides the styled tooltip surface. Its `show` prop controls the
rendered surface; Bootstrap's JavaScript plugin creates and positions tooltips
from trigger elements. Do not rely on hover-only content to convey essential
information.

## Placement

Set `placement` to `top`, `end`, `bottom`, or `start`.

## Plugin trigger

For Bootstrap-managed tooltips, initialize a native trigger with a title. The
plugin creates and positions its own tooltip surface.

## API

| Prop        | Type                                    | Description                             |
| ----------- | --------------------------------------- | --------------------------------------- |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | Selects the placement style.            |
| `show`      | `boolean`                               | Adds `.show`; false by default.         |
| `instant`   | `boolean`                               | Disables the fade transition.           |
| `component` | `ElementType`                           | Changes the root element.               |
| `...props`  | `BoxProps<C>`                           | Native props and all Box utility props. |

`TooltipInner` applies the inner text styling. Provide trigger text through
Bootstrap's supported title attributes when using the plugin.

## Accessibility

Keep essential instructions available without a tooltip, support keyboard
focus on its trigger, and make the trigger's accessible name clear.
