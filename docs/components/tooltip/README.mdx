# Tooltip

`Tooltip` uses `@floating-ui/react` for positioning and interactions. It does not
initialize Bootstrap's JavaScript plugin or read `data-bs-toggle` attributes.
Pass one trigger element through `trigger`; its children are rendered as the
tooltip content.

## Overview

Hover or focus the button to see a tooltip above its trigger.

<DemoContainer>
  <TooltipBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

Things to know when using this component:

- Tooltips use Floating UI and render in a portal attached to `document.body`.
- Empty content is not displayed.
- Hidden triggers cannot be positioned reliably.
- Disabled controls cannot receive focus or pointer events; use a focusable
  wrapper as the trigger.
- Keep essential information available outside the tooltip.

## CSS variables

Bootstrap tooltip variables can be overridden on a custom class:

```css
.custom-tooltip {
  --bs-tooltip-bg: #563d7c;
  --bs-tooltip-color: #fff;
}
```

## API

| Prop           | Type                                                                | Description                                                                   |
| -------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `trigger`      | `ReactElement`                                                      | Trigger element; enables interactive mode.                                    |
| `placement`    | `TooltipPlacement \| Partial<Record<Breakpoint, TooltipPlacement>>` | Preferred placement or responsive placements; defaults to `top`.              |
| `triggers`     | `('hover' \| 'focus' \| 'click')[]`                                 | Interaction sources; defaults to `['hover', 'focus']`.                        |
| `delay`        | `number \| { open?: number; close?: number }`                       | Hover delay in milliseconds.                                                  |
| `show`         | `boolean`                                                           | Controlled visibility in interactive mode; static surface modifier otherwise. |
| `onShowChange` | `(show: boolean) => void`                                           | Called when an interaction requests a visibility change.                      |
| `instant`      | `boolean`                                                           | Disables the fade transition.                                                 |
| `component`    | `ElementType`                                                       | Changes the tooltip surface element.                                          |
| `...props`     | `BoxProps<C>`                                                       | Native props and all Box utility props for the tooltip surface.               |

`TooltipInner` applies Bootstrap's inner text styling. Use `className`, Box
utility props, or Bootstrap tooltip CSS variables to customize its appearance.

## Accessibility

The tooltip is associated with its trigger using `aria-describedby`. Prefer
interactive, keyboard-focusable triggers and give them a clear accessible name.
Do not rely on tooltip content alone for important instructions. Tooltips with
links or other controls should be checked with both keyboard and touch input.
