# Tooltip

`Tooltip` uses `@floating-ui/react` for positioning and interactions. It does not
initialize Bootstrap's JavaScript plugin or read `data-bs-toggle` attributes.
Pass one trigger element through `trigger`; its children become the tooltip
content. Without `trigger`, the component renders a static tooltip surface.

## Overview

Hover or focus the button to see the tooltip. It appears above the trigger by
default.

<DemoContainer>
  <TooltipBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

Things to know when using this component:

- Floating UI positions the tooltip, which renders in a portal on `document.body`
  and is therefore not clipped by scrolling containers.
- Empty content is never displayed, and an open tooltip closes when its content
  becomes empty.
- Hidden triggers cannot be measured, so keep the trigger rendered while the
  tooltip can open.
- Disabled controls cannot receive focus or pointer events; use a focusable
  wrapper as the trigger.
- A link that wraps across multiple lines gets a tooltip centered on the whole
  box; add `white-space: nowrap` to keep it anchored to the visible text.
- Pressing Escape dismisses the tooltip.
- Keep essential information available outside the tooltip.

## CSS variables

The tooltip surface exposes Bootstrap's CSS variables on `.tooltip` and
`.tooltip-inner`. Override them on a class passed through `className`, as in the
custom tooltip example, or scope them to a wrapper.

| Variable                           | Default                         | Description                               |
| ---------------------------------- | ------------------------------- | ----------------------------------------- |
| `--bs-tooltip-zindex`              | `var(--bs-z-tooltip)`           | Stacking order of the tooltip.            |
| `--bs-tooltip-max-width`           | `200px`                         | Maximum width of the surface.             |
| `--bs-tooltip-padding-x`           | `var(--bs-spacer-3)`            | Horizontal padding of the inner content.  |
| `--bs-tooltip-padding-y`           | `calc(var(--bs-spacer) * .375)` | Vertical padding of the inner content.    |
| `--bs-tooltip-font-size`           | `var(--bs-font-size-sm)`        | Font size of the inner content.           |
| `--bs-tooltip-color`               | `var(--bs-bg-body)`             | Text color of the inner content.          |
| `--bs-tooltip-bg`                  | `var(--bs-fg-body)`             | Background color of the surface.          |
| `--bs-tooltip-border-radius`       | `var(--bs-radius-5)`            | Corner radius of the surface.             |
| `--bs-tooltip-opacity`             | `0.95`                          | Opacity of a visible tooltip.             |
| `--bs-tooltip-arrow-width`         | `0.8rem`                        | Width of the arrow.                       |
| `--bs-tooltip-arrow-height`        | `0.4rem`                        | Height of the arrow.                      |
| `--bs-tooltip-transition-property` | `opacity`                       | Property animated by the fade transition. |
| `--bs-tooltip-transition-duration` | `0.15s`                         | Duration of the fade transition.          |
| `--bs-tooltip-transition-timing`   | `linear`                        | Timing function of the fade transition.   |

## API

### Tooltip

Renders a `div` with `.tooltip`, a `.tooltip-arrow`, and `TooltipInner`. With
`trigger`, it also renders the trigger element and the tooltip in a portal;
without it, the tooltip surface is static and `show` toggles its visibility.

| Prop           | Type                                                                | Description                                                                    |
| -------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `trigger`      | `ReactElement`                                                      | Trigger element; passing it enables the interactive tooltip.                   |
| `placement`    | `TooltipPlacement \| Partial<Record<Breakpoint, TooltipPlacement>>` | Preferred placement or a placement per breakpoint; defaults to `top`.          |
| `triggers`     | `('hover' \| 'focus' \| 'click')[]`                                 | Interaction sources; defaults to `['hover', 'focus']`.                         |
| `delay`        | `number \| { open?: number; close?: number }`                       | Delay in milliseconds before showing or hiding the tooltip.                    |
| `show`         | `boolean`                                                           | Controlled visibility in interactive mode; reveals a static surface otherwise. |
| `onShowChange` | `(show: boolean) => void`                                           | Called when an interaction requests a visibility change.                       |
| `instant`      | `boolean`                                                           | Adds `.tooltip-instant` to disable the fade transition.                        |

`TooltipPlacement` is `'top'`, `'right'`, `'bottom'`, `'left'`, `'start'`, or
`'end'`; `start` and `end` follow the writing direction. A placement object
resolves from the current viewport width, falling back to smaller breakpoints and
then to `top`. The component inherits native props for the selected element and
all [`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`.

### TooltipInner

Renders a `div` with `.tooltip-inner` for the text content. It has no own props
and inherits native props and all [`Box`](../box/README.mdx#api) utility props
through `BoxProps<C>`.

## Accessibility

Tooltips are supplementary. Keep the trigger's accessible name and any essential
information in the page itself, because tooltip content is announced only while
the tooltip is open. Prefer interactive, keyboard-focusable triggers with a clear
label.

The default `['hover', 'focus']` triggers open the tooltip for pointer and
keyboard users alike, and Escape dismisses it. Touch devices cannot hover, so add
`'click'` to `triggers` or provide the information in visible text when it
matters. Avoid links and buttons inside tooltips unless the tooltip is
interactive and stays open while the pointer moves onto it. For disabled
controls, trigger the tooltip from a focusable wrapper so keyboard users can
reach it.
