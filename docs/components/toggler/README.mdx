# Toggler

`Toggler` renders a trigger for Bootstrap's toggler plugin. The plugin can
toggle a class or attribute on the trigger itself or on a selected target.

## Target elements

Set a selector in `target` to modify another element. Without a target, the
plugin changes the trigger element.

## Toggle attributes

Set `attribute='aria-expanded'` to toggle an attribute on the target.

## API

| Prop        | Type          | Description                                        |
| ----------- | ------------- | -------------------------------------------------- |
| `target`    | `string`      | Optional selector for the element to update.       |
| `attribute` | `string`      | Attribute to toggle.                               |
| `value`     | `string`      | Class or attribute value toggled by the plugin.    |
| `component` | `ElementType` | Changes the trigger element; defaults to `button`. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.            |

The Bootstrap JavaScript bundle is required for toggling behavior.

## Accessibility

Use an interactive trigger such as a button and expose expanded state when the
toggled content is shown or hidden.
