# Table 表格

Bootstrap 的表格需要显式启用：`Table` 会添加基础的 `.table` 类，各个修饰属性覆盖条纹、
悬停、边框、卡片、堆叠与响应式等变体。`TableHead`、`TableBody`、`TableFoot`、
`TableRow`、`TableHeader`、`TableCell` 与 `TableCaption` 分别对应语义化标签，因此嵌套
表格的样式不会从父表格继承。

`Table` 渲染带 `.table` 的 `<table>`。表头单元格使用 `TableHeader`，列表头设置
`scope='col'`，行表头设置 `scope='row'`。

## 颜色变体

将任意主题色传给 `theme`，即可为整个表格、`TableRow` 行或单个 `TableHeader` /
`TableCell` 单元格着色，并自动适配明暗模式。

<DemoContainer>
  <TableVariantsDemo />
</DemoContainer>

```tsx src='./demos/variants.tsx'

```

仅用颜色表达含义只能提供视觉提示。请让内容本身表达含义，或通过 `.visually-hidden`
隐藏文本来补充说明。

`Table`、`TableRow` 或单元格上使用 Box 的 `verticalAlign` 属性重新对齐。

## 堆叠表格

设置 `stacked` 可在空间受限时将每行转换为堆叠块：第一列作为标题，其余单元格以「标签—
值」形式展示，标签来自每个 `TableCell` 的 `cell` 属性。

堆叠表格基于容器查询，因此组件始终会渲染响应式包裹层。传入断点可仅在该断点以下堆叠，
例如 `stacked='md'`。

<DemoContainer>
  <TableStackedDemo />
</DemoContainer>

```tsx src='./demos/stacked.tsx'

```

## 响应式表格

设置 `responsive` 会用 `.table-responsive` 包裹表格以支持横向滚动；也可传入断点，使其
仅在该宽度以下滚动，例如 `responsive='md'`。

<DemoContainer>
  <TableResponsiveDemo />
</DemoContainer>

```tsx src='./demos/responsive.tsx'

```

响应式表格使用 `overflow-y: hidden`，因此会裁剪超出表格上下边缘的内容，包括菜单与其他
第三方组件。

## API

### Table

| 属性             | 类型                                               | 说明                                        |
| ---------------- | -------------------------------------------------- | ------------------------------------------- |
| `striped`        | `boolean`                                          | 为 `<tbody>` 的行添加斑马纹。               |
| `stripedColumns` | `boolean`                                          | 为列添加斑马纹。                            |
| `hover`          | `boolean`                                          | 为 `<tbody>` 的行启用悬停效果。             |
| `bordered`       | `boolean`                                          | 为表格与单元格添加四周边框。                |
| `borderless`     | `boolean`                                          | 移除表格与单元格边框。                      |
| `small`          | `boolean`                                          | 将单元格内边距减半。                        |
| `card`           | `boolean`                                          | 用 `.table-card` 包裹表格。                 |
| `captionTop`     | `boolean`                                          | 将标题放到表格上方。                        |
| `stacked`        | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 行堆叠，可仅在指定断点以下生效。            |
| `responsive`     | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 包裹表格以支持横向滚动。                    |
| `component`      | `ElementType`                                      | 默认渲染 `table`。                          |
| `...props`       | `BoxProps<C>`                                      | 原生属性与全部 Box 工具属性（含 `theme`）。 |

### TableHead、TableBody、TableFoot

| 属性        | 类型          | 说明                                    |
| ----------- | ------------- | --------------------------------------- |
| `divider`   | `boolean`     | 在分组上方添加 `.table-group-divider`。 |
| `component` | `ElementType` | 默认渲染 `thead`、`tbody` 或 `tfoot`。  |
| `...props`  | `BoxProps<C>` | 原生属性与全部 Box 工具属性。           |

### TableRow

| 属性        | 类型          | 说明                          |
| ----------- | ------------- | ----------------------------- |
| `active`    | `boolean`     | 用 `.table-active` 高亮该行。 |
| `component` | `ElementType` | 默认渲染 `tr`。               |
| `...props`  | `BoxProps<C>` | 原生属性与全部 Box 工具属性。 |

### TableHeader 与 TableCell

| 属性        | 类型          | 说明                                        |
| ----------- | ------------- | ------------------------------------------- |
| `active`    | `boolean`     | 用 `.table-active` 高亮该单元格。           |
| `cell`      | `string`      | 表格堆叠时该单元格使用的标签。              |
| `component` | `ElementType` | 默认渲染 `th` 或 `td`。                     |
| `...props`  | `BoxProps<C>` | 原生属性与全部 Box 工具属性（含 `theme`）。 |

### TableCaption

| 属性        | 类型          | 说明                          |
| ----------- | ------------- | ----------------------------- |
| `component` | `ElementType` | 默认渲染 `caption`。          |
| `...props`  | `BoxProps<C>` | 原生属性与全部 Box 工具属性。 |

## 无障碍

使用语义化标记：表头单元格使用 `TableHeader` 并显式设置 `scope`，用 `TableCaption`
为表格命名，便于屏幕阅读器定位并描述表格。当每行描述一个实体时，保留第一列作为行表头。
不要仅依赖颜色，请为主题化的行或单元格补充文本或隐藏说明。
