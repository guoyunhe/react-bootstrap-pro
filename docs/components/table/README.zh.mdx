# Table 表格

Bootstrap 的表格需要显式启用：`Table` 会添加基础的 `.table` 类，各个属性覆盖条纹、悬停、
边框、紧凑、卡片、堆叠与响应式等变体。`TableHead`、`TableBody`、`TableFoot`、
`TableRow`、`TableHeader`、`TableCell` 与 `TableCaption` 分别渲染对应的语义化元素，
因此嵌套表格的样式不会从父表格继承。

`TableCell`；列表头设置 `scope='col'`，行表头设置 `scope='row'`。

## 堆叠表格

设置 `stacked` 可在空间受限时将行转换为堆叠块。每行成为一个纵向区块，第一个单元格作为
标题，其余单元格显示为标签与值的组合；标签来自每个 `TableCell` 的 `cell` 属性。

堆叠表格基于容器查询，因此始终会渲染响应式包裹层。传入断点可仅在低于该断点时堆叠，例如
`stacked='md'`。

<DemoContainer>
  <TableStackedDemo />
</DemoContainer>

```tsx src='./demos/stacked.tsx'

```

## 响应式表格

响应式表格会在包裹层内横向滚动。设置 `responsive` 可在任意宽度下将表格包裹在
`.table-responsive` 中；传入断点则仅在低于该宽度时滚动，例如 `responsive='md'`。

## API

### Table

默认渲染为 `table`，可使用 `component` 更换元素。继承原生表格属性，以及通过
`BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 工具类属性，因此 `theme`、
`verticalAlign` 等工具属性会作用于表格。

| 组件属性         | 类型                                               | 说明                                   |
| ---------------- | -------------------------------------------------- | -------------------------------------- |
| `striped`        | `boolean`                                          | 为 `<tbody>` 中的行添加斑马纹。        |
| `stripedColumns` | `boolean`                                          | 为列添加斑马纹。                       |
| `hover`          | `boolean`                                          | 为 `<tbody>` 中的行启用悬停状态。      |
| `bordered`       | `boolean`                                          | 为表格与单元格添加四周边框。           |
| `borderless`     | `boolean`                                          | 移除表格与单元格的边框。               |
| `small`          | `boolean`                                          | 将单元格内边距减半。                   |
| `card`           | `boolean`                                          | 将表格包裹在 `.table-card` 中。        |
| `captionTop`     | `boolean`                                          | 将标题显示在表格上方。                 |
| `stacked`        | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 将行堆叠为区块，可限定在断点以下生效。 |
| `responsive`     | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 为横向滚动包裹表格。                   |

`responsive`、`card` 与 `stacked` 会渲染带对应类的包裹 `div`。传入断点时，`.table-responsive`
或 `.table-stacked` 会加上响应式前缀，例如 `md:table-responsive`。未设置 `responsive` 时，
`stacked` 也会添加 `table-responsive` 包裹层，因为堆叠布局需要它作为容器查询上下文。

### TableHeader

默认渲染为 `th`，可使用 `component` 更换元素。

| 组件属性 | 类型      | 说明                              |
| -------- | --------- | --------------------------------- |
| `active` | `boolean` | 用 `.table-active` 高亮该单元格。 |
| `cell`   | `string`  | 表格堆叠时该单元格使用的标签。    |

[`Box`](../box/README.zh.mdx#api) 工具类属性。

## 无障碍访问

保持语义结构：使用 `TableHead` 与 `TableBody` 划分分组，为 `TableHeader` 明确设置
`scope='col'` 或 `scope='row'`，并通过 `TableCaption` 为表格命名，让屏幕阅读器能够定位
并描述表格。`captionTop` 只改变标题的视觉位置，标题仍是表格的第一个子元素，请保持这一
顺序。

仅用颜色无法向辅助技术传达含义。主题行或单元格应配合文字，或使用 `.visually-hidden`
隐藏标签补充说明。单元格中的链接、按钮等交互内容会保留原生键盘行为。

表格切换为堆叠布局后，`cell` 标签会替代列标题，请将其写为简短的字段名。响应式表格在包裹
层内滚动，视觉顺序与阅读顺序一致，请确保表格内容的顺序合乎逻辑。
