# Table

Bootstrap tables are opt-in: `Table` adds the base `.table` class, and the
modifier props cover the striped, hover, bordered, card, stacked, and responsive
variants. `TableHead`, `TableBody`, `TableFoot`, `TableRow`, `TableHeader`,
`TableCell`, and `TableCaption` map to the matching semantic elements, so nested
tables stay independent from their parent.

`Table` renders a `<table>` with `.table`. Use `TableHeader` for `th` cells,
passing `scope='col'` for column headings and `scope='row'` for row headings.

## Variants

Pass any theme color as `theme` to color an entire table, a `TableRow`, or a
single `TableHeader` or `TableCell`. The variants adapt to color modes.

<DemoContainer>
  <TableVariantsDemo />
</DemoContainer>

```tsx src='./demos/variants.tsx'

```

Using color to add meaning only provides a visual indication. Make the meaning
obvious from the content itself, or include it through additional text that is
hidden with `.visually-hidden`.

## Table borders

### Bordered tables

Set `bordered` for borders on all sides of the table and cells. Border color
utilities such as `borderColor='primary'` change the color.

## Vertical alignment

Cells in the `<thead>` are always aligned to the bottom, while `<tbody>` cells
inherit the table's alignment. Use the `verticalAlign` Box prop on `Table`,
`TableRow`, or a cell to re-align where needed.

## Stacked tables

Set `stacked` to convert rows into stacked blocks when space is limited. Each row
becomes a vertical block with the first cell as its title and the remaining cells
as label–value pairs; the label comes from the `cell` prop on each `TableCell`.

Stacked tables use container queries, so the responsive wrapper is always
rendered. Pass a breakpoint to only stack below it, for example `stacked='md'`.

## Responsive tables

Set `responsive` to wrap the table in `.table-responsive` for horizontal
scrolling, or pass a breakpoint to only scroll up to that width, for example
`responsive='md'`.

<DemoContainer>
  <TableResponsiveDemo />
</DemoContainer>

```tsx src='./demos/responsive.tsx'

```

Responsive tables use `overflow-y: hidden`, which clips content beyond the top
and bottom edges of the table, including menus and other third-party widgets.

## API

### Table

| Prop             | Type                                               | Description                                                |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| `striped`        | `boolean`                                          | Zebra-stripes the rows in the `<tbody>`.                   |
| `stripedColumns` | `boolean`                                          | Zebra-stripes the columns.                                 |
| `hover`          | `boolean`                                          | Enables a hover state on rows in the `<tbody>`.            |
| `bordered`       | `boolean`                                          | Adds borders on all sides of the table and cells.          |
| `borderless`     | `boolean`                                          | Removes borders from the table and cells.                  |
| `small`          | `boolean`                                          | Cuts cell padding in half.                                 |
| `card`           | `boolean`                                          | Wraps the table in `.table-card`.                          |
| `captionTop`     | `boolean`                                          | Places the caption above the table.                        |
| `stacked`        | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Stacks rows into blocks, optionally below a breakpoint.    |
| `responsive`     | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Wraps the table for horizontal scrolling.                  |
| `component`      | `ElementType`                                      | Renders a `table` by default.                              |
| `...props`       | `BoxProps<C>`                                      | Native props and all Box utility props, including `theme`. |

### TableHead, TableBody, TableFoot

| Prop        | Type          | Description                                      |
| ----------- | ------------- | ------------------------------------------------ |
| `divider`   | `boolean`     | Adds `.table-group-divider` above the group.     |
| `component` | `ElementType` | Renders `thead`, `tbody`, or `tfoot` by default. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.          |

### TableRow

| Prop        | Type          | Description                              |
| ----------- | ------------- | ---------------------------------------- |
| `active`    | `boolean`     | Highlights the row with `.table-active`. |
| `component` | `ElementType` | Renders a `tr` by default.               |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.  |

### TableHeader and TableCell

| Prop        | Type          | Description                                                |
| ----------- | ------------- | ---------------------------------------------------------- |
| `active`    | `boolean`     | Highlights the cell with `.table-active`.                  |
| `cell`      | `string`      | Label used for this cell when the table is stacked.        |
| `component` | `ElementType` | Renders a `th` or `td` by default.                         |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props, including `theme`. |

### TableCaption

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Renders a `caption` by default.         |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

## Accessibility

Use semantic markup: `TableHeader` for header cells with an explicit `scope`,
and `TableCaption` to name the table so screen readers can find and describe it.
Keep the first column as a row header when each row describes an entity. Do not
rely on color alone—pair themed rows or cells with text or hidden labels.
