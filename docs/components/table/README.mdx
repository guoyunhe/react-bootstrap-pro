# Table

Bootstrap tables are opt-in: `Table` adds the base `.table` class, and its props
cover the striped, hover, bordered, small, card, stacked, and responsive
variants. `TableHead`, `TableBody`, `TableFoot`, `TableRow`, `TableHeader`,
`TableCell`, and `TableCaption` render the matching semantic elements, so nested
tables stay independent from their parent.

## Stacked tables

Set `stacked` to convert rows into stacked blocks when space is limited. Each row
becomes a vertical block with the first cell as its title and the remaining cells
as label–value pairs; the label comes from the `cell` prop on each `TableCell`.

Stacked tables use container queries, so the responsive wrapper is always
rendered. Pass a breakpoint to only stack below it, for example `stacked='md'`.

## Responsive tables

Responsive tables scroll horizontally inside a wrapper. Set `responsive` to wrap
the table in `.table-responsive` at every width, or pass a breakpoint to only
scroll up to it, for example `responsive='md'`.

## API

### Table

Renders a `table` by default; use `component` to change the element. It inherits
native table props and all [`Box`](../box/README.mdx#api) utility props through
`BoxProps<C>`, so `theme`, `verticalAlign`, and other utilities apply to the
table.

| Prop             | Type                                               | Description                                             |
| ---------------- | -------------------------------------------------- | ------------------------------------------------------- |
| `striped`        | `boolean`                                          | Zebra-stripes the rows in the `<tbody>`.                |
| `stripedColumns` | `boolean`                                          | Zebra-stripes the columns.                              |
| `hover`          | `boolean`                                          | Enables a hover state on rows in the `<tbody>`.         |
| `bordered`       | `boolean`                                          | Adds borders on all sides of the table and cells.       |
| `borderless`     | `boolean`                                          | Removes borders from the table and cells.               |
| `small`          | `boolean`                                          | Cuts cell padding in half.                              |
| `card`           | `boolean`                                          | Wraps the table in `.table-card`.                       |
| `captionTop`     | `boolean`                                          | Places the caption above the table.                     |
| `stacked`        | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Stacks rows into blocks, optionally below a breakpoint. |
| `responsive`     | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Wraps the table for horizontal scrolling.               |

`responsive`, `card`, and `stacked` render a wrapper `div` with the matching
classes. A breakpoint value adds `.table-responsive` or `.table-stacked` with a
responsive prefix, for example `md:table-responsive`. `stacked` adds the
`table-responsive` wrapper when `responsive` is not set, because the stacked
layout needs it as its container query context.

### TableRow

Renders a `tr` by default; use `component` to change the element.

| Prop     | Type      | Description                              |
| -------- | --------- | ---------------------------------------- |
| `active` | `boolean` | Highlights the row with `.table-active`. |

It inherits native props and all [`Box`](../box/README.mdx#api) utility props

### TableHeader

Renders a `th` by default; use `component` to change the element.

| Prop     | Type      | Description                                         |
| -------- | --------- | --------------------------------------------------- |
| `active` | `boolean` | Highlights the cell with `.table-active`.           |
| `cell`   | `string`  | Label used for this cell when the table is stacked. |

`cell` is written to the `data-cell` attribute, which the stacked layout reads
for its label. Set `scope` to describe the header's role. It inherits native
props and all [`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`.

### TableCell

Renders a `td` by default; use `component` to change the element.

| Prop     | Type      | Description                                         |
| -------- | --------- | --------------------------------------------------- |
| `active` | `boolean` | Highlights the cell with `.table-active`.           |
| `cell`   | `string`  | Label used for this cell when the table is stacked. |

`cell` is written to the `data-cell` attribute, which the stacked layout reads
for its label. It inherits native props and all
[`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`.

### TableCaption

Renders a `caption` by default; use `component` to change the element. It has no
own props and inherits native props and all
[`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`.

## Accessibility

Keep the semantic structure: use `TableHead` and `TableBody` for the groups,
`TableHeader` with an explicit `scope='col'` or `scope='row'`, and `TableCaption`
to name the table so screen readers can find and describe it. `captionTop` only
moves the caption visually; it stays the first child of the table, so keep it
there.

Color alone does not convey meaning to assistive technology. Pair themed rows or
cells with text or labels hidden with `.visually-hidden`. Interactive content
inside cells, such as links or buttons, keeps its native keyboard behavior.

When the table becomes stacked, `cell` labels replace the column headings, so
write them as short field names. Responsive tables scroll inside their wrapper;
keep the table's reading order logical because the visual order stays the same.
