# Container 容器

容器用于包裹、留白并居中页面内容，是 Bootstrap 默认网格系统所需的基础布局元素。容器可以
嵌套，但大多数布局不需要嵌套容器。

Bootstrap 提供三种容器类型：

- `.container` 在不同断点设置响应式 `max-width`。
- `.sm:container`、`.md:container`、`.lg:container`、`.xl:container` 和
  `.2xl:container` 在到达对应断点之前保持全宽。
- `.container-fluid` 在所有断点都保持全宽。

下表对比了 Bootstrap 6 默认断点下的容器宽度。可查看
[Grid 示例](https://getbootstrap.com/docs/6.0/examples/grid/#containers)了解容器在布局中的效果。

| 类名               | 超小<br />&lt;576px | 小<br />≥576px | 中<br />≥768px | 大<br />≥1024px | 超大<br />≥1280px | 2 倍超大<br />≥1536px |
| ------------------ | ------------------: | -------------: | -------------: | --------------: | ----------------: | --------------------: |
| `.container`       |                100% |          540px |          720px |           960px |            1140px |                1440px |
| `.sm:container`    |                100% |          540px |          720px |           960px |            1140px |                1440px |
| `.md:container`    |                100% |           100% |          720px |           960px |            1140px |                1440px |

| `.xl:container`    |                100% |           100% |           100% |            100% |            1140px |                1440px |
| `.2xl:container`   |                100% |           100% |           100% |            100% |              100% |                1440px |
| `.container-fluid` |                100% |           100% |           100% |            100% |              100% |                  100% |

## CSS

### Sass 变量

Bootstrap 根据 `$container-max-widths` Sass 映射生成容器类。在编译 Bootstrap 前自定义此
映射，即可更改各断点的最大宽度。有关 Sass 映射的自定义方式，请参阅
[Grid Sass 文档](https://getbootstrap.com/docs/6.0/layout/grid/#css)。

### Sass 混入

使用 Bootstrap 的 `make-container` Sass 混入创建自定义容器类：

```scss
.custom-container {
  @include make-container();
}
```

## API

### Container

默认渲染为 `div`。自有属性为 `fluid`：值为 `true` 时应用 `.container-fluid`；传入断点值时
应用对应的响应式容器类。组件继承所选元素的原生属性及全部 [`Box`](../box/README.zh.mdx#api)
属性，包括 `component`、`className` 和 `classNameBefore`。

| 属性    | 类型                                               | 默认值  | 说明                                                               |
| ------- | -------------------------------------------------- | ------- | ------------------------------------------------------------------ |
| `fluid` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `false` | `true` 使用 `.container-fluid`；传入断点则使用对应的响应式容器类。 |

`Container` 继承 `BoxProps`，因此可以直接在容器上设置 `bg`、`fg`、`theme`、
`colorScheme` 等 [`Box`](../box/README.zh.mdx#api) 工具类属性。

## 无障碍

容器本身不会创建地标区域。适当时可通过 `component` 选择 `main` 或 `section` 等语义元素。
