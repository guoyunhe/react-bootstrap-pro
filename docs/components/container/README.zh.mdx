# Container 容器

`Container` 使用 Bootstrap 6 容器类，提供响应式、居中的布局包装器。使用组件前，
需要在应用中引入一次 Bootstrap 样式表。

## 容器类型

默认容器会在不同断点使用不同的 `max-width`。设置 `fluid` 可使用全宽容器；传入
断点则会让容器在到达该断点前保持全宽。

<DemoContainer>
  <ContainerTypesDemo />
</DemoContainer>

```tsx
<Container>默认响应式容器</Container>
<Container fluid>全宽容器</Container>
<Container fluid='md'>到达中等断点前保持全宽</Container>
```

## 响应式宽度

Bootstrap 6 容器在指定断点以下为 100% 宽度，到达断点后应用响应式
`max-width`：

| 类名               | 超小<br />&lt;576px | 小<br />≥576px | 中<br />≥768px | 大<br />≥1024px | 超大<br />≥1280px | 2 倍超大<br />≥1536px |
| ------------------ | ------------------: | -------------: | -------------: | --------------: | ----------------: | --------------------: |
| `.container`       |                100% |          540px |          720px |           960px |            1140px |                1440px |
| `.sm:container`    |                100% |          540px |          720px |           960px |            1140px |                1440px |
| `.md:container`    |                100% |           100% |          720px |           960px |            1140px |                1440px |
| `.lg:container`    |                100% |           100% |           100% |           960px |            1140px |                1440px |
| `.xl:container`    |                100% |           100% |           100% |            100% |            1140px |                1440px |
| `.2xl:container`   |                100% |           100% |           100% |            100% |              100% |                1440px |
| `.container-fluid` |                100% |           100% |           100% |            100% |              100% |                  100% |

断点宽度使用 Bootstrap 6 默认值。Sass 自定义详情请参阅 Bootstrap
[容器文档](https://getbootstrap.com/docs/6.0/layout/containers/)。

## API

| 属性        | 类型                                               | 默认值  | 说明                                                               |
| ----------- | -------------------------------------------------- | ------- | ------------------------------------------------------------------ |
| `component` | `C extends ElementType`                            | `'div'` | 渲染的原生元素或 React 组件。                                      |
| `fluid`     | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `false` | `true` 使用 `.container-fluid`；传入断点则使用对应的响应式容器类。 |
| `className` | `string`                                           | —       | 额外的类名。                                                       |
| `...props`  | `BoxProps<C>`                                      | —       | 所选组件的原生属性，以及全部 [`Box`](../box/) 工具类属性。         |

`Container` 继承 `BoxProps`，因此可以直接在容器上设置 `bg`、`fg`、`theme`、
`colorScheme` 等 [`Box`](../box/) 工具类属性。
