# Container

Containers contain, pad, and center page content. They are the basic layout
element required by Bootstrap's default grid system. Containers can be nested,
though most layouts do not need nested containers.

Bootstrap provides three container types:

- `.container` sets a responsive `max-width` at each breakpoint.
- `.sm:container`, `.md:container`, `.lg:container`, `.xl:container`, and
  `.2xl:container` remain full width until the named breakpoint.
- `.container-fluid` remains full width at every breakpoint.

The table compares their widths at Bootstrap 6's default breakpoints. See the
[Grid example](https://getbootstrap.com/docs/6.0/examples/grid/#containers) to
compare containers in a layout.

| Class              | Extra small<br />&lt;576px | Small<br />≥576px | Medium<br />≥768px | Large<br />≥1024px | X-large<br />≥1280px | 2X-large<br />≥1536px |
| ------------------ | -------------------------: | ----------------: | -----------------: | -----------------: | -------------------: | --------------------: |
| `.container`       |                       100% |             540px |              720px |              960px |               1140px |                1440px |
| `.sm:container`    |                       100% |             540px |              720px |              960px |               1140px |                1440px |
| `.md:container`    |                       100% |              100% |              720px |              960px |               1140px |                1440px |
| `.lg:container`    |                       100% |              100% |               100% |              960px |               1140px |                1440px |
| `.xl:container`    |                       100% |              100% |               100% |               100% |               1140px |                1440px |
| `.2xl:container`   |                       100% |              100% |               100% |               100% |                 100% |                1440px |
| `.container-fluid` |                       100% |              100% |               100% |               100% |                 100% |                  100% |

## CSS

### Sass variables

Bootstrap generates its container classes from the `$container-max-widths` Sass
map. Customize this map before compiling Bootstrap to change the responsive
maximum widths. See the [Grid Sass documentation](https://getbootstrap.com/docs/6.0/layout/grid/#css)
for details on customizing Sass maps.

### Sass mixins

Use Bootstrap's `make-container` Sass mixin to create a custom container class:

```scss
.custom-container {
  @include make-container();
}
```

## API

### Container

Renders a `div` by default. Its own prop is `fluid`: `true` applies
`.container-fluid`, and a breakpoint value applies the corresponding
responsive container class. It inherits native props for the selected element
and all [`Box`](../box/README.mdx#api) props, including `component`,
`className`, and `classNameBefore`.

| Prop    | Type                                               | Default | Description                                                                                           |
| ------- | -------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------- |
| `fluid` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `false` | `true` applies `.container-fluid`; a breakpoint applies the corresponding responsive container class. |

`Container` extends `BoxProps`, so `bg`, `fg`, `theme`, `colorScheme`, and the
other [`Box`](../box/README.mdx#api) utility props can be set directly on the
container.

## Accessibility

The container wrapper does not create a landmark by itself. Use `component` to
choose a semantic element such as `main` or `section` when appropriate.
