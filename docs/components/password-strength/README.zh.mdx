# PasswordStrength 密码强度

`PasswordStrength` 在 React 中计算分数并渲染装饰性强度条。它不会验证或强制执行
密码策略；安全要求也必须在服务器端执行。

## 概览

- **分段强度条**：密码越强，四段依次点亮。
- **进度条**：单条进度条随强度等级增长。
- **文本反馈**：可选地为各等级显示提示文本。
- **自定义评分**：调整内置标准或传入自定义评分函数。

## 评分标准

内置评分函数会为每项符合的标准加一分：

| 标准                          | 分值 |
| ----------------------------- | ---- |
| 达到最小长度（默认 8 个字符） | +1   |
| 比最小长度至少多 4 个字符     | +1   |
| 包含小写字母                  | +1   |
| 包含大写字母                  | +1   |
| 包含数字                      | +1   |
| 包含受支持的特殊字符          | +1   |
| 包含多个受支持的特殊字符      | +1   |
| 长度至少为 16 个字符          | +1   |

使用默认阈值时，分数 `1–2` 为弱，`3–4` 为一般，`5–6` 为良好，`7` 分及以上为强。
分数为 `0` 时强度条保持空状态。

## API

### PasswordStrength

默认渲染为强度条 `<div>`。设置 `showText` 时，还会渲染一个同级的实时区域 `<span>`。
强度条接受原生 `div` 属性（`children` 和原生 `onChange` 除外），并继承
[`Box`](../box/README.zh.mdx#api) 工具类属性。

| 属性         | 类型                                                                    | 默认值           | 说明                                           |
| ------------ | ----------------------------------------------------------------------- | ---------------- | ---------------------------------------------- |
| `value`      | `string`                                                                | —                | 待评估的密码。省略或传入空字符串时分数为 `0`。 |
| `strength`   | `'weak' \| 'fair' \| 'good' \| 'strong'`                                | —                | 设置显示等级，并优先于计算结果。               |
| `variant`    | `'segments' \| 'bar'`                                                   | `'segments'`     | 渲染四段式强度条或单条进度条。                 |
| `minLength`  | `number`                                                                | `8`              | 获得第一项长度分所需的长度。                   |
| `weights`    | `PasswordStrengthWeights`                                               | 所有权重均为 `1` | 内置各评分标准对应的分值。                     |
| `thresholds` | `readonly [number, number, number]`                                     | `[2, 4, 6]`      | 弱、一般、良好的分数边界；更高分数为强。       |
| `scorer`     | `(password: string) => number`                                          | 内置评分函数     | 替换内置评分函数。密码为空时不会调用。         |
| `messages`   | `Partial<Record<PasswordStrengthLevel, string>>`                        | 英文默认文本     | 设置 `showText` 时覆盖各等级显示文本。         |
| `showText`   | `boolean`                                                               | `false`          | 渲染 `.strength-text` 礼貌实时区域提示文本。   |
| `onChange`   | `(strength: PasswordStrengthLevel \| undefined, score: number) => void` | —                | 显示等级变化时调用。                           |

同时设置 `value` 和 `strength` 时，`strength` 控制显示等级，而传给 `onChange` 的
`score` 仍根据 `value` 计算。强度条接受其余原生属性及 `Box` 属性，不接受子元素。

`PasswordStrengthWeights` 的每个字段默认值均为 `1`。将字段设为 `0` 可停用对应评分标准。

| 字段              | 说明                                 |
| ----------------- | ------------------------------------ |
| `minLength`       | 密码达到 `minLength`。               |
| `extraLength`     | 密码比 `minLength` 至少多 4 个字符。 |
| `lowercase`       | 包含小写字母。                       |
| `uppercase`       | 包含大写字母。                       |
| `numbers`         | 包含数字。                           |
| `special`         | 包含受支持的特殊字符。               |
| `multipleSpecial` | 包含多个受支持的特殊字符。           |
| `longPassword`    | 密码长度至少为 16 个字符。           |

## 无障碍访问

强度条只提供视觉反馈，并非密码验证。请同时提供可见的密码要求，并通过
`aria-describedby` 将要求文本与输入框关联。启用 `showText` 时，强度变化会通过礼貌
实时区域播报，不会打断用户输入。
