# PasswordStrength

`PasswordStrength` calculates a score in React and renders a decorative meter.
It does not validate or enforce a password policy; enforce security
requirements on the server as well.

## Overview

- **Segmented meter**: four segments fill as the password gets stronger.
- **Progress bar**: a single bar grows with the strength level.
- **Text feedback**: optional messages for each level.
- **Custom scoring**: adjust the built-in criteria or supply a scorer.

## Strength criteria

The built-in scorer awards one point for each matching criterion:

| Criterion                               | Points |
| --------------------------------------- | ------ |
| Meets the minimum length (8 by default) | +1     |
| Is at least 4 characters over minimum   | +1     |
| Contains a lowercase letter             | +1     |
| Contains an uppercase letter            | +1     |
| Contains a number                       | +1     |
| Contains a supported special character  | +1     |
| Contains multiple special characters    | +1     |
| Is at least 16 characters long          | +1     |

With the default thresholds, scores of `1–2` are weak, `3–4` are fair, `5–6`
are good, and `7` or higher are strong. A score of `0` leaves the meter empty.

## API

### PasswordStrength

Renders a meter `<div>` by default. With `showText`, it also renders a sibling
`<span>` live region. The meter accepts native `div` props except `children`
and the native `onChange`, and inherits [`Box`](../box/README.mdx#api) utility
props.

| Prop         | Type                                                                    | Default          | Description                                                                    |
| ------------ | ----------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------ |
| `value`      | `string`                                                                | —                | Password to evaluate. An omitted or empty value produces a score of `0`.       |
| `strength`   | `'weak' \| 'fair' \| 'good' \| 'strong'`                                | —                | Sets the displayed level and takes precedence over the computed level.         |
| `variant`    | `'segments' \| 'bar'`                                                   | `'segments'`     | Renders a four-segment meter or a single progress bar.                         |
| `minLength`  | `number`                                                                | `8`              | Length required for the first length point.                                    |
| `weights`    | `PasswordStrengthWeights`                                               | All weights `1`  | Points awarded for each built-in scoring criterion.                            |
| `thresholds` | `readonly [number, number, number]`                                     | `[2, 4, 6]`      | Inclusive score boundaries for weak, fair, and good; higher scores are strong. |
| `scorer`     | `(password: string) => number`                                          | Built-in scorer  | Replaces the built-in scorer. It is not called for an empty password.          |
| `messages`   | `Partial<Record<PasswordStrengthLevel, string>>`                        | English defaults | Overrides the text for each level when `showText` is enabled.                  |
| `showText`   | `boolean`                                                               | `false`          | Renders the `.strength-text` polite live-region message.                       |
| `onChange`   | `(strength: PasswordStrengthLevel \| undefined, score: number) => void` | —                | Called when the displayed level changes.                                       |

When both `value` and `strength` are set, `strength` controls the displayed
level, while the `score` passed to `onChange` is still calculated from `value`.
The meter accepts the remaining native and `Box` props; it does not accept
children.

Each `PasswordStrengthWeights` field defaults to `1`. Set a field to `0` to
disable that criterion.

| Field             | Description                                         |
| ----------------- | --------------------------------------------------- |
| `minLength`       | Password reaches `minLength`.                       |
| `extraLength`     | Password is at least 4 characters over `minLength`. |
| `lowercase`       | Contains a lowercase letter.                        |
| `uppercase`       | Contains an uppercase letter.                       |
| `numbers`         | Contains a number.                                  |
| `special`         | Contains a supported special character.             |
| `multipleSpecial` | Contains more than one supported special character. |
| `longPassword`    | Password is at least 16 characters long.            |

## Accessibility

The meter is visual feedback, not password validation. Pair it with visible
password requirements and connect those requirements to the input with
`aria-describedby`. When `showText` is enabled, changes are announced through a
polite live region without interrupting typing.
