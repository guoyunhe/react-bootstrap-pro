## API

### Spinner

Renders a `span` by default and defaults to the `border` variant, `Loading`
label, and `status` role. Its own props are `variant`, `size`, and `label`;
`aria-label` can override the accessible label. It inherits native props for
the selected element and [`Box`](../box/README.mdx#api) utility props.

| Prop        | Type                             | Description                                 |
| ----------- | -------------------------------- | ------------------------------------------- |
| `variant`   | `'border' \| 'grow' \| 'rotate'` | Selects the spinner appearance.             |
| `size`      | `'sm'`                           | Uses the compact size.                      |
| `label`     | `string`                         | Accessible name, defaulting to `'Loading'`. |
| `component` | `ElementType`                    | Changes the rendered element.               |
| `...props`  | `BoxProps<C>`                    | Native props and all Box utility props.     |

Spinners use `currentColor`; use Box foreground utilities to change their color.

## Accessibility

Provide a concise accessible label for the loading status. Hide the visual
indicator from assistive technology when a separate status message already
announces the same information.
