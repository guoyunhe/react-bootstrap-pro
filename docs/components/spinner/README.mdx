# Spinner

`Spinner` renders Bootstrap's CSS-only loading indicator. Use the `border` or
`grow` variant for the built-in shapes, or `rotate` to animate custom content.
Rendering needs no JavaScript; your application still decides when to show the
spinner. By default it has `role='status'` and the accessible label `Loading`.

The indicator also renders without animation when CSS animations are
unavailable, so it never blocks the surrounding interface.

## CSS

### Variables

Bootstrap defines these variables on `.spinner-border` and `.spinner-grow`;
override them on `Spinner`.

| Variable                                 | Purpose                                                        |
| ---------------------------------------- | -------------------------------------------------------------- |
| `--bs-spinner-width`                     | Width; defaults to `1em`.                                      |
| `--bs-spinner-height`                    | Height; defaults to `1em`.                                     |
| `--bs-spinner-border-width`              | Border thickness of the border variant; defaults to `0.125em`. |
| `--bs-spinner-animation-speed`           | Animation duration; defaults to `1s`.                          |
| `--bs-spinner-animation-timing-function` | Border defaults to `linear`; grow defaults to `ease-in-out`.   |
| `--bs-spinner-animation-name`            | Keyframes name used by the animation.                          |

`size='sm'` sets `--bs-spinner-width` and `--bs-spinner-height` to `0.75em`.

### Keyframes

`spinner-border` rotates the border and rotate variants a full turn, and
`spinner-grow` scales and fades the grow variant. When the user prefers reduced
motion, Bootstrap slows the border and grow animations to `1.5s`.

## API

### Spinner

Renders a `span` by default and sets `role='status'` and `aria-label` from
`label`, unless those props are overridden.

| Prop       | Type                             | Description                                     |
| ---------- | -------------------------------- | ----------------------------------------------- |
| `variant`  | `'border' \| 'grow' \| 'rotate'` | Selects the appearance; defaults to `'border'`. |
| `size`     | `'sm'`                           | Uses the `0.75em` size.                         |
| `label`    | `string`                         | Accessible name; defaults to `'Loading'`.       |
| `children` | `ReactNode`                      | Content animated by the `rotate` variant.       |

Its own props are `variant`, `size`, and `label`; it inherits native props for
the selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`. Children render inside the spinner and are only meaningful with
the `rotate` variant. That variant adds no border or size, so `size` does not
affect it.

## Accessibility

- Keep the `status` role and a concise accessible label; `label` defaults to
  `Loading`.
- `status` is a live region. Prefer a stable label and expose changing progress
  elsewhere instead of updating the label rapidly.
- When visible text already announces the same loading state, hide the spinner
  with `aria-hidden` so it is not announced twice, as in the badge and button
  examples.
- Animation is not a sufficient status indicator. Pair the spinner with text or
  another accessible status.
- Bootstrap slows the border and grow animations when the user prefers reduced
  motion; the rotate variant keeps its fixed one-second rotation.
