# Datepicker 日期选择器

`Datepicker` 与 Bootstrap 日期选择器一样封装了
[Vanilla Calendar Pro](https://vanilla-calendar.pro/)，并复用 Bootstrap 的日期
选择器样式。它支持明暗两种颜色模式、输入框与按钮两种触发器、内联日历，以及单日、
多日与区间选择，并可按语言格式化日期。

输入框使用 `.form-control`；加上 `.w-12` 宽度工具类可让所选日期完整显示。日历在
聚焦时打开，选择完成后关闭，按 Escape、点击日历外部或将焦点移出时也会关闭。

## 暗色模式

日期选择器会继承最近的 `[data-bs-theme]` 祖先元素的颜色模式。将 `theme` 设为
`'light'` 或 `'dark'` 可让日历样式独立于周围环境；默认值 `'auto'` 跟随周围颜色模式。

<DemoContainer>
  <DatepickerDarkDemo />
</DemoContainer>

```tsx src='./demos/dark.tsx'

```

日历浮层会被添加到 `document.body`，因此解析后的颜色模式会复制到浮层上。组件在挂载
期间还会监听祖先元素的主题变化并同步。

## API

| 属性                 | 类型                                                     | 说明                                            |
| -------------------- | -------------------------------------------------------- | ----------------------------------------------- |
| `value`              | `string \| readonly string[]`                            | 受控选择值，格式为 `YYYY-MM-DD`。               |
| `defaultValue`       | `string \| readonly string[]`                            | 非受控用法的初始选择值。                        |
| `onChange`           | `(dates: string[]) => void`                              | 选择变化时以所选日期数组调用。                  |
| `selectionMode`      | `'single' \| 'multiple' \| 'multiple-ranged'`            | 最多可选日期数量。                              |
| `firstWeekday`       | `0`–`6`                                                  | 每周第一天，`0` 为周日。                        |
| `displayMonthsCount` | `1`–`12`                                                 | 同时渲染的月份数量。                            |
| `dateMin`            | `string \| Date \| number`                               | 可选的最早日期。                                |
| `dateMax`            | `string \| Date \| number`                               | 可选的最晚日期。                                |
| `locale`             | `string`                                                 | 用于月份、星期名称与输入框格式的语言标签。      |
| `format`             | `Intl.DateTimeFormatOptions \| (date, locale) => string` | 所选日期的文本格式。                            |
| `theme`              | `'light' \| 'dark' \| 'auto'`                            | 日历的颜色模式。                                |
| `placement`          | `'left' \| 'center' \| 'right' \| 'auto'`                | 浮层相对触发器的对齐方式。                      |
| `trigger`            | `'input' \| 'button'`                                    | 渲染输入框（默认）或按钮触发器。                |
| `icon`               | `ReactNode`                                              | 按钮触发器的前置图标。                          |
| `ghost`              | `boolean`                                                | 输入框使用 `.form-ghost` 而非 `.form-control`。 |
| `inline`             | `boolean`                                                | 直接渲染日历而不使用浮层。                      |
| `placeholder`        | `string`                                                 | 未选择任何日期时显示的文本。                    |
| `name`               | `string`                                                 | 表单字段名；内联模式下会渲染隐藏输入框。        |
| `disabled`           | `boolean`                                                | 禁用输入框或按钮。                              |
| `id`、`aria-*`       |                                                          | 传递给输入框或按钮。                            |

## 无障碍

输入框是普通文本输入框，请用 `htmlFor` 绑定的 `FormLabel` 或 `aria-label` 为其命名。
按钮触发器带有 `aria-haspopup='dialog'` 与 `aria-expanded`，日历本身是带可访问名称的
`role='dialog'` 区域。所选日期通过输入框的值朗读，日历支持方向键、Home、End、
Page Up、Page Down 与 Escape 操作。
