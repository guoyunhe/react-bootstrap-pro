# Datepicker 日期选择器

`Datepicker` 是基于 [Vanilla Calendar Pro](https://vanilla-calendar.pro/) 的 React
封装，并使用 Bootstrap 6 的日期选择器样式。它通过 React 属性而非 Bootstrap 的
`data-bs-*` 初始化 API 使用，支持单日、多日和区间选择、弹出与内联日历、本地化日期格式，
以及明暗主题。

## 概览

<DemoContainer>
  <DatepickerBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

弹出触发器是文本输入框。使用 `.w-12` 宽度工具类为格式化后的日期留出足够空间。输入框在
获得焦点时打开日历，并禁用浏览器自动补全。

## 工作原理

- `selectionMode` 控制用户可选择单个日期、多个日期或日期区间。
- `value` 和 `defaultValue` 使用 `YYYY-MM-DD` 字符串。`onChange` 也会以相同格式返回所选日期；
  触发器则显示本地化或自定义格式的日期文本。
- 选择单日或完成日期区间后，弹出日历会关闭。多日选择会保持打开，直到用户将其关闭。
- 点击外部、按 Escape 或将焦点移出日历后，弹出日历会关闭。按钮触发器通过激活操作打开或关闭日历。
- 日历默认跟随最近的 Bootstrap `[data-bs-theme]` 颜色模式。也可以通过 `theme` 覆盖。

日历会跟随系统颜色方案。

祖先元素的主题变化也会同步到弹出日历。

## Shadow DOM

弹出日历会添加到 `document.body`，位于组件的 shadow root 之外。在 shadow root 中使用
`Datepicker` 时，也要确保 Bootstrap 日期选择器样式在文档作用域中可用；仅应用于 shadow root
的样式不会影响弹出日历。

## CSS

Bootstrap 在 `[data-vc="calendar"]` 上定义了日历 CSS 变量。可在样式表中覆盖这些变量来自定义外观。

| 变量                              | 默认值                            | 说明                 |
| --------------------------------- | --------------------------------- | -------------------- |
| `--datepicker-padding`            | `1rem`                            | 日历内边距。         |
| `--datepicker-bg`                 | `var(--bg-body)`                  | 日历背景色。         |
| `--datepicker-color`              | `var(--fg-body)`                  | 日历文字和控件颜色。 |
| `--datepicker-border-color`       | `var(--border-color-translucent)` | 日历边框颜色。       |
| `--datepicker-border-width`       | `var(--border-width)`             | 日历边框宽度。       |
| `--datepicker-border-radius`      | `var(--radius-7)`                 | 日历圆角。           |
| `--datepicker-box-shadow`         | `var(--box-shadow)`               | 弹出日历阴影。       |
| `--datepicker-font-size`          | `var(--font-size-sm)`             | 日历字号。           |
| `--datepicker-min-width`          | `280px`                           | 日历最小宽度。       |
| `--datepicker-zindex`             | `var(--z-menu)`                   | 弹出层堆叠顺序。     |
| `--datepicker-header-font-weight` | `600`                             | 月份和年份标题字重。 |
| `--datepicker-weekday-color`      | `var(--fg-3)`                     | 星期标签颜色。       |
| `--datepicker-day-hover-bg`       | `var(--bg-1)`                     | 日期悬停背景色。     |
| `--datepicker-day-selected-bg`    | `var(--primary-bg)`               | 已选日期背景色。     |
| `--datepicker-day-selected-color` | `var(--primary-contrast)`         | 已选日期文字颜色。   |
| `--datepicker-day-today-bg`       | `var(--bg-2)`                     | 今天的背景色。       |
| `--datepicker-day-today-color`    | `var(--fg-1)`                     | 今天的文字颜色。     |
| `--datepicker-day-disabled-color` | `var(--fg-4)`                     | 禁用日期文字颜色。   |

弹出日历会添加到 `document.body`，因此应全局覆盖变量或直接选择 `[data-vc="calendar"]`；仅作用于本地包装元素的样式不会应用到弹出日历。

## API

### Datepicker

默认弹出触发器为 `<input type="text">`。设置 `trigger='button'` 会渲染
`<button type="button">`；设置 `inline` 则会在 `<div>` 中渲染日历。

`Datepicker` 不是泛型组件，不继承原生 input、button 或 [`Box`](../box/README.mdx#api)
属性。组件只接受下表列出的属性。

| 属性                 | 类型                                                                                            | 默认值           | 说明                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------- |
| `value`              | `string \| string[]`                                                                            | —                | 受控选择值，格式为 `YYYY-MM-DD`。                                    |
| `defaultValue`       | `string \| string[]`                                                                            | —                | 非受控用法的初始选择值。                                             |
| `onChange`           | `(dates: string[]) => void`                                                                     | —                | 选择变化时以 `YYYY-MM-DD` 日期数组调用。                             |
| `selectionMode`      | `'single' \| 'multiple' \| 'multiple-ranged'`                                                   | `'single'`       | 选择单日、多日或开始与结束日期组成的区间。                           |
| `firstWeekday`       | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6`                                                               | `1`              | 每周第一天；`0` 表示周日。                                           |
| `displayMonthsCount` | `1`–`12`                                                                                        | `1`              | 并排显示的月份数量。                                                 |
| `dateMin`            | `string \| Date \| number`                                                                      | —                | 最早可选日期；可用 `YYYY-MM-DD`、`'today'` 字符串、`Date` 或时间戳。 |
| `dateMax`            | `string \| Date \| number`                                                                      | —                | 最晚可选日期；可用 `YYYY-MM-DD`、`'today'` 字符串、`Date` 或时间戳。 |
| `locale`             | `string`                                                                                        | `'default'`      | 日历标签和默认触发器日期格式所用的语言标签。                         |
| `format`             | `Intl.DateTimeFormatOptions \| ((date: Date, locale: string \| undefined) => string)`           | —                | 自定义触发器中显示的文本格式。                                       |
| `theme`              | `'light' \| 'dark' \| 'auto'`                                                                   | `'auto'`         | 日历颜色模式；`auto` 跟随祖先元素或系统颜色方案。                    |
| `placement`          | `'auto' \| 'left' \| 'center' \| 'right' \| ['top' \| 'bottom', 'left' \| 'center' \| 'right']` | `'left'`         | 弹出日历相对触发器的位置。                                           |
| `trigger`            | `'input' \| 'button'`                                                                           | `'input'`        | 渲染文本输入框或按钮触发器；`inline` 为 `true` 时忽略。              |
| `inline`             | `boolean`                                                                                       | `false`          | 渲染始终可见的日历，而不是弹出日历。                                 |
| `icon`               | `ReactNode`                                                                                     | —                | 按钮触发器的前置图标。                                               |
| `ghost`              | `boolean`                                                                                       | `false`          | 输入框触发器使用 `.form-ghost` 而非 `.form-control`。                |
| `placeholder`        | `string`                                                                                        | `'Choose date…'` | 尚未选择日期时显示的文本。                                           |
| `id`                 | `string`                                                                                        | —                | 传递给输入框或按钮触发器的 ID。                                      |
| `name`               | `string`                                                                                        | —                | 传递给触发器的名称；内联模式下创建带逗号分隔 ISO 日期的隐藏输入框。  |
| `disabled`           | `boolean`                                                                                       | `false`          | 禁用输入框或按钮触发器。                                             |
| `className`          | `string`                                                                                        | —                | 添加到触发器；内联模式下添加到日历容器元素。                         |
| `aria-label`         | `string`                                                                                        | —                | 传递给输入框或按钮触发器的可访问名称。                               |
| `aria-labelledby`    | `string`                                                                                        | —                | 传递给输入框或按钮触发器的标签 ID 引用。                             |
| `aria-describedby`   | `string`                                                                                        | —                | 传递给输入框或按钮触发器的描述 ID 引用。                             |

选择和日历配置属性在内联模式下仍然生效，`className` 会添加到日历容器。`id`、`disabled`
和 `aria-*` 只会传递给弹出触发器，不会应用于内联日历。`trigger`、`icon`、`ghost` 和
`placeholder` 在内联模式下不生效；`format` 和 `placement` 也不会产生效果。`name` 会创建
内联隐藏输入框。弹出输入框提交的原生值是格式化后的显示文本，不一定是 ISO 日期值。

## 无障碍

使用可见的 `FormLabel`、`aria-label` 或 `aria-labelledby` 为弹出输入框和按钮提供可访问名称。
按钮触发器带有 `aria-haspopup='dialog'` 和 `aria-expanded`。底层日历提供键盘导航、屏幕阅读器
标签和焦点管理。

内联日历没有可供组件 `aria-*` 属性标记的触发器，应将其放在具有可访问名称的区域中。若
JavaScript 未运行，弹出触发器仍是普通文本输入框，但日历不可用。该输入框不是原生
`type="date"` 控件，也不提供浏览器原生日期验证。
