# Select

`Select` renders a native `<select>` with Bootstrap's `.form-select` styling.
Options, selection, keyboard interaction, and disabled behavior remain native
browser features.

## Sizes and disabled state

Use `size='sm'` or `size='lg'` to apply Bootstrap select sizing. The native
`disabled` attribute prevents interaction and excludes the select from form
submission.

## API

### Select

Renders a `select` by default and does not expose a polymorphic `component`
prop. Its own props are listed below; it inherits the remaining native select
props and all [`Box`](../box/README.mdx#api) utility props. Its `size` prop is
reserved for Bootstrap sizing; use the other native select attributes for
selection behavior.

| Prop         | Type                   | Description                                       |
| ------------ | ---------------------- | ------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap select size. |
| `validation` | `'valid' \| 'invalid'` | Applies the corresponding validation class.       |
| `...props`   | `BoxProps<'select'>`   | Native select props and all Box utility props.    |

## Accessibility

Give each select an accessible name with a visible `<label>` bound through
`htmlFor`, or with `aria-label` when a visible label is not possible. Keep an
empty first option when a placeholder-like choice is needed.
