# Select

`Select` renders a native `<select>` with Bootstrap 6's `.form-control` styling.
Styling is limited by the browser: options and their popovers cannot be styled
consistently. Selection and keyboard interaction remain native browser features.

## Native size

The native `size` attribute sets the number of visible options. `Select` reserves
its `size` prop for Bootstrap's `'sm'` and `'lg'` styles, so use a
[`Box`](../box/README.mdx#api) rendered as a `select` with `.form-control`
when a native numeric `size` is needed.

## API

### Select

Renders a `select` by default and does not expose a polymorphic `component`
prop. Its own props are listed below; it inherits the remaining native select
props and all [`Box`](../box/README.mdx#api) utility props. Its `size` prop is
reserved for Bootstrap sizing and cannot set the native number of visible
options. The native `disabled` attribute prevents interaction and excludes the
select from form submission.

| Prop         | Type                   | Description                                       |
| ------------ | ---------------------- | ------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap select size. |
| `validation` | `'valid' \| 'invalid'` | Applies the corresponding validation class.       |

## Accessibility

Give each select an accessible name with a visible `<label>` bound through
`htmlFor`, or with `aria-label` when a visible label is not possible. Keep an
empty first option when a placeholder-like choice is needed.
Multi-select keyboard interactions depend on the browser and operating system.
