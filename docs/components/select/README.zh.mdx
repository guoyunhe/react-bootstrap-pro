# Select 下拉选择框

`Select` 使用 Bootstrap 的 `.form-select` 样式渲染原生 `<select>`。选项、选择状态、
键盘交互和禁用行为仍由浏览器原生实现。

## 尺寸与禁用状态

使用 `size='sm'` 或 `size='lg'` 设置 Bootstrap 下拉框尺寸。原生 `disabled` 属性会
阻止交互，并使该下拉框不参与表单提交。

## API

### Select

默认渲染为 `select`，不提供多态 `component` 属性。下表列出自有属性；此外还继承其余
原生 select 属性及 [`Box`](../box/README.zh.mdx#api) 的全部工具类属性。`size` 属性
用于 Bootstrap 尺寸；选择行为可通过其他原生 select 属性设置。

| 属性         | 类型                   | 说明                                    |
| ------------ | ---------------------- | --------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | 应用小型或大型 Bootstrap 下拉框尺寸。   |
| `validation` | `'valid' \| 'invalid'` | 应用对应的校验状态类。                  |
| `...props`   | `BoxProps<'select'>`   | 原生 select 属性及全部 Box 工具类属性。 |

## 无障碍

使用通过 `htmlFor` 绑定的可见 `<label>` 为下拉框提供可访问名称；无法显示可见标签时，
可使用 `aria-label`。若需要类似占位文本的选项，请将值为空的选项放在首位。
