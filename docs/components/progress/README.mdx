# Progress

`Progress` renders Bootstrap's `.progress` track together with the inner
`.progress-bar`, and `ProgressStacked` renders a `.progress-stacked` group of
segments. The components do not use the native `<progress>` element, so bars can
be stacked, animated, and labeled. The track exposes the value through
`role='progressbar'` and the `aria-value*` attributes, while the inner bar shows
the percentage of `value` within `max`.

`max` to `100`. Children of `Progress` render inside the bar.

### Long labels

The bar clips overflowing content, so a label wider than the bar is cut off. Set
`overflow='visible'` on `barProps` to let the label extend outside the bar.

<DemoContainer>
  <ProgressLongLabelDemo />
</DemoContainer>

```tsx src='./demos/long-label.tsx'

```

The label then overlaps the track, and its text color must contrast with both
the bar and the track. When the label can overlap the bar, prefer displaying it
outside the progress bar.

accessible value, while `ProgressStacked` names the group with `label`.

## CSS

### Variables

Bootstrap defines these variables on `.progress` and `.progress-stacked`; the
bars inherit them. Override any of them on `Progress`.

| Variable                       | Purpose                    |
| ------------------------------ | -------------------------- |
| `--bs-progress-height`         | Track height.              |
| `--bs-progress-font-size`      | Label font size.           |
| `--bs-progress-bg`             | Unfilled track background. |
| `--bs-progress-border-radius`  | Track corner radius.       |
| `--bs-progress-box-shadow`     | Track shadow.              |
| `--bs-progress-bar-color`      | Bar text color.            |
| `--bs-progress-bar-bg`         | Bar background color.      |
| `--bs-progress-bar-transition` | Width transition.          |
| `--bs-progress-bar-animation`  | Stripe animation.          |

### Keyframes

`progress-bar-stripes` shifts the striped gradient; `animated` enables it on
`Progress`.

## API

### Progress

Renders a `div` track with `role='progressbar'` and an inner `div` bar. The
track receives `aria-valuemin`, `aria-valuemax`, and `aria-valuenow` from
`min`, `max`, and `value`, and `aria-label` from `label`.

| Prop       | Type               | Description                                            |
| ---------- | ------------------ | ------------------------------------------------------ |
| `label`    | `string`           | Accessible name, applied as `aria-label`.              |
| `value`    | `number`           | Current value; sets `aria-valuenow` and the bar width. |
| `min`      | `number`           | Minimum value; defaults to `0`.                        |
| `max`      | `number`           | Maximum value; defaults to `100`.                      |
| `striped`  | `boolean`          | Adds the striped background gradient.                  |
| `animated` | `boolean`          | Animates the stripes.                                  |
| `barProps` | `ProgressBarProps` | Native and Box utility props for the inner bar.        |
| `children` | `ReactNode`        | Bar label.                                             |

Its own props are `label` (required), `min`, `max`, `value`, `striped`,
`animated`, and `barProps`; it inherits native props for the selected element
and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`. `barProps`
accepts the same native and [`Box`](../box/README.mdx#api) props for the inner
bar, except `children`.

The bar width is the percentage of `value` within `max`. A width utility or
`style.width` passed through `barProps` takes precedence.

### ProgressStacked

Renders a `div` with the `.progress-stacked` class and `role='group'`. Nested
`Progress` elements render as segments: the percentage width moves to each
segment's track, and each bar fills its track.

| Prop    | Type     | Description                                            |
| ------- | -------- | ------------------------------------------------------ |
| `label` | `string` | Accessible name of the group, applied as `aria-label`. |

Its own prop is `label`; it inherits native props for the selected element and
all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`. `role` defaults
to `group` and can be overridden.

## Accessibility

- Every track needs an accessible name. `Progress` requires `label`, which
  becomes `aria-label`; use a meaningful description instead of repeating the
  value.
- `ProgressStacked` names its group with `label`; every nested segment still
  needs its own meaningful `label` for its `progressbar` role.
- Keep `value`, `min`, and `max` in sync so `aria-valuenow` announces the
  correct progress. Omitting `value` omits `aria-valuenow`, so assistive
  technology treats the progress as indeterminate.
- Do not rely on the bar color, stripe, or animation alone. Include the meaning
  in visible text or in text hidden for assistive technology.
- Bootstrap disables the width transition and the stripe animation when the user
  prefers reduced motion, so the value remains readable without animation.
