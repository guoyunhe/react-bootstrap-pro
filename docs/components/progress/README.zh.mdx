# Progress 进度条

`Progress` 同时渲染 Bootstrap 的 `.progress` 轨道与内部的 `.progress-bar`，
`ProgressStacked` 则渲染由多个分段组成的 `.progress-stacked` 分组。组件不使用
原生 `<progress>` 元素，因此进度条可以堆叠、播放动画并显示标签。轨道通过
`role='progressbar'` 和 `aria-value*` 属性提供数值，内部进度条则显示 `value`
在 `max` 中所占的百分比。

### 长标签

进度条会裁剪溢出内容，因此比进度条更宽的标签会被截断。在 `barProps` 上设置
`overflow='visible'`，可以允许标签延伸到进度条之外。

```tsx src='./demos/long-label.tsx'

```

此时标签会与轨道重叠，文字颜色必须同时与进度条和轨道的背景保持足够对比度。
当标签可能覆盖进度条时，建议将标签显示在进度条外部。

`ProgressStacked` 则通过 `label` 为分组命名。

## CSS

### 自定义属性

Bootstrap 在 `.progress` 和 `.progress-stacked` 上定义以下变量，内部进度条会继承它们。
可以在 `Progress` 上覆盖任意变量。

| 属性                           | 用途                   |
| ------------------------------ | ---------------------- |
| `--bs-progress-height`         | 轨道高度。             |
| `--bs-progress-font-size`      | 标签字号。             |
| `--bs-progress-bg`             | 未填充部分的轨道背景。 |
| `--bs-progress-border-radius`  | 轨道圆角。             |
| `--bs-progress-box-shadow`     | 轨道阴影。             |
| `--bs-progress-bar-color`      | 进度条文字颜色。       |
| `--bs-progress-bar-bg`         | 进度条背景颜色。       |
| `--bs-progress-bar-transition` | 宽度过渡。             |
| `--bs-progress-bar-animation`  | 条纹动画。             |

### 关键帧

`progress-bar-stripes` 用于移动条纹渐变，由 `Progress` 的 `animated` 属性启用。

## API

### Progress

默认渲染一个带 `role='progressbar'` 的 `div` 轨道，以及内部的 `div` 进度条。
轨道根据 `min`、`max`、`value` 设置 `aria-valuemin`、`aria-valuemax` 和
`aria-valuenow`，并根据 `label` 设置 `aria-label`。

| 组件属性   | 类型               | 说明                                        |
| ---------- | ------------------ | ------------------------------------------- |
| `label`    | `string`           | 无障碍名称，写入 `aria-label`。             |
| `value`    | `number`           | 当前值，决定 `aria-valuenow` 和进度条宽度。 |
| `min`      | `number`           | 最小值，默认值为 `0`。                      |
| `max`      | `number`           | 最大值，默认值为 `100`。                    |
| `striped`  | `boolean`          | 添加背景条纹渐变。                          |
| `animated` | `boolean`          | 播放条纹动画。                              |
| `barProps` | `ProgressBarProps` | 内部进度条的原生属性及 Box 工具类属性。     |
| `children` | `ReactNode`        | 进度条标签。                                |

自有属性为必需的 `label` 以及 `min`、`max`、`value`、`striped`、`animated` 和
`barProps`；继承所选元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。`barProps` 接受相同的原生属性与
[`Box`](../box/README.zh.mdx#api) 属性（`children` 除外），作用于内部进度条。

进度条宽度为 `value` 在 `max` 中所占的百分比。通过 `barProps` 传入的宽度工具类或
`style.width` 优先。

### ProgressStacked

默认渲染一个带 `.progress-stacked` 类与 `role='group'` 的 `div`。嵌套的
`Progress` 会渲染为分段：百分比宽度移动到各分段的轨道上，进度条则填满该轨道。

| 组件属性 | 类型     | 说明                                |
| -------- | -------- | ----------------------------------- |
| `label`  | `string` | 分组无障碍名称，写入 `aria-label`。 |

自有属性为 `label`；继承所选元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。`role` 默认为 `group`，可以覆盖。

## 无障碍访问

- 每个轨道都需要可访问名称。`Progress` 要求提供 `label`，它会写入 `aria-label`；
  请使用有意义的描述，而不是重复当前数值。
- `ProgressStacked` 通过 `label` 为分组命名；每个嵌套分段仍需要自己的 `label`，
  用于其 `progressbar` 角色。
- 保持 `value`、`min` 和 `max` 一致，使 `aria-valuenow` 朗读出正确的进度。省略
  `value` 会同时省略 `aria-valuenow`，辅助技术会将进度视为不确定状态。
- 不要仅依靠进度条颜色、条纹或动画传达含义，应通过可见文本或仅供辅助技术读取的
  文本表达含义。
- 当用户偏好减少动态效果时，Bootstrap 会停用宽度过渡和条纹动画，数值本身仍可读取。
