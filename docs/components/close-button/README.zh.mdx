# Close button 关闭按钮

`CloseButton` 使用 CSS 遮罩图标渲染原生按钮。默认无障碍名称为“Close”，可通过
`label` 或 `aria-label` 自定义。

<DemoContainer>
  <CloseButton />
</DemoContainer>

```tsx src='./demos/basic.tsx'
<CloseButton label='关闭通知' onClick={dismiss} />
```

## API

### CloseButton

默认渲染为 `button`，原生 `type` 默认值为 `button`。自有属性为 `label`；
未提供 `aria-label` 时，它用于提供可访问名称。组件继承所选元素的原生属性及
全部 [`Box`](../box/README.zh.mdx#api) 属性，包括 `component`、`className`
和 `classNameBefore`。

| 属性        | 类型          | 说明                            |
| ----------- | ------------- | ------------------------------- |
| `label`     | `string`      | 无障碍名称，默认为 `'Close'`。  |
| `component` | `ElementType` | 更换元素，默认为 `button`。     |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |
