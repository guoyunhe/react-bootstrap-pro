# CloseButton

Use `CloseButton` to dismiss or close a component. Bootstrap renders the icon
with a CSS mask, so it inherits the button's color without an inline SVG. The
component provides the accessible name “Close” by default.

## Example

The close icon is rendered by the `.btn-close` class. Always give the button an
accessible name; `CloseButton` defaults its `aria-label` to `Close`.

## CSS

### Variables

Override these Bootstrap CSS custom properties on the button or an ancestor.

| Variable                          | Purpose                   |
| --------------------------------- | ------------------------- |
| `--bs-btn-close-size`             | Minimum width and height. |
| `--bs-btn-close-color`            | Icon color.               |
| `--bs-btn-close-icon`             | CSS mask image.           |
| `--bs-btn-close-opacity`          | Default opacity.          |
| `--bs-btn-close-hover-opacity`    | Opacity on hover.         |
| `--bs-btn-close-focus-opacity`    | Opacity when focused.     |
| `--bs-btn-close-disabled-opacity` | Opacity when disabled.    |

## API

### CloseButton

Renders a `button` with the `.btn-close` class by default and defaults its native
`type` to `button`. Its own prop is `label`, which supplies the accessible name
when `aria-label` is not provided.

`CloseButton` inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component` and styling
utilities. Replacing the root with `component` may remove native button
semantics.

| Prop    | Type     | Default   | Description                                        |
| ------- | -------- | --------- | -------------------------------------------------- |
| `label` | `string` | `'Close'` | Accessible name when `aria-label` is not provided. |

## Accessibility

Provide an accessible name that describes the action in context. Set `label` or
`aria-label` when “Close” is not specific enough. The default `type='button'`
prevents accidental form submission; use the native `disabled` prop when the
action is unavailable.
