# Chips

## Overview

Chips represent values or entities in forms and other interactive contexts.
Unlike badges, chips have a fixed size and support icons, avatars, themes, active
states, and dismiss actions. `Chip` renders one chip; `ChipInput` manages a
keyboard-navigable collection of chips in React.

## Chips

Use `icon` for a leading icon, `image` for an avatar, and `onDismiss` to add a

separator adds a value; pasted text containing the separator is split into

## Usage

This is a React component, so Bootstrap's `data-bs-chips` attribute and
imperative `bootstrap.Chips` plugin API are not used. Pass `defaultValue` for
uncontrolled usage, or pass `value` and `onChange` to control the chip list.

<DemoContainer>
  <ChipInputControlledDemo />
</DemoContainer>

```tsx src='./demos/chip-input-controlled.tsx'

```

`onChange` runs when values are added or removed, not when the selection
changes. The `name` prop belongs to the ghost text input; `ChipInput` does not
serialize its chip values as a form field. Use `onChange` to sync form state or
add hidden inputs when submitting the values.

## API

### Chip

`Chip` renders a `span` with the `.chip` class by default. `active` changes its
appearance but does not add selection behavior by itself. `onDismiss` renders a
button inside the chip.

| Prop           | Type                            | Default    | Description                                                       |
| -------------- | ------------------------------- | ---------- | ----------------------------------------------------------------- |
| `active`       | `boolean`                       | `false`    | Uses the solid selected appearance.                               |
| `disabled`     | `boolean`                       | `false`    | Applies disabled styling and disables dismissal.                  |
| `icon`         | `ReactNode`                     | —          | Renders a leading `.chip-icon`.                                   |
| `image`        | `{ src: string; alt?: string }` | —          | Renders a leading `.chip-img`; `alt` defaults to an empty string. |
| `onDismiss`    | `() => void`                    | —          | Renders a dismiss button and calls this handler.                  |
| `dismissLabel` | `string`                        | `'Remove'` | Accessible name for the dismiss button.                           |

`Chip` inherits native props for its selected element and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`.

### ChipInput

`ChipInput` renders a `div` with the `.chip-input` class by default. It contains
the chip collection and a text input used to enter new values.

| Prop                                                | Type                                                   | Default   | Description                                                                                       |
| --------------------------------------------------- | ------------------------------------------------------ | --------- | ------------------------------------------------------------------------------------------------- |
| `value`                                             | `readonly string[]`                                    | —         | Controlled chip values.                                                                           |
| `defaultValue`                                      | `readonly string[]`                                    | `[]`      | Initial values for uncontrolled usage.                                                            |
| `onChange`                                          | `(values: string[]) => void`                           | —         | Called when values are added or removed.                                                          |
| `separator`                                         | `string \| null`                                       | `','`     | Character that creates a chip; `null` disables separator splitting. Enter still adds a chip.      |
| `allowDuplicates`                                   | `boolean`                                              | `false`   | Allows duplicate values.                                                                          |
| `maxChips`                                          | `number`                                               | Unlimited | Maximum number of chips.                                                                          |
| `createOnBlur`                                      | `boolean`                                              | `true`    | Creates a chip from the draft when focus leaves the field.                                        |
| `dismissible`                                       | `boolean`                                              | `true`    | Renders dismiss buttons on generated chips.                                                       |
| `disabled`                                          | `boolean`                                              | `false`   | Disables the ghost input, chips, and dismiss buttons.                                             |
| `validation`                                        | `'valid' \| 'invalid'`                                 | —         | Applies validation styling to the ghost input.                                                    |
| `label`                                             | `ReactNode`                                            | —         | Renders a `.chip-input-label` inside the container; requires `id` to associate it with the input. |
| `chipProps`                                         | `(value: string, index: number) => ChipInputChipProps` | —         | Configures each generated chip, such as its theme.                                                |
| `id`, `name`, `placeholder`                         | `string`                                               | —         | Forwarded to the ghost input.                                                                     |
| `aria-label`, `aria-labelledby`, `aria-describedby` | `string`                                               | —         | Forwarded to the ghost input.                                                                     |

`ChipInput` inherits native props for its root and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`. Other
Box props apply to the container.

## Keyboard behavior

### When the input is focused

| Key                    | Action                                                      |
| ---------------------- | ----------------------------------------------------------- |
| `Enter` or separator   | Adds the current draft.                                     |
| Paste with separator   | Splits the pasted text and adds valid values.               |
| `Backspace` / `Delete` | When the draft is empty, selects and focuses the last chip. |
| `ArrowLeft`            | At the start of the input, focuses the last chip.           |
| `Shift` + `ArrowLeft`  | Selects or toggles the last chip.                           |
| `Escape`               | Clears the draft and selection, then blurs the input.       |

### When a chip is focused

| Key                        | Action                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `Backspace` / `Delete`     | Removes the selected chips and focuses the input.                                         |
| `ArrowLeft` / `ArrowRight` | Moves to the previous or next chip; moving right past the last chip returns to the input. |
| `Shift` + arrow            | Extends the chip selection.                                                               |
| `Home`                     | Focuses the first chip.                                                                   |
| `End`                      | Clears the selection and focuses the input.                                               |
| `Ctrl` / `Cmd` + `A`       | Selects all chips.                                                                        |
| `Escape`                   | Clears the selection and focuses the input.                                               |

Click a chip to select it, `Ctrl`/`Cmd`-click to toggle it, or `Shift`-click to
select a range. Selected chips receive the `.active` class.

## Accessibility

Name the text input with a visible `<label>` associated through `htmlFor`, the
`label` prop, or `aria-label` / `aria-labelledby`. Each dismiss button has an
accessible name, configurable through `dismissLabel` on `Chip` or `chipProps`
on `ChipInput`. Chips inside `ChipInput` are focusable and support the keyboard
navigation described above. Standalone `Chip` renders a `span` by default and
does not provide selection semantics.

## CSS

### Chip variables

Override these Bootstrap CSS custom properties on `.chip` or an ancestor.

| Variable                          | Purpose                             |
| --------------------------------- | ----------------------------------- |
| `--bs-chip-height`                | Chip height.                        |
| `--bs-chip-padding-x`             | Horizontal padding.                 |
| `--bs-chip-gap`                   | Space between chip contents.        |
| `--bs-chip-border-radius`         | Chip corner radius.                 |
| `--bs-chip-img-size`              | Avatar size.                        |
| `--bs-chip-icon-size`             | Leading icon size.                  |
| `--bs-chip-dismiss-size`          | Dismiss button size.                |
| `--bs-chip-dismiss-opacity`       | Default dismiss button opacity.     |
| `--bs-chip-dismiss-hover-opacity` | Dismiss button opacity on hover.    |
| `--bs-chip-color`, `--bs-chip-bg` | Default text and background colors. |
| `--bs-chip-border-color`          | Default border color.               |
| `--bs-chip-selected-color`        | Active text color.                  |
| `--bs-chip-selected-bg`           | Active background color.            |
| `--bs-chip-selected-border-color` | Active border color.                |

### Chip input variables

These properties are scoped to `.chip-input`. Shared `--bs-control-*` variables
also control its text, background, border, and corner radius.

| Variable                          | Purpose                                |
| --------------------------------- | -------------------------------------- |
| `--bs-chip-input-padding-y`       | Vertical container padding.            |
| `--bs-chip-input-padding-x`       | Horizontal container padding.          |
| `--bs-chip-input-gap`             | Gap between chips and the ghost input. |
| `--bs-chip-input-ghost-min-width` | Minimum width of the text input.       |
| `--bs-control-fg`                 | Text color.                            |
| `--bs-control-bg`                 | Container background color.            |
| `--bs-control-border-width`       | Container border width.                |
| `--bs-control-border-color`       | Container border color.                |
| `--bs-control-border-radius`      | Container corner radius.               |
