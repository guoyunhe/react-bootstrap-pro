# Chips 标签

## 概览

Chips 用于在表单或其他交互场景中表示值或实体。与徽章不同，Chip 尺寸固定，可包含
图标、头像、主题色和删除操作。`Chip` 渲染单个标签；`ChipInput` 则在 React 中管理
支持键盘导航的标签集合。

## Chips

使用 `icon` 添加前置图标，`image` 添加头像，使用 `onDismiss` 添加删除按钮。
删除按钮的可访问名称默认为 `Remove`。

## 使用方式

这是 React 组件，不使用 Bootstrap 的 `data-bs-chips` 属性或命令式
`bootstrap.Chips` 插件 API。非受控用法传入 `defaultValue`；受控用法传入 `value` 和
`onChange`。

<DemoContainer>
  <ChipInputControlledDemo />
</DemoContainer>

```tsx src='./demos/chip-input-controlled.tsx'

```

添加或删除值时会调用 `onChange`，选择状态变化时不会调用。`name` 属性作用于 ghost
文本输入框；`ChipInput` 不会自动将标签值序列化为表单字段。提交标签值时，请通过
`onChange` 同步表单状态，或添加隐藏输入框。

## API

### Chip

`Chip` 默认渲染带有 `.chip` 类的 `span`。`active` 只改变外观，不会单独添加选择交互；
`onDismiss` 会在标签中渲染按钮。

| 属性           | 类型                            | 默认值     | 说明                                           |
| -------------- | ------------------------------- | ---------- | ---------------------------------------------- |
| `active`       | `boolean`                       | `false`    | 使用实心的选中样式。                           |
| `disabled`     | `boolean`                       | `false`    | 应用禁用样式并禁用删除操作。                   |
| `icon`         | `ReactNode`                     | —          | 在前方渲染 `.chip-icon`。                      |
| `image`        | `{ src: string; alt?: string }` | —          | 在前方渲染 `.chip-img`；`alt` 默认为空字符串。 |
| `onDismiss`    | `() => void`                    | —          | 渲染删除按钮并在点击时调用。                   |
| `dismissLabel` | `string`                        | `'Remove'` | 删除按钮的可访问名称。                         |

`Chip` 还继承所选根元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。

### ChipInput

`ChipInput` 默认渲染带有 `.chip-input` 类的 `div`，其中包含标签集合和用于输入新值的文本框。

| 属性                                                | 类型                                                   | 默认值  | 说明                                                           |
| --------------------------------------------------- | ------------------------------------------------------ | ------- | -------------------------------------------------------------- |
| `value`                                             | `readonly string[]`                                    | —       | 受控标签值。                                                   |
| `defaultValue`                                      | `readonly string[]`                                    | `[]`    | 非受控初始值。                                                 |
| `onChange`                                          | `(values: string[]) => void`                           | —       | 添加或删除值时调用。                                           |
| `separator`                                         | `string \| null`                                       | `','`   | 触发创建标签的字符；`null` 禁用分隔符拆分，但 Enter 仍可添加。 |
| `allowDuplicates`                                   | `boolean`                                              | `false` | 是否允许重复值。                                               |
| `maxChips`                                          | `number`                                               | 不限    | 标签数量上限。                                                 |
| `createOnBlur`                                      | `boolean`                                              | `true`  | 失焦时将草稿值创建为标签。                                     |
| `dismissible`                                       | `boolean`                                              | `true`  | 是否为生成的标签显示删除按钮。                                 |
| `disabled`                                          | `boolean`                                              | `false` | 禁用 ghost 输入框、标签和删除按钮。                            |
| `validation`                                        | `'valid' \| 'invalid'`                                 | —       | 为 ghost 输入框应用校验样式。                                  |
| `label`                                             | `ReactNode`                                            | —       | 在容器中渲染 `.chip-input-label`；需提供 `id` 关联输入框。     |
| `chipProps`                                         | `(value: string, index: number) => ChipInputChipProps` | —       | 配置每个生成的标签，例如设置主题色。                           |
| `id`、`name`、`placeholder`                         | `string`                                               | —       | 透传给 ghost 输入框。                                          |
| `aria-label`、`aria-labelledby`、`aria-describedby` | `string`                                               | —       | 透传给 ghost 输入框。                                          |

`ChipInput` 继承根元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。其他 Box 属性作用于容器。

## 键盘行为

### 输入框获得焦点时

| 按键                   | 行为                                 |
| ---------------------- | ------------------------------------ |
| `Enter` 或分隔符       | 添加当前草稿值。                     |
| 粘贴包含分隔符的文本   | 拆分文本并添加有效值。               |
| `Backspace` / `Delete` | 草稿为空时，选中并聚焦最后一个标签。 |
| `ArrowLeft`            | 光标位于开头时，聚焦最后一个标签。   |
| `Shift` + `ArrowLeft`  | 选择或切换最后一个标签。             |
| `Escape`               | 清空草稿和选择，然后使输入框失焦。   |

### 标签获得焦点时

| 按键                       | 行为                                                         |
| -------------------------- | ------------------------------------------------------------ |
| `Backspace` / `Delete`     | 删除选中的标签并聚焦输入框。                                 |
| `ArrowLeft` / `ArrowRight` | 移至上一个或下一个标签；从最后一个标签继续向右会返回输入框。 |
| `Shift` + 方向键           | 扩展标签选择范围。                                           |
| `Home`                     | 聚焦第一个标签。                                             |
| `End`                      | 清除选择并聚焦输入框。                                       |
| `Ctrl` / `Cmd` + `A`       | 选中所有标签。                                               |
| `Escape`                   | 清除选择并聚焦输入框。                                       |

点击标签可选中；`Ctrl` / `Cmd` + 点击可切换选择；`Shift` + 点击可选择范围。
选中的标签会获得 `.active` 类。

## 无障碍

使用可见 `<label>`（通过 `htmlFor` 关联）、`label` 属性，或
`aria-label` / `aria-labelledby` 为输入框命名。删除按钮均有可访问名称：`Chip` 可通过
`dismissLabel` 设置，`ChipInput` 可通过 `chipProps` 设置。`ChipInput` 中的标签可聚焦并
支持上述键盘导航。独立的 `Chip` 默认渲染为 `span`，本身不提供选择语义。

## CSS

### Chip 变量

可在 `.chip` 或其祖先元素上覆盖以下 Bootstrap CSS 自定义属性。

| 属性                              | 用途                       |
| --------------------------------- | -------------------------- |
| `--bs-chip-height`                | 标签高度。                 |
| `--bs-chip-padding-x`             | 水平内边距。               |
| `--bs-chip-gap`                   | 标签内容之间的间距。       |
| `--bs-chip-border-radius`         | 标签圆角。                 |
| `--bs-chip-img-size`              | 头像尺寸。                 |
| `--bs-chip-icon-size`             | 前置图标尺寸。             |
| `--bs-chip-dismiss-size`          | 删除按钮尺寸。             |
| `--bs-chip-dismiss-opacity`       | 删除按钮默认不透明度。     |
| `--bs-chip-dismiss-hover-opacity` | 删除按钮悬停时的不透明度。 |
| `--bs-chip-color`、`--bs-chip-bg` | 默认文字和背景颜色。       |
| `--bs-chip-border-color`          | 默认边框颜色。             |
| `--bs-chip-selected-color`        | 激活状态的文字颜色。       |
| `--bs-chip-selected-bg`           | 激活状态的背景颜色。       |
| `--bs-chip-selected-border-color` | 激活状态的边框颜色。       |

### Chip input 变量

以下属性作用于 `.chip-input`。共享的 `--bs-control-*` 属性也会影响输入文字、背景、
边框和圆角。

| 属性                              | 用途                            |
| --------------------------------- | ------------------------------- |
| `--bs-chip-input-padding-y`       | 容器垂直内边距。                |
| `--bs-chip-input-padding-x`       | 容器水平内边距。                |
| `--bs-chip-input-gap`             | 标签与 ghost 输入框之间的间距。 |
| `--bs-chip-input-ghost-min-width` | 文本输入框最小宽度。            |
| `--bs-control-fg`                 | 文字颜色。                      |
| `--bs-control-bg`                 | 容器背景颜色。                  |
| `--bs-control-border-width`       | 容器边框宽度。                  |
| `--bs-control-border-color`       | 容器边框颜色。                  |
| `--bs-control-border-radius`      | 容器圆角。                      |
