# Toasts 轻提示

`Toast` 组合通知表面和无障碍实时区域。可使用 Bootstrap JavaScript 插件，也可在
React 中控制 `show` 属性。

<DemoContainer>
  <ToastContainer>
    <Toast show>
      <ToastHeader>
        <strong>已保存</strong>
        <CloseButton />
      </ToastHeader>
      <ToastBody>更改已生效。</ToastBody>
    </Toast>
  </ToastContainer>
</DemoContainer>

## API

### Toast

默认渲染为 `div`。自有属性为 `instant?: boolean`、`show?: boolean` 和
`translucent?: boolean`；继承所选元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

| 属性          | 类型          | 说明                            |
| ------------- | ------------- | ------------------------------- |
| `show`        | `boolean`     | 添加 `.show` 以显示轻提示。     |
| `instant`     | `boolean`     | 禁用淡入淡出动画。              |
| `translucent` | `boolean`     | 添加半透明背景效果。            |
| `component`   | `ElementType` | 更换渲染元素。                  |
| `...props`    | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |

`ToastHeader`、`ToastBody` 和 `ToastContainer` 提供对应布局类名。关闭和自动隐藏需要
JavaScript。

### ToastContainer

默认渲染为 `div`，没有自有属性；默认设置 `role="region"` 和 `aria-live="polite"`。
继承原生属性及通过 `BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

### ToastHeader

默认渲染为 `div`，没有自有属性。继承原生 `div` 属性及通过 `BoxProps<C>` 继承的
全部 [`Box`](../box/README.zh.mdx#api) 属性。

### ToastBody

默认渲染为 `div`，没有自有属性。继承原生 `div` 属性及通过 `BoxProps<C>` 继承的
全部 [`Box`](../box/README.zh.mdx#api) 属性。
