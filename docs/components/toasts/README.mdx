# Toasts

`Toast` composes a notification surface and accessible live region. Use the
Bootstrap JavaScript plugin or control the `show` prop from React.

## Example

<DemoContainer>
  <ToastContainer>
    <Toast show role='alert' aria-live='assertive' aria-atomic='true'>
      <ToastHeader>
        <strong>Saved</strong>
        <CloseButton data-bs-dismiss='toast' />
      </ToastHeader>
      <ToastBody>Your changes are ready.</ToastBody>
    </Toast>
  </ToastContainer>
</DemoContainer>

```tsx
<ToastContainer>
  <Toast show role='status' aria-live='polite' aria-atomic='true'>
    <ToastHeader>
      <strong>Saved</strong>
      <CloseButton data-bs-dismiss='toast' />
    </ToastHeader>
    <ToastBody>Your changes are ready.</ToastBody>
  </Toast>
</ToastContainer>
```

## Translucent

Set `translucent` to apply the translucent surface treatment.

```tsx
<Toast show translucent>
  <ToastBody>Background work is complete.</ToastBody>
</Toast>
```

## API

| Prop          | Type          | Description                              |
| ------------- | ------------- | ---------------------------------------- |
| `show`        | `boolean`     | Adds `.show` to display the toast.       |
| `instant`     | `boolean`     | Disables the fade transition.            |
| `translucent` | `boolean`     | Adds a translucent background treatment. |
| `component`   | `ElementType` | Changes the rendered element.            |
| `...props`    | `BoxProps<C>` | Native props and all Box utility props.  |

`ToastHeader`, `ToastBody`, and `ToastContainer` provide the corresponding
layout classes. Dismissal and autohide require JavaScript.

## Accessibility

Choose a live-region role and politeness level appropriate to the message, and
provide a close control when users need to dismiss the toast. Do not rely on
autohide for important information.
