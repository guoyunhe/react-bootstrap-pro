# OTP input

`OtpInput` renders a one-time-password field as separate digit slots on top of a
single real text input. Screen readers, password managers, and SMS autofill see
one ordinary text field, while users get the familiar multi-box appearance. All
behavior—sanitizing, overwriting, grouping, masking, and caret handling—is
implemented in React, so no Bootstrap JavaScript plugin is required.

## Behavior

- **Paste support**: pasting a formatted code such as `123-456` strips the extra
  characters before applying the length limit.
- **Click to edit**: clicking a slot moves the caret there, never past the first
  empty slot.
- **Overwrite in place**: typing on a filled slot replaces that character
  instead of shifting the following ones.
- **Autofill**: multi-character `input` events from SMS or password managers are
  sanitized and the caret moves to the first empty slot.
- **Keyboard**: arrows, Home, End, Backspace, Delete, and selection work as they
  do in a regular text field.

## API

### OtpInput

Renders a `div` by default. Its own props configure code length and accepted
characters (`length`, `type`), display (`mask`, `groups`, `separator`,
`connected`, `size`, `validation`), value and callbacks (`value`,
`defaultValue`, `onChange`, `onComplete`), and input state and labeling (`id`,
`name`, `autoComplete`, `disabled`, `readOnly`, `required`, `autoFocus`,
`aria-label`, `aria-labelledby`, `aria-describedby`). It inherits native `div`
props and [`Box`](../box/README.mdx#api) utility props, except `children`,
`component`, and `onChange`.

| Prop                                            | Type                                     | Description                                               |
| ----------------------------------------------- | ---------------------------------------- | --------------------------------------------------------- |
| `length`                                        | `number`                                 | Number of slots and maximum length. Defaults to `6`.      |
| `type`                                          | `'numeric' \| 'alphanumeric' \| 'alpha'` | Accepted characters, also sets `inputmode` and `pattern`. |
| `mask`                                          | `boolean`                                | Shows a dot in each filled slot.                          |
| `groups`                                        | `readonly number[]`                      | Group sizes used to insert separators, e.g. `[3, 3]`.     |
| `separator`                                     | `string`                                 | Separator character between groups. Defaults to `·`.      |
| `connected`                                     | `boolean`                                | Merges the slots into a single field with shared borders. |
| `size`                                          | `'sm' \| 'lg'`                           | Changes the slot size.                                    |
| `validation`                                    | `'valid' \| 'invalid'`                   | Applies `.is-valid` or `.is-invalid` to the slots.        |
| `value`                                         | `string`                                 | Controlled code.                                          |
| `defaultValue`                                  | `string`                                 | Initial code for uncontrolled usage.                      |
| `onChange`                                      | `(value: string) => void`                | Called with the sanitized code on every change.           |
| `onComplete`                                    | `(value: string) => void`                | Called when every slot is filled.                         |
| `name`                                          | `string`                                 | Form field name submitted with the code.                  |
| `autoComplete`                                  | `string`                                 | Defaults to `one-time-code`.                              |
| `disabled`, `readOnly`, `required`, `autoFocus` |                                          | Forwarded to the input.                                   |
| `id`, `aria-*`                                  |                                          | Forwarded to the input.                                   |
| `...props`                                      | `BoxProps<'div'>`                        | Box utility props for the container.                      |

## Accessibility

The control is a single text input, so assistive technology announces one
accessible name, role, and value; the visual slots are decorative and marked
`aria-hidden`. The input sets `autocomplete='one-time-code'`, an appropriate
`inputmode`, and a `pattern`, which supports SMS autofill and the right mobile
keyboard. Copy, paste, and autofill are never blocked, so password managers can
fill the code directly.
