# OTP input 一次性密码输入

`OtpInput` 用一个真实的文本输入框承载验证码，并在其上绘制独立的数字格。屏幕阅读器、
密码管理器与短信自动填充都把它当作一个普通文本框，而用户看到的是熟悉的多格样式。
字符过滤、覆盖输入、分组、掩码与光标处理全部由 React 实现，无需加载 Bootstrap
JavaScript 插件。

## 行为说明

- **支持粘贴**：粘贴 `123-456` 这类带格式的验证码时，会先去除多余字符再应用长度限制。
- **点击编辑**：点击某个格子会把光标移到该格，但不会越过第一个空格子。
- **原地覆盖**：在已填写的格子上输入会替换该字符，而不会把后续字符向后推。
- **自动填充**：短信或密码管理器触发的多字符 `input` 事件会被过滤，光标移动到第一个
  空格子。
- **键盘**：方向键、Home、End、Backspace、Delete 与选区行为与普通文本框一致。

## API

### OtpInput

默认渲染为 `div`。自有属性用于配置验证码长度和允许字符（`length`、`type`）、
显示方式（`mask`、`groups`、`separator`、`connected`、`size`、`validation`）、
值与回调（`value`、`defaultValue`、`onChange`、`onComplete`），以及原生输入状态
和标签（`id`、`name`、`autoComplete`、`disabled`、`readOnly`、`required`、
`autoFocus`、`aria-label`、`aria-labelledby`、`aria-describedby`）。组件继承
原生 `div` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，但不包括
`children`、`component` 和 `onChange`。

| 属性                                            | 类型                                     | 说明                                            |
| ----------------------------------------------- | ---------------------------------------- | ----------------------------------------------- |
| `length`                                        | `number`                                 | 格子数量与最大长度，默认 `6`。                  |
| `type`                                          | `'numeric' \| 'alphanumeric' \| 'alpha'` | 允许的字符，同时设置 `inputmode` 与 `pattern`。 |
| `mask`                                          | `boolean`                                | 在填入的格子中显示圆点。                        |
| `groups`                                        | `readonly number[]`                      | 分组大小，用于插入分隔符，如 `[3, 3]`。         |
| `separator`                                     | `string`                                 | 分组之间的分隔字符，默认 `·`。                  |
| `connected`                                     | `boolean`                                | 合并格子为共享边框的整体。                      |
| `size`                                          | `'sm' \| 'lg'`                           | 改变格子大小。                                  |
| `validation`                                    | `'valid' \| 'invalid'`                   | 为格子添加 `.is-valid` 或 `.is-invalid`。       |
| `value`                                         | `string`                                 | 受控验证码。                                    |
| `defaultValue`                                  | `string`                                 | 非受控用法的初始验证码。                        |
| `onChange`                                      | `(value: string) => void`                | 每次变化时以过滤后的验证码调用。                |
| `onComplete`                                    | `(value: string) => void`                | 全部格子填满时调用。                            |
| `name`                                          | `string`                                 | 随表单提交的字段名。                            |
| `autoComplete`                                  | `string`                                 | 默认为 `one-time-code`。                        |
| `disabled`、`readOnly`、`required`、`autoFocus` |                                          | 传递给输入框。                                  |
| `id`、`aria-*`                                  |                                          | 传递给输入框。                                  |
| `...props`                                      | `BoxProps<'div'>`                        | 容器的 Box 工具属性。                           |

## 无障碍

该控件是单个文本输入框，因此辅助技术只会朗读一个可访问名称、角色与值；可见的格子是
装饰性的并标记为 `aria-hidden`。输入框会设置 `autocomplete='one-time-code'`、合适的
`inputmode` 与 `pattern`，从而支持短信自动填充与正确的移动端键盘。复制、粘贴与自动
填充从不会被阻止，密码管理器可以直接填入验证码。
