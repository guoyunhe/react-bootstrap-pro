# Input

`Input` renders a native `input` with Bootstrap's form-control styling.
Choose an appropriate native `type` for browser-provided input, validation,
keyboard and autofill behavior.

### Ghost

`ghost` replaces `.form-control` with `.form-ghost` for composite controls.
The ghost style removes the input's focus outline, so its wrapper must provide
a visible focus indicator; `FormControl` supplies a `:focus-within` style.

## API

### Input

Renders an `input` by default and does not expose a polymorphic `component`
prop. Its own props are listed below; it inherits remaining native input props
and [`Box`](../box/README.mdx#api) utility props. `size` is reserved for
Bootstrap sizing rather than the native input's numeric `size` attribute.

| Prop         | Type                   | Description                                               |
| ------------ | ---------------------- | --------------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap size.                |
| `plaintext`  | `boolean`              | Applies `.form-control-plaintext` styling.                |
| `ghost`      | `boolean`              | Applies `.form-ghost`; takes precedence over `plaintext`. |
| `caret`      | `boolean`              | Adds `.form-control-caret` for a decorative caret.        |
| `validation` | `'valid' \| 'invalid'` | Applies the matching validation class.                    |

`validation` adds a CSS class; set `aria-invalid` and associate feedback when
appropriate. See [`Form`](../form/) for validation handling.

## Accessibility

Give each input an accessible name with a visible label or, when necessary,
`aria-label`. Placeholders do not replace labels. Associate instructions and
feedback using `aria-describedby`; native controls and keyboard interactions
depend on browser and operating system support.
