# Input

`Input` renders a native `<input>` with Bootstrap's `.form-control` styling.
Choose an appropriate native `type` so browsers provide the expected keyboard,
validation, autofill, and input behavior.

## Sizes and styles

Use `size='sm'` or `size='lg'` for Bootstrap sizing. `plaintext` applies
`.form-control-plaintext`, while `ghost` applies the borderless `.form-ghost`
style used inside adorned fields.

## API

### Input

Renders an `input` by default and does not expose a polymorphic `component`
prop. Its own props are listed below; it inherits the remaining native input
props and all [`Box`](../box/README.mdx#api) utility props.

| Prop         | Type                   | Description                                                       |
| ------------ | ---------------------- | ----------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap input size.                  |
| `plaintext`  | `boolean`              | Applies `.form-control-plaintext` styling.                        |
| `ghost`      | `boolean`              | Applies the borderless `.form-ghost` style.                       |
| `validation` | `'valid' \| 'invalid'` | Applies the corresponding validation class.                       |
| `...props`   | `BoxProps<'input'>`    | Native input props, including `type`, plus all Box utility props. |

## Accessibility

Give each input an accessible name with a visible `<label>` bound through
`htmlFor`, or with `aria-label` when a visible label is not possible. Native
input types retain their browser-provided keyboard, validation, and autofill
behavior.
