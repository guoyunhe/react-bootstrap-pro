# Input 输入框

`Input` 使用 Bootstrap 表单控件样式渲染原生 `input`。请选择合适的原生 `type`，
以使用浏览器提供的输入、校验、键盘和自动填充行为。

`ghost` 将 `.form-control` 替换为 `.form-ghost`，适用于组合控件。该样式移除输入框
的焦点轮廓，因此容器必须提供可见的焦点指示；`FormControl` 提供 `:focus-within` 样式。

## API

### Input

默认渲染为 `input`，不提供多态 `component` 属性。下表列出自有属性；此外继承其余原生
input 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。`size` 用于 Bootstrap
尺寸，而不是原生输入框的数字 `size` 属性。

| 属性         | 类型                   | 说明                                     |
| ------------ | ---------------------- | ---------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | 应用小型或大型 Bootstrap 尺寸。          |
| `plaintext`  | `boolean`              | 应用 `.form-control-plaintext` 样式。    |
| `ghost`      | `boolean`              | 应用 `.form-ghost`；优先于 `plaintext`。 |
| `caret`      | `boolean`              | 添加 `.form-control-caret` 装饰性箭头。  |
| `validation` | `'valid' \| 'invalid'` | 应用对应的校验状态类。                   |

`validation` 只添加 CSS 类；请在适当情况下设置 `aria-invalid` 并关联反馈。校验处理
请参阅 [`Form`](../form/)。

## 无障碍

使用可见标签为输入框提供无障碍名称；必要时可使用 `aria-label`。占位文本不能替代标签。
使用 `aria-describedby` 关联说明和反馈；原生控件和键盘交互取决于浏览器与操作系统支持。
