# Datepicker

`Datepicker` is a React wrapper around [Vanilla Calendar Pro](https://vanilla-calendar.pro/)
with Bootstrap 6 datepicker styles. It uses React props rather than Bootstrap's
`data-bs-*` initialization API, and supports single, multiple, and ranged date
selection, popup and inline calendars, localized formatting, and light and dark
themes.

## Overview

<DemoContainer>
  <DatepickerBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

The popup trigger is a text input. Use `w={12}` to give the formatted date
enough room. The input opens the calendar on focus and disables browser
autocomplete.

## How it works

- `selectionMode` controls whether users can choose one date, multiple dates,
  or a date range.
- `value` and `defaultValue` use `YYYY-MM-DD` strings. `onChange` receives the
  selected dates in the same format, while the trigger displays a localized
  or custom-formatted value.
- A single selection and a completed date range close the popup. Multiple-date
  selection stays open until the user dismisses it.
- Popup calendars close on outside interaction, Escape, or when focus moves
  outside the calendar. A button trigger opens and closes the calendar when
  activated.
- The calendar follows the closest Bootstrap `[data-bs-theme]` color mode by
  default. Set `theme` to override it.

## Dark mode

By default, the calendar follows the closest `[data-bs-theme]` ancestor. If
there is no Bootstrap color mode on an ancestor, the calendar follows the
system color scheme.

is copied to the calendar. Changes to the ancestor theme are observed while the
datepicker is mounted.

## Shadow DOM

The popup is attached to `document.body`, outside the component's shadow root.
When using `Datepicker` inside a shadow root, ensure Bootstrap's datepicker
styles are also available in the document scope; styles adopted only by the
shadow root do not style the popup.

## CSS

Bootstrap defines CSS variables for the calendar on `[data-vc="calendar"]`.
Override them in your stylesheet to customize its appearance.

| Variable                          | Default                           | Description                      |
| --------------------------------- | --------------------------------- | -------------------------------- |
| `--datepicker-padding`            | `1rem`                            | Calendar padding.                |
| `--datepicker-bg`                 | `var(--bg-body)`                  | Calendar background.             |
| `--datepicker-color`              | `var(--fg-body)`                  | Calendar text and control color. |
| `--datepicker-border-color`       | `var(--border-color-translucent)` | Calendar border color.           |
| `--datepicker-border-width`       | `var(--border-width)`             | Calendar border width.           |
| `--datepicker-border-radius`      | `var(--radius-7)`                 | Calendar corner radius.          |
| `--datepicker-box-shadow`         | `var(--box-shadow)`               | Popup shadow.                    |
| `--datepicker-font-size`          | `var(--font-size-sm)`             | Calendar font size.              |
| `--datepicker-min-width`          | `280px`                           | Minimum calendar width.          |
| `--datepicker-zindex`             | `var(--z-menu)`                   | Popup stacking order.            |
| `--datepicker-header-font-weight` | `600`                             | Month and year heading weight.   |
| `--datepicker-weekday-color`      | `var(--fg-3)`                     | Weekday label color.             |
| `--datepicker-day-hover-bg`       | `var(--bg-1)`                     | Day background on hover.         |
| `--datepicker-day-selected-bg`    | `var(--primary-bg)`               | Selected day background.         |
| `--datepicker-day-selected-color` | `var(--primary-contrast)`         | Selected day text color.         |
| `--datepicker-day-today-bg`       | `var(--bg-2)`                     | Today's background.              |
| `--datepicker-day-today-color`    | `var(--fg-1)`                     | Today's text color.              |
| `--datepicker-day-disabled-color` | `var(--fg-4)`                     | Disabled day text color.         |

Because the popup is attached to `document.body`, apply overrides globally or
target `[data-vc="calendar"]`; styles scoped only to a local wrapper do not
reach the popup.

## API

### Datepicker

The default popup trigger is an `<input type="text">`. Set `trigger='button'`
to render a `<button type="button">`; set `inline` to render the calendar in a
`<div>` instead.

`Datepicker` is not generic and does not inherit native input, button, or
[`Box`](../box/README.mdx#api) props. Only the props listed below are accepted;
`w` is an explicit width prop that applies a Bootstrap `w-*` utility to the
trigger or inline calendar element.

| Prop                 | Type                                                                                            | Default          | Description                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------- |
| `value`              | `string \| string[]`                                                                            | —                | Controlled selected date(s), as `YYYY-MM-DD` strings.                                                 |
| `defaultValue`       | `string \| string[]`                                                                            | —                | Initial selected date(s) for uncontrolled usage.                                                      |
| `onChange`           | `(dates: string[]) => void`                                                                     | —                | Called with the selected date(s) as `YYYY-MM-DD` strings.                                             |
| `selectionMode`      | `'single' \| 'multiple' \| 'multiple-ranged'`                                                   | `'single'`       | Allows one date, multiple dates, or a start/end date range.                                           |
| `firstWeekday`       | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6`                                                               | `1`              | First weekday; `0` is Sunday.                                                                         |
| `displayMonthsCount` | `1`–`12`                                                                                        | `1`              | Number of months shown side by side.                                                                  |
| `dateMin`            | `string \| Date \| number`                                                                      | —                | Earliest selectable date; use `YYYY-MM-DD`, `'today'`, a `Date`, or a timestamp.                      |
| `dateMax`            | `string \| Date \| number`                                                                      | —                | Latest selectable date; use `YYYY-MM-DD`, `'today'`, a `Date`, or a timestamp.                        |
| `locale`             | `string`                                                                                        | `'default'`      | Locale for calendar labels and default trigger formatting.                                            |
| `format`             | `Intl.DateTimeFormatOptions \| ((date: Date, locale: string \| undefined) => string)`           | —                | Customizes the text shown in the trigger.                                                             |
| `theme`              | `'light' \| 'dark' \| 'auto'`                                                                   | `'auto'`         | Calendar color mode; `auto` follows the ancestor or system color scheme.                              |
| `placement`          | `'auto' \| 'left' \| 'center' \| 'right' \| ['top' \| 'bottom', 'left' \| 'center' \| 'right']` | `'left'`         | Popup position relative to the trigger.                                                               |
| `trigger`            | `'input' \| 'button'`                                                                           | `'input'`        | Renders a text input or button trigger; ignored when `inline` is true.                                |
| `inline`             | `boolean`                                                                                       | `false`          | Renders an always-visible calendar instead of a popup.                                                |
| `icon`               | `ReactNode`                                                                                     | —                | Leading icon for the button trigger.                                                                  |
| `ghost`              | `boolean`                                                                                       | `false`          | Uses `.form-ghost` instead of `.form-control` on the input trigger.                                   |
| `placeholder`        | `string`                                                                                        | `'Choose date…'` | Text shown when no date is selected.                                                                  |
| `id`                 | `string`                                                                                        | —                | ID forwarded to the input or button trigger.                                                          |
| `name`               | `string`                                                                                        | —                | Name forwarded to the trigger; in inline mode, creates a hidden input with comma-separated ISO dates. |
| `disabled`           | `boolean`                                                                                       | `false`          | Disables the input or button trigger.                                                                 |
| `w`                  | `Width`                                                                                         | —                | Applies `w-*`; accepts `1`–`12`, `25`, `50`, `75`, `100`, `'auto'`, `'min'`, `'max'`, or `'fit'`.     |
| `className`          | `string`                                                                                        | —                | Class added to the trigger or, in inline mode, the calendar element.                                  |
| `aria-label`         | `string`                                                                                        | —                | Accessible name forwarded to the input or button trigger.                                             |
| `aria-labelledby`    | `string`                                                                                        | —                | ID reference forwarded to the input or button trigger.                                                |
| `aria-describedby`   | `string`                                                                                        | —                | Description reference forwarded to the input or button trigger.                                       |

Selection and calendar settings continue to apply in inline mode, and
`className` is added to the calendar element. `id`, `disabled`, and `aria-*` are
forwarded only to popup triggers. `trigger`, `icon`, `ghost`, and `placeholder`
do not affect inline calendars; neither does `format` or `placement`. `name`
creates an inline hidden input. For popup inputs, the submitted native input
value is the formatted display string, not necessarily the ISO selection value.

## Accessibility

Give popup inputs and buttons an accessible name with a visible `FormLabel`,
`aria-label`, or `aria-labelledby`. The button trigger has
`aria-haspopup='dialog'` and `aria-expanded`. The underlying calendar provides
keyboard navigation, screen-reader labels, and focus management.

Inline calendars have no trigger for the component's `aria-*` props to label;
place them in a labelled region. If JavaScript does not run, the popup trigger
remains a plain text input and the calendar is unavailable. The input is not a
native `type="date"` control and does not provide native date validation.
