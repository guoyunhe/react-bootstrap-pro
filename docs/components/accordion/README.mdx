# Accordion

`Accordion` groups native `<details>` elements. Matching `name` values make the
items exclusive; without `name`, each item opens independently. No JavaScript is
needed for the core interaction.

## Example

<DemoContainer>
  <Accordion>
    <AccordionItem name='faq' open>
      <AccordionHeader>
        Accordion Item #1
        <AccordionIcon />
      </AccordionHeader>
      <AccordionBody>
        <strong>This item is open by default.</strong> The browser handles the disclosure behavior,
        and the shared name makes the items exclusive.
      </AccordionBody>
    </AccordionItem>
    <AccordionItem name='faq'>
      <AccordionHeader>
        Accordion Item #2
        <AccordionIcon />
      </AccordionHeader>
      <AccordionBody>
        Opening this item closes the first item because they share a name.
      </AccordionBody>
    </AccordionItem>
    <AccordionItem name='faq'>
      <AccordionHeader>
        Accordion Item #3
        <AccordionIcon />
      </AccordionHeader>
      <AccordionBody>
        Place any content inside the body, including text, links, or other components.
      </AccordionBody>
    </AccordionItem>
  </Accordion>
</DemoContainer>

```tsx
<Accordion>
  <AccordionItem name='faq' open>
    <AccordionHeader>
      Accordion Item #1
      <AccordionIcon />
    </AccordionHeader>
    <AccordionBody>First item content</AccordionBody>
  </AccordionItem>
  <AccordionItem name='faq'>
    <AccordionHeader>
      Accordion Item #2
      <AccordionIcon />
    </AccordionHeader>
    <AccordionBody>Second item content</AccordionBody>
  </AccordionItem>
</Accordion>
```

The panel transition progressively uses CSS `interpolate-size`. Browsers without
support still open and close the native details panel, but without the height
animation.

## Expand and collapse all

The native items need no JavaScript, but a button can change them as a group.
This example removes `name` while expanding all items and restores it when
collapsing them.

<DemoContainer>
  <AccordionExpandCollapseDemo expandLabel='Expand all' collapseLabel='Collapse all' />
</DemoContainer>

```tsx
function toggleAll(accordion: HTMLElement, expand: boolean) {
  const items = accordion.querySelectorAll<HTMLDetailsElement>('.accordion-item');

  for (const item of items) {
    if (expand) {
      item.removeAttribute('name');
      item.open = true;
    } else {
      item.open = false;
      item.setAttribute('name', 'faq');
    }
  }
}
```

## Nested

Place another accordion in an item body and use a different `name` for each
level.

<DemoContainer>
  <Accordion>
    <AccordionItem name='outer' open>
      <AccordionHeader>
        Parent item #1
        <AccordionIcon />
      </AccordionHeader>
      <AccordionBody>
        This item contains a nested accordion.
        <Accordion className='mt-3'>
          <AccordionItem name='inner' open>
            <AccordionHeader>
              Nested item #1
              <AccordionIcon />
            </AccordionHeader>
            <AccordionBody>First nested item content.</AccordionBody>
          </AccordionItem>
          <AccordionItem name='inner'>
            <AccordionHeader>
              Nested item #2
              <AccordionIcon />
            </AccordionHeader>
            <AccordionBody>Second nested item content.</AccordionBody>
          </AccordionItem>
        </Accordion>
      </AccordionBody>
    </AccordionItem>
    <AccordionItem name='outer'>
      <AccordionHeader>
        Parent item #2
        <AccordionIcon />
      </AccordionHeader>
      <AccordionBody>This item has no nested accordion.</AccordionBody>
    </AccordionItem>
  </Accordion>
</DemoContainer>

```tsx

  <AccordionItem name='outer'>
    <AccordionHeader>Parent item</AccordionHeader>
    <AccordionBody>

        <AccordionItem name='inner'>...</AccordionItem>
      </Accordion>
    </AccordionBody>
  </AccordionItem>
</Accordion>
```

## API

| Prop        | Type          | Description                              |
| ----------- | ------------- | ---------------------------------------- |
| `component` | `ElementType` | Changes the root element.                |
| `flush`     | `boolean`     | Removes outer item borders and rounding. |
| `gap`       | `boolean`     | Adds spacing between items.              |
| `size`      | `'sm'`        | Uses compact spacing and type.           |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.  |

`AccordionItem`, `AccordionHeader`, `AccordionBody`, and `AccordionIcon` provide
the corresponding Bootstrap classes. `AccordionItem` renders a native
`<details>` element and accepts its `open` and `name` attributes.

## Accessibility

The native `<details>` and `<summary>` elements expose the expanded state to
assistive technology and support keyboard activation with Enter or Space.
