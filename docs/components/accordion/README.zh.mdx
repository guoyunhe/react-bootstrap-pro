# Accordion 手风琴

`Accordion` 使用原生 `<details>` 元素组合面板。多个条目设置相同的 `name`
即可互斥展开；省略 `name` 时，各条目可以独立展开。核心交互不需要 JavaScript。

## 示例

<DemoContainer>
  <AccordionBasicDemo />
</DemoContainer>

```tsx
<Accordion>
  <AccordionItem name='faq' open>
    <AccordionHeader>Accordion 条目 #1</AccordionHeader>
    <AccordionBody>第一个条目的内容</AccordionBody>
  </AccordionItem>
  <AccordionItem name='faq'>
    <AccordionHeader>Accordion 条目 #2</AccordionHeader>
    <AccordionBody>第二个条目的内容</AccordionBody>
  </AccordionItem>
</Accordion>
```

面板动画会渐进增强地使用 CSS `interpolate-size`。不支持该属性的浏览器仍可
原生展开和收起，只是不显示高度动画。

## 自定义图标

`AccordionHeader` 默认内置 chevron 图标。通过 `icon` 属性传入图标组件即可替换。

<DemoContainer>
  <AccordionCustomIconDemo />
</DemoContainer>

```tsx
import { BiPlus } from 'react-bootstrap-icons-pro';

<AccordionHeader icon={BiPlus}>自定义图标</AccordionHeader>;
```

## 主题变体

设置语义主题，为当前展开的条目应用对应颜色。

<DemoContainer>
  <AccordionVariantsDemo />
</DemoContainer>

```tsx

```

## 紧凑尺寸

使用紧凑尺寸可缩小内边距、圆角和字号。

<DemoContainer>
  <AccordionSmallDemo />
</DemoContainer>

```tsx

```

## 无边框

移除外侧边框和圆角，让手风琴与父容器边缘对齐。

<DemoContainer>
  <AccordionFlushDemo />
</DemoContainer>

```tsx
<Accordion flush>...</Accordion>
```

## 间距

在条目之间增加间距，并让每个条目保留独立圆角。

<DemoContainer>
  <AccordionGapDemo />
</DemoContainer>

```tsx
<Accordion gap>
  <AccordionItem name='faq' open>
    <AccordionHeader>问题</AccordionHeader>
    <AccordionBody>答案</AccordionBody>
  </AccordionItem>
</Accordion>
```

## 同时展开多个条目

省略 `name` 属性即可让多个条目同时保持展开。

<DemoContainer>
  <AccordionAlwaysOpenDemo />
</DemoContainer>

```tsx
<Accordion>
  <AccordionItem open>...</AccordionItem>
  <AccordionItem open>...</AccordionItem>
</Accordion>
```

## 全部展开与收起

原生条目不需要 JavaScript；若要一次切换所有条目，可通过按钮批量操作。
展开时会移除 `name`，收起时再恢复。

<DemoContainer>
  <AccordionExpandCollapseDemo />
</DemoContainer>

```tsx
function toggleAll(accordion: HTMLElement, expand: boolean) {
  const items = accordion.querySelectorAll<HTMLDetailsElement>('.accordion-item');

  for (const item of items) {
    if (expand) {
      item.removeAttribute('name');
      item.open = true;
    } else {
      item.open = false;
      item.setAttribute('name', 'faq');
    }
  }
}
```

## 嵌套

可以在条目内容中嵌套另一个 Accordion，并为每一层设置不同的 `name`。

<DemoContainer>
  <AccordionNestedDemo />
</DemoContainer>

```tsx
<Accordion>
  <AccordionItem name='outer'>
    <AccordionHeader>外层条目</AccordionHeader>
    <AccordionBody>
      <Accordion>
        <AccordionItem name='inner'>...</AccordionItem>
      </Accordion>
    </AccordionBody>
  </AccordionItem>
</Accordion>
```

## API

### Accordion

| 属性    | 类型      | 说明                     |
| ------- | --------- | ------------------------ |
| `flush` | `boolean` | 移除条目外侧边框和圆角。 |
| `gap`   | `boolean` | 在条目之间增加间距。     |
| `size`  | `'sm'`    | 使用紧凑间距和字号。     |

继承原生属性及 Box 工具类属性。

### AccordionItem

继承原生 `<details>` 属性（包括 `open` 和 `name`）及 Box 工具类属性。

### AccordionHeader

默认图标为 `BiChevronDown`。

| 属性   | 类型                       | 说明               |
| ------ | -------------------------- | ------------------ |
| `icon` | `ComponentType<IconProps>` | 替换默认图标组件。 |

继承原生属性及 Box 工具类属性。

### AccordionBody

继承原生属性及 Box 工具类属性。

## 无障碍访问

原生 `<details>` 和 `<summary>` 会向辅助技术提供展开状态，并支持使用 Enter
或 Space 键切换。
