# Images 图片

`Image` 提供 Bootstrap 响应式图片和缩略图样式；`Figure` 与 `FigureCaption`
用于语义化图片及其说明文字。

<DemoContainer>
  <Figure>
    <Image
      fluid
      src='https://placehold.co/600x400'
      alt='带有说明文字的风景占位图'
      className='rounded-3'
    />
    <FigureCaption>图片说明文字。</FigureCaption>
  </Figure>
</DemoContainer>

## 响应式图片与缩略图

设置 `fluid` 会应用 `.img-fluid`（`max-width: 100%; height: auto`），设置
`thumbnail` 会应用 `.img-thumbnail`。两者可以同时使用。可通过 `className`
传入 `float-start`、`mx-auto`、`text-center` 等对齐工具类。

## 图片与说明

`Figure` 和 `FigureCaption` 用于组合图片及可选说明。Figure 中的图片不会自动变为响应式，
请给 `Image` 添加 `fluid`。可在 `Figure` 上使用 flex 工具类调整说明文字的位置。

需要根据屏幕尺寸选择图片时，可直接组合原生 `<picture>` 和 `<source>`，并将
`fluid` 或 `thumbnail` 加到内部的 `Image`，而不是 `<picture>`。

## 属性

| 组件     | 属性        | 类型          | 说明                               |
| -------- | ----------- | ------------- | ---------------------------------- |
| `Image`  | `fluid`     | `boolean`     | 应用 `.img-fluid` 响应式尺寸样式。 |
| `Image`  | `thumbnail` | `boolean`     | 应用 `.img-thumbnail` 缩略图样式。 |
| 所有组件 | `component` | `ElementType` | 更换渲染元素。                     |
| 所有组件 | `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。    |

### Image

默认渲染为 `img`。自有属性为 `fluid?: boolean` 和 `thumbnail?: boolean`；继承所选
元素的原生属性及通过 `BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api)
属性。

### Figure

默认渲染为 `figure`，没有自有属性。继承原生 `figure` 属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

### FigureCaption

默认渲染为 `figcaption`，没有自有属性。继承原生 `figcaption` 属性及通过
`BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

## 无障碍

信息性图片应提供有意义的 `alt` 文本；装饰性图片应使用 `alt=""`。图片说明文字应与替代文本互补，
不要重复传达相同内容。
