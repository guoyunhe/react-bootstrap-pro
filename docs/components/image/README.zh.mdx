# Image 图片

`Image` 提供 Bootstrap 响应式图片和缩略图样式；`Figure` 与 `FigureCaption` 提供
语义化图片及其说明文字样式。

## 响应式图片

使用 `fluid` 应用 `.img-fluid`，设置 `max-width: 100%` 和 `height: auto`，
使图片适应父元素宽度。

  <ImageResponsiveDemo />
</DemoContainer>


## Picture

使用原生 `picture` 和 `source` 元素提供备选图片源。将 `fluid` 和 `thumbnail` 加到
内部 `Image`，而不是 `picture`。浏览器选择第一个匹配且受支持的图片源；没有匹配项时
回退到 `Image` 的图片源。

## CSS

Bootstrap 为缩略图的内边距、背景、边框和阴影，以及 figure 的间距和说明文字样式提供
局部 CSS 变量。完整列表请参阅[上游 CSS 变量文档](https://getbootstrap.com/docs/6.0/content/images/#css)。

## API

### Image

默认渲染为 `img`，下表列出自有属性。此外继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

| 属性        | 类型      | 说明                             |
| ----------- | --------- | -------------------------------- |
| `fluid`     | `boolean` | 应用 `.img-fluid` 响应式样式。   |
| `thumbnail` | `boolean` | 应用 `.img-thumbnail` 边框样式。 |

### Figure

默认渲染为 `figure`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### FigureCaption

默认渲染为 `figcaption`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

## 无障碍

信息性图片应提供有意义的 `alt` 文本，装饰性图片应使用 `alt=''`。说明文字可以补充
上下文，但不能取代 `alt` 文本。对于 `picture`，无论浏览器选择哪个图片源，都使用
`Image` 提供的替代文本。
