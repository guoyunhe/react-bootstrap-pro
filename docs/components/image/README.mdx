# Image

`Image` adds Bootstrap's responsive and thumbnail image styles. `Figure` and
`FigureCaption` provide semantic figure markup and caption styling.

## Responsive images

Use `fluid` to apply `.img-fluid`, which sets `max-width: 100%` and
`height: auto` so the image fits its parent.

## Picture

Use native `picture` and `source` elements for alternative image sources. Put
`fluid` and `thumbnail` on the nested `Image`, not on `picture`. The browser
chooses the first matching supported source and falls back to the `Image` source.

## CSS

Bootstrap exposes local CSS variables for thumbnail padding, background,
border and shadow, and for figure spacing and caption styling. See the
[upstream CSS variables](https://getbootstrap.com/docs/6.0/content/images/#css)
for the complete list.

## API

### Image

Renders an `img` by default. Its own props are listed below. It inherits native
props for the selected element and [`Box`](../box/README.mdx#api) utility props,
including `component`.

| Prop        | Type      | Description                                |
| ----------- | --------- | ------------------------------------------ |
| `fluid`     | `boolean` | Applies responsive `.img-fluid` styling.   |
| `thumbnail` | `boolean` | Applies bordered `.img-thumbnail` styling. |

### Figure

Renders a `figure` by default and has no additional props. It inherits native
props for the selected element and [`Box`](../box/README.mdx#api) utility props,
including `component`.

### FigureCaption

Renders a `figcaption` by default and has no additional props. It inherits
native props for the selected element and [`Box`](../box/README.mdx#api)
utility props, including `component`.

## Accessibility

Provide meaningful `alt` text for informative images and use `alt=''` for
decorative images. A caption can add context but does not replace alternative
text. For `picture`, the `Image` provides the alternative text for whichever
source the browser selects.
