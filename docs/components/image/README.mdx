# Images

`Image` adds Bootstrap's responsive and thumbnail image classes. `Figure` and
`FigureCaption` provide semantic figure markup with Bootstrap's baseline styles.

## Responsive images and thumbnails

Use `fluid` to apply `.img-fluid` (`max-width: 100%; height: auto`) and
`thumbnail` to apply `.img-thumbnail`. Both options can be combined. Alignment
utilities such as `float-start`, `mx-auto`, and `text-center` can be passed
through `className`.

## Figures

Use `Figure` and `FigureCaption` for an image with an optional caption. Images
inside figures are not automatically responsive; add `fluid` to the `Image`.
Use flex utilities on `Figure` to change the caption alignment.

For responsive art direction, use the native `<picture>` and `<source>` elements
and apply `fluid` or `thumbnail` to the nested `Image`, not to `<picture>`.

## API

### Image

Renders an `img` by default. Its own props are `fluid?: boolean` and
`thumbnail?: boolean`; it inherits native props for the selected element and
all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

| Component      | Prop        | Type          | Description                                        |
| -------------- | ----------- | ------------- | -------------------------------------------------- |
| `Image`        | `fluid`     | `boolean`     | Applies `.img-fluid` for responsive sizing.        |
| `Image`        | `thumbnail` | `boolean`     | Applies `.img-thumbnail` for a bordered thumbnail. |
| All components | `component` | `ElementType` | Changes the rendered element.                      |
| All components | `...props`  | `BoxProps<C>` | Native props and all Box utility props.            |

### Figure

Renders a `figure` by default and has no own props. It inherits native figure
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### FigureCaption

Renders a `figcaption` by default and has no own props. It inherits native
figcaption props and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

## Accessibility

Provide meaningful `alt` text for informative images. Use `alt=""` for
decorative images, and keep captions distinct from alternative text.
