# Menu 菜单

`Menu` 为链接、操作和其他内容提供 Bootstrap 菜单样式。传入 `trigger` 元素即可使用
Floating UI 驱动的交互菜单，无需 Bootstrap JavaScript。触发器必须支持 ref 并将事件
处理器传递给 DOM 元素。不要在同一触发器上同时使用 Bootstrap 菜单插件。

## 无障碍

使用原生控件，并保持触发器的 `aria-expanded` 与菜单状态同步。Bootstrap 菜单是通用
容器，不会自动成为 ARIA `menu` 控件；仅在内容和完整键盘行为满足该模式时添加 menu
角色。交互菜单支持方向键导航、Home、End、Escape 和子菜单方向键。菜单不限制焦点，
Tab 可正常移动。不要仅通过颜色传达状态。

## CSS

Bootstrap 提供控制菜单和条目外观、位置及过渡的
[局部 CSS 变量](https://getbootstrap.com/docs/6.0/components/menu/#variables)。
Bootstrap 的过渡样式支持减少动态效果偏好。

## 用法

传入 `trigger` 时，省略 `show` 可使用内部状态，也可同时传入 `show` 和
`onShowChange` 进行受控管理。不传 `trigger` 时，`show` 仅控制 Bootstrap 类名，
定位和交互仍需由调用方处理。

## API

### Menu

默认渲染为 `div`。继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component`。

| 属性           | 类型                               | 说明                                      |
| -------------- | ---------------------------------- | ----------------------------------------- |
| `trigger`      | `ReactElement`                     | 支持 ref 的触发器；启用交互和定位。       |
| `show`         | `boolean`                          | 控制显示；无触发器时仅添加 `.show`。      |
| `onShowChange` | `(show: boolean) => void`          | 接收状态变更请求。                        |
| `placement`    | `MenuPlacement`                    | Floating UI 位置，默认为 `bottom-start`。 |
| `offset`       | `number`                           | 与触发器的距离（像素），默认为 `2`。      |
| `autoClose`    | `boolean \| 'inside' \| 'outside'` | 控制点击条目或外部时关闭，默认为 `true`。 |
| `scrollable`   | `boolean`                          | 启用滚动并将最大高度设为 `80dvh`。        |
| `translucent`  | `boolean`                          | 应用半透明表面。                          |

### MenuItem

默认渲染为 `a`。继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。

| 属性       | 类型      | 说明                                                             |
| ---------- | --------- | ---------------------------------------------------------------- |
| `active`   | `boolean` | 应用激活样式，但不设置 `aria-current`。                          |
| `disabled` | `boolean` | 添加禁用样式、`aria-disabled` 和 `tabIndex={-1}`；不会阻止激活。 |

### MenuDivider

默认渲染为 `hr`，除非覆盖，否则设置 `role='separator'`。没有自有属性，继承原生属性
及 [`Box`](../box/README.zh.mdx#api) 属性。

### MenuItemContent

默认渲染为 `span`。没有自有属性，继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component`。

### MenuItemDescription

默认渲染为 `small`。没有自有属性，继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component`。

### MenuHeader

默认渲染为 `h6`。没有自有属性，继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 属性。

### MenuText

默认渲染为 `span`。没有自有属性，继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 属性。
