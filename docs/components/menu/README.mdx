# Menu

`Menu` provides the popup menu classes. Use the Bootstrap JavaScript bundle to
position, toggle, and manage keyboard interaction.

## Translucent

Set `translucent` to apply the translucent surface treatment.

## Scrollable

Use `scrollable` when a menu may exceed the available height.

## API

| Prop          | Type          | Description                                        |
| ------------- | ------------- | -------------------------------------------------- |
| `show`        | `boolean`     | Adds `.show` to display the menu.                  |
| `scrollable`  | `boolean`     | Limits menu height and enables vertical scrolling. |
| `translucent` | `boolean`     | Uses a translucent menu surface.                   |
| `component`   | `ElementType` | Changes the root element.                          |
| `...props`    | `BoxProps<C>` | Native props and all Box utility props.            |

`MenuItem`, `MenuHeader`, `MenuDivider`, and `MenuText` provide menu structure.

## Accessibility

Use a button as the toggle when possible and keep its `aria-expanded` value in
sync with the menu. Ensure the menu items have meaningful link or button
semantics.
