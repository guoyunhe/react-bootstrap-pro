# Menu

`Menu` provides the popup menu classes. Use the Bootstrap JavaScript bundle to
position, toggle, and manage keyboard interaction.

## Translucent

Set `translucent` to apply the translucent surface treatment.

## Scrollable

Use `scrollable` when a menu may exceed the available height.

## API

### Menu

Renders a `div` by default. Its own props are `scrollable?: boolean`,
`translucent?: boolean`, and `show?: boolean`; it inherits native props for the
selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

| Prop          | Type          | Description                                        |
| ------------- | ------------- | -------------------------------------------------- |
| `show`        | `boolean`     | Adds `.show` to display the menu.                  |
| `scrollable`  | `boolean`     | Limits menu height and enables vertical scrolling. |
| `translucent` | `boolean`     | Uses a translucent menu surface.                   |
| `component`   | `ElementType` | Changes the root element.                          |
| `...props`    | `BoxProps<C>` | Native props and all Box utility props.            |

`MenuItem`, `MenuHeader`, `MenuDivider`, and `MenuText` provide menu structure.

### MenuItem

Renders an `a` by default. Its own props are `active?: boolean` and
`disabled?: boolean`; when disabled, it sets `aria-disabled` and removes the
item from sequential keyboard focus. It inherits native props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### MenuDivider

Renders an `hr` by default and has no own props. It defaults to
`role="separator"` and inherits native props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### MenuHeader

Renders an `h6` by default and has no own props. It inherits native heading
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### MenuText

Renders a `span` by default and has no own props. It inherits native `span`
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Use a button as the toggle when possible and keep its `aria-expanded` value in
sync with the menu. Ensure the menu items have meaningful link or button
semantics.
