# Menu

`Menu` provides Bootstrap menu styling for links, actions and other content.
Pass a `trigger` element for interactive menus driven by Floating UI; no
Bootstrap JavaScript is needed. The trigger must accept a ref and forward
event handlers to its DOM element. Do not attach the Bootstrap menu plugin to
the same trigger.

## Accessibility

Use native controls and keep a toggle's `aria-expanded` in sync. Bootstrap
menus are generic containers, not automatically ARIA `menu` widgets: only add
menu roles when the content and full keyboard behavior satisfy that pattern.
Interactive menus support arrow-key navigation, Home, End, Escape and submenu
arrow keys. Menu contents are not focus-trapped, so Tab moves normally.
Do not communicate state through color alone.

## CSS

Bootstrap exposes [local CSS variables](https://getbootstrap.com/docs/6.0/components/menu/#variables)
for menu and item appearance, positioning and transitions. Reduced-motion
preferences are handled by Bootstrap's transition styles.

## Usage

With `trigger`, omit `show` for internal state, or pass `show` and
`onShowChange` to control it. Without `trigger`, `show` only controls the
Bootstrap class and positioning and interactions remain the caller's responsibility.

## API

### Menu

Renders `div` by default. Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component`.

| Prop           | Type                               | Description                                                    |
| -------------- | ---------------------------------- | -------------------------------------------------------------- |
| `trigger`      | `ReactElement`                     | Ref-capable trigger; enables interaction and positioning.      |
| `show`         | `boolean`                          | Controls visibility; without a trigger only adds `.show`.      |
| `onShowChange` | `(show: boolean) => void`          | Receives requested visibility changes.                         |
| `placement`    | `MenuPlacement`                    | Floating UI placement; defaults to `bottom-start`.             |
| `offset`       | `number`                           | Distance from trigger in pixels; defaults to `2`.              |
| `autoClose`    | `boolean \| 'inside' \| 'outside'` | Controls item and outside click dismissal; defaults to `true`. |
| `scrollable`   | `boolean`                          | Enables scrolling with an `80dvh` maximum height.              |
| `translucent`  | `boolean`                          | Applies a translucent surface.                                 |

### MenuItem

Renders `a` by default. Inherits selected-element native props and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`.

| Prop       | Type      | Description                                                                               |
| ---------- | --------- | ----------------------------------------------------------------------------------------- |
| `active`   | `boolean` | Applies active styling, without setting `aria-current`.                                   |
| `disabled` | `boolean` | Adds disabled styling, `aria-disabled` and `tabIndex={-1}`; does not suppress activation. |

### MenuDivider

Renders `hr` by default, with `role='separator'` unless overridden. It has no
own props and inherits native props and [`Box`](../box/README.mdx#api) props.

### MenuItemContent

Renders `span` by default. It has no own props and inherits selected-element
native props and [`Box`](../box/README.mdx#api) props, including `component`.

### MenuItemDescription

Renders `small` by default. It has no own props and inherits selected-element
native props and [`Box`](../box/README.mdx#api) props, including `component`.

### MenuHeader

Renders `h6` by default. It has no own props and inherits selected-element
native props and [`Box`](../box/README.mdx#api) props.

### MenuText

Renders `span` by default. It has no own props and inherits selected-element
native props and [`Box`](../box/README.mdx#api) props.
