# Placeholder 占位符

`Placeholder` 和 `PlaceholderGroup` 用 CSS 渲染 Bootstrap 加载骨架。其外观和动画
不需要 JavaScript，但加载完成后，应用必须将骨架替换为实际内容。

## API

### Placeholder

默认渲染为 `span`。自有属性为 `size`；继承所选元素的原生属性及通过
`BoxProps<C>` 继承的 [`Box`](../box/README.zh.mdx#api) 属性，包括多态
`component` 属性。

| 属性   | 类型                   | 说明             |
| ------ | ---------------------- | ---------------- |
| `size` | `'xs' \| 'sm' \| 'lg'` | 应用尺寸修饰类。 |

### PlaceholderGroup

默认渲染为 `span`。自有属性为 `animation`；继承所选元素的原生属性及通过
`BoxProps<C>` 继承的 [`Box`](../box/README.zh.mdx#api) 属性，包括多态
`component` 属性。

| 属性        | 类型                          | 说明                   |
| ----------- | ----------------------------- | ---------------------- |
| `animation` | `'glow' \| 'pulse' \| 'wave'` | 为子元素应用对应动画。 |

两个组件默认都会设置 `aria-hidden='true'`。只有在需要让辅助技术读取占位符本身时，
才传入 `aria-hidden={false}`。

## 无障碍访问

占位符只负责视觉呈现，不会播报加载状态或加载完成。请将装饰性骨架从辅助技术中隐藏，
另行播报加载状态和内容更新，并在实际内容就绪后替换骨架。
