# Placeholder

`Placeholder` and `PlaceholderGroup` render Bootstrap's CSS loading skeletons.
Their appearance and animation need no JavaScript, but your application must
replace the skeleton with real content when loading finishes.

## API

### Placeholder

Renders a `span` by default. Its own prop is `size`; it inherits native props
for the selected element and [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`, including the polymorphic `component` prop.

| Prop   | Type                   | Description              |
| ------ | ---------------------- | ------------------------ |
| `size` | `'xs' \| 'sm' \| 'lg'` | Applies a size modifier. |

### PlaceholderGroup

Renders a `span` by default. Its own prop is `animation`; it inherits native
props for the selected element and [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`, including the polymorphic `component` prop.

| Prop        | Type                          | Description                                      |
| ----------- | ----------------------------- | ------------------------------------------------ |
| `animation` | `'glow' \| 'pulse' \| 'wave'` | Applies the corresponding animation to children. |

Both components set `aria-hidden='true'` by default. Pass `aria-hidden={false}`
only when the placeholder itself should be exposed to assistive technology.

## Accessibility

Placeholders are visual and do not announce loading or completion. Keep
decorative skeletons hidden from assistive technology, announce loading state
and updates separately, and replace the skeleton when real content is ready.
