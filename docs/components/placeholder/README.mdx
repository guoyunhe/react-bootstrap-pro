# Placeholder

`Placeholder` renders a loading skeleton. Put placeholders inside a
`PlaceholderGroup` to apply the pulse, glow, or wave animation.

## Sizing

Use the width utilities to match placeholder proportions to the content they
replace; `size` changes their height.

## API

### Placeholder

Renders a `span` by default. Its own prop is `size?: 'xs' | 'sm' | 'lg'`; it
inherits native props for the selected element and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

| Prop        | Type                          | Description                             |
| ----------- | ----------------------------- | --------------------------------------- |
| `size`      | `'xs' \| 'sm' \| 'lg'`        | Adjusts the placeholder height.         |
| `animation` | `'glow' \| 'pulse' \| 'wave'` | Selects a group animation.              |
| `component` | `ElementType`                 | Changes the rendered element.           |
| `...props`  | `BoxProps<C>`                 | Native props and all Box utility props. |

Placeholders are presentational. Toggle the real content and skeleton visibility
in your application, and use `aria-hidden` where appropriate.

### PlaceholderGroup

Renders a `span` by default. Its own prop is
`animation?: 'glow' | 'pulse' | 'wave'`; it inherits native props for the
selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

## Accessibility

Hide decorative skeletons from assistive technology and announce loading state
or updated content separately. Replace the placeholder when real content is
available.
