# Switch

`Switch` renders the `.switch` track and indicator, while `SwitchInput` renders
the invisible checkbox layered over it. The input keeps the native checkbox
semantics; `SwitchInput` sets `type='checkbox'`, `role='switch'`, and the
`switch` attribute, which browsers that support it can use for haptic feedback.
Wrap the pair in a `FormField` to place the label next to the control.

## API

### Switch

| Prop        | Type                    | Description                             |
| ----------- | ----------------------- | --------------------------------------- |
| `size`      | `'sm' \| 'lg'`          | Scales the track and its label.         |
| `theme`     | Bootstrap theme literal | Sets the checked color via `.theme-*`.  |
| `component` | `ElementType`           | Renders a `div` by default.             |
| `...props`  | `BoxProps<C>`           | Native props and all Box utility props. |

### SwitchInput

| Prop        | Type          | Description                                    |
| ----------- | ------------- | ---------------------------------------------- |
| `component` | `ElementType` | Renders an `input type='checkbox'` by default. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.        |

## Accessibility

`SwitchInput` always renders `role='switch'` so assistive technologies announce
the control as a switch instead of a checkbox. Give it an accessible name with a
`<label for>` bound through `htmlFor`, and group the label with the track in a
`FormField`.
