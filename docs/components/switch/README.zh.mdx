# Switch 开关

`Switch` 渲染 `.switch` 轨道与指示器，并在其上叠加一个原生复选框输入框。
输入框保留原生复选框语义，并自动设置 `type='checkbox'`、`role='switch'` 以及
`switch` 属性（支持的浏览器可用它提供触觉反馈）。将开关放入 `FormField`，并通过
`htmlFor` 绑定 `<label>`，标签会显示在控件旁边。

## API

### Switch

默认渲染一个 `div` 轨道，内部包含 `<input type='checkbox'>`，输入框始终带有
`role='switch'` 和 `switch` 属性。

| 组件属性         | 类型                     | 说明                         |
| ---------------- | ------------------------ | ---------------------------- |
| `size`           | `'sm' \| 'lg'`           | 调整轨道及其标签的尺寸。     |
| `validation`     | `'valid' \| 'invalid'`   | 为内部输入框添加校验状态类。 |
| `width`          | `CSSProperties['width']` | 设置轨道宽度。               |
| `indicatorWidth` | `CSSProperties['width']` | 设置指示器宽度。             |
| `inputRef`       | `Ref<HTMLInputElement>`  | 指向内部复选框的 ref。       |

自有属性为 `size`、`validation`、`width`、`indicatorWidth` 和 `inputRef`。原生
复选框属性会透传给内部输入框，包括 `id`、`name`、`value`、`checked`、
`defaultChecked`、`disabled`、`required`、`readOnly`、`autoComplete`、`form`、
`onChange`、`onInput`、`onBlur`、`onFocus`，以及 `aria-label`、`aria-describedby`
和 `aria-labelledby` 属性。其余原生属性及所有
[`Box`](../box/README.zh.mdx#api) 工具类属性作用于轨道；`theme`、`style` 和
`component` 同样作用于轨道。

## 无障碍访问

内部输入框始终渲染 `role='switch'`，辅助技术会将控件朗读为开关而非复选框，并提供
原生选中状态。通过 `htmlFor` 绑定 `<label>` 或使用 `aria-label` 提供可访问名称。
键盘交互保持原生行为：输入框获得焦点时，按 Space 切换开关。

如示例所示，将标签与轨道一起放入 `FormField`，网格布局会把二者并排显示，标签也会
跟随禁用状态的样式。颜色只是视觉提示，请保留可见标签，不要仅依靠选中态颜色传达状态。
