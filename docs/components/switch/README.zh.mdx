# Switch 开关

`Switch` 渲染 `.switch` 轨道与指示器，`SwitchInput` 渲染覆盖在其上的不可见
复选框。输入框保留原生复选框语义；`SwitchInput` 会自动设置
`type='checkbox'`、`role='switch'` 以及 `switch` 属性（支持的浏览器可用它提供
触觉反馈）。将两者放入 `FormField`，标签会显示在控件旁边。

## API

### Switch

| 属性        | 类型                 | 说明                             |
| ----------- | -------------------- | -------------------------------- |
| `size`      | `'sm' \| 'lg'`       | 调整轨道及其标签的尺寸。         |
| `theme`     | Bootstrap 主题字面量 | 通过 `.theme-*` 设置选中态颜色。 |
| `component` | `ElementType`        | 默认渲染 `div`。                 |
| `...props`  | `BoxProps<C>`        | 原生属性及所有 Box 工具类属性。  |

### SwitchInput

| 属性        | 类型          | 说明                               |
| ----------- | ------------- | ---------------------------------- |
| `component` | `ElementType` | 默认渲染 `input type='checkbox'`。 |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。    |

## 无障碍

`SwitchInput` 始终渲染 `role='switch'`，辅助技术会把控件朗读为开关而非复选框。
通过 `htmlFor` 绑定 `<label for>` 提供可访问名称，并将标签与轨道一起放在
`FormField` 中。
