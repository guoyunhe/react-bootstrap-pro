# InputGroup 输入框组

`InputGroup` 为文本控件挂载附加内容，`InputGroupText` 渲染对应的
`.input-group-text` 附加块。附加块可以是文本、图标、复选框、单选按钮或按钮。
标签应放在输入框组之外，并配合 `FormField` 获得标签、帮助文本与校验样式。

可在控件一侧放置一个附加块，或两侧各放一个。

## 圆角

输入框组会自动移除内部圆角。若插入的多余元素不应参与该逻辑，为其添加
`className='input-group-ignore'`。

## 尺寸

在 `InputGroup` 上设置 `size='sm'` 或 `size='lg'`，整个输入框组会一起缩放。
不要在单个附加块或控件上设置尺寸。

## API

### InputGroup

| 属性        | 类型           | 说明                            |
| ----------- | -------------- | ------------------------------- |
| `size`      | `'sm' \| 'lg'` | 同时缩放附加块与控件。          |
| `component` | `ElementType`  | 默认渲染 `div`。                |
| `...props`  | `BoxProps<C>`  | 原生属性及所有 Box 工具类属性。 |

### InputGroupText

| 属性        | 类型          | 说明                                           |
| ----------- | ------------- | ---------------------------------------------- |
| `component` | `ElementType` | 默认渲染 `span`；可按需使用 `div` 或 `label`。 |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。                |

## 无障碍

为输入框组中的控件提供可访问名称：标签放在组外，或使用 `aria-label`。文本附加块
通过 `aria-describedby` 关联到控件。
