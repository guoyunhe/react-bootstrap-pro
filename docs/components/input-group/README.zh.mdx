# InputGroup 输入框组

`InputGroup` 为控件附加文本、按钮或其他内容，`InputGroupText` 渲染带样式的文本附加块。

## 示例

可在控件任意一侧放置附加块。可见标签通常放在组外，但 `InputGroupText` 也可作为
下拉框或文件输入框的标签。

## 尺寸

在 `InputGroup` 上设置 `size='sm'` 或 `size='lg'`，即可调整组内元素的尺寸。
Bootstrap 不支持单独设置组内元素的尺寸。

## API

### InputGroup

默认渲染为 `div`，下表列出自有属性。此外继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

| 属性   | 类型           | 说明                       |
| ------ | -------------- | -------------------------- |
| `size` | `'sm' \| 'lg'` | 同时调整组内控件和附加块。 |

### InputGroupText

默认渲染为 `span`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`；可按需使用 `label`
或 `div`。

### InputGroupButton

默认渲染为 `button` 并添加 `.input-group-btn`。没有额外属性，继承
[`Button`](../button/README.zh.mdx#api) 的属性，包括所选元素的原生属性和 `component`。

## 无障碍

使用标签或 `aria-label` 为每个控件提供无障碍名称。通过 `aria-describedby` 关联有
意义的附加块和说明文字；每个复选框、单选按钮和菜单按钮也需要各自的无障碍名称。
