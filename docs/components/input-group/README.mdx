# InputGroup

`InputGroup` attaches add-ons to a textual control, and `InputGroupText` renders
the matching `.input-group-text` addon. Add-ons can be text, icons, checkboxes,
radios, or buttons. Keep labels outside the group and pair it with `FormField`
for labels, help text, and validation styles.

## Border radius

The group removes inner border radii automatically. When you insert an extra
element that should not take part in that logic, add `className='input-group-ignore'`
to it.

## Sizing

Set `size='sm'` or `size='lg'` on `InputGroup` to resize the whole group. Do not
set sizes on the individual add-ons or controls.

## API

### InputGroup

| Prop        | Type           | Description                              |
| ----------- | -------------- | ---------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Scales the add-ons and control together. |
| `component` | `ElementType`  | Renders a `div` by default.              |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props.  |

### InputGroupText

| Prop        | Type          | Description                                                  |
| ----------- | ------------- | ------------------------------------------------------------ |
| `component` | `ElementType` | Renders a `span` by default; use `div` or `label` as needed. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.                      |

## Accessibility

Give the group's control an accessible name: keep the label outside the group,
or use `aria-label` when no visible label fits. Reference text add-ons with
`aria-describedby`.
