# InputGroup

`InputGroup` attaches text, buttons or other add-ons to a control.
`InputGroupText` renders a styled text add-on.

## Examples

Place an add-on on either side of the control. Keep visible labels outside the
group, except when an `InputGroupText` is itself a label for a select or file input.

## CSS

Bootstrap exposes local CSS variables for add-on padding, color, background,
border and sizing. See the [upstream variables](https://getbootstrap.com/docs/6.0/forms/input-group/#css).

## API

### InputGroup

Renders a `div` by default. Its own prop is listed below; it inherits native
props for the selected element and [`Box`](../box/README.mdx#api) utility props,
including `component`.

| Prop   | Type           | Description                              |
| ------ | -------------- | ---------------------------------------- |
| `size` | `'sm' \| 'lg'` | Scales the group's controls and add-ons. |

### InputGroupText

Renders a `span` by default and has no additional props. It inherits native
props for the selected element and [`Box`](../box/README.mdx#api) utility props,
including `component`; use `label` or `div` when appropriate.

### InputGroupButton

Renders a `button` by default and adds `.input-group-btn`. It has no additional
props and inherits [`Button`](../button/README.mdx#api) props, including native
props for the selected element and `component`.

## Accessibility

Give each control an accessible name with a label or `aria-label`. Associate
meaningful add-ons and help text with `aria-describedby`; each checkbox,
radio and menu button also needs its own accessible name.
