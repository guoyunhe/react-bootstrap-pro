# Nav 导航

`Nav`、`NavItem` 和 `NavLink` 提供导航结构，支持标签、胶囊和下划线样式。
它们本身不会切换标签面板。

## 溢出导航

`NavOverflow` 是 React 实现的 Priority+ 导航。传入一个 `Nav` 或 `NavbarNav`，
其直接子项为包含 `NavLink` 的 `NavItem`。组件使用 `ResizeObserver` 测量容器和条目宽度
（不可用时监听窗口尺寸变化），将放不下的条目放入基于 Floating UI 的 React `Menu`，
不需要 Bootstrap JavaScript。默认触发器支持方向键、Escape、外部点击关闭和焦点返回；
请提供有名称的导航地标。

原始条目始终挂载，溢出时在原处隐藏，因此调整尺寸不会丢失其状态。打开菜单时会单独
渲染溢出条目的 React 副本，保留其 React 事件处理器和属性；副本内部状态相互独立，
关闭菜单后丢弃。请将共享状态提升到条目之外。避免在条目中使用 ID、嵌套交互菜单或
带挂载副作用的组件：副本和原始条目可能同时存在。测量及菜单链接行为要求直接使用
`NavItem` 和 `NavLink`。禁用的菜单链接无法激活；原始禁用链接也应移除 `href`。

服务端渲染或无 JavaScript 时导航换行并保持可见；水合后才开始测量溢出。此优先级
布局为横向布局；如果保留条目和触发器超出可用宽度，仍可能溢出。`threshold` 的最少
可见数量也可能超出可用宽度。

**迁移：**删除 `useNavOverflow`、Bootstrap 插件初始化和
`data-bs-toggle='nav-overflow'`，将插件数据属性改为下列 React 属性。不支持 HTML 字符串
`moreIcon`、插件事件、`menuStrategy` 和 Bootstrap 菜单移动；请改用 React 图标节点和
React 事件处理器。不要在此容器上初始化 Bootstrap 插件。

## 无障碍

适当时将列表导航包裹在有名称的 `nav` 地标中，不要在列表本身设置
`role='navigation'`。激活链接的 `aria-current` 默认为 `page`，可以覆盖。标签样式的
导航并不是标签页界面；除非实现完整的标签交互模式，否则不要添加标签角色。

`disabled` 只设置样式、`aria-disabled` 和 `tabIndex={-1}`，不会阻止带 `href` 的链接
被激活，也不会给按钮设置原生 `disabled` 属性。应移除目标地址或自行阻止激活；
按钮应使用原生按钮或自行设置原生 `disabled` 的自定义组件：`NavLink` 会消费自身的
`disabled` 属性，不会将其透传。

## API

所有组件均接受所选元素的原生属性，并通过 `BoxProps<C>` 继承
[`Box`](../box/README.zh.mdx#api) 工具类属性；`component` 可更换默认元素。

### Nav

默认渲染为 `ul`。自有属性如下：

| 属性          | 类型                               | 说明                                    |
| ------------- | ---------------------------------- | --------------------------------------- |
| `variant`     | `'tabs' \| 'pills' \| 'underline'` | 导航样式。                              |
| `orientation` | `'horizontal' \| 'vertical'`       | `vertical` 仅为胶囊导航添加纵向修饰类。 |
| `fill`        | `boolean`                          | 按比例分配空间。                        |
| `justified`   | `boolean`                          | 使各项等宽。                            |

### NavItem

默认渲染为 `li`，没有自有属性。

### NavLink

默认渲染为 `a`。自有属性为 `active?: boolean` 和 `disabled?: boolean`；
其行为详见无障碍说明。

### NavOverflow

默认渲染为 `div`，继承原生及 `Box` 属性。自有属性如下：

| 属性            | 类型               | 默认值              | 说明                                            |
| --------------- | ------------------ | ------------------- | ----------------------------------------------- |
| `moreText`      | `string`           | `'More'`            | 触发器文本；空字符串显示纯图标，名称为 “More”。 |
| `moreLabel`     | `string`           | 触发器文本或 `More` | 触发器的无障碍名称，也适用于纯图标触发器。      |
| `moreIcon`      | `ReactNode`        | 三点图标            | 触发器图标；使用 React 节点而非 HTML 字符串。   |
| `iconPlacement` | `'start' \| 'end'` | `'start'`           | 图标位置。                                      |
| `menuPlacement` | `MenuPlacement`    | `'bottom-end'`      | Floating UI 定位。                              |
| `collapseBelow` | `number \| string` | `0`                 | 容器像素宽度或 Bootstrap 断点名称。             |
| `threshold`     | `number`           | `0`                 | 溢出时的最少可见条目数；可能超出可用宽度。      |

### NavOverflowItem

默认渲染为 `li`，没有自有属性。为自定义溢出结构添加
`nav-overflow-item`；同时需要 `nav-item` 类时可使用 `component={NavItem}`。

### NavOverflowIcon

默认渲染为 `span`，没有自有属性。添加 `nav-overflow-icon`，并默认设置
`aria-hidden` 为 `true`。
