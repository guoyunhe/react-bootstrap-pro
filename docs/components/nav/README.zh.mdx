# Nav 导航

`Nav`、`NavItem` 和 `NavLink` 提供导航结构，支持标签、胶囊和下划线样式。
它们本身不会切换标签面板。

## 溢出导航

`NavOverflow` 为 Bootstrap 的 Priority+ 插件提供结构。插件测量容器，隐藏放不下的条目，
并将其链接克隆到 More 菜单。它通过 `ResizeObserver` 观察容器尺寸；不支持时退回监听
窗口尺寸变化。生成的菜单使用 Bootstrap JavaScript Menu 插件，而非本库的 React `Menu`。

示例通过[此辅助函数](./use-nav-overflow.ts)在挂载后初始化 Bootstrap 插件并在卸载时销毁。
只有加载插件并且 Bootstrap 的 `DOMContentLoaded` 处理器找到容器时，`data-bs-toggle`
才会触发数据 API；之后挂载的 React 内容需要显式初始化。Bootstrap 默认 CSS 会隐藏
未初始化的导航，因此没有 JavaScript 时，除非应用提供降级方案（例如不使用
`NavOverflow` 而直接渲染 `Nav`），否则导航和溢出菜单都无法使用。

插件克隆的是 DOM 节点，而不是 React 事件处理器或组件状态。溢出项应使用普通链接，
不要依赖克隆节点上的 React 事件处理器。动态更改列表时必须管理插件实例及其生命周期。
Bootstrap 的菜单移动逻辑依赖其自身的菜单结构，不能与 React 控制的 `Menu` 互换。

## 无障碍

适当时将列表导航包裹在有名称的 `nav` 地标中，不要在列表本身设置
`role='navigation'`。激活链接的 `aria-current` 默认为 `page`，可以覆盖。标签样式的
导航并不是标签页界面；除非实现完整的标签交互模式，否则不要添加标签角色。

`disabled` 只设置样式、`aria-disabled` 和 `tabIndex={-1}`，不会阻止带 `href` 的链接
被激活，也不会给按钮设置原生 `disabled` 属性。应移除目标地址或自行阻止激活；
按钮应使用原生按钮或自行设置原生 `disabled` 的自定义组件：`NavLink` 会消费自身的
`disabled` 属性，不会将其透传。

## API

所有组件均接受所选元素的原生属性，并通过 `BoxProps<C>` 继承
[`Box`](../box/README.zh.mdx#api) 工具类属性；`component` 可更换默认元素。

### Nav

默认渲染为 `ul`。自有属性如下：

| 属性          | 类型                               | 说明                                    |
| ------------- | ---------------------------------- | --------------------------------------- |
| `variant`     | `'tabs' \| 'pills' \| 'underline'` | 导航样式。                              |
| `orientation` | `'horizontal' \| 'vertical'`       | `vertical` 仅为胶囊导航添加纵向修饰类。 |
| `fill`        | `boolean`                          | 按比例分配空间。                        |
| `justified`   | `boolean`                          | 使各项等宽。                            |

### NavItem

默认渲染为 `li`，没有自有属性。

### NavLink

默认渲染为 `a`。自有属性为 `active?: boolean` 和 `disabled?: boolean`；
其行为详见无障碍说明。

### NavOverflow

默认渲染为 `div`，没有自有属性。`data-bs-toggle` 默认为 `nav-overflow`；
组件本身不会初始化插件。

### NavOverflowItem

默认渲染为 `li`，没有自有属性。为自定义 Bootstrap 溢出结构添加
`nav-overflow-item`；同时需要 `nav-item` 类时可使用 `component={NavItem}`。

### NavOverflowIcon

默认渲染为 `span`，没有自有属性。添加 `nav-overflow-icon`，并默认设置
`aria-hidden` 为 `true`。
