# Nav

`Nav` provides shared navigation markup and supports tabs, pills, and underline
styles. Use `aria-current="page"` for the current page link.

## Styles and layout

`variant` accepts `tabs`, `pills`, or `underline`. Use `orientation='vertical'`
for a vertical pill navigation; `fill` and `justified` distribute links across
the available width.

## API

### Nav

Renders a `ul` by default. Its own props are `fill?: boolean`,
`justified?: boolean`, `orientation?: 'horizontal' | 'vertical'`, and
`variant?: 'tabs' | 'pills' | 'underline'`; it inherits native props for the
selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

| Prop          | Type                               | Description                               |
| ------------- | ---------------------------------- | ----------------------------------------- |
| `variant`     | `'tabs' \| 'pills' \| 'underline'` | Selects the navigation style.             |
| `orientation` | `'horizontal' \| 'vertical'`       | Vertical layout is available for pills.   |
| `fill`        | `boolean`                          | Distributes links across available width. |
| `justified`   | `boolean`                          | Gives links equal widths.                 |
| `component`   | `ElementType`                      | Changes the root element.                 |
| `...props`    | `BoxProps<C>`                      | Native props and all Box utility props.   |

`NavItem` and `NavLink` render the corresponding item and link classes.

### NavItem

Renders an `li` by default and has no own props. It inherits native props and
all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### NavLink

Renders an `a` by default. Its own props are `active?: boolean` and
`disabled?: boolean`; active links default `aria-current` to `page`, and
disabled links receive `aria-disabled` and `tabIndex={-1}`. It inherits native
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Use `aria-current='page'` for the current page, or `aria-current='true'` for
the current item in a set. Use the tab component when links should switch
panels instead of navigating.
