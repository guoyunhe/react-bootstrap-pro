# Nav

`Nav`, `NavItem`, and `NavLink` provide navigation markup with optional tabs,
pills, and underline styles. They do not switch tab panels themselves.

## Tab behavior

For interactive tab panels, combine `Nav`, `NavItem`, and `NavLink tab` with
[TabContent and TabPane](../tab/README.mdx). Set `role='tablist'` on `Nav` and
`role='presentation'` on every `NavItem`. Navigation links styled as tabs are
not tab controls.

## Overflow

`NavOverflow` is a React Priority+ navigation. Pass one `Nav` or `NavbarNav`
containing direct `NavItem` children with `NavLink` links. It measures the
container and item widths with `ResizeObserver` (or window resize when unavailable)
and renders a Floating UI-backed React `Menu` for items that do not fit. No
Bootstrap JavaScript is needed. The default toggle supports arrow keys, Escape,
outside dismissal and focus return; provide a named navigation landmark.

Original items remain mounted, hidden in place when overflowed, so their state
survives resizing. The open menu renders separate React copies of overflowed
items, preserving their React handlers and props; state inside a menu copy is
independent and is discarded on close. Lift shared state above the items. Avoid
IDs inside items, nested interactive menus, or components with mounting side
effects: copies can exist alongside originals. Direct `NavItem` and `NavLink`
children are required for measurement and menu link behavior. Disabled menu
links cannot be activated; also remove `href` from disabled original links.

Server-rendered or no-JavaScript navigation wraps and remains visible; overflow
measurement starts after hydration. The priority layout is horizontal; if kept
items and the toggle exceed the available width, they may still overflow. The
`threshold` minimum can also exceed the available width.

**Migration:** remove `useNavOverflow`, Bootstrap plugin initialization and
`data-bs-toggle='nav-overflow'`. Replace the plugin's data attributes with the
React props below; HTML-string `moreIcon`, plugin events, `menuStrategy`, and
Bootstrap menu relocation are not supported. Use a React icon node and React
handlers instead. Do not initialize the Bootstrap plugin on this wrapper.

## Accessibility

Wrap list navigation in a named `nav` landmark when appropriate; do not put
`role='navigation'` on the list itself. An active link defaults to
`aria-current='page'`, which can be overridden. Navigation styled as tabs is
not a tab interface: do not add tab roles unless implementing the full tab
interaction pattern.

`disabled` supplies styling and, for anchors, `aria-disabled` and
`tabIndex={-1}`; it does not prevent activation of an anchor with `href`. Remove
the destination or implement appropriate activation prevention. A native
`button` receives the native `disabled` attribute instead.

## API

All components accept native props for their selected element and
[`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`;
`component` changes the default element.

### Nav

Renders `ul` by default. Its own props are:

| Prop          | Type                               | Description                                           |
| ------------- | ---------------------------------- | ----------------------------------------------------- |
| `variant`     | `'tabs' \| 'pills' \| 'underline'` | Navigation style.                                     |
| `orientation` | `'horizontal' \| 'vertical'`       | `vertical` adds the vertical modifier only for pills. |
| `fill`        | `boolean`                          | Distributes space proportionally.                     |
| `justified`   | `boolean`                          | Gives items equal width.                              |

### NavItem

Renders `li` by default and has no own props.

### NavLink

Renders `a` by default, or `button` when `tab` is set. Its own props are:

| Prop       | Type      | Description                                                                  |
| ---------- | --------- | ---------------------------------------------------------------------------- |
| `active`   | `boolean` | Applies `.active` and `aria-current='page'`, or `aria-selected` in tab mode. |
| `disabled` | `boolean` | Applies `.disabled` and disables the control.                                |
| `tab`      | `boolean` | Renders a button tab control with `role='tab'`.                              |
| `targetId` | `string`  | Tab mode: pane ID, mapped to `aria-controls` and `data-bs-target`.           |

Anchors receive `aria-disabled` and `tabIndex={-1}` when disabled; native
buttons use the native `disabled` attribute. In tab mode, `NavLink` also sets
`data-bs-toggle='tab'` from `targetId`.

### NavOverflow

Renders `div` by default, inheriting native and `Box` props. Its own props are:

| Prop            | Type               | Default               | Description                                                              |
| --------------- | ------------------ | --------------------- | ------------------------------------------------------------------------ |
| `moreText`      | `string`           | `'More'`              | Toggle label; an empty string uses an icon-only toggle named “More”.     |
| `moreLabel`     | `string`           | toggle text or `More` | Accessible toggle name, including for icon-only toggles.                 |
| `moreIcon`      | `ReactNode`        | three dots icon       | Toggle icon; use a React node, not an HTML string.                       |
| `iconPlacement` | `'start' \| 'end'` | `'start'`             | Icon position.                                                           |
| `menuPlacement` | `MenuPlacement`    | `'bottom-end'`        | Floating UI placement.                                                   |
| `collapseBelow` | `number \| string` | `0`                   | Container pixel width or Bootstrap breakpoint name.                      |
| `threshold`     | `number`           | `0`                   | Minimum visible item count when overflowing; may exceed available space. |

### NavOverflowItem

Renders `li` by default and has no own props. Adds `nav-overflow-item` for
custom overflow markup; use `component={NavItem}` when a `nav-item`
class is also needed.

### NavOverflowIcon

Renders `span` by default and has no own props. Adds `nav-overflow-icon` and
defaults `aria-hidden` to `true`.
