# Tab

`TabList`, `TabItem`, `Tab`, `TabContent`, and `TabPane` render Bootstrap's tab
markup and its ARIA relationships. `Tab` and `TabPane` are controlled through
`active`: keep the selected tab in React state and update it from the trigger
handlers, as in the examples. The components do not load Bootstrap JavaScript.

They still emit Bootstrap's `data-bs-toggle` and `data-bs-target` attributes
for markup parity, but the selected tab is controlled by the `active` props.

## With buttons

`TabList` renders a `ul` with `.nav .nav-tabs`. To keep a navigation landmark,
wrap it in a `<nav>` and render the list as a `div` with `component='div'`. Do
not put `role='tablist'` on the `<nav>` itself, because that would override its
native navigation role.

## API

### TabList

Renders a `ul` by default with `.nav .nav-tabs` and `role='tablist'`. It has no
own props and inherits native props for the selected element and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### TabItem

Renders an `li` by default with `.nav-item` and `role='presentation'`. It has no
own props and inherits native props and all [`Box`](../box/README.mdx#api) props
through `BoxProps<C>`.

### Tab

Renders a `button` by default with `.nav-link`, `type='button'`, and
`role='tab'`. It sets `aria-selected` from `active` and maps `targetId` to both
`aria-controls` and `data-bs-target`; `data-bs-toggle` defaults to `tab`.

| Prop       | Type      | Description                                 |
| ---------- | --------- | ------------------------------------------- |
| `active`   | `boolean` | Applies `.active` and sets `aria-selected`. |
| `targetId` | `string`  | ID of the controlled pane.                  |

Its own props are `active` and `targetId`; it inherits native button props and
all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### TabContent

Renders a `div` by default with `.tab-content`. It has no own props and inherits
native props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### TabPane

Renders a `div` by default with `.tab-pane`, `role='tabpanel'`, and `.active`
when `active` is set. Inactive panes also receive `hidden`.

| Prop     | Type      | Description                        |
| -------- | --------- | ---------------------------------- |
| `active` | `boolean` | Shows the pane and adds `.active`. |

Its own prop is `active`; it inherits native props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Tabs use `role='tablist'` on the list, `role='tab'` on each trigger, and
`role='tabpanel'` on each pane. Give every trigger a `targetId` matching its
pane `id`, and set `aria-labelledby` on the pane to the trigger `id`, as in the
examples.

`Tab` renders a native button, so Enter and Space activate the focused trigger.
The components do not implement roving `tabindex` or arrow-key navigation; all
tabs stay in the tab order. Add a keyboard handler to the tab list if you need
the full ARIA tabs pattern.

Make a panel focusable with `tabIndex={0}` when it contains no focusable content,
so keyboard users can reach its text. Use tabs for switching in-page panels, not
for navigating to another page. Color is only a visual cue: keep the visible
label on every trigger, and keep disabled triggers unavailable.
