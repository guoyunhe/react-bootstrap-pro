# Tab

`TabList`, `TabItem`, `Tab`, and `TabPane` provide Bootstrap tab markup and ARIA
relationships. Use the Bootstrap JavaScript bundle to switch tabs and update
their active state.

## Connect triggers and panels

Each trigger's `targetId` must match its panel `id`; the panel should label
itself with the corresponding trigger ID.

## API

### TabList

Renders a `ul` by default and has no own props. It inherits native props for
the selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

| Component prop   | Type          | Description                                   |
| ---------------- | ------------- | --------------------------------------------- |
| `TabItem`        | —             | Wraps each tab in a presentation list item.   |
| `Tab.active`     | `boolean`     | Applies the active state and `aria-selected`. |
| `Tab.targetId`   | `string`      | Links the trigger to its panel ID.            |
| `TabPane.active` | `boolean`     | Shows the panel and removes its hidden state. |
| `component`      | `ElementType` | Changes the rendered element.                 |
| `...props`       | `BoxProps<C>` | Native props and all Box utility props.       |

### TabItem

Renders an `li` by default and has no own props. It defaults to
`role="presentation"` and inherits native props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### Tab

Renders a `button` by default. Its own props are `active?: boolean` and
`targetId?: string`; it defaults to `type="button"` and `role="tab"` and maps
`targetId` to the controlled pane. It inherits native button props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### TabContent

Renders a `div` by default and has no own props. It inherits native `div` props
and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### TabPane

Renders a `div` by default. Its own prop is `active?: boolean`; it defaults to
`role="tabpanel"` and hides the pane when inactive. It inherits native props and
all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Keep `aria-controls`, `aria-labelledby`, `aria-selected`, and the active panel
state in sync. Use tabs for switching in-page panels, not for ordinary page
navigation.
