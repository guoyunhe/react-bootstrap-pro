# Tab

`TabList`, `TabItem`, `Tab`, and `TabPane` provide Bootstrap tab markup and ARIA
relationships. Use the Bootstrap JavaScript bundle to switch tabs and update
their active state.

<DemoContainer>
  <TabList aria-label='Example tabs'>
    <TabItem>
      <Tab id='home-tab' active targetId='home-pane'>
        Home
      </Tab>
    </TabItem>
    <TabItem>
      <Tab id='profile-tab' targetId='profile-pane'>
        Profile
      </Tab>
    </TabItem>
  </TabList>
  <TabContent>
    <TabPane active id='home-pane' aria-labelledby='home-tab'>
      Home content
    </TabPane>
    <TabPane id='profile-pane' aria-labelledby='profile-tab'>
      Profile content
    </TabPane>
  </TabContent>
</DemoContainer>

## API

| Component prop   | Type          | Description                                   |
| ---------------- | ------------- | --------------------------------------------- |
| `TabItem`        | —             | Wraps each tab in a presentation list item.   |
| `Tab.active`     | `boolean`     | Applies the active state and `aria-selected`. |
| `Tab.targetId`   | `string`      | Links the trigger to its panel ID.            |
| `TabPane.active` | `boolean`     | Shows the panel and removes its hidden state. |
| `component`      | `ElementType` | Changes the rendered element.                 |
| `...props`       | `BoxProps<C>` | Native props and all Box utility props.       |
