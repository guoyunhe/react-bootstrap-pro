# Form

Bootstrap's form controls extend the rebooted form styles with component
classes. `FormField`, `FormLabel`, `FormText`, and `FormControl` build a control
with its label and help text, while `Checkbox`, `Radio`, `Switch`, and `Range`
render the `.check` checkbox, `.radio` radio, `.switch` track, and `.form-range`
slider. `InputGroup` attaches add-ons to a control, `FormFloating` wraps a control and
label into a floating-label field, and `FormControl adorn` builds an adorned
control around a ghost input. Always set an appropriate `type` on inputs so
browsers provide the matching keyboard, validation, and autofill behavior.

## Disabled forms

Add the native `disabled` attribute to a single control, or disable a group of
controls with a `fieldset disabled`. Browsers ignore all native form controls
inside a disabled fieldset, including keyboard and mouse interaction.

<DemoContainer>
  <FormDisabledDemo />
</DemoContainer>

```tsx src='./demos/disabled.tsx'

```

A disabled fieldset still needs a `<legend>` so assistive technologies can name
the group.

## Form adorn

Set `adorn` on `FormControl` to render the `.form-adorn` wrapper: a
`.form-control` element that lays out adornments beside a "ghost input". Render
the wrapper as a `label` and put a `FormControl ghost` input inside it, so
clicking the icon, text, or padding focuses the control without JavaScript. Add
`adornEnd` to place the adornment on the trailing side.

`FormLabel` pointing at the ghost input through `htmlFor`.

## Accessibility

Give every control an accessible name. The simplest approach is a visible
`FormLabel` bound with `htmlFor`, or `aria-label` when no visible label is
possible. Associate help text with `aria-describedby`.

## API

### FormControl

| Prop        | Type           | Description                                                           |
| ----------- | -------------- | --------------------------------------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Scales height, padding, font size, and radius.                        |
| `plaintext` | `boolean`      | Renders `.form-control-plaintext` instead of `.form-control`.         |
| `ghost`     | `boolean`      | Renders `.form-ghost`, a borderless control for adorned fields.       |
| `adorn`     | `boolean`      | Adds `.form-adorn` to lay out adornments beside a ghost input.        |
| `adornEnd`  | `boolean`      | Adds `.form-adorn-end` and `.form-adorn` to place the adornment last. |
| `component` | `ElementType`  | Renders an `input` by default; also `textarea` or `select`.           |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props.                               |

### FormField

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Renders a `div` by default.             |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

### FormLabel

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Renders a `label` by default.           |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

### FormText

| Prop        | Type          | Description                                                  |
| ----------- | ------------- | ------------------------------------------------------------ |
| `component` | `ElementType` | Renders a `div` by default; use `span` for inline help text. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.                      |

### Checkbox

| Prop        | Type           | Description                                    |
| ----------- | -------------- | ---------------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Scales the checkbox and its label.             |
| `component` | `ElementType`  | Renders an `input type='checkbox'` by default. |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props.        |
