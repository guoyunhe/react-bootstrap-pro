# Form

Bootstrap's form controls extend the rebooted form styles with component
classes. `FormField`, `FormLabel`, `FormText`, and `FormControl` build a control
with its label and help text, while `FormCheck` renders a `.check` checkbox.
Always set an appropriate `type` on inputs so browsers provide the matching
keyboard, validation, and autofill behavior.

Use `FormControl` for inputs, textareas, and selects by changing `component`.
`FormText` renders the `.form-text` help text and can be associated with the
control through `aria-describedby`.

## Disabled forms

Add the native `disabled` attribute to a single control, or disable a group of
controls with a `fieldset disabled`. Browsers ignore all native form controls
inside a disabled fieldset, including keyboard and mouse interaction.

<DemoContainer>
  <FormDisabledDemo />
</DemoContainer>

```tsx src='./demos/disabled.tsx'

```

A disabled fieldset still needs a `<legend>` so assistive technologies can name
the group.

## Accessibility

Give every control an accessible name. The simplest approach is a visible
`FormLabel` bound with `htmlFor`, or `aria-label` when no visible label is
possible. Associate help text with `aria-describedby`.

## API

### FormControl

| Prop        | Type           | Description                                                 |
| ----------- | -------------- | ----------------------------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Scales height, padding, font size, and radius.              |
| `component` | `ElementType`  | Renders an `input` by default; also `textarea` or `select`. |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props.                     |

### FormField

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Renders a `div` by default.             |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

### FormLabel

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Renders a `label` by default.           |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

### FormText

| Prop        | Type          | Description                                                  |
| ----------- | ------------- | ------------------------------------------------------------ |
| `component` | `ElementType` | Renders a `div` by default; use `span` for inline help text. |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props.                      |

### FormCheck

| Prop        | Type           | Description                                    |
| ----------- | -------------- | ---------------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Scales the checkbox and its label.             |
| `component` | `ElementType`  | Renders an `input type='checkbox'` by default. |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props.        |
