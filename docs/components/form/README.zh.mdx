# Form 表单

Bootstrap 表单控件在 Reboot 表单样式之上提供组件类。`FormField`、`FormLabel` 和
`FormText` 组合出带标签与帮助文本的控件；[`Input`](../input/README.zh.mdx)、
[`Select`](../select/README.zh.mdx) 和 [`Textarea`](../textarea/README.zh.mdx) 分别封装
对应的原生元素。`Checkbox`、`Radio`、`Switch` 和 `Range` 分别渲染 `.check` 复选框、
`.radio` 单选按钮、`.switch` 开关与 `.form-range` 滑块；`InputGroup` 为控件挂载附加
内容，`FormFloating` 将控件与标签包装为浮动标签字段，`FormControl` 可包装 ghost
`Input` 和装饰元素。请始终为输入框设置合适的 `type`，以便浏览器提供对应
的键盘、校验与自动填充行为。

## 浮动标签

`FormFloating` 包裹标签与控件，构建浮动标签。将标签放在控件之前，并通过
`htmlFor` 绑定。文本控件需要非空 `placeholder`，因为纯 CSS 实现依赖
`:placeholder-shown` 判断空值。控件未聚焦时占位文本是透明的。

## 布局

表单默认纵向堆叠，因为 Bootstrap 为几乎所有表单控件设置了 `display: block` 与
`width: 100%`。可以按表单使用间距工具类、栅格与弹性布局工具类来改变这种排列。请将每
组字段放在 `<form>` 中，并为每个按钮显式设置 `type`，因为表单内的 `<button>` 默认是
`type="submit"`。

添加下外边距。为了保持一致，整个表单建议只使用一个方向的外边距。

## 表单校验

使用 Bootstrap 的表单校验样式提供可操作的反馈。`Form` 管理 `data-bs-validate`
开关和 `aria-invalid`，`FormFeedback` 渲染反馈文本，控件通过 `validation` 属性支持
服务端校验状态。

### 工作原理

- **客户端校验**基于 `data-bs-validate` 作用域内的 CSS 伪类。为 `Form` 设置
  `validation` 可启用 `:user-invalid` 样式，用户与控件交互后才会显示。
- 默认**只显示无效样式**。设置 `validation='valid'` 可同时显示有效样式。
- **服务端校验**通过控件的 `validation` 属性直接渲染 `.is-valid` 或 `.is-invalid`，
  无需用户交互。
- `FormFeedback` 渲染 `.invalid-feedback`、`.valid-feedback` 或它们的 tooltip 变体。
- 设置 `validation` 时，`Form` 默认启用 `noValidate`，提交时检查有效性，并在用户修正
  已标记的控件时更新 `aria-invalid`。

### 自定义样式

在 `Form` 上设置 `validation`，并为每个 `FormFeedback` 添加 `id`，让控件通过
`aria-describedby` 关联反馈文本。为必填字段添加 `required` 并提供针对性的提示。

`Form` 在提交时调用 `checkValidity()`、为符合条件的控件设置 `aria-invalid`，并在存在
无效字段时阻止提交。

  <ValidationCustomDemo />
</DemoContainer>

```tsx src='./demos/validation-custom.tsx'

```

浏览器使用自带的提示气泡进行校验。这些提示的样式随浏览器与操作系统不同，且无法通过
CSS 定制。

### 服务端校验

通过控件的 `validation` 属性标记服务端返回的有效与无效字段。可以同时渲染两种反馈
文本，由状态决定显示哪一个。


请传入 `d='block'`，因为反馈位于 `.form-floating` 包装之外。

`Range`、`ChipInput`、`Combobox` 与 `OTPInput` 都支持 `validation='valid' | 'invalid'`。
为装饰输入框的 `FormControl` 设置 `validation` 可调整容器样式；输入组与浮动标签可
使用内部控件的状态。

## 无障碍

每个控件都需要可访问名称。最简单的方式是用 `htmlFor` 绑定可见的 `FormLabel`；
没有可见标签时可用 `aria-label`。帮助文本通过 `aria-describedby` 关联。浮动标签的
占位文本不能作为可访问名称，因此请保留可见标签。

通过 `aria-describedby` 将反馈文本与控件关联。设置 `validation` 时，`Form` 在提交时为
符合条件的控件设置 `aria-invalid`，并在用户修正已标记控件时持续同步。对于不依赖焦点
变化出现的提示，可使用 `aria-live` 或状态元素；标签与反馈文本应针对具体字段。

## API

### FormControl

默认渲染为 `div`。

| 属性         | 类型                   | 说明                                              |
| ------------ | ---------------------- | ------------------------------------------------- |
| `adorn`      | `boolean`              | 添加 `.form-adorn`，排列装饰元素和 ghost 输入框。 |
| `adornEnd`   | `boolean`              | 添加 `.form-adorn` 并将装饰元素放在末尾。         |
| `size`       | `'sm' \| 'lg'`         | 为容器应用小型或大型表单控件尺寸。                |
| `validation` | `'valid' \| 'invalid'` | 为容器应用对应的校验状态类。                      |

继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于
选择渲染元素的 `component`。容器内包含 ghost 输入框时，可使用 `component='label'`。

### FormAdornIcon

默认渲染为 `div` 并添加 `.form-adorn-icon`，没有额外属性。继承所选元素的原生属性
及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于选择渲染元素的 `component`。
装饰性图标应设置 `aria-hidden='true'`。

### FormAdornText

默认渲染为 `span` 并添加 `.form-adorn-text`，没有额外属性。继承所选元素的原生属性
及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于选择渲染元素的 `component`。
装饰性文字应设置 `aria-hidden='true'`。

### Form

默认渲染为 `form`。

| 属性         | 类型                                | 说明                                                                     |
| ------------ | ----------------------------------- | ------------------------------------------------------------------------ |
| `validation` | `boolean \| 'valid'`                | 启用校验处理；`true` 添加 `data-bs-validate`，`'valid'` 还显示有效样式。 |
| `onSubmit`   | `FormEventHandler<HTMLFormElement>` | 校验后调用；无效时 `event.defaultPrevented` 为 `true`。                  |
| `onInput`    | `FormEventHandler<HTMLFormElement>` | 与内部 `aria-invalid` 更新一同调用。                                     |

继承原生 form 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。提供
`validation` 时，原生 `noValidate` 属性默认为 `true`。传入 `validation={false}`
仍会启用提交检查并使 `noValidate` 默认为 `true`，但不会添加 `data-bs-validate`。

### FormFeedback

默认渲染为 `div`。

| 属性      | 类型                   | 说明                                     |
| --------- | ---------------------- | ---------------------------------------- |
| `type`    | `'valid' \| 'invalid'` | 渲染有效或无效反馈，默认为 `'invalid'`。 |
| `tooltip` | `boolean`              | 渲染校验 tooltip，而非行内反馈。         |

继承原生 `div` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于
`aria-describedby` 的 `id`。继承的 `component` 属性类型限定为 `'div'`。

### FormFloating

默认渲染为 `div`。

| 属性     | 类型      | 说明                               |
| -------- | --------- | ---------------------------------- |
| `always` | `boolean` | 标签始终浮动，且占位文本保持可见。 |

继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于
选择渲染元素的 `component`。

### FormField

默认渲染为 `div`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于选择渲染元素的 `component`。

### FormFieldContent

默认渲染为 `div`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于选择渲染元素的 `component`。

### FormLabel

默认渲染为 `label`。

| 属性  | 类型                      | 说明                                                              |
| ----- | ------------------------- | ----------------------------------------------------------------- |
| `col` | `boolean \| 'sm' \| 'lg'` | 水平表单中渲染 `.col-form-label`；`'sm'` 与 `'lg'` 匹配控件尺寸。 |

继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括用于
选择渲染元素的 `component`。

### FormText

默认渲染为 `div`，没有额外属性。继承所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`；行内帮助文本可用
`span`。
