# Form 表单

Bootstrap 表单控件在 Reboot 表单样式之上提供组件类。`FormField`、`FormLabel` 和
`FormText` 组合出带标签与帮助文本的控件；[`Input`](../input/README.zh.mdx)、
[`Select`](../select/README.zh.mdx) 和 [`Textarea`](../textarea/README.zh.mdx) 分别封装
对应的原生元素。`Checkbox`、`Radio`、`Switch` 和 `Range` 分别渲染 `.check` 复选框、
`.radio` 单选按钮、`.switch` 开关与 `.form-range` 滑块；`InputGroup` 为控件挂载附加
内容，`FormFloating` 将控件与标签包装为浮动标签字段，带装饰控件则由 ghost `Input`
与 `.form-adorn` 容器组合而成。请始终为输入框设置合适的 `type`，以便浏览器提供对应
的键盘、校验与自动填充行为。

## 禁用表单

浏览器会忽略禁用 fieldset 内所有原生表单控件的键盘与鼠标交互。

## 浮动标签

`FormFloating` 包裹标签与控件，构建浮动标签。将标签放在控件之前，并通过
`htmlFor` 绑定。文本控件需要非空 `placeholder`，因为纯 CSS 实现依赖
`:placeholder-shown` 判断空值。控件未聚焦时占位文本是透明的。

## 装饰控件

将 ghost `Input` 放入带有
`classNameBefore='form-control form-adorn'` 的 `Box component='label'`，即可让装饰元素
与输入框并排；点击图标、文字或内边距即可聚焦控件，无需 JavaScript。在容器上添加

## 布局

表单默认纵向堆叠，因为 Bootstrap 为几乎所有表单控件设置了 `display: block` 与
`width: 100%`。可以按表单使用间距工具类、栅格与弹性布局工具类来改变这种排列。请将每
组字段放在 `<form>` 中，并为每个按钮显式设置 `type`，因为表单内的 `<button>` 默认是
`type="submit"`。

### 工具类

间距工具类是添加结构最简单的方式：把标签、控件与帮助文本放进 `FormField`，再给分组
添加下外边距。为了保持一致，整个表单建议只使用一个方向的外边距。

<DemoContainer>
  <FormLayoutUtilitiesDemo />
</DemoContainer>

```tsx src='./demos/layout-utilities.tsx'

```

### 表单栅格

需要多列、不同宽度或更多对齐方式时，使用 `Row` 与 `Col`。除非指定跨度，同一行中的
列会均分可用宽度。

响应式的 `Col` 跨度，可构建更复杂的布局。

### 水平表单

将每组字段放进 `Row`，并分别为标签与控件设置 `Col` 跨度，即可创建水平表单。在
`FormLabel` 上设置 `col` 会渲染 `.col-form-label`，让标签与控件对齐。

`FormLabel component='legend' col` 渲染 `legend`，在同一个 `Col` 内用
`FormField mb={1}` 逐项堆叠选项。

## 无障碍

每个控件都需要可访问名称。最简单的方式是用 `htmlFor` 绑定可见的 `FormLabel`；
没有可见标签时可用 `aria-label`。帮助文本通过 `aria-describedby` 关联。浮动标签的
占位文本不能作为可访问名称，因此请保留可见标签。

## API

### FormFloating

默认渲染为 `div`。自有属性为 `always`；继承所选元素的原生属性及通过
`BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

| 属性        | 类型          | 说明                                      |
| ----------- | ------------- | ----------------------------------------- |
| `always`    | `boolean`     | 标签始终浮动，且占位文本保持可见。        |
| `component` | `ElementType` | 指定渲染元素，默认为 `div`。              |
| `...props`  | `BoxProps<C>` | 所选元素的原生属性及全部 Box 工具类属性。 |

### FormField

| 属性        | 类型          | 说明                            |
| ----------- | ------------- | ------------------------------- |
| `component` | `ElementType` | 默认渲染 `div`。                |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |

### FormLabel

| 属性        | 类型                      | 说明                                                              |
| ----------- | ------------------------- | ----------------------------------------------------------------- |
| `col`       | `boolean \| 'sm' \| 'lg'` | 水平表单中渲染 `.col-form-label`；`'sm'` 与 `'lg'` 匹配控件尺寸。 |
| `component` | `ElementType`             | 默认渲染 `label`。                                                |
| `...props`  | `BoxProps<C>`             | 原生属性及所有 Box 工具类属性。                                   |

### FormText

| 属性        | 类型          | 说明                                      |
| ----------- | ------------- | ----------------------------------------- |
| `component` | `ElementType` | 默认渲染 `div`；行内帮助文本可用 `span`。 |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。           |
