# Form 表单

Bootstrap 表单控件在 Reboot 表单样式之上提供组件类。`FormField`、`FormLabel`、
`FormText` 和 `FormControl` 组合出带标签与帮助文本的控件，`Checkbox`、`Radio`、
`Switch` 和 `Range` 分别渲染 `.check` 复选框、`.radio` 单选按钮、`.switch` 开关与
`.form-range` 滑块；`InputGroup` 为控件挂载附加内容，`FormFloating` 将控件与标签
包装为浮动标签字段，`FormControl adorn` 则围绕 ghost 输入框构建带装饰控件的字段。
请始终为输入框设置合适的 `type`，以便浏览器提供对应的键盘、校验与自动填充行为。

## 禁用表单

为单个控件添加原生 `disabled` 属性，或使用 `fieldset disabled` 禁用一组控件。
浏览器会忽略禁用 fieldset 内所有原生表单控件的键盘与鼠标交互。

  <FormDisabledDemo />


禁用的 fieldset 仍需要 `<legend>`，以便辅助技术说明该控件组。

## 装饰控件

在 `FormControl` 上设置 `adorn` 会渲染 `.form-adorn` 容器：它本身是
`.form-control`，用 flex 布局把装饰元素与「ghost 输入框」并排。把容器渲染为
`label`，并在其中放入 `FormControl ghost` 输入框，点击图标、文字或内边距即可聚焦
控件，无需 JavaScript。添加 `adornEnd` 可将装饰元素放到末尾。

<DemoContainer>
  <FormAdornBasicDemo />
</DemoContainer>

```tsx src='./demos/adorn-basic.tsx'

```

图标使用 `.form-adorn-icon`，货币符号、域名后缀等文字使用 `.form-adorn-text`。
两者都是装饰性的，需要标记 `aria-hidden='true'`。

<DemoContainer>
  <FormAdornTextDemo />
</DemoContainer>

```tsx src='./demos/adorn-text.tsx'

```

```tsx src='./demos/adorn-field.tsx'

```

`FormLabel` 通过 `htmlFor` 指向 ghost 输入框来命名该字段。

## 布局

表单默认纵向堆叠，因为 Bootstrap 为几乎所有表单控件设置了 `display: block` 与
`width: 100%`。可以按表单使用间距工具类、栅格与弹性布局工具类来改变这种排列。请将每
组字段放在 `<form>` 中，并为每个按钮显式设置 `type`，因为表单内的 `<button>` 默认是
`type="submit"`。

### 工具类

间距工具类是添加结构最简单的方式：把标签、控件与帮助文本放进 `FormField`，再给分组
添加下外边距。为了保持一致，整个表单建议只使用一个方向的外边距。

  <FormLayoutUtilitiesDemo />
</DemoContainer>

需要多列、不同宽度或更多对齐方式时，使用 `Row` 与 `Col`。除非指定跨度，同一行中的

响应式的 `Col` 跨度，可构建更复杂的布局。

### 水平表单

将每组字段放进 `Row`，并分别为标签与控件设置 `Col` 跨度，即可创建水平表单。在
`FormLabel` 上设置 `col` 会渲染 `.col-form-label`，让标签与控件对齐。

<DemoContainer>
  <FormLayoutHorizontalDemo />
</DemoContainer>

```tsx src='./demos/layout-horizontal.tsx'

```

将一组复选框或单选按钮放进 `fieldset`，并用
`FormLabel component='legend' col` 渲染 `legend`，在同一个 `Col` 内用
`FormField mb={1}` 逐项堆叠选项。

`size='lg'` 的尺寸。

### 列宽

为部分列指定数字 `span`，其余列不设置跨度，它们会均分剩余空间。使用
`span={{ sm: true }}` 可渲染不带数字的 `sm:col` 类。

`Col span='auto'` 让列宽由内容决定。配合 `Row` 的 `alignItems='center'` 可让输入框、
复选框与按钮垂直居中；需要固定宽度时，把自动列换成指定跨度的列。

## 无障碍

每个控件都需要可访问名称。最简单的方式是用 `htmlFor` 绑定可见的 `FormLabel`；
没有可见标签时可用 `aria-label`。帮助文本通过 `aria-describedby` 关联。

## API

### FormControl

| 属性        | 类型           | 说明                                                          |
| ----------- | -------------- | ------------------------------------------------------------- |
| `size`      | `'sm' \| 'lg'` | 调整高度、内边距、字号和圆角。                                |
| `plaintext` | `boolean`      | 渲染 `.form-control-plaintext` 而非 `.form-control`。         |
| `ghost`     | `boolean`      | 渲染无边框的 `.form-ghost`，用于装饰控件字段。                |
| `adorn`     | `boolean`      | 添加 `.form-adorn`，把装饰元素与 ghost 输入框并排布局。       |
| `adornEnd`  | `boolean`      | 添加 `.form-adorn-end` 与 `.form-adorn`，将装饰元素放到末尾。 |
| `component` | `ElementType`  | 默认渲染 `input`，也可渲染 `textarea` 或 `select`。           |
| `...props`  | `BoxProps<C>`  | 原生属性及所有 Box 工具类属性。                               |

### FormField

| 属性        | 类型          | 说明                            |
| ----------- | ------------- | ------------------------------- |
| `component` | `ElementType` | 默认渲染 `div`。                |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |

### FormLabel

| 属性        | 类型                      | 说明                                                              |
| ----------- | ------------------------- | ----------------------------------------------------------------- |
| `col`       | `boolean \| 'sm' \| 'lg'` | 水平表单中渲染 `.col-form-label`；`'sm'` 与 `'lg'` 匹配控件尺寸。 |
| `component` | `ElementType`             | 默认渲染 `label`。                                                |
| `...props`  | `BoxProps<C>`             | 原生属性及所有 Box 工具类属性。                                   |

### FormText

| 属性        | 类型          | 说明                                      |
| ----------- | ------------- | ----------------------------------------- |
| `component` | `ElementType` | 默认渲染 `div`；行内帮助文本可用 `span`。 |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。           |

### Checkbox

| 属性        | 类型           | 说明                               |
| ----------- | -------------- | ---------------------------------- |
| `size`      | `'sm' \| 'lg'` | 调整复选框及其标签的尺寸。         |
| `component` | `ElementType`  | 默认渲染 `input type='checkbox'`。 |
| `...props`  | `BoxProps<C>`  | 原生属性及所有 Box 工具类属性。    |
