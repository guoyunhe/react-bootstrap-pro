# Stepper

`Stepper` renders an ordered list of steps. Set `active` on completed and
current steps, and use the responsive `horizontal` option when space allows.

## Example

<DemoContainer>
  <Stepper>
    <StepperItem active>Create account</StepperItem>
    <StepperItem active aria-current='step'>
      Confirm email
    </StepperItem>
    <StepperItem>Finish</StepperItem>
  </Stepper>
</DemoContainer>

## Responsive layout

```tsx
<Stepper horizontal='md'>
  <StepperItem active>Step one</StepperItem>
  <StepperItem>Step two</StepperItem>
</Stepper>
```

## API

| Prop         | Type                                               | Description                                           |
| ------------ | -------------------------------------------------- | ----------------------------------------------------- |
| `horizontal` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Switches to horizontal layout.                        |
| `overflow`   | `boolean`                                          | Enables horizontal scrolling for long step sequences. |
| `component`  | `ElementType`                                      | Changes the ordered-list element.                     |
| `...props`   | `BoxProps<C>`                                      | Native props and all Box utility props.               |

`StepperItem` renders a numbered step and supports `active`.

## Accessibility

Mark the current step with `aria-current='step'`. Keep the source order
meaningful because the ordered list also conveys the sequence.
