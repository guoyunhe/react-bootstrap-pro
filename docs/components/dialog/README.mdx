# Dialog

## How it works

`Dialog` renders the native `<dialog>` element and adds Bootstrap's dialog
classes. Pass `show` and `onShowChange` to control it with React. Without `show`,
it remains an uncontrolled native dialog that can be used with browser methods
or Invoker Commands.

`showModal()` opens a modal dialog in the browser's top layer, displays the
backdrop, and makes the rest of the document inert. `show()` and the `open`
attribute create a non-modal dialog. In controlled mode, `nonmodal` selects
`show()` and adds a positioning class.

## Static backdrop

By default, clicking the backdrop dismisses a modal dialog. Set
`backdrop='static'` on the dialog to keep it open when the backdrop is
clicked. The close button and Escape key still dismiss it unless

## Non-modal dialogs

Controlled dialogs open modally by default. Set `nonmodal` to call the native
`show()` method instead.
A non-modal dialog has no backdrop, does not trap focus, and leaves the rest of
the page interactive. Escape requests closure when focus is inside the dialog,
unless `keyboard={false}` is set.

## React behavior

`show` is controlled state; update it in `onShowChange` and wire close buttons
to the same state. Modal dialogs lock page scrolling; `nonmodal` opens a
non-modal dialog. `backdrop='static'` prevents backdrop dismissal, while
`backdrop={false}` hides the backdrop but keeps the dialog modal. Set
`keyboard={false}` to prevent Escape from requesting closure. Closing waits
for CSS transitions. Plugin data APIs and events are not supported.

## API

### Dialog

Renders a native `<dialog>` by default. `component` can override the element;
when doing so, the replacement must support the dialog behavior you use.

| Prop           | Type                      | Default | Description                                                                 |
| -------------- | ------------------------- | ------- | --------------------------------------------------------------------------- |
| `show`         | `boolean`                 | —       | Controls the native dialog's open state.                                    |
| `onShowChange` | `(show: boolean) => void` | —       | Requests an open-state change.                                              |
| `backdrop`     | `boolean \| 'static'`     | `true`  | Controls backdrop visibility and dismissal.                                 |
| `keyboard`     | `boolean`                 | `true`  | Allow Escape to request closure.                                            |
| `size`         | `'sm' \| 'lg' \| 'xl'`    | —       | Sets the dialog width; the default width is `500px`.                        |
| `fullscreen`   | `boolean`                 | `false` | Makes the dialog fill the viewport.                                         |
| `scrollable`   | `boolean`                 | `false` | Scrolls the body while keeping the header and footer in place.              |
| `nonmodal`     | `boolean`                 | `false` | Opens non-modally when controlled and adds the non-modal positioning class. |
| `instant`      | `boolean`                 | `false` | Disables dialog transitions.                                                |
| `slide`        | `'up' \| 'down'`          | —       | Selects the vertical entry and exit direction.                              |

Inherits native props for the selected element and all [`Box`](../box/README.mdx#api)
utility props, including `component` and `className`.

### DialogHeader

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DialogTitle

Renders an `h1` by default. It has no own props and inherits native heading
props and [`Box`](../box/README.mdx#api) utility props.

### DialogBody

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DialogFooter

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

## Accessibility

Give each dialog a visible `DialogTitle` and connect it with
`aria-labelledby`. Provide a clearly labeled close button. Opening a modal with
`showModal()` enables native focus management and makes
background content inert. The native Escape behavior can be disabled through
the `keyboard` prop.

Setting the `open` attribute alone does not create a modal dialog or backdrop.
Use the Invoker Commands API only where supported, and provide a JavaScript
fallback for browsers that do not support it.
