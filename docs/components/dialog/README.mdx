# Dialog

## How it works

`Dialog` renders the native `<dialog>` element and adds Bootstrap's dialog
classes. It does not manage open state by itself. Use Bootstrap's JavaScript
data API or the browser's `showModal()`, `show()`, and `close()` methods to
control it.

`showModal()` opens a modal dialog in the browser's top layer, displays the
backdrop, and makes the rest of the document inert. `show()` and the `open`
attribute create a non-modal dialog. The `nonmodal` prop only adds a positioning
class; it does not change how the dialog is opened.

## Static backdrop

By default, clicking the backdrop dismisses a modal dialog. Set
`data-bs-backdrop='static'` on the trigger to keep it open when the backdrop is
clicked. The close button and Escape key still dismiss it unless
`data-bs-keyboard='false'` is also set.

## Overlays

`document.body` appear behind it. Set `data-bs-container` to the dialog for

## Non-modal dialogs

The Bootstrap plugin opens modal dialogs by default. Set
`data-bs-modal='false'` on a trigger to call the native `show()` method instead.
A non-modal dialog has no backdrop, does not trap focus, and leaves the rest of
the page interactive. It still closes with Escape unless
`data-bs-keyboard='false'` is set.

## JavaScript behavior

The React components provide markup and classes; they do not manage visibility
or expose Bootstrap plugin options as React props. The page imports Bootstrap's
JavaScript bundle for the examples below. For an application, load the bundle
once or control the native `<dialog>` element through a ref.

### Data attributes

| Attribute                    | Description                                 |
| ---------------------------- | ------------------------------------------- |
| `data-bs-toggle='dialog'`    | Opens or toggles the target dialog.         |
| `data-bs-target='#myDialog'` | Selects the dialog to control.              |
| `data-bs-dismiss='dialog'`   | Closes the dialog when activated inside it. |
| `data-bs-backdrop='static'`  | Prevents dismissal from a backdrop click.   |
| `data-bs-keyboard='false'`   | Prevents dismissal with Escape.             |
| `data-bs-modal='false'`      | Opens the dialog non-modally with `show()`. |

### JavaScript API

The Bootstrap `Dialog` plugin accepts `backdrop`, `keyboard`, and `modal`
options. These are plugin options, not `Dialog` component props.

| Option     | Type                  | Default | Description                                                                 |
| ---------- | --------------------- | ------- | --------------------------------------------------------------------------- |
| `backdrop` | `boolean \| 'static'` | `true`  | Dismiss on backdrop click, keep open with `'static'`, or hide the backdrop. |
| `keyboard` | `boolean`             | `true`  | Dismiss when Escape is pressed.                                             |
| `modal`    | `boolean`             | `true`  | Use `showModal()` when true or `show()` when false.                         |

Use the plugin instance for imperative control:

```js
const dialog = new bootstrap.Dialog('#myDialog', { modal: false });
await dialog.show();
await dialog.hide();
```

The plugin also provides `toggle`, `dispose`, `getInstance`, and
`getOrCreateInstance`. `handleUpdate` is provided for API consistency; native
dialogs handle their own positioning.

| Event                     | Description                                 |
| ------------------------- | ------------------------------------------- |
| `show.bs.dialog`          | Fires when opening begins.                  |
| `shown.bs.dialog`         | Fires after the dialog is visible.          |
| `hide.bs.dialog`          | Fires when closing begins.                  |
| `hidden.bs.dialog`        | Fires after the dialog is hidden.           |
| `hidePrevented.bs.dialog` | Fires when a static backdrop blocks hiding. |
| `cancel.bs.dialog`        | Fires when Escape is pressed.               |

## API

### Dialog

Renders a native `<dialog>` by default. `component` can override the element;
when doing so, the replacement must support the dialog behavior you use.

| Prop         | Type                   | Default | Description                                                                                   |
| ------------ | ---------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg' \| 'xl'` | —       | Sets the dialog width; the default width is `500px`.                                          |
| `fullscreen` | `boolean`              | `false` | Makes the dialog fill the viewport.                                                           |
| `scrollable` | `boolean`              | `false` | Scrolls the body while keeping the header and footer in place.                                |
| `nonmodal`   | `boolean`              | `false` | Adds the non-modal positioning class; use `show()` or the plugin's `modal: false` to open it. |
| `instant`    | `boolean`              | `false` | Disables dialog transitions.                                                                  |
| `slide`      | `'up' \| 'down'`       | —       | Selects the vertical entry and exit direction.                                                |

Inherits native props for the selected element and all [`Box`](../box/README.mdx#api)
utility props, including `component` and `className`.

### DialogHeader

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DialogTitle

Renders an `h1` by default. It has no own props and inherits native heading
props and [`Box`](../box/README.mdx#api) utility props.

### DialogBody

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DialogFooter

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

## Accessibility

Give each dialog a visible `DialogTitle` and connect it with
`aria-labelledby`. Provide a clearly labeled close button. Opening a modal with
`showModal()` or the Bootstrap plugin enables native focus management and makes
background content inert. The native Escape behavior can be disabled through
the plugin's `keyboard` option.

Setting the `open` attribute alone does not create a modal dialog or backdrop.
Use the Invoker Commands API only where supported, and provide a JavaScript
fallback for browsers that do not support it.
