# Dialog

`Dialog` defaults to the native `<dialog>` element. Use Bootstrap's JavaScript
plugin or the native `showModal()` API to open a modal dialog; an `open`
attribute alone is non-modal.

## Modal behavior

Use `showModal()` or Bootstrap's dialog plugin for modal focus and backdrop
behavior. The `open` attribute alone only opens the native dialog non-modally.

## API

| Prop         | Type                   | Description                                                 |
| ------------ | ---------------------- | ----------------------------------------------------------- |
| `size`       | `'sm' \| 'lg' \| 'xl'` | Sets the dialog width.                                      |
| `fullscreen` | `boolean`              | Fills the viewport.                                         |
| `scrollable` | `boolean`              | Makes the body scroll while header and footer remain fixed. |
| `nonmodal`   | `boolean`              | Adds the non-modal positioning class.                       |
| `instant`    | `boolean`              | Disables transitions.                                       |
| `slide`      | `'up' \| 'down'`       | Selects the entry/exit direction.                           |
| `...props`   | `BoxProps<C>`          | Native dialog props and all Box utility props.              |

`DialogHeader`, `DialogTitle`, `DialogBody`, and `DialogFooter` provide the
corresponding structural classes.

## Accessibility

Associate the dialog with a visible title using `aria-labelledby`, and provide
a clear way to close it. Native modal dialogs manage focus when opened with
`showModal()`.
