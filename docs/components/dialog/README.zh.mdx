# Dialog 对话框

## 工作方式

`Dialog` 默认渲染原生 `<dialog>` 元素，并添加 Bootstrap 对话框类名；组件本身不管理
打开状态。可以使用 Bootstrap JavaScript data API，或浏览器原生的 `showModal()`、
`show()` 和 `close()` 方法控制对话框。

`showModal()` 会在浏览器顶层打开模态对话框、显示背景并使文档其他内容不可交互。
`show()` 和 `open` 属性会创建非模态对话框。`nonmodal` 属性只添加定位类，不会改变
打开方式。

| `--bs-dialog-border-color`        | `var(--bs-border-color-translucent)`                | 边框颜色。       |
| `--bs-dialog-border-width`        | `var(--bs-border-width)`                            | 边框宽度。       |
| `--bs-dialog-border-radius`       | `var(--bs-radius-7)`                                | 圆角。           |
| `--bs-dialog-box-shadow`          | `var(--bs-box-shadow-xl)`                           | 对话框阴影。     |
| `--bs-dialog-transition-property` | `opacity, transform, visibility`                    | 动画属性。       |
| `--bs-dialog-transition-duration` | `.3s`                                               | 过渡时长。       |

## JavaScript 行为

React 组件只提供标记和类名，不管理显示状态，也不会将 Bootstrap 插件选项作为 React
属性提供。本文通过 Bootstrap JavaScript bundle 演示 data API；应用中只需加载一次，
也可以通过 ref 调用原生 `<dialog>` 方法。

### Data attributes

| 属性                         | 说明                                   |
| ---------------------------- | -------------------------------------- |
| `data-bs-toggle='dialog'`    | 打开或切换目标对话框。                 |
| `data-bs-target='#myDialog'` | 指定要控制的对话框。                   |
| `data-bs-dismiss='dialog'`   | 在对话框内部关闭对话框。               |
| `data-bs-backdrop='static'`  | 点击背景时不关闭对话框。               |
| `data-bs-keyboard='false'`   | 禁止使用 Escape 关闭对话框。           |
| `data-bs-modal='false'`      | 使用 `show()` 以非模态方式打开对话框。 |

### JavaScript API

Bootstrap `Dialog` 插件支持 `backdrop`、`keyboard` 和 `modal` 选项。这些是插件选项，
不是 `Dialog` 组件属性。

| 选项       | 类型                  | 默认值 | 说明                                                   |
| ---------- | --------------------- | ------ | ------------------------------------------------------ |
| `backdrop` | `boolean \| 'static'` | `true` | 点击背景时关闭、设为 `'static'` 保持打开，或隐藏背景。 |
| `keyboard` | `boolean`             | `true` | 按下 Escape 时关闭。                                   |
| `modal`    | `boolean`             | `true` | `true` 使用 `showModal()`，`false` 使用 `show()`。     |

可通过插件实例进行命令式控制：

```js
const dialog = new bootstrap.Dialog('#myDialog', { modal: false });
await dialog.show();
await dialog.hide();
```

插件还提供 `toggle`、`dispose`、`getInstance` 和 `getOrCreateInstance`。`handleUpdate`
仅为 API 一致性保留；原生对话框会自行处理位置。

| 事件                      | 说明                     |
| ------------------------- | ------------------------ |
| `show.bs.dialog`          | 开始打开时触发。         |
| `shown.bs.dialog`         | 对话框显示完成后触发。   |
| `hide.bs.dialog`          | 开始关闭时触发。         |
| `hidden.bs.dialog`        | 对话框隐藏后触发。       |
| `hidePrevented.bs.dialog` | 静态背景阻止关闭时触发。 |
| `cancel.bs.dialog`        | 按下 Escape 时触发。     |

## API

### Dialog

默认渲染原生 `<dialog>`。`component` 可以覆盖默认元素；替换后的元素需要支持所使用的
对话框行为。

| 属性         | 类型                   | 默认值  | 说明                                                             |
| ------------ | ---------------------- | ------- | ---------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg' \| 'xl'` | —       | 设置对话框宽度；默认宽度为 `500px`。                             |
| `fullscreen` | `boolean`              | `false` | 让对话框填满视口。                                               |
| `scrollable` | `boolean`              | `false` | 滚动主体，同时固定页眉和页脚。                                   |
| `nonmodal`   | `boolean`              | `false` | 添加非模态定位类；需通过 `show()` 或插件的 `modal: false` 打开。 |
| `instant`    | `boolean`              | `false` | 禁用对话框过渡动画。                                             |
| `slide`      | `'up' \| 'down'`       | —       | 设置垂直进入与退出方向。                                         |

继承所选元素的原生属性及全部 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括
`component` 和 `className`。

### DialogHeader

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogTitle

默认渲染为 `h1`。没有自有属性；继承原生标题属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogBody

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogFooter

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

## 无障碍访问

为每个对话框提供可见的 `DialogTitle`，并通过 `aria-labelledby` 关联标题；同时提供
带有明确可访问名称的关闭按钮。使用 `showModal()` 或 Bootstrap 插件打开模态对话框时，
浏览器会管理焦点，并阻止交互背景内容。可通过插件的 `keyboard` 选项禁用原生 Escape
关闭行为。

单独设置 `open` 属性不会创建模态对话框或背景。仅在浏览器支持时使用 Invoker Commands
API；对不支持的浏览器应提供 JavaScript 回退方案。
