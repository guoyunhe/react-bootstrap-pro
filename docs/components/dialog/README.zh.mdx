# Dialog 对话框

## 工作方式

`Dialog` 默认渲染原生 `<dialog>` 元素，并添加 Bootstrap 对话框类名。通过 `show` 和
`onShowChange` 使用 React 控制打开状态；不提供 `show` 时仍可使用浏览器原生方法或
Invoker Commands 控制。

`showModal()` 会在浏览器顶层打开模态对话框、显示背景并使文档其他内容不可交互。
`show()` 和 `open` 属性会创建非模态对话框。在受控模式下，`nonmodal` 会使用 `show()`
并添加定位类。

## CSS

### CSS 变量

可在对话框上覆盖以下变量以自定义外观。

| 变量                              | 默认值                                              | 说明             |
| --------------------------------- | --------------------------------------------------- | ---------------- |
| `--bs-dialog-padding`             | `1rem`                                              | 主体内边距。     |
| `--bs-dialog-width`               | `500px`                                             | 对话框宽度。     |
| `--bs-dialog-margin`              | `1.75rem`                                           | 对话框周围间距。 |
| `--bs-dialog-color`               | `var(--bs-fg-body)`                                 | 文字颜色。       |
| `--bs-dialog-bg`                  | `var(--bs-bg-body)`                                 | 背景颜色。       |
| `--bs-dialog-border-color`        | `var(--bs-border-color-translucent)`                | 边框颜色。       |
| `--bs-dialog-border-width`        | `var(--bs-border-width)`                            | 边框宽度。       |
| `--bs-dialog-border-radius`       | `var(--bs-radius-7)`                                | 圆角。           |
| `--bs-dialog-box-shadow`          | `var(--bs-box-shadow-xl)`                           | 对话框阴影。     |
| `--bs-dialog-transition-property` | `opacity, transform, visibility`                    | 动画属性。       |
| `--bs-dialog-transition-duration` | `.3s`                                               | 过渡时长。       |
| `--bs-dialog-transition-timing`   | `var(--bs-transition-timing-overlay)`               | 过渡时间函数。   |

| `--bs-dialog-header-border-color` | `var(--bs-border-color-translucent)`                | 页眉分隔线颜色。 |
| `--bs-dialog-header-border-width` | `var(--bs-border-width)`                            | 页眉分隔线宽度。 |
| `--bs-dialog-footer-padding`      | `1rem`                                              | 页脚内边距。     |

## React 行为

`show` 为受控状态；请在 `onShowChange` 中更新状态，并为关闭按钮设置点击处理函数。
默认模态对话框锁定页面滚动；`nonmodal` 使用非模态对话框。`backdrop='static'` 阻止
背景点击关闭，`backdrop={false}` 隐藏背景但仍保持模态。`keyboard={false}` 禁止 Escape
请求关闭。关闭时等待 CSS 过渡；插件的 data API 和事件不受支持。

## API

### Dialog

默认渲染原生 `<dialog>`。`component` 可以覆盖默认元素；替换后的元素需要支持所使用的
对话框行为。

| 属性           | 类型                      | 默认值  | 说明                                   |
| -------------- | ------------------------- | ------- | -------------------------------------- |
| `show`         | `boolean`                 | —       | 控制原生对话框的打开状态。             |
| `onShowChange` | `(show: boolean) => void` | —       | 请求更新打开状态。                     |
| `backdrop`     | `boolean \| 'static'`     | `true`  | 控制背景显示和点击关闭行为。           |
| `keyboard`     | `boolean`                 | `true`  | 是否允许 Escape 请求关闭。             |
| `size`         | `'sm' \| 'lg' \| 'xl'`    | —       | 设置对话框宽度；默认宽度为 `500px`。   |
| `fullscreen`   | `boolean`                 | `false` | 让对话框填满视口。                     |
| `scrollable`   | `boolean`                 | `false` | 滚动主体，同时固定页眉和页脚。         |
| `nonmodal`     | `boolean`                 | `false` | 受控时以非模态方式打开，并添加定位类。 |
| `instant`      | `boolean`                 | `false` | 禁用对话框过渡动画。                   |
| `slide`        | `'up' \| 'down'`          | —       | 设置垂直进入与退出方向。               |

继承所选元素的原生属性及全部 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括
`component` 和 `className`。

### DialogHeader

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogTitle

默认渲染为 `h1`。没有自有属性；继承原生标题属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogBody

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DialogFooter

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

## 无障碍访问

为每个对话框提供可见的 `DialogTitle`，并通过 `aria-labelledby` 关联标题；同时提供
带有明确可访问名称的关闭按钮。使用 `showModal()` 打开模态对话框时，
浏览器会管理焦点，并阻止交互背景内容。可通过 `keyboard` 属性禁用原生 Escape
关闭行为。

单独设置 `open` 属性不会创建模态对话框或背景。仅在浏览器支持时使用 Invoker Commands
API；对不支持的浏览器应提供 JavaScript 回退方案。
