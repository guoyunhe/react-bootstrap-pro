# Button 按钮

`Button` 渲染原生 React `<button>`，并组合 Bootstrap 6 的按钮样式。应用使用
组件前，需要引入 Bootstrap CSS。

## 基础类

原生 `<button>` 是语义上的基础元素。Bootstrap 的 `.btn` 类提供共用基础样式；
React `Button` 组件始终添加 `.btn`；只有显式传入 `variant` 和 `theme` 时，
才会添加对应的样式类。

## 变体

Bootstrap 6 将样式与主题颜色分开组合。支持的 `variant` 有 `solid`、
`outline`、`subtle`、`text` 和 `link`；支持的主题有 `primary`、`accent`、
`secondary`、`success`、`danger`、`warning`、`info` 和 `inverse`。
`variant` 和 `theme` 均无默认值；两者都省略时只生成基础 `.btn` 类。

## 按钮标签

`Button` 默认渲染为 `<button>`。将 `component` 设置为其他原生元素或 React
组件即可切换渲染目标，目标组件的属性会自动推断。页面跳转可使用
`component='a'`，保留原生链接语义。

<DemoContainer>
  <ButtonTagsDemo />
</DemoContainer>

```tsx src='./demos/button-tags.tsx'

```

如果链接用于页面内操作而非导航，可添加 `role='button'`。禁用链接还需设置
`aria-disabled='true'` 并阻止导航；`disabled` 属性不会禁用 `<a>`。
也可以通过 `component='input'` 将组件渲染为原生 `<input>` 按钮。

## 禁用状态

Bootstrap 的 `.disabled` 类、设置 `aria-disabled`、移出键盘焦点顺序并阻止导航。

## 切换按钮

复选框和单选框保留原生表单语义。使用 `Button component='label' check` 添加
Bootstrap 的 `.btn-check` 样式，同时继续由输入框记录选择状态。

### 单选框

同名的 radio 输入组成单选组。每个输入框都应关联到对应的标签；上方示例展示了
选中、未选中和禁用状态。复选框会向辅助技术报告“已选中/未选中”，而 JavaScript
切换按钮会报告“按钮/按钮已按下”；应根据实际语义选择对应实现。

## Button 插件

Bootstrap JavaScript 插件会切换按钮的 `.active` 类和 `aria-pressed`。本 React
组件不会初始化 Bootstrap JavaScript，应改用 React 状态管理。`active` 属性会添加或
移除 `.active` 类；还应单独设置 `aria-pressed` 来表达按下状态。

<DemoContainer>

</DemoContainer>

```tsx src='./demos/toggle-button.tsx'

```

### 数据属性与插件方法

`Button` 会转发原生 `data-*` 属性，但 `data-bs-toggle='button'` 只有在 Bootstrap
JavaScript 已加载并初始化时才会生效。React 组件不提供 `toggle()` 等 Bootstrap
插件实例方法，应将状态保存在 React 中。不要让两套机制同时管理同一个按钮状态。

| 变量                                                | 说明                     |
| --------------------------------------------------- | ------------------------ |
| `--bs-btn-min-height`                               | 按钮最小高度             |
| `--bs-btn-padding-x` / `--bs-btn-padding-y`         | 水平和垂直内边距         |
| `--bs-btn-font-size` / `--bs-btn-line-height`       | 字号和行高               |
| `--bs-btn-border-radius`                            | 按钮圆角                 |
| `--bs-btn-gradient-start` / `--bs-btn-gradient-end` | `.btn-styled` 渐变颜色   |
| `--bs-btn-border-mix-color`                         | 混合到按钮边框的颜色     |
| `--bs-btn-border-mix-amount`                        | 边框颜色混合比例         |
| `--bs-btn-border-hover-mix-amount`                  | 悬停时的边框颜色混合比例 |
| `--bs-btn-border-active-mix-amount`                 | 按下时的边框颜色混合比例 |
| `--bs-btn-shadow` / `--bs-btn-active-shadow`        | 默认和按下状态的阴影     |

## API

### Button

| 属性         | 类型                          | 默认值                | 说明                                                                 |
| ------------ | ----------------------------- | --------------------- | -------------------------------------------------------------------- |
| `component`  | `C extends ElementType`       | `'button'`            | 要渲染的原生元素或 React 组件。                                      |
| `variant`    | `ButtonVariant`               | —                     | 按钮样式：`'solid'`、`'outline'`、`'subtle'`、`'text'` 或 `'link'`。 |
| `size`       | `'xs' \| 'sm' \| 'lg'`        | —                     | Bootstrap 按钮尺寸。不设置时使用默认尺寸。                           |
| `active`     | `boolean`                     | `false`               | 添加 `.active` 类；不会自动设置 `aria-pressed`。                     |
| `styled`     | `boolean`                     | `false`               | 添加 `.btn-styled` 修饰类。                                          |
| `check`      | `boolean`                     | `false`               | 添加 `.btn-check` 修饰类。                                           |
| `className`  | `string`                      | —                     | 附加类名，会与组件生成的类名合并。                                   |
| `type`       | `C` 的原生属性                | 仅 button：`'button'` | 渲染按钮元素时默认为 `'button'`。                                    |
| `disabled`   | `C` 的原生属性                | —                     | 支持时禁用渲染后的元素。                                             |
| `children`   | `C` 的原生属性                | —                     | 当前渲染组件接受的内容。                                             |
| 其他组件属性 | `ComponentPropsWithoutRef<C>` | —                     | 属性会根据渲染目标推断，并转发给该组件。                             |

继承当前渲染元素的原生属性（例如 `<button>` 或 `<a>`），以及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### IconButton

`IconButton` 默认渲染原生 `<button>`，并添加 `.btn-icon` 类；没有额外的专属属性。
它接受所有 [`Button`](#button) 属性，包括多态的 `component` 属性以及
[`Box`](../box/) 工具类属性。`IconButtonProps<C>` 是 `ButtonProps<C>` 的类型别名。

包入口导出 `Button`、`ButtonProps`、`ButtonTheme`、`ButtonVariant`、
`IconButton` 和 `IconButtonProps`。
