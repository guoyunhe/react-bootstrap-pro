# Button

`Button` renders a native React `<button>` with Bootstrap 6 button classes.
Import Bootstrap's stylesheet once in your application before using the
component.

## Base class

The native `<button>` is the semantic starting point. Bootstrap's `.btn` class
adds its shared base styles. The React `Button` component always adds `.btn`;
it only adds variant and theme classes when those props are provided.

<DemoContainer>
  <Button>{'Base Button'}</Button>
</DemoContainer>

```tsx
<Button>Base Button</Button>
```

Use the controls to preview theme colors, variants, sizes, content, and shape.

## Variants

Bootstrap combines a button style with a theme color. This component supports
the `solid`, `outline`, `subtle`, `text`, and `link` styles and the themes
`primary`, `accent`, `secondary`, `success`, `danger`, `warning`, `info`, and
`inverse`. Neither `variant` nor `theme` has a default; omit both to render only
the `.btn` base class.

<DemoContainer>
  <ButtonVariantsDemo />
</DemoContainer>

```tsx
<Button variant='solid' theme='primary'>
  Primary
</Button>
<Button variant='outline' theme='primary'>
  Primary outline
</Button>
<Button variant='subtle' theme='success'>
  Success subtle
</Button>
<Button variant='text' theme='secondary'>
  Secondary text
</Button>
```

Color is only a visual cue. Include visible text that communicates the action
and meaning to all users.

## Link buttons

Use `variant='link'` for a button that looks like a link. Set `theme` to color
it, or omit `theme` to use Bootstrap's default link color.

<DemoContainer>
  <ButtonLinkDemo />
</DemoContainer>

```tsx
<Button variant='link'>Default link color</Button>
<Button variant='link' theme='primary'>
  Primary link color
</Button>
```

## Styled buttons

Add `className='btn-styled'` to a solid button for the gradient and shadow
modifier. `className` is appended to the classes generated by `Button`.

<DemoContainer>
  <ButtonStyledDemo />
</DemoContainer>

```tsx
<Button variant='solid' theme='primary' className='btn-styled'>
  Styled primary
</Button>
```

## Button tags

Button classes are intended for `<button>` elements, but can also style anchors
and inputs. `Button` itself always renders a `<button>`; use a native anchor for
navigation and preserve its link semantics.

<DemoContainer>
  <ButtonTagsDemo />
</DemoContainer>

```tsx
<a className='btn-solid theme-primary' href='/settings'>
  Open settings
</a>
<a href='#details' className='btn-solid theme-primary' role='button'>
  Reveal details
</a>
<Button variant='solid' theme='primary' type='button'>
  Run action
</Button>
<input className='btn-solid theme-primary' type='button' value='Input button' />
<input className='btn-solid theme-secondary' type='submit' value='Submit' />
```

If an anchor performs an in-page action instead of navigation, add
`role='button'`. A disabled anchor needs `aria-disabled='true'` and must have
its navigation behavior prevented; unlike a native button, the `disabled`
attribute does not disable an anchor.

## Sizes

Use `size='xs'`, `size='sm'`, or `size='lg'`. Omit `size` for the default.

<DemoContainer>
  <ButtonSizesDemo />
</DemoContainer>

```tsx
<Button variant='solid' theme='primary' size='xs'>Extra small</Button>
<Button variant='solid' theme='primary' size='sm'>Small</Button>
<Button variant='solid' theme='primary'>Default</Button>
<Button variant='solid' theme='primary' size='lg'>Large</Button>
```

Use CSS variables for a custom size:

```tsx
<Button
  variant='solid'
  theme='primary'
  style={{
    '--bs-btn-padding-y': '.25rem',
    '--bs-btn-padding-x': '.5rem',
    '--bs-btn-font-size': '.75rem',
  }}
>
  Custom size
</Button>
```

## Icon buttons

Use `className='btn-icon'` for a square icon-only button. Always provide an
accessible name with `aria-label`. Combine it with a size to adjust the icon
button dimensions.

<DemoContainer>
  <ButtonIconDemo />
</DemoContainer>

```tsx
<Button variant='solid' theme='primary' className='btn-icon' aria-label='Add item'>
  <svg
    width='16'
    height='16'
    viewBox='0 0 16 16'
    fill='none'
    stroke='currentColor'
    aria-hidden='true'
  >
    <path d='M8 3v10M3 8h10' />
  </svg>
</Button>
```

For buttons with text and an icon, keep the text visible and mark decorative
icons with `aria-hidden='true'`.

## Disabled state

Use the native `disabled` prop to disable a button. It prevents activation and
applies Bootstrap's disabled styling.

<DemoContainer>
  <ButtonDisabledDemo />
</DemoContainer>

```tsx
<Button variant='solid' theme='primary' disabled>Saving</Button>
<Button variant='outline' theme='secondary' disabled>
  Cancel
</Button>
<a className='btn-solid theme-primary disabled' aria-disabled='true' tabIndex={-1}>
  Disabled link
</a>
```

For anchors, use the `.disabled` class and `aria-disabled='true'`. If the
anchor has an `href`, also remove it from keyboard navigation and prevent
navigation as needed.

## Block buttons

Use Bootstrap's grid and gap utilities to make buttons full width or stack them
vertically. Responsive display utilities can change the layout at a breakpoint.


## Toggle buttons

Checkbox and radio inputs provide native checked-state semantics. Bootstrap's
`.btn-check` styles a label like a button while retaining the input's form and
accessibility behavior.

### Checkboxes

Checkbox buttons toggle independently:

<DemoContainer>
  <ButtonInputToggleDemo />
</DemoContainer>

```tsx
<label className='btn-check btn-solid theme-primary'>
  <input type='checkbox' />
  Follow
</label>
```

### Radios

Radio buttons with the same `name` form a single-choice group. Associate every
input with a label as shown in the live demo above.

## Button plugin

Bootstrap's JavaScript button plugin toggles the `.active` class and
`aria-pressed`. This React component provides button styling and native props;
it does not initialize Bootstrap JavaScript. Prefer React state to keep the
rendered active state in sync.

<DemoContainer>
  <ButtonToggleDemo />
</DemoContainer>

```tsx
import { useState } from 'react';

function ToggleButton() {
  const [pressed, setPressed] = useState(false);

  return (
    <Button
      variant='solid'
      theme='primary'
      aria-pressed={pressed}
      className={pressed ? 'active' : undefined}
      onClick={() => setPressed((value) => !value)}
    >
      {pressed ? 'Pressed' : 'Toggle me'}
    </Button>
  );
}
```

### Data attributes and plugin methods

`Button` forwards native `data-*` attributes, but
`data-bs-toggle='button'` only has an effect when Bootstrap's JavaScript is
loaded and initialized. The React component does not expose Bootstrap plugin
instance methods such as `toggle()`; keep the state in React instead. Do not let
both systems manage the same button state.

## CSS

Button variants use Bootstrap CSS variables that can be customized through the
native `style` prop:

<DemoContainer>
  <ButtonCSSVariablesDemo />
</DemoContainer>

| Variable                                            | Description                     |
| --------------------------------------------------- | ------------------------------- |
| `--bs-btn-min-height`                               | Minimum button height           |
| `--bs-btn-padding-x` / `--bs-btn-padding-y`         | Horizontal and vertical padding |
| `--bs-btn-font-size` / `--bs-btn-line-height`       | Text size and line height       |
| `--bs-btn-border-radius`                            | Button corner radius            |
| `--bs-btn-gradient-start` / `--bs-btn-gradient-end` | `.btn-styled` gradient colors   |
| `--bs-btn-shadow` / `--bs-btn-active-shadow`        | Resting and active shadows      |

Use `className` for Bootstrap modifiers and utility classes, and `style` when
you need to set per-instance CSS variables.
Sass maps and loops are build-time Bootstrap customization points; this React
package exposes no Sass API.

## API

| Prop               | Type                                      | Default    | Description                                                                    |
| ------------------ | ----------------------------------------- | ---------- | ------------------------------------------------------------------------------ |
| `variant`          | `ButtonVariant`                           | —          | Button style: `'solid'`, `'outline'`, `'subtle'`, `'text'`, or `'link'`.       |
| `theme`            | `ButtonTheme`                             | —          | Theme color. Omit with `variant='link'` to use Bootstrap's default link color. |
| `size`             | `'xs' \| 'sm' \| 'lg'`                    | —          | Bootstrap button size. Omit for the default size.                              |
| `className`        | `string`                                  | —          | Additional CSS classes, appended to the generated classes.                     |
| `type`             | `'button' \| 'submit' \| 'reset'`         | `'button'` | Native button type.                                                            |
| `disabled`         | `boolean`                                 | `false`    | Disables the native button.                                                    |
| `children`         | `ReactNode`                               | —          | Button content.                                                                |
| Other button props | `ButtonHTMLAttributes<HTMLButtonElement>` | —          | Native button attributes and event handlers are forwarded.                     |

`Button`, `ButtonProps`, `ButtonTheme`, and `ButtonVariant` are exported from the
package entry point.
