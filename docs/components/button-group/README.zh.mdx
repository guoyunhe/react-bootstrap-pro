# ButtonGroup 按钮组

`ButtonGroup` 用于组合相关操作，默认设置 `role='group'`。使用
`ButtonToolbar` 可以组合多个按钮组。请用 `aria-label` 或 `aria-labelledby`
为每个按钮组和工具栏提供无障碍名称。

## API

### ButtonGroup

| 属性          | 类型                         | 默认值         | 说明                            |
| ------------- | ---------------------------- | -------------- | ------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 设置按钮组方向。                |
| `divider`     | `boolean`                    | `false`        | 在控件之间添加分隔线。          |
| `size`        | `'sm' \| 'lg'`               | —              | 设置小号或大号按钮组尺寸。      |
| `component`   | `C extends ElementType`      | `'div'`        | 要渲染的原生元素或 React 组件。 |

默认设置 `role='group'`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### ButtonToolbar

`ButtonToolbar` 默认渲染为 `<div>` 并设置 `role='toolbar'`。它没有专属属性；继承当前
渲染元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。`component`
属性可以更改根元素。

包入口导出 `ButtonGroup`、`ButtonGroupProps`、`ButtonToolbar` 和
`ButtonToolbarProps`。

## 无障碍访问

为每个按钮组和工具栏设置 `aria-label` 或 `aria-labelledby`。操作使用按钮，导航使用链接。
切换按钮组保留原生复选框和单选框语义；当前链接应设置 `aria-current='page'`。
