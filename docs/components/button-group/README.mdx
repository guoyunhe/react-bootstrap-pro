# Button group

`ButtonGroup` groups related actions and defaults to `role='group'`. Use
`ButtonToolbar` to combine multiple groups. Give each group and toolbar an
accessible name with `aria-label` or `aria-labelledby`.

## API

### ButtonGroup

| Prop          | Type                         | Default        | Description                                   |
| ------------- | ---------------------------- | -------------- | --------------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Selects the group layout.                     |
| `divider`     | `boolean`                    | `false`        | Adds dividers between controls.               |
| `size`        | `'sm' \| 'lg'`               | —              | Applies the small or large button-group size. |
| `component`   | `C extends ElementType`      | `'div'`        | Native element or React component to render.  |

Defaults to `role='group'`. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### ButtonToolbar

`ButtonToolbar` renders a `<div>` by default and sets `role='toolbar'`. It has
no component-specific props; it accepts native props for the selected element
and [`Box`](../box/README.mdx#api) utility props. The `component` prop can
change its root element.

`ButtonGroup`, `ButtonGroupProps`, `ButtonToolbar`, and `ButtonToolbarProps` are
exported from the package entry point.

## Accessibility

Label every group and toolbar with `aria-label` or `aria-labelledby`. Use
buttons for actions and links for navigation. Toggle groups retain native
checkbox and radio semantics; set `aria-current='page'` on the current link.
