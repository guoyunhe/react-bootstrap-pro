# Avatar 头像

头像用于展示用户或其他实体的图片或姓名首字母。`Avatar` 也可作为状态指示器和重叠头像组的容器。

## 示例

### 图片

将 `AvatarImage` 放在 `Avatar` 中，图片会填满头像容器。不需要容器时，也可以单独使用
`AvatarImage`，并直接设置图片尺寸。

## API

### Avatar

渲染 `.avatar` 容器，默认使用 `span` 元素。

| 属性     | 类型                           | 说明                 |
| -------- | ------------------------------ | -------------------- |
| `size`   | `'xs' \| 'sm' \| 'lg' \| 'xl'` | 设置头像尺寸。       |
| `subtle` | `boolean`                      | 使用柔和的主题样式。 |

继承原生 `span` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `theme` 和 `component`。

### AvatarImage

渲染带有 `.avatar-img` 类的图片，默认使用 `img` 元素。放在 `Avatar` 内时，图片会填满容器。

继承原生 `img` 属性（包括 `src`、`alt`、`width` 和 `height`）及
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### AvatarStatus

渲染 `.avatar-status` 状态指示器，默认使用 `span` 元素。

| 属性     | 类型                                        | 说明               |
| -------- | ------------------------------------------- | ------------------ |
| `status` | `'online' \| 'offline' \| 'busy' \| 'away'` | 添加对应的状态类。 |

继承原生 `span` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。`aria-hidden` 默认为 `true`；
若状态需要被辅助技术播报，请将其设为 `false` 并提供无障碍名称。

### AvatarStack

渲染 `.avatar-stack` 重叠头像容器，默认使用 `div` 元素。组件没有尺寸属性；可通过
`className` 添加 `avatar-stack-xs`、`avatar-stack-sm`、`avatar-stack-lg` 或
`avatar-stack-xl` 类来设置头像组尺寸。

继承原生 `div` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `className` 和 `component`。

## 无障碍访问

为每张头像图片提供有意义的替代文本。如果状态指示器包含有意义的信息，请为其提供无障碍名称，并在
`AvatarStatus` 上设置 `aria-hidden={false}`；该组件默认会将指示器从辅助技术中隐藏。
