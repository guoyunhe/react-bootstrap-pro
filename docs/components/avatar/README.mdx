# Avatar

Bootstrap does not include an avatar component; `Avatar` is a library extension
for displaying initials or grouping an image and optional status indicator.

## API

| Prop        | Type                           | Description                             |
| ----------- | ------------------------------ | --------------------------------------- |
| `size`      | `'xs' \| 'sm' \| 'lg' \| 'xl'` | Sets avatar dimensions.                 |
| `subtle`    | `boolean`                      | Uses the subtle theme treatment.        |
| `component` | `ElementType`                  | Changes the avatar root element.        |
| `...props`  | `BoxProps<C>`                  | Native props and all Box utility props. |

`AvatarImage`, `AvatarStatus`, and `AvatarStack` provide image, status, and
overlapping-stack classes.

## Accessibility

Give each avatar image meaningful alternative text. If initials or a status
indicator convey information, provide an accessible name and do not rely on
color alone.
