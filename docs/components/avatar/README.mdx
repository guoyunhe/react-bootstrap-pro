# Avatar

Avatars represent users or entities with an image or initials. The `Avatar`
component also provides wrappers for status indicators and overlapping stacks.

## Examples

### Image

Wrap `AvatarImage` in `Avatar` to make the image fill the avatar. `AvatarImage`
can also be used on its own when a wrapper is not needed; set its dimensions
directly in that case.

## API

### Avatar

Renders the `.avatar` wrapper, using a `span` by default.

| Prop     | Type                           | Description                      |
| -------- | ------------------------------ | -------------------------------- |
| `size`   | `'xs' \| 'sm' \| 'lg' \| 'xl'` | Sets the avatar size.            |
| `subtle` | `boolean`                      | Uses the subtle theme treatment. |

Inherits native `span` props and [`Box`](../box/README.mdx#api) utility props,
including `theme` and `component`.

### AvatarImage

Renders an image with the `.avatar-img` class. It defaults to an `img` element;
when nested inside `Avatar`, the image fills the wrapper.

Inherits native `img` props, including `src`, `alt`, `width`, and `height`, and
[`Box`](../box/README.mdx#api) utility props, including `component`.

### AvatarStatus

Renders the `.avatar-status` indicator, using a `span` by default.

| Prop     | Type                                        | Description              |
| -------- | ------------------------------------------- | ------------------------ |
| `status` | `'online' \| 'offline' \| 'busy' \| 'away'` | Adds the matching class. |

Inherits native `span` props and [`Box`](../box/README.mdx#api) utility props.
`aria-hidden` defaults to `true`; set it to `false` and provide an accessible
name when the status needs to be announced.

### AvatarStack

Renders the `.avatar-stack` overlapping container, using a `div` by default.
There is no size prop: use `avatar-stack-xs`, `avatar-stack-sm`,
`avatar-stack-lg`, or `avatar-stack-xl` in `className` to size the avatars in a
stack.

Inherits native `div` props and [`Box`](../box/README.mdx#api) utility props,
including `className` and `component`.

## Accessibility

Give each avatar image meaningful alternative text. If a status conveys
information, provide an accessible name and set `aria-hidden={false}` on
`AvatarStatus`; it is hidden from assistive technologies by default.
