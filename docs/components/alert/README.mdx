# Alert

`Alert` renders Bootstrap's contextual `.alert` container and defaults to
`role="alert"`. Dismissal requires the Bootstrap JavaScript plugin and a
`CloseButton`.

## Links and additional content

Alerts can include links and structured content; keep related content grouped
inside the alert.

## Dismiss

Pass Bootstrap's dismiss data attribute to a close button to enable plugin
dismissal.

## API

| Prop        | Type                    | Description                             |
| ----------- | ----------------------- | --------------------------------------- |
| `instant`   | `boolean`               | Disables the exit transition.           |
| `theme`     | Bootstrap theme literal | Sets contextual theme colors.           |
| `component` | `ElementType`           | Changes the root element.               |
| `...props`  | `BoxProps<C>`           | Native props and all Box utility props. |

## Accessibility

Use the default `role='alert'` for urgent, dynamically announced content.
For non-urgent updates, choose a less disruptive role such as `status`.
Color is supplementary; keep the alert's meaning in its text.
