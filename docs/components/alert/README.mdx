# Alert

`Alert` renders Bootstrap's contextual `.alert` container and defaults to
`role="alert"`. Alerts support any text content and use neutral colors when no
theme is set. Dismissal with [`CloseButton`](../close-button/) requires the
Bootstrap JavaScript plugin.

## Dismiss

Add a [`CloseButton`](../close-button/) with `data-bs-dismiss='alert'` to enable
dismissal through the Bootstrap JavaScript plugin. The plugin fades the alert
out before removing it; set `instant` to skip the exit transition.

<DemoContainer>
  <AlertDismissDemo />
</DemoContainer>

```tsx src='./demos/dismiss.tsx'

```

The plugin removes a dismissed alert from the page. Since this can leave
keyboard users without a predictable focus location, manage focus after
dismissal when needed.

## API

### Alert

Renders the `.alert` container as a `div` by default, with `role="alert"`. The
inherited `theme` prop sets contextual colors; without a theme, the alert uses
neutral colors.

| Prop      | Type      | Description                                 |
| --------- | --------- | ------------------------------------------- |
| `instant` | `boolean` | Removes the exit transition when dismissed. |

Inherits native `div` props, including `role`, and [`Box`](../box/README.mdx#api)
utility props, including `theme` and `component`.

### AlertLink

Renders the `.alert-link` class on an `a` element by default. Inherits native
anchor props, including `href`, and [`Box`](../box/README.mdx#api) utility props.

### AlertHeading

Renders the `.alert-heading` class on an `h4` element by default. Inherits
native heading props and [`Box`](../box/README.mdx#api) utility props.

## Accessibility

Use the default `role='alert'` for urgent, dynamically announced content.
For non-urgent updates, choose a less disruptive role such as `status`.
Color is supplementary; keep the alert's meaning in its text. Decorative icons
should be hidden from assistive technology.
