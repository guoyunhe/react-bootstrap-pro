# Alert 提示

`Alert` 渲染 Bootstrap `.alert` 提示容器，默认设置 `role="alert"`。提示内容可包含任意文本；未设置
主题时会使用中性色。通过 [`CloseButton`](../close-button/) 关闭提示需要加载 Bootstrap JavaScript 插件。

## 关闭

为 [`CloseButton`](../close-button/) 添加 `data-bs-dismiss='alert'`，即可通过 Bootstrap JavaScript 插件关闭提示。
插件会在移除提示前播放淡出动画；设置 `instant` 可跳过退出过渡动画。

<DemoContainer>
  <AlertDismissDemo />
</DemoContainer>

```tsx src='./demos/dismiss.tsx'

```

插件会从页面结构中移除已关闭的提示。对于键盘用户，这可能导致焦点位置不明确；必要时应在关闭后主动管理焦点。

## API

### Alert

渲染 `.alert` 容器，默认使用 `div` 元素，并设置 `role="alert"`。继承的 `theme` 属性用于设置提示主题；
未设置主题时使用中性色。

| 属性      | 类型      | 说明                     |
| --------- | --------- | ------------------------ |
| `instant` | `boolean` | 关闭时跳过退出过渡动画。 |

继承原生 `div` 属性（包括 `role`）及 [`Box`](../box/README.zh.mdx#api) 工具类属性，其中包括 `theme` 和 `component`。

### AlertLink

默认在 `a` 元素上渲染 `.alert-link` 类。继承原生链接属性（包括 `href`）和
[`Box`](../box/README.zh.mdx#api) 工具类属性；可使用继承的 `component` 属性更换元素。

### AlertHeading

默认在 `h4` 元素上渲染 `.alert-heading` 类。继承原生标题属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性；可使用继承的 `component` 属性更换标题级别或元素。

## 无障碍访问

紧急且需要动态播报的内容使用默认的 `role='alert'`。非紧急更新可选择干扰性较低的角色，例如
`status`。颜色仅作辅助提示，应通过文本表达提示含义；装饰性图标应从辅助技术中隐藏。
