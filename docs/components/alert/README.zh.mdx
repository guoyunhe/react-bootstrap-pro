# Alert 提示

`Alert` 渲染 Bootstrap `.alert` 容器，默认设置 `role="alert"`。关闭交互需要
Bootstrap JavaScript 插件和 `CloseButton`。

<DemoContainer>
  <Alert theme='success'>更改已保存。</Alert>
</DemoContainer>

`AlertLink` 渲染带有 Bootstrap `.alert-link` 样式的链接，默认使用 `<a>` 元素。
可通过 `component` 属性更换元素。

```tsx
<Alert theme='warning' instant>
  继续之前请检查 <AlertLink href='#details'>相关信息</AlertLink>。
</Alert>
```

## API

| 属性        | 类型                 | 说明                            |
| ----------- | -------------------- | ------------------------------- |
| `instant`   | `boolean`            | 禁用退出过渡动画。              |
| `theme`     | Bootstrap 主题字面量 | 设置提示主题颜色。              |
| `component` | `ElementType`        | 更换根元素。                    |
| `...props`  | `BoxProps<C>`        | 原生属性及所有 Box 工具类属性。 |

`AlertHeading` 渲染 `.alert-heading` 标题，默认使用 `h4` 元素；可通过 `component`
更换标题级别。

`AlertLink` 渲染 `.alert-link` 链接，默认使用 `a` 元素；可通过 `component` 更换元素。

颜色仅作辅助提示，请通过文本说明提示含义。
