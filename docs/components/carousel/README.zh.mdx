# Carousel 轮播

## 工作原理

`Carousel` 使用 CSS 滚动捕捉，因此滑动、触摸拖动、惯性滚动和键盘滚动都由浏览器处理。
Bootstrap JavaScript 管理自动播放、前后控件、指示器和活动幻灯片同步。

由于幻灯片位于真实的滚动容器中，轮播可以同时显示多个幻灯片、露出相邻幻灯片的一部分，
也可以混合不同宽度的幻灯片。幻灯片可以包含任意内容，但不会自动调整尺寸；请使用工具类
或自定义样式设置尺寸。控件和指示器均为可选。

设置一个活动幻灯片作为起始位置；若未标记，默认使用第一张幻灯片。包含控件或指示器时，
为每个轮播设置唯一的 `id`，并确保其 `target` 与该 `id` 匹配。

## 幻灯片布局

设置 `--bs-carousel-items` 控制同时显示的幻灯片数量，设置
`--bs-carousel-items-gap` 增加间距。设置 `--bs-carousel-items-peek` 可露出相邻幻灯片的一部分。
这些原生 CSS 选项不需要 JavaScript：

- `--bs-carousel-items` 设置每个视口可完整显示的幻灯片数量（默认 `1`）。
- `--bs-carousel-items-gap` 设置幻灯片之间的间距（默认 `0`）。
- `--bs-carousel-items-peek` 设置相邻幻灯片的露出宽度（默认 `0`）。

## 自动播放

设置 `autoplay` 属性，即可在页面加载时开始循环播放。鼠标悬停或页面隐藏时会暂停；
用户进行操作后自动播放会停止。建议尽量避免自动播放；若启用，应提供易于发现的暂停和恢复控件。
仅在悬停或聚焦时暂停并不充分。

播放/暂停按钮会切换自动播放状态并更新其无障碍名称。活动指示器还会显示当前幻灯片间隔的进度；
用户偏好减少动态效果时会禁用该效果。


## 结束行为

使用 `ends` 属性选择轮播到达首尾时的行为：`loop`（默认）、`wrap` 或 `stop`。

### 循环（默认）

会回退为 `wrap`。

## API

### Carousel

| 属性        | 类型                         | 默认值    | 说明                                         |
| ----------- | ---------------------------- | --------- | -------------------------------------------- |
| `auto`      | `boolean`                    | `false`   | 允许每个轮播项使用自身宽度。                 |
| `autoplay`  | `boolean`                    | `false`   | 在页面加载时开始自动播放。                   |
| `center`    | `boolean`                    | `false`   | 将滚动捕捉位置置于视口中央。                 |
| `colorMode` | `'light' \| 'dark'`          | —         | 设置 Bootstrap 的 `data-bs-theme` 色彩模式。 |
| `effect`    | `'slide' \| 'fade'`          | `'slide'` | 选择滑动或淡入淡出效果。                     |
| `ends`      | `'loop' \| 'wrap' \| 'stop'` | `'loop'`  | 选择轮播到达首尾时的行为。                   |
| `overlay`   | `boolean`                    | `false`   | 将叠加控件放置在幻灯片上方。                 |
| `component` | `ElementType`                | `'div'`   | 更换根元素。                                 |

接受所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselInner

默认渲染为用于容纳幻灯片的 `div`。继承的 `component` 属性可更换根元素。
接受所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselItem

| 属性       | 类型      | 默认值  | 说明                               |
| ---------- | --------- | ------- | ---------------------------------- |
| `active`   | `boolean` | `false` | 标记初始活动幻灯片。               |
| `interval` | `number`  | —       | 设置幻灯片的显示时长，单位为毫秒。 |

默认渲染为 `div`。继承的 `component` 属性可更换根元素。接受所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselIndicators

默认渲染为用于容纳指示器的 `div`。继承的 `component` 属性可更换根元素。
接受所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselIndicator

| 属性     | 类型      | 默认值  | 说明                         |
| -------- | --------- | ------- | ---------------------------- |
| `index`  | `number`  | 必填    | 从零开始的幻灯片索引。       |
| `target` | `string`  | 必填    | 目标轮播的选择器。           |
| `active` | `boolean` | `false` | 标记当前幻灯片对应的指示器。 |

默认渲染为 `button`，并根据 `index` 生成无障碍名称（例如“Slide 1”）。
继承的 `component` 属性可更换根元素。接受所选元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselControl

| 属性        | 类型                               | 默认值 | 说明               |
| ----------- | ---------------------------------- | ------ | ------------------ |
| `direction` | `'next' \| 'previous'`             | 必填   | 导航方向。         |
| `target`    | `string`                           | 必填   | 目标轮播的选择器。 |
| `size`      | `'xs' \| 'sm' \| 'lg'`             | —      | 图标按钮尺寸。     |
| `variant`   | `'solid' \| 'outline' \| 'subtle'` | —      | 图标按钮样式。     |

默认渲染为 `button`，无障碍名称默认为“Next”或“Previous”。继承的 `component`
属性可更换根元素。接受所选元素的原生属性、
[`IconButton`](../button/README.zh.mdx#iconbutton) 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselOverlayControls

默认渲染为用于将控件置于幻灯片上方的 `div`。继承的 `component` 属性可更换根元素。
接受所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

### CarouselCaption

默认渲染为用于显示幻灯片说明文字的 `div`。继承的 `component` 属性可更换根元素。
接受所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

## 无障碍访问

为图片提供有意义的替代文本。控件和指示器均为可选；若使用，请为轮播设置 `id`，
并确保每个控件和指示器的 `target` 与之匹配。标记一个初始活动幻灯片。自动播放必须提供
易于发现的暂停/恢复控件，并尊重用户减少动态效果的偏好。
