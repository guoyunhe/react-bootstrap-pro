# Carousel

## How it works

`Carousel` uses CSS scroll snapping, so sliding, touch dragging, momentum, and
keyboard scrolling come from the browser. React manages autoplay,
previous/next controls, indicators, and active-slide syncing.

Because slides live in a real scroll container, a carousel can show multiple
slides, peek at neighboring slides, and mix variable-width slides. Slides can
contain arbitrary content and are not sized automatically, so use utilities or
custom styles to size them. Controls and indicators are optional.

Mark one slide active to set the starting position; if none is marked, the first
slide is used. Nested controls and indicators connect to their `Carousel`
automatically. A unique `id` is generated by default, or you can provide one.

## Items

Use `items` to control how many whole slides are visible per view (default `1`).
Set `itemsGap` to add space between slides and `itemsPeek` to reveal parts of
neighboring slides (default `0`). `itemsGap` and `itemsPeek` accept CSS values
such as `'1rem'`; numeric values are treated as pixels.

## Autoplay

Set the `autoplay` prop to start cycling on page load. Autoplay pauses on
hover and while the page is hidden. When a visitor takes control, autoplay
stops. Avoid autoplay where possible; if used, provide a discoverable control
to pause and resume. Hover- or focus-only pauses are not sufficient.
Changing `autoplay` after mount starts or stops playback; manual controls can
also pause it without changing the prop.

The play/pause button toggles autoplay and updates its accessible name. The
active indicator also shows a progress fill for the current slide's interval;
this is disabled under reduced motion.

## End behavior

Use the `ends` prop to choose what happens at the first and last slide:
`loop` (the default), `wrap`, or `stop`.

### Loop (default)

`loop` scrolls seamlessly past the ends for a single-slide sliding carousel.
Fade, reduced-motion, multi-item, peek, centered, and variable-width layouts
fall back to `wrap`.

## API

### Carousel

| Prop        | Type                         | Default   | Description                                       |
| ----------- | ---------------------------- | --------- | ------------------------------------------------- |
| `auto`      | `boolean`                    | `false`   | Lets each item use its own width.                 |
| `autoplay`  | `boolean`                    | `false`   | Starts cycling automatically on page load.        |
| `center`    | `boolean`                    | `false`   | Centers snap positions in the viewport.           |
| `colorMode` | `'light' \| 'dark'`          | —         | Sets Bootstrap's `data-bs-theme` color mode.      |
| `effect`    | `'slide' \| 'fade'`          | `'slide'` | Chooses the slide or fade transition.             |
| `ends`      | `'loop' \| 'wrap' \| 'stop'` | `'loop'`  | Chooses the behavior at the first and last slide. |
| `id`        | `string`                     | generated | Sets the root element's id.                       |
| `items`     | `number`                     | `1`       | Sets the number of whole slides visible per view. |
| `itemsGap`  | `string \| number`           | —         | Sets the gap between slides; numbers are pixels.  |
| `itemsPeek` | `string \| number`           | —         | Reveals neighboring slides; numbers are pixels.   |
| `overlay`   | `boolean`                    | `false`   | Positions overlay controls over the slides.       |
| `component` | `ElementType`                | `'div'`   | Changes the root element.                         |

Generates a unique `id` when one is not provided and uses it to connect nested
controls and indicators automatically. Accepts other native props for the
selected element and [`Box`](../box/README.mdx#api) utility props.

### CarouselInner

Renders a `div` by default for the slide viewport. The inherited `component`
prop can change the root element. Accepts native props for the selected element
and [`Box`](../box/README.mdx#api) utility props.

### CarouselItem

| Prop       | Type      | Default | Description                                               |
| ---------- | --------- | ------- | --------------------------------------------------------- |
| `active`   | `boolean` | `false` | Marks the initial active slide.                           |
| `interval` | `number`  | —       | Sets how long the slide remains visible, in milliseconds. |

Renders a `div` by default. The inherited `component` prop can change the root
element. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CarouselIndicators

Renders a `div` by default to contain indicators. When nested in a `Carousel`
without `children`, it generates an indicator for each slide after the carousel
mounts and updates as slides are added or removed. Each indicator tracks the
active slide and can navigate to it. Supply `children` to render custom
indicators instead; even `null` suppresses automatic generation.
The inherited `component` prop can change the root element. It has no additional
own props and accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CarouselIndicator

| Prop     | Type      | Default  | Description                               |
| -------- | --------- | -------- | ----------------------------------------- |
| `index`  | `number`  | Required | Zero-based slide index.                   |
| `active` | `boolean` | `false`  | Marks the indicator for the active slide. |

Renders a `button` by default and generates an accessible name from `index`
(for example, “Slide 1”). The target carousel is resolved automatically when
the indicator is nested inside a `Carousel`. The inherited `component` prop
can change the root element. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CarouselControl

| Prop        | Type                               | Default  | Description            |
| ----------- | ---------------------------------- | -------- | ---------------------- |
| `direction` | `'next' \| 'previous'`             | Required | Direction to navigate. |
| `size`      | `'xs' \| 'sm' \| 'lg'`             | —        | Icon button size.      |
| `variant`   | `'solid' \| 'outline' \| 'subtle'` | —        | Icon button style.     |

Renders a `button` by default, with “Next” or “Previous” as its accessible name.
The target carousel is resolved automatically when the control is nested inside
a `Carousel`. The inherited `component` prop can change the root element.
Accepts native props for the selected element,
[`IconButton`](../button/README.mdx#iconbutton) props, and
[`Box`](../box/README.mdx#api) utility props.

### CarouselPlayPause

| Prop         | Type     | Default   | Description                                     |
| ------------ | -------- | --------- | ----------------------------------------------- |
| `pauseLabel` | `string` | `'Pause'` | Accessible label while the carousel is playing. |
| `playLabel`  | `string` | `'Play'`  | Accessible label while the carousel is paused.  |

Renders a `button` by default, with both play and pause icons. React toggles
the icons and accessible name using the playback state and label props.
The target carousel is resolved automatically when this control is nested
inside a `Carousel`. The inherited `component` prop can change the root element.
Accepts native props for the selected element,
[`IconButton`](../button/README.mdx#iconbutton) props, and
[`Box`](../box/README.mdx#api) utility props.

### CarouselOverlayControls

Renders a `div` by default to position controls over slides. The inherited
`component` prop can change the root element. Accepts native props for the
selected element and [`Box`](../box/README.mdx#api) utility props.

### CarouselCaption

Renders a `div` by default for slide captions. The inherited `component` prop
can change the root element. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

## Accessibility

Use informative alternative text for images. Controls and indicators are
optional; when used, nest them inside the carousel to connect them automatically.
The carousel generates an internal unique id with React's `useId` unless an
`id` is provided. Mark one initial slide active. Autoplay must have a
discoverable pause/resume control, and the carousel respects reduced-motion
preferences.
