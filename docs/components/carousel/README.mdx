# Carousel

`Carousel` uses a native horizontal scroll container with CSS scroll snapping.
The Bootstrap JavaScript bundle is required for previous/next controls,
indicators, and autoplay.

## Example

<DemoContainer>
  <Carousel id='features' overlay>
    <CarouselInner>
      <CarouselItem active>First slide</CarouselItem>
      <CarouselItem>Second slide</CarouselItem>
    </CarouselInner>
    <CarouselOverlayControls>
      <CarouselControl target='#features' direction='previous' />
      <CarouselIndicators>
        <CarouselIndicator target='#features' index={0} active />
        <CarouselIndicator target='#features' index={1} />
      </CarouselIndicators>
      <CarouselControl target='#features' direction='next' />
    </CarouselOverlayControls>
  </Carousel>
</DemoContainer>

## Modifiers

`auto` fits slides to their own widths, `center` centers snap positions, and
`fade` switches to the stacked fade presentation.

```tsx
<Carousel fade>
  <CarouselInner>
    <CarouselItem active>Featured content</CarouselItem>
    <CarouselItem>More content</CarouselItem>
  </CarouselInner>
</Carousel>
```

## Autoplay

Use Bootstrap's `data-bs-autoplay` option to enable autoplay. Provide controls
so users can pause or navigate the slides.

```tsx
<Carousel id='announcements' data-bs-autoplay='true'>
  <CarouselInner>
    <CarouselItem active>Announcement one</CarouselItem>
    <CarouselItem>Announcement two</CarouselItem>
  </CarouselInner>
  <CarouselControl target='#announcements' direction='previous' />
  <CarouselControl target='#announcements' direction='next' />
</Carousel>
```

## API

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `auto`      | `boolean`     | Lets each item use its own width.       |
| `center`    | `boolean`     | Centers snap positions in the viewport. |
| `fade`      | `boolean`     | Uses the stacked fade transition mode.  |
| `overlay`   | `boolean`     | Positions controls over the slides.     |
| `component` | `ElementType` | Changes the root element.               |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

Use `CarouselInner` and `CarouselItem` for the scroll viewport and slides.
`CarouselControl` and `CarouselIndicator` require a selector `target` matching
the carousel `id`; controls also accept `direction`, `size`, and `variant`, while
indicators accept `index` and `active`. `CarouselOverlayControls` positions
controls over the slides.

## Accessibility

Give controls and indicators accessible names, set exactly one initial slide
active, and provide alternative text for informative images. Avoid autoplay
when users cannot pause or stop it.
