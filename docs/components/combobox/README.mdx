# Combobox

`Combobox` provides a styled select control with a button toggle and a listbox
menu. Define options as React data; the component manages selection, search,
keyboard navigation, and form submission.

This package's React component does not initialize Bootstrap's JavaScript
combobox plugin. Use the React props documented below rather than the plugin's
`data-bs-*` attributes, options, or methods.

- Custom option content, including icons and descriptions
- Optional search and check marks for selected options
- Single or multiple selection
- Keyboard navigation and accessible listbox semantics
- A hidden input for native form submission when `name` is provided

## Keyboard behavior

| Context | Keys                | Action                                            |
| ------- | ------------------- | ------------------------------------------------- |
| Toggle  | ArrowDown / ArrowUp | Opens the menu and focuses the first/last option. |
| Toggle  | Enter / Space       | Opens the menu.                                   |
| Menu    | ArrowDown / ArrowUp | Moves focus between options.                      |
| Menu    | Home / End          | Focuses the first or last option.                 |
| Menu    | Enter / Space       | Selects the focused option.                       |
| Menu    | Escape              | Closes the menu and focuses the toggle.           |
| Menu    | Tab                 | Closes the menu.                                  |

Focus wraps between enabled options when using the arrow keys. A pointer event
outside the control also closes the menu.

## Accessibility

The toggle is a native button with `aria-haspopup='listbox'`, `aria-expanded`,
and `aria-controls`. The menu uses `role='listbox'`; options use
`role='option'` and `aria-selected`. Multiple selection also sets
`aria-multiselectable`. Disabled options are disabled buttons and expose
`aria-disabled='true'`.

Name the toggle with a [`FormLabel`](../form/README.mdx#formlabel) associated
through `htmlFor`, or pass `aria-label` or `aria-labelledby`. Use
`aria-describedby` to associate additional instructions.

## CSS custom properties

The adjacent menu uses these defaults, which can be overridden with CSS:

| CSS variable           | Default | Description                             |
| ---------------------- | ------- | --------------------------------------- |
| `--bs-menu-max-height` | `300px` | Maximum height of the combobox menu.    |
| `--bs-menu-overflow-y` | `auto`  | Vertical overflow behavior of the menu. |

The menu also inherits the `--bs-menu-*` properties documented by Bootstrap's
[Menu component](https://getbootstrap.com/docs/6.0/components/menu/).

## API

### Combobox

Renders a `div` wrapper by default. It contains a native `button` toggle, a
listbox menu, and a hidden input when `name` is set. Its own props are listed
below. `id` and the listed `aria-*` props apply to the toggle; native `div`
props and [`Box`](../box/README.mdx#api) props apply to the wrapper, except for
`children` and native `onChange`. The wrapper is positioned relative to anchor
the menu.

| Prop                | Type                                  | Default              | Description                                           |
| ------------------- | ------------------------------------- | -------------------- | ----------------------------------------------------- |
| `options`           | `(ComboboxOption \| ComboboxGroup)[]` | `[]`                 | Options and group items in display order.             |
| `value`             | `string \| string[]`                  | —                    | Controlled selection.                                 |
| `defaultValue`      | `string \| string[]`                  | —                    | Initial selection for uncontrolled usage.             |
| `onChange`          | `(value: string \| string[]) => void` | —                    | Called with the selected value or values.             |
| `multiple`          | `boolean`                             | `false`              | Enables multiple selection.                           |
| `placeholder`       | `string`                              | `''`                 | Text shown when nothing is selected.                  |
| `name`              | `string`                              | —                    | Adds a hidden input with this name.                   |
| `disabled`          | `boolean`                             | `false`              | Disables the toggle.                                  |
| `size`              | `'sm' \| 'lg'`                        | Default size         | Scales the toggle.                                    |
| `search`            | `boolean`                             | `false`              | Renders a search field inside the menu.               |
| `searchPlaceholder` | `string`                              | `'Search…'`          | Search field placeholder and accessible name.         |
| `noResults`         | `ReactNode`                           | `'No results found'` | Content shown when the search has no matches.         |
| `check`             | `boolean`                             | `false`              | Renders a check mark on selected options.             |
| `validation`        | `'valid' \| 'invalid'`                | —                    | Applies a validation state to the wrapper and toggle. |
| `id`                | `string`                              | —                    | Sets the toggle button's `id`.                        |
| `aria-label`        | `string`                              | —                    | Sets the toggle button's accessible name.             |
| `aria-labelledby`   | `string`                              | —                    | References the element that names the toggle button.  |
| `aria-describedby`  | `string`                              | —                    | References descriptive text for the toggle button.    |

Use a string value for single selection and an array of strings for multiple
selection.

The wrapper's position is fixed to `relative` to anchor the menu. The
`className` and `classNameBefore` props style the wrapper.

### ComboboxOption

| Field         | Type        | Default | Description                                                  |
| ------------- | ----------- | ------- | ------------------------------------------------------------ |
| `value`       | `string`    | —       | Required selection key and submitted value.                  |
| `label`       | `ReactNode` | —       | Required content shown in the menu and single-select toggle. |
| `description` | `ReactNode` | —       | Secondary text below the label.                              |
| `icon`        | `ReactNode` | —       | Leading icon.                                                |
| `disabled`    | `boolean`   | `false` | Prevents selecting the option.                               |
| `text`        | `string`    | —       | Explicit plain text used for search matching.                |

### ComboboxGroup

A group is an item in the `options` array.

| Field     | Type               | Default | Description                      |
| --------- | ------------------ | ------- | -------------------------------- |
| `label`   | `ReactNode`        | —       | Group heading shown in the menu. |
| `options` | `ComboboxOption[]` | —       | Options in the group.            |
