# Combobox

`Combobox` provides a styled select built from a `.form-control` toggle button
and a `.menu` overlay. Options accept icons, descriptions, and any other React
content. Selection, search, groups, multiple selection, keyboard navigation, and
the hidden input used for form submission are handled in React, so no Bootstrap
JavaScript plugin is required.

## Form submission

Set `name` to render a hidden input whose value is the selected value, or a
comma-separated list of values in multiple mode.

## API

| Prop                | Type                                  | Description                                          |
| ------------------- | ------------------------------------- | ---------------------------------------------------- |
| `options`           | `readonly ComboboxOption[]`           | Flat list of options.                                |
| `groups`            | `readonly ComboboxGroup[]`            | Labeled option groups.                               |
| `value`             | `string \| readonly string[]`         | Controlled selection.                                |
| `defaultValue`      | `string \| readonly string[]`         | Initial selection for uncontrolled usage.            |
| `onChange`          | `(value: string \| string[]) => void` | Called when the selection changes.                   |
| `multiple`          | `boolean`                             | Enables multiple selection.                          |
| `placeholder`       | `string`                              | Text shown when nothing is selected.                 |
| `search`            | `boolean`                             | Renders a search field inside the menu.              |
| `searchPlaceholder` | `string`                              | Placeholder and accessible name of the search field. |
| `noResults`         | `ReactNode`                           | Content shown when the search has no matches.        |
| `check`             | `boolean`                             | Renders a check mark on selected options.            |
| `name`              | `string`                              | Renders a hidden input with this name.               |
| `size`              | `'sm' \| 'lg'`                        | Scales the toggle.                                   |
| `disabled`          | `boolean`                             | Disables the toggle.                                 |
| `id`, `aria-*`      |                                       | Forwarded to the toggle button.                      |
| `...props`          | `BoxProps<'div'>`                     | Box utility props for the wrapper.                   |

### ComboboxOption

| Field         | Type        | Description                                  |
| ------------- | ----------- | -------------------------------------------- |
| `value`       | `string`    | Submitted value and selection key.           |
| `label`       | `ReactNode` | Content shown in the menu and on the toggle. |
| `description` | `ReactNode` | Secondary text below the label.              |
| `icon`        | `ReactNode` | Leading icon.                                |
| `disabled`    | `boolean`   | Prevents selecting the option.               |
| `text`        | `string`    | Plain text used for search matching.         |

## Keyboard behavior

| Context | Keys                | Action                                            |
| ------- | ------------------- | ------------------------------------------------- |
| Toggle  | ArrowDown / ArrowUp | Opens the menu and focuses the first/last option. |
| Toggle  | Enter / Space       | Opens the menu.                                   |
| Menu    | ArrowDown / ArrowUp | Moves focus between options.                      |
| Menu    | Home / End          | Focuses the first or last option.                 |
| Menu    | Enter / Space       | Selects the focused option.                       |
| Menu    | Escape              | Closes the menu and focuses the toggle.           |
| Menu    | Tab                 | Closes the menu.                                  |

Clicking outside the combobox also closes the menu.

## Accessibility

The toggle exposes `aria-haspopup='listbox'` and `aria-expanded`, the menu uses
`role='listbox'`, and each option uses `role='option'` with `aria-selected`.
Disabled options receive `disabled` and `aria-disabled='true'`. Name the toggle
with a `FormLabel` bound through `htmlFor`, or with `aria-label`.
