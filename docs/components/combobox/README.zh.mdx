# Combobox 组合框

`Combobox` 提供带有按钮触发器和列表框菜单的样式化选择控件。选项以 React 数据定义；
组件负责管理选择、搜索、键盘导航和表单提交。

本项目的 React 组件不会初始化 Bootstrap JavaScript combobox 插件。请使用下方的 React
属性，而不是插件的 `data-bs-*` 属性、选项或方法。

- 支持选项自定义内容，包括图标和描述
- 可选搜索，以及选中项勾选标记
- 支持单选和多选
- 支持键盘导航和无障碍列表框语义
- 设置 `name` 后提供用于原生表单提交的隐藏输入框

## 键盘行为

| 场景   | 按键                | 行为                                |
| ------ | ------------------- | ----------------------------------- |
| 切换键 | ArrowDown / ArrowUp | 打开菜单并聚焦第一个/最后一个选项。 |
| 切换键 | Enter / Space       | 打开菜单。                          |
| 菜单   | ArrowDown / ArrowUp | 在选项间移动焦点。                  |
| 菜单   | Home / End          | 聚焦第一个或最后一个选项。          |
| 菜单   | Enter / Space       | 选中当前聚焦的选项。                |
| 菜单   | Escape              | 关闭菜单并聚焦切换按钮。            |
| 菜单   | Tab                 | 关闭菜单。                          |

使用方向键时，焦点会在可用选项间循环移动。通过指针操作控件外部也会关闭菜单。

## 无障碍

切换按钮是原生按钮，带有 `aria-haspopup='listbox'`、`aria-expanded` 和
`aria-controls`。菜单使用 `role='listbox'`，选项使用 `role='option'` 和
`aria-selected`。多选模式还会设置 `aria-multiselectable`。禁用选项是禁用状态的按钮，并
提供 `aria-disabled='true'`。

使用通过 `htmlFor` 关联的 [`FormLabel`](../form/README.zh.mdx#formlabel)、`aria-label`
或 `aria-labelledby` 为切换按钮命名。可用 `aria-describedby` 关联补充说明。

## CSS 自定义属性

相邻菜单使用以下默认值，可通过 CSS 覆盖：

| CSS 变量               | 默认值  | 说明                     |
| ---------------------- | ------- | ------------------------ |
| `--bs-menu-max-height` | `300px` | combobox 菜单最大高度。  |
| `--bs-menu-overflow-y` | `auto`  | 菜单的垂直溢出处理方式。 |

菜单也会继承 Bootstrap [Menu 组件](https://getbootstrap.com/docs/6.0/components/menu/)文档中的
`--bs-menu-*` 属性。

## API

### Combobox

默认渲染为 `div` 容器，其中包含原生 `button` 切换按钮、列表框菜单，以及设置 `name` 时
生成的隐藏输入框。组件自有属性如下。`id` 和表格中的 `aria-*` 属性作用于切换按钮；原生
`div` 属性和 [`Box`](../box/README.zh.mdx#api) 属性作用于外层容器，但不包括 `children`
和原生 `onChange`。由于选项和分组都通过 `options` 传入，不接受 `children`。容器始终
使用相对定位以锚定菜单。

| 属性                | 类型                                  | 默认值               | 说明                                   |
| ------------------- | ------------------------------------- | -------------------- | -------------------------------------- |
| `options`           | `(ComboboxOption \| ComboboxGroup)[]` | `[]`                 | 按显示顺序排列的普通选项或分组项。     |
| `value`             | `string \| string[]`                  | —                    | 受控选中值。                           |
| `defaultValue`      | `string \| string[]`                  | —                    | 非受控模式的初始选中值。               |
| `onChange`          | `(value: string \| string[]) => void` | —                    | 选中值变化时调用，传入选中值或值列表。 |
| `multiple`          | `boolean`                             | `false`              | 启用多选。                             |
| `placeholder`       | `string`                              | `''`                 | 未选中时显示的文本。                   |
| `name`              | `string`                              | —                    | 设置后添加带有该名称的隐藏输入框。     |
| `disabled`          | `boolean`                             | `false`              | 禁用切换按钮。                         |
| `size`              | `'sm' \| 'lg'`                        | 默认尺寸             | 调整切换按钮尺寸。                     |
| `search`            | `boolean`                             | `false`              | 在菜单内渲染搜索框。                   |
| `searchPlaceholder` | `string`                              | `'Search…'`          | 搜索框占位文本与可访问名称。           |
| `noResults`         | `ReactNode`                           | `'No results found'` | 搜索无匹配项时显示的内容。             |
| `check`             | `boolean`                             | `false`              | 在选中选项上显示勾选标记。             |
| `validation`        | `'valid' \| 'invalid'`                | —                    | 为外层容器和切换按钮应用验证状态。     |
| `id`                | `string`                              | —                    | 设置切换按钮的 `id`。                  |
| `aria-label`        | `string`                              | —                    | 设置切换按钮的可访问名称。             |
| `aria-labelledby`   | `string`                              | —                    | 引用为切换按钮提供名称的元素。         |
| `aria-describedby`  | `string`                              | —                    | 引用切换按钮的描述文本。               |

单选时使用字符串，多选时使用字符串数组。

容器固定使用 `relative` 定位以锚定菜单。`className` 和 `classNameBefore` 用于设置外层
容器样式。

### ComboboxOption

| 字段          | 类型        | 默认值  | 说明                                   |
| ------------- | ----------- | ------- | -------------------------------------- |
| `value`       | `string`    | —       | 必填；选项标识和表单提交值。           |
| `label`       | `ReactNode` | —       | 必填；菜单及单选模式下切换按钮的内容。 |
| `description` | `ReactNode` | —       | 标签下方的次要文本。                   |
| `icon`        | `ReactNode` | —       | 前置图标。                             |
| `disabled`    | `boolean`   | `false` | 禁止选择该选项。                       |
| `text`        | `string`    | —       | 用于搜索匹配的纯文本。                 |

### ComboboxGroup

分组项是 `options` 数组中的一项。

| 字段      | 类型               | 默认值 | 说明                   |
| --------- | ------------------ | ------ | ---------------------- |
| `label`   | `ReactNode`        | —      | 菜单中显示的分组标题。 |
| `options` | `ComboboxOption[]` | —      | 该分组包含的选项。     |
