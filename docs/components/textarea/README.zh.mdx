# Textarea 文本域

`Textarea` 使用 Bootstrap 的 `.form-control` 样式渲染原生 `<textarea>`。文本域与输入框
共用控件样式；可通过原生 `rows` 属性或自定义 CSS 调整高度。

## 示例

使用 `FormField` 与 `FormLabel` 将标签与文本域组合在一起。原生 `rows` 属性设置可见行数；
未设置时使用浏览器默认高度。

## 浮动标签

将标签与文本域包裹在 `FormFloating` 中即可生成浮动标签。标签需放在前面，并通过
`htmlFor` 与文本域关联。必须提供非空的 `placeholder`：该实现完全依赖 CSS 的
`:placeholder-shown` 判断是否为空。文本域默认与输入框等高。

`--bs-form-floating-height` 自定义属性，使标签在任意高度下都能正确浮动。

## API

### Textarea

渲染为 `textarea`，不提供多态 `component` 属性。自有属性为 `size`、`plaintext` 与
`validation`；其余原生 textarea 属性均会透传，包括 `rows`、`disabled`、`readOnly`、
`placeholder`、`maxLength`、`required`，以及通过 `BoxProps<'textarea'>` 继承的全部
[`Box`](../box/#api) 工具类属性。

| 组件属性     | 类型                   | 说明                                                |
| ------------ | ---------------------- | --------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | 应用 `.form-control-sm` 或 `.form-control-lg`。     |
| `plaintext`  | `boolean`              | 用 `.form-control-plaintext` 替代 `.form-control`。 |
| `validation` | `'valid' \| 'invalid'` | 应用 `.is-valid` 或 `.is-invalid`。                 |

`validation` 只添加 CSS 类；请按需设置 `aria-invalid` 并关联反馈信息。表单校验处理见
[`Form`](../form/)。

## 无障碍

使用通过 `htmlFor` 绑定的可见 `<label>` 为文本域提供可访问名称；无法显示可见标签时，
可使用 `aria-label`。占位符不能替代标签；`rows` 只影响初始高度，内容超出时由浏览器在
控件内滚动。

禁用的文本域会被键盘导航和表单提交跳过，只读的文本域仍可聚焦并参与提交。若要使用
`plaintext`，请同时保留 `readOnly`，因为该属性只改变样式。使用浮动标签时，标签需放在
最前面，以便屏幕阅读器先朗读标签再朗读值，并提供非空的 `placeholder`。
