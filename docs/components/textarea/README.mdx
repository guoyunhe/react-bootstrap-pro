# Textarea

`Textarea` renders a native `<textarea>` with Bootstrap's `.form-control`
styling. Textareas share the control styles of inputs; change their height with
the native `rows` attribute or with custom CSS.

## Example

Use `FormField` and `FormLabel` to group a label with the textarea. The native
`rows` attribute sets the visible line count; without it, the browser's default
height applies.

### Readonly plain text

removes the field styling while keeping the control's margin and padding.
`plaintext` only changes styling; combine it with `readOnly` to prevent editing.

## Floating labels

Wrap the label and textarea in `FormFloating` to build a floating label. Put the
label first and bind it to the textarea with `htmlFor`. A non-empty
`placeholder` is required: the CSS-only implementation uses `:placeholder-shown`
to detect an empty field. Textareas match the height of inputs by default.

## API

### Textarea

Renders a `textarea` and does not expose a polymorphic `component` prop. Its own
props are `size`, `plaintext`, and `validation`; it inherits the remaining native
textarea attributes, including `rows`, `disabled`, `readOnly`, `placeholder`,
`maxLength`, `required`, and all [`Box`](../box/README.mdx#api) utility props
through `BoxProps<'textarea'>`.

| Prop         | Type                   | Description                                                   |
| ------------ | ---------------------- | ------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies `.form-control-sm` or `.form-control-lg`.             |
| `plaintext`  | `boolean`              | Applies `.form-control-plaintext` instead of `.form-control`. |
| `validation` | `'valid' \| 'invalid'` | Applies `.is-valid` or `.is-invalid`.                         |

`validation` adds a CSS class; set `aria-invalid` and associate feedback when
appropriate. See [`Form`](../form/README.mdx) for validation handling.

## Accessibility

Give each textarea an accessible name with a visible `<label>` bound through
`htmlFor`, or with `aria-label` when a visible label is not possible.
Placeholders do not replace labels, and `rows` affects the initial height only:
the browser lets users scroll long content inside the control.

Disabled textareas are skipped by keyboard navigation and form submission, while
readonly textareas stay focusable and are still submitted. Keep `readOnly` when
using `plaintext`, because the prop only changes styling. With floating labels,
keep the label first so screen readers announce it before the value, and provide
the required non-empty placeholder.
