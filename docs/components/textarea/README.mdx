# Textarea

`Textarea` renders a native `<textarea>` with Bootstrap's `.form-control`
styling. Use the native `rows` attribute to choose its visible line count.

## Sizes and plaintext

Use `size='sm'` or `size='lg'` for Bootstrap sizing. Set `plaintext` to display

## API

### Textarea

Renders a `textarea` by default and does not expose a polymorphic `component`
prop. Its own props are listed below; it inherits the remaining native textarea
props and all [`Box`](../box/README.mdx#api) utility props.

| Prop         | Type                   | Description                                                         |
| ------------ | ---------------------- | ------------------------------------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | Applies the small or large Bootstrap textarea size.                 |
| `plaintext`  | `boolean`              | Applies `.form-control-plaintext` styling.                          |
| `validation` | `'valid' \| 'invalid'` | Applies the corresponding validation class.                         |
| `...props`   | `BoxProps<'textarea'>` | Native textarea props, including `rows`, and all Box utility props. |

## Accessibility

Give each textarea an accessible name with a visible `<label>` bound through
`htmlFor`, or with `aria-label` when a visible label is not possible. The
browser preserves native text editing, selection, and form submission behavior.
