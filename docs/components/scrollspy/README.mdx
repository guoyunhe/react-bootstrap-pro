# Scrollspy

`Scrollspy` adds Bootstrap's scrollspy data attributes and keyboard focusability
to a scroll container. The Bootstrap JavaScript bundle updates links as targets
enter the viewport.

## API

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `target`    | `string`      | Selector for the associated navigation. |
| `component` | `ElementType` | Changes the scroll container element.   |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

Make the scroll area keyboard-accessible and ensure each navigation hash points
to an element with a matching `id`.

## Accessibility

Provide a focusable scroll container when it has no focusable descendants, and
ensure each navigation link has a matching target ID.
