# Navbar 导航栏

`Navbar` 提供响应式导航外壳，可以组合品牌、导航、表单、文本以及关联
[Drawer](../drawer/README.zh.mdx) 的切换按钮。


## 工作原理

当**导航栏容器**达到指定宽度时，`expand` 将抽屉变为内联导航，而不是依据视口宽度。
不带值的 `expand` 始终展开；省略时始终显示切换按钮。Bootstrap drawer 插件负责打开、
关闭和焦点管理，`NavbarToggler` 只渲染标记。

交互示例通过[此辅助函数](./use-drawer-cleanup.ts)加载 Bootstrap JavaScript bundle，并在
卸载时销毁实例。应用中使用 `data-bs-toggle='drawer'` 前应加载 Bootstrap drawer
JavaScript 或 bundle，并在移除元素时销毁实例。没有 JavaScript 时切换按钮无法打开抽屉，
应提供其他导航方式。达到展开断点时，Bootstrap CSS 会以内联方式显示抽屉内容。

## 无障碍

存在多个导航区域时，使用有名称的 `nav` 地标。如果根元素不是 `nav`，请设置
`role='navigation'`。用 `aria-controls` 将切换按钮关联到具有唯一 ID 的抽屉，
为按钮提供无障碍名称并为抽屉设置标签。使用 `aria-current='page'` 标记当前页面。

Bootstrap drawer 插件在折叠状态使用原生模态 `dialog`，包括焦点管理和 Escape 关闭。
插件不会更新切换按钮上的 `aria-expanded`；如果应用设置该属性，应通过抽屉的 shown
和 hidden 事件同步状态。行为和降级方案详见 [Drawer 文档](../drawer/README.zh.mdx)。

## API

所有组件均接受所选元素的原生属性，并通过 `BoxProps<C>` 继承
[`Box`](../box/README.zh.mdx#api) 工具类属性；`component` 可更换默认元素。

### Navbar

默认渲染为 `nav`。自有属性为 `expand?: boolean | 'sm' | 'md' | 'lg' | 'xl' | '2xl'`：
`true` 始终展开，断点值在对应容器宽度下展开。

### NavbarBrand

默认渲染为 `a`，没有自有属性。

### NavbarToggler

默认渲染为 `button`，没有自有属性。组件添加 `btn-icon` 和 `navbar-toggler`，
默认设置 `type='button'` 和 `aria-label='Toggle navigation'`，未提供子元素时渲染装饰性图标。
可通过子元素或无障碍标签覆盖默认值；组件本身不管理抽屉状态。

### NavbarNav

默认渲染为 `ul`，没有自有属性，添加 `nav` 和 `navbar-nav`。

### NavbarText

默认渲染为 `span`，没有自有属性。
