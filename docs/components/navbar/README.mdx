# Navbar

`Navbar` provides a responsive site-navigation shell. Compose the brand, nav,
and toggler subcomponents; use the Bootstrap drawer plugin for responsive
off-canvas navigation.

## Responsive behavior

Set `expand` to the breakpoint at which the navbar content expands. At smaller
widths, connect `NavbarToggler` to the navigation drawer with the matching
target ID and Bootstrap's drawer data attributes.

## API

### Navbar

Renders a `nav` by default. Its own prop is
`expand?: boolean | 'sm' | 'md' | 'lg' | 'xl' | '2xl'`; it inherits native props
for the selected element and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

| Prop        | Type                                               | Description                               |
| ----------- | -------------------------------------------------- | ----------------------------------------- |
| `expand`    | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Selects the responsive expand breakpoint. |
| `component` | `ElementType`                                      | Changes the navbar root element.          |
| `...props`  | `BoxProps<C>`                                      | Native props and all Box utility props.   |

`NavbarBrand`, `NavbarToggler`, `NavbarNav`, and `NavbarText` cover common
navbar sections. Connect the toggler to its controlled element with plugin
attributes. The example uses a drawer element as the responsive controlled
region, matching the Bootstrap 6 navbar pattern.

### NavbarBrand

Renders an `a` by default and has no own props. It inherits native anchor props
and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### NavbarToggler

Renders a `button` by default and has no own props. It defaults to
`type="button"`, an accessible label of “Toggle navigation”, and a toggler icon
when no children are provided. It inherits native button props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### NavbarNav

Renders a `ul` by default and has no own props. It inherits native list props
and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

### NavbarText

Renders a `span` by default and has no own props. It inherits native `span`
props and all [`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Use a `<nav>` landmark, name the toggler with `aria-label`, and connect it to
the controlled navigation with `aria-controls`. Expose the current link with
`aria-current`.
