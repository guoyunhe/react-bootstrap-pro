# Navbar

`Navbar` provides a responsive navigation shell. Compose it with a brand,
navigation, form, text, and a toggler linked to a [Drawer](../drawer/README.mdx).

## How it works

`expand` changes a drawer to inline navigation once the **navbar container**
reaches the specified width, not the viewport width. `expand` without a value
always expands; omit it to keep the toggler visible. The examples manage
`Drawer` with React state and its `show` and `onShowChange` props;
`NavbarToggler` itself only renders markup. No Bootstrap JavaScript is needed.
At the expanded breakpoint Bootstrap CSS displays the drawer contents inline.
Without JavaScript the toggler cannot open the drawer, so provide an alternative
navigation path.

## Accessibility

Use a named `nav` landmark when multiple navigation regions exist. If the root
is not a `nav`, provide `role='navigation'`. Connect each toggler to a uniquely
identified drawer with `aria-controls`, give it an accessible name, and label
the drawer. Mark the current page with `aria-current='page'`.

The controlled drawer uses a native modal `dialog`, including browser focus
management and Escape dismissal. Keep the toggler's `aria-expanded` synchronized
with React state, as in the examples. See the
[Drawer documentation](../drawer/README.mdx) for behavior and fallbacks.

## API

All components accept native props for the selected element and
[`Box`](../box/README.mdx#api) utility props through `BoxProps<C>`;
`component` changes the default element.

### Navbar

Renders `nav` by default. Its own prop is `expand?: boolean | 'sm' | 'md' |
'lg' | 'xl' | '2xl'`: `true` always expands, while a breakpoint expands at the
corresponding container width.

### NavbarBrand

Renders `a` by default and has no own props.

### NavbarToggler

Renders `button` by default and has no own props. It applies `btn-icon` and
`navbar-toggler`, defaults to `type='button'` and `aria-label='Toggle navigation'`,
and renders a decorative icon when children are omitted. Supply children or
an accessible label to override those defaults. It does not manage drawer state.

### NavbarNav

Renders `ul` by default and has no own props. It adds `nav` and `navbar-nav`.

### NavbarText

Renders `span` by default and has no own props.
