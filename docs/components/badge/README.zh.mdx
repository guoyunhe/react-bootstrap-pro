# Badge 徽标

`Badge` 渲染静态的小标签，用于为其他内容补充上下文。徽标会随周围文本缩放，可用于标题、按钮和其他控件。

## 示例

徽标支持实心、柔和和描边样式。

## API

### Badge

默认在 `span` 元素上渲染 `.badge` 类。

| 属性      | 类型                               | 说明                       |
| --------- | ---------------------------------- | -------------------------- |
| `variant` | `'solid' \| 'subtle' \| 'outline'` | 设置样式；默认为 `solid`。 |
| `size`    | `'lg'`                             | 使用较大的徽标尺寸。       |

继承原生 `span` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `theme` 和 `component`。

## 无障碍访问

徽标本身不提供文本以外的含义。请在周围标签中补充上下文（例如“通知 4”），不要只用颜色表达状态。
定位指示器应包含能够说明其含义的视觉隐藏文本。
