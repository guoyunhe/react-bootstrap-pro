# Badge

`Badge` renders a small, static label that adds context to other content. Badges
scale with their surrounding text and can be used in headings, buttons, and
other controls.

## API

### Badge

Renders the `.badge` class on a `span` by default.

| Prop      | Type                               | Description                                    |
| --------- | ---------------------------------- | ---------------------------------------------- |
| `variant` | `'solid' \| 'subtle' \| 'outline'` | Selects the treatment; `solid` is the default. |
| `size`    | `'lg'`                             | Uses the larger badge size.                    |

Inherits native `span` props and [`Box`](../box/README.mdx#api) utility props,
including `theme` and `component`.

## Accessibility

Badges add no meaning beyond their text. Include context in the surrounding
label (for example, “Notifications 4”) and do not communicate status by color
alone. For positioned indicators, include visually hidden text that explains
the indicator.
