# Badge

`Badge` renders a compact label that scales with its surrounding text.

## Example

<DemoContainer>
  <Badge theme='primary'>New</Badge>{' '}
  <Badge theme='success' variant='subtle'>
    Ready
  </Badge>{' '}
  <Badge theme='danger' variant='outline'>
    4
  </Badge>
</DemoContainer>

## Variants

```tsx
<Badge theme='primary' variant='outline' size='lg'>
  New
</Badge>
```

## In buttons

Use nearby text to make a badge's meaning clear to assistive technology.

```tsx
<Button variant='solid' theme='primary'>
  Notifications <Badge theme='danger'>4</Badge>
</Button>
```

## Positioned indicators

Combine positioning utilities with a badge to place a count on a button.

```tsx
<Button variant='solid' theme='primary' className='position-relative'>
  Inbox
  <Badge theme='danger' className='position-absolute top-0 start-100 translate-middle'>
    4
  </Badge>
</Button>
```

## API

| Prop        | Type                               | Description                                    |
| ----------- | ---------------------------------- | ---------------------------------------------- |
| `variant`   | `'solid' \| 'subtle' \| 'outline'` | Selects badge treatment; solid is the default. |
| `size`      | `'lg'`                             | Enlarges the badge.                            |
| `theme`     | Bootstrap theme literal            | Sets contextual colors.                        |
| `component` | `ElementType`                      | Changes the root element.                      |
| `...props`  | `BoxProps<C>`                      | Native props and all Box utility props.        |

## Accessibility

Badges do not add meaning beyond their text. Include context in the surrounding
label (for example, “Notifications 4”) and do not communicate status by color
alone.
