# Grid 网格

`Row` 和 `Col` 组合使用 Bootstrap 6 的响应式 Flexbox 网格。使用前请在应用中引入
一次 Bootstrap 样式表。

## 示例

将列放入行中，并将行放入 [`Container`](../container/) 中。此示例在所有视口中
显示三个等宽列。

<DemoContainer>
  <GridBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

## 工作原理

行使用负外边距抵消列的水平 gutter 内边距。网格每行有 12 个网格列；数字跨度表示
其占用的宽度比例。列宽之和超过可用空间时会换行。断点基于最小宽度，属性值从该断点
开始生效，直到被覆盖。使用 [`Container`](../container/) 设置响应式宽度，或使用
`fluid` 设置全宽。

## 网格选项

响应式属性接受单个值，或以 `xs`、`sm`、`md`、`lg`、`xl`、`2xl` 为键的对象。
`xs` 生成无前缀的类，其他断点生成 `md:col-6` 等类。

| 断点  | 最小宽度 |
| ----- | -------- |
| `xs`  | 0        |
| `sm`  | 576px    |
| `md`  | 768px    |
| `lg`  | 1024px   |
| `xl`  | 1280px   |
| `2xl` | 1536px   |

这些是 Bootstrap 的默认值，自定义样式表可能不同。

## 对齐、换行与排序

使用行的 `alignItems` 和 `justifyContent`，或列的 `alignSelf` 设置对齐。列宽之和
超过 12 时会换行；全宽元素可强制换行，响应式显示工具类可控制其生效断点。使用
`order` 改变视觉顺序，使用 `offset` 在列前添加间距。可在后续断点将偏移设为 `0`
以重置，也可使用 `ms-auto` 等 margin 工具类分配空间。

<DemoContainer>
  <ColumnFeaturesDemo />
</DemoContainer>

```tsx src='./demos/column-features.tsx'

```

`Col` 也可在 `Row` 外作为宽度工具使用，此时没有行提供的 gutter 内边距。更多对齐、
换行和偏移示例请参阅[上游列文档](https://getbootstrap.com/docs/6.0/layout/columns/)。

## 间距

`gutter`、`gutterX` 和 `gutterY` 分别设置双向、水平和垂直间距。Bootstrap 默认
间距级别为 `0`–`5`；这些属性也接受断点对象。较大的 gutter 可能溢出容器，可以调整
容器内边距或使用控制溢出的外层容器。详见[上游间距文档](https://getbootstrap.com/docs/6.0/layout/gutters/)。

## API

### Row

默认渲染为 `div`。下表列出自有属性；此外继承所选元素的原生属性和
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

| 属性             | 类型                                 | 说明                   |
| ---------------- | ------------------------------------ | ---------------------- |
| `alignItems`     | `GridResponsive<GridAlignItems>`     | 设置列的垂直对齐方式。 |
| `cols`           | `GridResponsive<number \| 'auto'>`   | 设置列数或自然宽度。   |
| `gutter`         | `GridResponsive<number>`             | 设置水平和垂直间距。   |
| `gutterX`        | `GridResponsive<number>`             | 设置水平间距。         |
| `gutterY`        | `GridResponsive<number>`             | 设置垂直间距。         |
| `justifyContent` | `GridResponsive<GridJustifyContent>` | 设置列的水平分布方式。 |

### Col

默认渲染为 `div`。下表列出自有属性；此外继承所选元素的原生属性和
[`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

| 属性        | 类型                                          | 说明                                                          |
| ----------- | --------------------------------------------- | ------------------------------------------------------------- |
| `alignSelf` | `GridResponsive<GridAlignSelf>`               | 覆盖行对该列的对齐方式。                                      |
| `span`      | `GridResponsive<number \| 'auto' \| true>`    | 设置宽度；`auto` 适应内容，`true` 均分空间。默认使用 `.col`。 |
| `offset`    | `GridResponsive<number>`                      | 添加列偏移。                                                  |
| `order`     | `GridResponsive<number \| 'first' \| 'last'>` | 设置视觉顺序。                                                |

`GridResponsive<T>` 是单个值或包含断点键的对象。`GridAlignItems` 接受 `'start'`、
`'center'`、`'end'`、`'baseline'` 或 `'stretch'`；`GridAlignSelf` 还接受 `'auto'`。
`GridJustifyContent` 接受 `'start'`、`'center'`、`'end'`、`'around'`、`'between'`
或 `'evenly'`。Bootstrap 默认排序工具类支持 `1`–`5`、`first` 和 `last`。数字属性
会生成类名；可用类取决于 Bootstrap 样式表及其配置。

## 无障碍

使用合理的 DOM 顺序和语义化元素。视觉上的 `order` 不会改变键盘或屏幕阅读器的顺序。
