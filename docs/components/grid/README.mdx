# Grid

`Row` and `Col` compose Bootstrap 6's responsive, flexbox-based grid. The grid
uses 12 columns per row; place columns inside a row and rows inside a
[`Container`](../container/). Import Bootstrap's stylesheet once in your
application before using these components.

## Example

The basic grid uses rows and columns that share the available width.

```tsx
<Container>
  <Row>
    <Col>Column</Col>
    <Col>Column</Col>
    <Col>Column</Col>
  </Row>
</Container>
```

## Responsive layout

Use `Row`'s `cols` prop to set the number of equal-width columns, or set each
`Col`'s `span` to control how many of the 12 grid columns it occupies. Values
can be a single number for all viewports or an object keyed by breakpoint.

<DemoContainer>
  <Container fluid>
    <GridLayoutsDemo />
  </Container>
</DemoContainer>

```tsx
<Row cols={{ xs: 1, sm: 2, md: 4 }} gutter={3}>
  <Col>One</Col>
  <Col>Two</Col>
  <Col>Three</Col>
  <Col>Four</Col>
</Row>

<Row gutter={3}>
  <Col span={{ xs: 12, md: 8 }}>Main content</Col>
  <Col span={{ xs: 12, md: 4 }}>Sidebar</Col>
</Row>
```

The breakpoint keys are `xs`, `sm`, `md`, `lg`, `xl`, and `2xl`. `xs` maps to
the unprefixed class, while later breakpoints use Bootstrap 6's `sm:`, `md:`,
`lg:`, `xl:`, or `2xl:` prefix.

## Columns

`Col` renders `.col` by default. Use `span='auto'` for content-sized columns,
and set `offset` or `order` to position or reorder a column at selected
breakpoints. Columns wrap when their combined widths exceed 12 grid columns.

<DemoContainer>
  <Container fluid>
    <ColumnFeaturesDemo />
  </Container>
</DemoContainer>

```tsx
<Row>
  <Col span='auto'>Natural width</Col>
  <Col span={{ xs: 12, md: 6 }} offset={{ md: 3 }}>
    Centered from medium breakpoint up
  </Col>
  <Col order={{ xs: 'last', md: 'first' }}>Responsive order</Col>
</Row>
```

## Alignment

Set `alignItems` on a row to vertically align all its columns, and
`justifyContent` to distribute columns horizontally. Set `alignSelf` on an
individual column to override the row's vertical alignment. All three props
accept responsive values. `alignItems` and `alignSelf` support `start`,
`center`, `end`, `baseline`, and `stretch`; `alignSelf` also supports `auto`.
`justifyContent` supports `start`, `center`, `end`, `around`, `between`, and
`evenly`.

```tsx
<Row
  alignItems={{ xs: 'start', md: 'center' }}
  justifyContent='between'
  style={{ minHeight: '8rem' }}
>
  <Col>Aligned with the row</Col>
  <Col alignSelf='end'>Aligned individually</Col>
</Row>
```

## Column wrapping and breaks

Columns wrap naturally when their widths exceed the 12-column row. To start a
new line at a specific point, add a full-width element. Use responsive display
utilities to make the break conditional:

```tsx
<Row>
  <Col span={{ xs: 6, sm: 3 }}>First</Col>
  <Col span={{ xs: 6, sm: 3 }}>Second</Col>
  <div className='w-100 d-none md:d-block' aria-hidden='true' />
  <Col span={{ xs: 6, sm: 3 }}>Third</Col>
  <Col span={{ xs: 6, sm: 3 }}>Fourth</Col>
</Row>
```

## Reordering

Use `order` to change the visual order at selected breakpoints. Available
utilities include numbers `1` through `5`, `first`, and `last`. Visual order
does not change DOM order, so keep the source order meaningful for keyboard and
screen-reader users.

```tsx
<Row>
  <Col order={{ xs: 'last', md: 'first' }}>First in the DOM</Col>
  <Col>Second in the DOM</Col>
  <Col order={{ xs: 1, md: 5 }}>Third in the DOM</Col>
</Row>
```

## Offsetting

Use `offset` to move a column to the right by a number of grid columns. Set a
responsive offset to `0` to reset it at a later breakpoint. For flexible
spacing, Bootstrap margin utilities such as `ms-auto` can be passed through
`className`.

```tsx
<Row>
  <Col span={{ sm: 5, md: 6 }}>First column</Col>
  <Col span={{ sm: 5, md: 6 }} offset={{ sm: 2, md: 0 }}>
    Responsive offset
  </Col>
</Row>
<Row>
  <Col span='auto'>Natural width</Col>
  <Col span='auto' className='ms-auto'>Pushed to the end</Col>
</Row>
```

## Standalone columns

`Col` can also be used outside a `Row` to apply a responsive width. In that
case, Bootstrap does not apply the row's gutter padding.

```tsx
<Col span={{ xs: 6, md: 3 }} className='border p-3'>
  Standalone column
</Col>
```

## Gutters

Rows use Bootstrap's gutter utilities for horizontal and vertical spacing.
`gutter` sets both directions, while `gutterX` and `gutterY` control them
independently. Values from `0` to `5` use Bootstrap's predefined spacing scale;
responsive values can use the same breakpoint object as column sizes.

```tsx
<Row gutter={{ xs: 2, md: 4 }} gutterY={3}>
  <Col>First</Col>
  <Col>Second</Col>
</Row>
```

## API

### Row

| Prop             | Type                                 | Default | Description                                                                                       |
| ---------------- | ------------------------------------ | ------- | ------------------------------------------------------------------------------------------------- |
| `alignItems`     | `GridResponsive<GridAlignItems>`     | —       | Sets responsive vertical alignment for the row's columns.                                         |
| `cols`           | `GridResponsive<number \| 'auto'>`   | —       | Sets `.row-cols-*`; a number applies at all sizes, or a breakpoint object sets responsive counts. |
| `gutter`         | `GridResponsive<number>`             | —       | Sets horizontal and vertical gutters using `.g-*` classes.                                        |
| `gutterX`        | `GridResponsive<number>`             | —       | Sets horizontal gutters using `.gx-*` classes.                                                    |
| `gutterY`        | `GridResponsive<number>`             | —       | Sets vertical gutters using `.gy-*` classes.                                                      |
| `justifyContent` | `GridResponsive<GridJustifyContent>` | —       | Sets responsive horizontal distribution of columns.                                               |
| `component`      | `C extends ElementType`              | `'div'` | Native element or React component to render.                                                      |
| `className`      | `string`                             | —       | Additional class names.                                                                           |
| `...props`       | `BoxProps<C>`                        | —       | Native props of the selected component, plus every [`Box`](../box/) utility prop.                 |

### Col

| Prop        | Type                                          | Default | Description                                                   |
| ----------- | --------------------------------------------- | ------- | ------------------------------------------------------------- |
| `alignSelf` | `GridResponsive<GridAlignSelf>`               | —       | Overrides the row's vertical alignment for this column.       |
| `span`      | `GridResponsive<number \| 'auto'>`            | `.col`  | Sets the column width with `.col-*`; `auto` sizes to content. |
| `offset`    | `GridResponsive<number>`                      | —       | Adds `.offset-*` to move the column to the right.             |
| `order`     | `GridResponsive<number \| 'first' \| 'last'>` | —       | Sets the visual order with `.order-*` classes.                |
| `component` | `C extends ElementType`                       | `'div'` | Native element or React component to render.                  |
| `className` | `string`                                      | —       | Additional class names.                                       |
| `...props`  | `BoxProps<C>`                                 | —       | Native props plus every [`Box`](../box/) utility prop.        |

`Row` and `Col` extend `BoxProps`, so [`Box`](../box/) utility props such as
`bg`, `fg`, `theme`, and `colorScheme` are available on both components.

`GridResponsive<T>` accepts either a value applied at every breakpoint or an
object with `xs`, `sm`, `md`, `lg`, `xl`, and `2xl` keys.

## Accessibility

Use a meaningful DOM order and do not rely on visual column reordering to
communicate sequence. Prefer semantic elements for content placed in columns.
