# Grid

`Row` and `Col` compose Bootstrap 6's responsive flexbox grid. Import Bootstrap's
stylesheet once in your application.

## Example

Place columns inside a row and rows inside a [`Container`](../container/). This
example has three equal-width columns at every viewport.

</DemoContainer>


## How it works

Rows use negative margins to balance the horizontal gutter padding on their
columns. The grid has 12 columns per row; numbered spans use proportions of
that width. Columns wrap when their widths exceed the available space.
Breakpoints use minimum widths, so a value applies at its breakpoint and above
until overridden. Use [`Container`](../container/) for responsive widths or
`fluid` for full width.

## Grid options

Responsive props accept a single value or an object keyed by `xs`, `sm`, `md`,
`lg`, `xl`, and `2xl`. `xs` generates an unprefixed class; other breakpoints
generate classes such as `md:col-6`.

| Breakpoint | Minimum width |
| ---------- | ------------- |
| `xs`       | 0             |
| `sm`       | 576px         |
| `md`       | 768px         |
| `lg`       | 1024px        |
| `xl`       | 1280px        |
| `2xl`      | 1536px        |

These are Bootstrap's defaults and can differ in a customized stylesheet.

## Alignment, wrapping and reordering

Use `alignItems` and `justifyContent` on a row, or `alignSelf` on a column.
Columns wrap when their widths exceed 12. A full-width element can force a
break; responsive display utilities can make it conditional. Use `order` to
change visual order and `offset` to add space before a column. Set an offset
to `0` at a later breakpoint to reset it; margin utilities such as `ms-auto`
can also distribute space.

<DemoContainer>
  <ColumnFeaturesDemo />
</DemoContainer>

```tsx src='./demos/column-features.tsx'

```

`Col` can also be used outside a `Row` as a width utility, without the row's
gutter padding. See the [upstream columns documentation](https://getbootstrap.com/docs/6.0/layout/columns/)
for additional alignment, wrapping and offset examples.

## Gutters

`gutter`, `gutterX`, and `gutterY` set both directions, horizontal spacing, and
vertical spacing respectively. Bootstrap's default spacing scale is `0`–`5`;
these props also accept breakpoint objects. Large gutters can overflow their
container: adjust its padding or use an overflow wrapper. See the
[upstream gutters documentation](https://getbootstrap.com/docs/6.0/layout/gutters/).

## API

### Row

Renders a `div` by default. Its own props are listed below; it also inherits
native props for the selected element and [`Box`](../box/README.mdx#api)
utility props, including `component`.

| Prop             | Type                                 | Description                                  |
| ---------------- | ------------------------------------ | -------------------------------------------- |
| `alignItems`     | `GridResponsive<GridAlignItems>`     | Sets vertical column alignment.              |
| `cols`           | `GridResponsive<number \| 'auto'>`   | Sets the number or natural width of columns. |
| `gutter`         | `GridResponsive<number>`             | Sets horizontal and vertical gutters.        |
| `gutterX`        | `GridResponsive<number>`             | Sets horizontal gutters.                     |
| `gutterY`        | `GridResponsive<number>`             | Sets vertical gutters.                       |
| `justifyContent` | `GridResponsive<GridJustifyContent>` | Sets horizontal column distribution.         |

### Col

Renders a `div` by default. Its own props are listed below; it also inherits
native props for the selected element and [`Box`](../box/README.mdx#api)
utility props, including `component`.

| Prop        | Type                                          | Description                                                               |
| ----------- | --------------------------------------------- | ------------------------------------------------------------------------- |
| `alignSelf` | `GridResponsive<GridAlignSelf>`               | Overrides row alignment for this column.                                  |
| `span`      | `GridResponsive<number \| 'auto' \| true>`    | Sets width; `auto` fits content, `true` shares space. Defaults to `.col`. |
| `offset`    | `GridResponsive<number>`                      | Adds a column offset.                                                     |
| `order`     | `GridResponsive<number \| 'first' \| 'last'>` | Sets visual order.                                                        |

`GridResponsive<T>` is a value or an object with breakpoint keys.
`GridAlignItems` accepts `'start'`, `'center'`, `'end'`, `'baseline'`, or
`'stretch'`; `GridAlignSelf` also accepts `'auto'`. `GridJustifyContent` accepts
`'start'`, `'center'`, `'end'`, `'around'`, `'between'`, or `'evenly'`.
Bootstrap's default order utilities support `1`–`5`, `first`, and `last`.
Numeric props generate class names; available classes depend on the Bootstrap
stylesheet and its configuration.

## Accessibility

Use meaningful DOM order and semantic elements. Visual `order` does not change
keyboard or screen-reader order.
