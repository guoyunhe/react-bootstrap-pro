# Nav overflow 导航溢出

`NavOverflow` 为导航列表提供 Priority+ 插件容器。JavaScript bundle 会测量容器，
并将放不下的条目移动到“更多”菜单。

<DemoContainer>
  <NavOverflow>
    <Nav>
      <NavItem>
        <NavLink href='/one'>一</NavLink>
      </NavItem>
      <NavItem>
        <NavLink href='/two'>二</NavLink>
      </NavItem>
    </Nav>
  </NavOverflow>
</DemoContainer>

## API

### NavOverflow

默认渲染为 `div`，没有自有属性。继承所选元素的原生属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

| 属性        | 类型          | 说明                            |
| ----------- | ------------- | ------------------------------- |
| `component` | `ElementType` | 更换容器元素。                  |
| `className` | `string`      | 添加容器类名。                  |
| `...props`  | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |

组件会自动添加 `data-bs-toggle="nav-overflow"`。可使用 `NavOverflowItem` 和
`NavOverflowIcon` 自定义溢出菜单标记。

### NavOverflowItem

默认渲染为 `li`，没有自有属性。继承原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

### NavOverflowIcon

默认渲染为 `span`，没有自有属性；默认设置 `aria-hidden={true}`。继承原生属性及
通过 `BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。
