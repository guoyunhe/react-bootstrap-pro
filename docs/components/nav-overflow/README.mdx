# Nav overflow

`NavOverflow` wraps a navigation list for Bootstrap's Priority+ plugin. The
JavaScript bundle measures the wrapper and moves items that do not fit into a
“More” menu.

## Example

<DemoContainer>
  <NavOverflow>
    <Nav>
      <NavItem>
        <NavLink href='/one'>One</NavLink>
      </NavItem>
      <NavItem>
        <NavLink href='/two'>Two</NavLink>
      </NavItem>
    </Nav>
  </NavOverflow>
</DemoContainer>

```tsx
<NavOverflow>
  <Nav variant='pills'>
    <NavItem>
      <NavLink href='/one'>One</NavLink>
    </NavItem>
    <NavItem>
      <NavLink href='/two'>Two</NavLink>
    </NavItem>
    <NavItem>
      <NavLink href='/three'>Three</NavLink>
    </NavItem>
  </Nav>
</NavOverflow>
```

## API

| Prop        | Type          | Description                             |
| ----------- | ------------- | --------------------------------------- |
| `component` | `ElementType` | Changes the wrapper element.            |
| `className` | `string`      | Adds wrapper classes.                   |
| `...props`  | `BoxProps<C>` | Native props and all Box utility props. |

The component adds `data-bs-toggle="nav-overflow"` automatically. Use
`NavOverflowItem` and `NavOverflowIcon` for custom overflow-menu markup.

## Accessibility

Keep the navigation links usable at every container width, and mark the active
destination with `aria-current`. The overflow menu is managed by Bootstrap's
JavaScript plugin.
