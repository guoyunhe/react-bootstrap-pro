# Radio 单选

`Radio` 渲染 `.radio` 输入框。单选按钮的选中态完全由 CSS 绘制，不使用自定义
SVG，因此在任意尺寸下都保持清晰。同一组的单选按钮共享 `name`，并将每个选项放在
`FormField` 中与标签并排。

## 配合 FormField

`FormField` 的网格布局会把单选按钮和标签并排摆放。嵌套的 `FormField` 行为相同，
因此一组单选按钮可以共用一个外层容器和标签。

## API

| 属性        | 类型                 | 说明                             |
| ----------- | -------------------- | -------------------------------- |
| `size`      | `'sm' \| 'lg'`       | 调整单选按钮及其标签的尺寸。     |
| `theme`     | Bootstrap 主题字面量 | 通过 `.theme-*` 设置选中态颜色。 |
| `component` | `ElementType`        | 默认渲染 `input type='radio'`。  |
| `...props`  | `BoxProps<C>`        | 原生属性及所有 Box 工具类属性。  |

`FormFieldContent` 在 `FormField` 内包裹标签与描述文本，默认渲染 `div`。

## 无障碍

为每个单选按钮提供可访问名称：用 `<label for>` 并通过 `htmlFor` 关联。同组单选
按钮必须共享相同的 `name`，浏览器才会将它们视为同一组。
