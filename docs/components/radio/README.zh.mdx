# Radio 单选

`Radio` 默认渲染原生 `<input type='radio'>`，并将 Bootstrap 6 的 `.radio`
类直接添加到输入框。

`.radio` 类用于自定义原生输入框外观。选中标记完全由 CSS 绘制，无需自定义 SVG。

## CSS

### 自定义属性

单选按钮的 CSS 自定义属性基于 Sass tokens。可在输入框或其祖先元素上覆盖这些属性。

| 属性                              | 用途                         |
| --------------------------------- | ---------------------------- |
| `--bs-radio-size`                 | 单选按钮宽度和高度。         |
| `--bs-radio-margin-block`         | 单选按钮上下间距。           |
| `--bs-radio-bg`                   | 未选中状态的背景色。         |
| `--bs-radio-border-color`         | 未选中状态的边框颜色。       |
| `--bs-radio-checked-bg`           | 选中状态的背景色。           |
| `--bs-radio-checked-border-color` | 选中状态的边框颜色。         |
| `--bs-radio-disabled-bg`          | 禁用状态的背景色。           |
| `--bs-radio-disabled-opacity`     | 禁用且已选中控件的不透明度。 |

## API

### Radio

默认渲染为 `input` 元素，设置 `type='radio'` 并添加 `.radio` 类。自有属性包括
`size` 和 `validation`。

`Radio` 还继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。更换 `component` 根元素或 input 的 `type` 可能会失去原生
单选按钮行为。

| 属性         | 类型                   | 默认值 | 说明                              |
| ------------ | ---------------------- | ------ | --------------------------------- |
| `size`       | `'sm' \| 'lg'`         | —      | 添加 `.radio-sm` 或 `.radio-lg`。 |
| `validation` | `'valid' \| 'invalid'` | —      | 添加对应的表单校验状态类。        |

当根元素为 `input` 时，`type` 默认为 `'radio'`。原生输入属性包括 `checked`、
`defaultChecked`、`disabled`、`name`、`required` 和 `type`。

## 无障碍

为每个单选按钮提供可访问名称。对于可见文本，使用 `htmlFor` 和唯一的输入框 `id` 关联
`<label>`；对于无可见标签的单选按钮，提供 `aria-label` 或 `aria-labelledby`。
同组单选按钮必须共享相同的 `name`，浏览器才会提供原生单选和键盘交互行为。
