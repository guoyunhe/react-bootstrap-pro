# Radio

`Radio` renders a native `<input type='radio'>` by default and adds Bootstrap
6's `.radio` class directly to the input.

## Basic radio

The `.radio` class customizes the native input. Its checked indicator is drawn
with CSS, so no custom SVG is needed.

## CSS

### Variables

The radio component's CSS custom properties are built on Sass tokens. Override
these properties on the input or an ancestor.

| Variable                          | Purpose                                |
| --------------------------------- | -------------------------------------- |
| `--bs-radio-size`                 | Radio width and height.                |
| `--bs-radio-margin-block`         | Vertical spacing around the radio.     |
| `--bs-radio-bg`                   | Unchecked background color.            |
| `--bs-radio-border-color`         | Unchecked border color.                |
| `--bs-radio-checked-bg`           | Checked background color.              |
| `--bs-radio-checked-border-color` | Checked border color.                  |
| `--bs-radio-disabled-bg`          | Disabled background color.             |
| `--bs-radio-disabled-opacity`     | Opacity for disabled checked controls. |

## API

### Radio

Renders an `input` element by default, sets `type='radio'`, and adds the
`.radio` class. Its own props are `size` and `validation`.

`Radio` also inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`. Changing
the root with `component` or changing the input `type` may remove native radio
behavior.

| Prop         | Type                   | Default | Description                              |
| ------------ | ---------------------- | ------- | ---------------------------------------- |
| `size`       | `'sm' \| 'lg'`         | —       | Adds `.radio-sm` or `.radio-lg`.         |
| `validation` | `'valid' \| 'invalid'` | —       | Adds the corresponding validation class. |

When the selected root is an `input`, `type` defaults to `'radio'`. Native input
props include `checked`, `defaultChecked`, `disabled`, `name`, `required`, and
`type`.

## Accessibility

Give every radio an accessible name. For visible text, associate a `<label>`
using `htmlFor` and a unique input `id`; for an unlabeled radio, provide
`aria-label` or `aria-labelledby`. Radios that belong together must share the
same `name`, which enables the browser's native single-selection and keyboard
behavior.
