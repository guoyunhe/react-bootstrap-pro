# Radio

`Radio` renders a `.radio` input. Radios use CSS for the checked state instead of
a custom SVG, so they scale without losing sharpness. Group radios with a shared
`name` and place each one in a `FormField` beside its label.

## With form field

The `FormField` grid places the radio and its label side by side. Nested fields
work the same way, so a group of radios can share one wrapper and label.

## API

| Prop        | Type                    | Description                                 |
| ----------- | ----------------------- | ------------------------------------------- |
| `size`      | `'sm' \| 'lg'`          | Scales the radio and its label.             |
| `theme`     | Bootstrap theme literal | Sets the checked color via `.theme-*`.      |
| `component` | `ElementType`           | Renders an `input type='radio'` by default. |
| `...props`  | `BoxProps<C>`           | Native props and all Box utility props.     |

`FormFieldContent` wraps a label and its description inside a `FormField`; it
renders a `div` by default.

## Accessibility

Give every radio an accessible name with a `<label for>` bound through `htmlFor`.
Radios that belong together must share the same `name` so browsers treat them as
one group.
