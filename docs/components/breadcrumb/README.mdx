# Breadcrumb

Use an ordered list inside a navigation landmark to represent the current
location in a hierarchy. The empty `BreadcrumbDivider` uses a CSS chevron by
default; it can also contain custom content.

## Example

Use a `BreadcrumbItem` for each page, and mark the current page with
`BreadcrumbLink`'s `active` prop.

## Trail from nested providers

`BreadcrumbProvider` collects entries for a breadcrumb trail. Each provider appends its `items`
after the entries inherited from its ancestors, so route components can contribute their own
prefix as they nest. `useBreadcrumb` returns the assembled entries, ordered from the outermost
provider, for rendering `Breadcrumb`.

<DemoContainer>
  <BreadcrumbProviderNestedDemo />
</DemoContainer>

```tsx src='./demos/provider-nested.tsx'

```

Set `root` to start a new trail that ignores inherited entries. Providers below the root stack
onto the new trail.

<DemoContainer>
  <BreadcrumbProviderRootDemo />
</DemoContainer>

```tsx src='./demos/provider-root.tsx'

```

A provider renders no markup of its own. Entries are plain data: `label` is any React node and
the optional `href` is the link target. Mark the last entry as `active` so it sets
`aria-current='page'`. `useBreadcrumb` returns an empty array when no provider is rendered above
the calling component.

## API

### Breadcrumb

Renders an ordered list with the `.breadcrumb` class, using `ol` by default.
Place it inside a navigation landmark.

Inherits native `ol` props and [`Box`](../box/README.mdx#api) utility props,
including `component`.

### BreadcrumbItem

Renders a list item with the `.breadcrumb-item` class, using `li` by default.
Inherits native `li` props and [`Box`](../box/README.mdx#api) props, including
utility props and `component`.

### BreadcrumbLink

Renders the `.breadcrumb-link` class on an `a` element by default.

| Prop     | Type      | Description                                           |
| -------- | --------- | ----------------------------------------------------- |
| `active` | `boolean` | Adds the active style and sets `aria-current='page'`. |

Inherits native anchor props and [`Box`](../box/README.mdx#api) utility props,
including `component`.

### BreadcrumbProvider

Renders no markup. It provides breadcrumb entries to its descendants.

| Prop       | Type                         | Description                                                             |
| ---------- | ---------------------------- | ----------------------------------------------------------------------- |
| `items`    | `readonly BreadcrumbEntry[]` | Entries appended after the entries inherited from ancestor providers.   |
| `root`     | `boolean`                    | Starts a new trail that ignores inherited entries. Defaults to `false`. |
| `children` | `ReactNode`                  | Descendants that can read the entries with `useBreadcrumb`.             |

A `BreadcrumbEntry` has a required `label` (`ReactNode`) and an optional
`href` (`string`). Providers on the same trail stack their entries in nesting
order, so the outermost provider contributes the first entry.

### useBreadcrumb

The hook takes no parameters and returns the assembled `BreadcrumbEntry` list
of the enclosing provider and its ancestors, ordered from the outermost
provider. Outside a provider it returns an empty array instead of throwing.

### BreadcrumbDivider

Renders a list item with the `.breadcrumb-divider` class, using `li` by default.
When empty, it displays the CSS chevron. Custom children replace the chevron.
The divider is hidden from assistive technology by default. Inherits native
`li` props and [`Box`](../box/README.mdx#api) props, including `component`.

## Accessibility

Add an accessible `aria-label` to the surrounding `<nav>` landmark and mark the
current page with `aria-current='page'`. Divider elements are hidden from
assistive technology; provide an accessible name for icon-only breadcrumb
links.
