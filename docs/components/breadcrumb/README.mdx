# Breadcrumb

Use an accessible navigation landmark around `Breadcrumb`. Its item, link, and
divider components render the expected list semantics.

## Custom divider

`BreadcrumbDivider` can contain custom content instead of the default chevron.

## API

| Component           | Purpose                                                             |
| ------------------- | ------------------------------------------------------------------- |
| `Breadcrumb`        | Ordered-list root with `.breadcrumb`.                               |
| `BreadcrumbItem`    | List item with `.breadcrumb-item`.                                  |
| `BreadcrumbLink`    | Link with optional `active` state.                                  |
| `BreadcrumbDivider` | Empty list item that displays the CSS chevron.                      |
| `...props`          | Every component supports `component`, native props, and `BoxProps`. |

## Accessibility

Label the surrounding navigation landmark and mark the current page with
`aria-current='page'`.
