# Breadcrumb

Use an ordered list inside a navigation landmark to represent the current
location in a hierarchy. The empty `BreadcrumbDivider` uses a CSS chevron by
default; it can also contain custom content.

## Example

Use a `BreadcrumbItem` for each page, and mark the current page with
`BreadcrumbLink`'s `active` prop.

## Dividers

Dividers are explicit list items. An empty `BreadcrumbDivider` displays the
default chevron; adding content replaces it.

## API

### Breadcrumb

Renders an ordered list with the `.breadcrumb` class, using `ol` by default.
Place it inside a navigation landmark.

Inherits native `ol` props and [`Box`](../box/README.mdx#api) utility props,
including `component`.

### BreadcrumbItem

Renders a list item with the `.breadcrumb-item` class, using `li` by default.
Inherits native `li` props and [`Box`](../box/README.mdx#api) props, including
utility props and `component`.

### BreadcrumbLink

Renders the `.breadcrumb-link` class on an `a` element by default.

| Prop     | Type      | Description                                           |
| -------- | --------- | ----------------------------------------------------- |
| `active` | `boolean` | Adds the active style and sets `aria-current='page'`. |

Inherits native anchor props and [`Box`](../box/README.mdx#api) utility props,
including `component`.

### BreadcrumbDivider

Renders a list item with the `.breadcrumb-divider` class, using `li` by default.
When empty, it displays the CSS chevron. Custom children replace the chevron.
The divider is hidden from assistive technology by default. Inherits native
`li` props and [`Box`](../box/README.mdx#api) props, including `component`.

## Accessibility

Add an accessible `aria-label` to the surrounding `<nav>` landmark and mark the
current page with `aria-current='page'`. Divider elements are hidden from
assistive technology; provide an accessible name for icon-only breadcrumb
links.
