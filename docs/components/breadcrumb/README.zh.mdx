# Breadcrumb 面包屑

使用导航区域中的有序列表表示当前页面在层级结构中的位置。空的 `BreadcrumbDivider` 默认显示 CSS
chevron，也可以在其中放入自定义内容。

每个页面使用一个 `BreadcrumbItem`，并通过 `BreadcrumbLink` 的 `active` 属性标记当前页面。

## 分隔符

分隔符是列表中的独立条目。空的 `BreadcrumbDivider` 会显示默认 chevron；添加内容后则显示自定义内容。

### 默认分隔符

保持分隔符为空即可使用 CSS chevron。它会继承分隔符颜色，包括深色模式下的颜色。

## 嵌套 Provider 堆叠路径

`BreadcrumbProvider` 收集面包屑路径的条目。每个 Provider 会把自身的 `items` 追加到从祖先
Provider 继承的条目之后，因此路由组件可以随着嵌套贡献自己的前缀。`useBreadcrumb`
返回按最外层 Provider 优先排序的完整条目列表，用于渲染 `Breadcrumb`。

<DemoContainer>
  <BreadcrumbProviderNestedDemo />
</DemoContainer>

```tsx src='./demos/provider-nested.tsx'

```

设置 `root` 可以开始一条新路径并忽略继承的条目。位于 root 之下的 Provider 会继续堆叠到这条
新路径上。

<DemoContainer>
  <BreadcrumbProviderRootDemo />
</DemoContainer>

```tsx src='./demos/provider-root.tsx'

```

Provider 自身不渲染任何标记。条目是纯数据：`label` 可以是任意 React 节点，可选的 `href`
是链接目标。将最后一个条目标记为 `active`，即可设置 `aria-current='page'`。如果调用组件之上
没有 Provider，`useBreadcrumb` 会返回空数组。

## API

### Breadcrumb

默认使用 `ol` 元素渲染带有 `.breadcrumb` 类的有序列表。请将其放置在导航区域中。

继承原生 `ol` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### BreadcrumbItem

默认使用 `li` 元素渲染带有 `.breadcrumb-item` 类的列表项。继承原生 `li` 属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括工具类属性和 `component`。

### BreadcrumbLink

默认在 `a` 元素上渲染 `.breadcrumb-link` 类。

| 属性     | 类型      | 说明                                         |
| -------- | --------- | -------------------------------------------- |
| `active` | `boolean` | 添加当前页样式并设置 `aria-current='page'`。 |

继承原生链接属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### BreadcrumbProvider

不渲染任何标记，仅向其后代提供面包屑条目。

| 属性       | 类型                         | 说明                                         |
| ---------- | ---------------------------- | -------------------------------------------- |
| `items`    | `readonly BreadcrumbEntry[]` | 追加在从祖先 Provider 继承的条目之后的条目。 |
| `root`     | `boolean`                    | 开始新路径并忽略继承的条目。默认为 `false`。 |
| `children` | `ReactNode`                  | 可通过 `useBreadcrumb` 读取条目的后代内容。  |

`BreadcrumbEntry` 包含必需的 `label`（`ReactNode`）和可选的 `href`（`string`）。同一路径上的
Provider 按嵌套顺序堆叠条目，因此最外层的 Provider 提供第一个条目。

### useBreadcrumb

该钩子不接受参数，返回当前 Provider 及其祖先组合而成的 `BreadcrumbEntry` 列表，按最外层
Provider 优先排序。在没有 Provider 的环境中调用时返回空数组，不会抛出错误。

### BreadcrumbDivider

默认使用 `li` 元素渲染带有 `.breadcrumb-divider` 类的列表项。内容为空时显示 CSS chevron；
添加子内容会替换该图标。分隔符默认对辅助技术隐藏。继承原生 `li` 属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component`。

## 无障碍访问

为外层 `<nav>` 添加易于理解的 `aria-label`，并使用 `aria-current='page'` 标记当前页面。
分隔符默认对辅助技术隐藏；仅含图标的面包屑链接应提供无障碍名称。
