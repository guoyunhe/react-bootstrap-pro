# Breadcrumb 面包屑

使用导航区域中的有序列表表示当前页面在层级结构中的位置。空的 `BreadcrumbDivider` 默认显示 CSS
chevron，也可以在其中放入自定义内容。

## 示例

每个页面使用一个 `BreadcrumbItem`，并通过 `BreadcrumbLink` 的 `active` 属性标记当前页面。

## 分隔符

分隔符是列表中的独立条目。空的 `BreadcrumbDivider` 会显示默认 chevron；添加内容后则显示自定义内容。

### 默认分隔符

保持分隔符为空即可使用 CSS chevron。它会继承分隔符颜色，包括深色模式下的颜色。

## API

### Breadcrumb

默认使用 `ol` 元素渲染带有 `.breadcrumb` 类的有序列表。请将其放置在导航区域中。

继承原生 `ol` 属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### BreadcrumbItem

默认使用 `li` 元素渲染带有 `.breadcrumb-item` 类的列表项。继承原生 `li` 属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括工具类属性和 `component`。

### BreadcrumbLink

默认在 `a` 元素上渲染 `.breadcrumb-link` 类。

| 属性     | 类型      | 说明                                         |
| -------- | --------- | -------------------------------------------- |
| `active` | `boolean` | 添加当前页样式并设置 `aria-current='page'`。 |

继承原生链接属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括 `component`。

### BreadcrumbDivider

默认使用 `li` 元素渲染带有 `.breadcrumb-divider` 类的列表项。内容为空时显示 CSS chevron；
添加子内容会替换该图标。分隔符默认对辅助技术隐藏。继承原生 `li` 属性及
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component`。

## 无障碍访问

为外层 `<nav>` 添加易于理解的 `aria-label`，并使用 `aria-current='page'` 标记当前页面。
分隔符默认对辅助技术隐藏；仅含图标的面包屑链接应提供无障碍名称。
