# Range 滑块

原生滑块无法在各浏览器中一致地显示已填充轨道，因为 CSS 无法读取输入值。`Range`
渲染 `.form-range` 轨道与内部的 `.form-range-input`，并同步 `--bs-range-fill`
自定义属性，因此填充轨道、数值气泡与刻度都能在各浏览器中正常显示。Bootstrap 用
JavaScript 插件实现该效果，本组件用 React 复刻了相同行为，无需加载插件。

## API

| 属性           | 类型                           | 说明                           |
| -------------- | ------------------------------ | ------------------------------ |
| `min`          | `number`                       | 最小值，默认 `0`。             |
| `max`          | `number`                       | 最大值，默认 `100`。           |
| `step`         | `number \| 'any'`              | 吸附步长。                     |
| `value`        | `number`                       | 受控值。                       |
| `defaultValue` | `number`                       | 非受控初始值。                 |
| `disabled`     | `boolean`                      | 禁用输入框。                   |
| `bubble`       | `boolean`                      | 在滑块上方显示数值气泡。       |
| `format`       | `(value: number) => string`    | 格式化气泡文本。               |
| `ticks`        | `readonly { value, label? }[]` | 按数值渲染刻度。               |
| `component`    | `ElementType`                  | 更换轨道元素，默认 `div`。     |
| `...props`     | `BoxProps<C>`                  | Box 工具类属性及其余原生属性。 |

原生输入属性（`id`、`name`、`list`、`required`、`onChange`、`onInput`、`aria-*`
等）会透传给内部输入框。

## 无障碍

每个滑块都需要可访问名称：使用 `htmlFor` 绑定的可见 `FormLabel`，没有可见标签时
使用 `aria-label`。数值气泡是装饰性的（`aria-hidden`），屏幕阅读器朗读的是输入
框自身的值。
