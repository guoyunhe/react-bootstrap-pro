# Range 滑块

原生滑块无法在各浏览器中一致地显示已填充轨道，因为 CSS 无法读取输入值。`Range`
渲染 `.form-range` 容器与内部的 `.form-range-input`，并同步 `--bs-range-fill`
自定义属性，因此填充轨道、数值气泡与刻度都能在各浏览器中正常显示。Bootstrap 用
JavaScript 插件实现该效果，本组件用 React 复刻了相同行为，无需加载插件。

## CSS

### 自定义属性

组件会根据输入框的当前值在容器上写入 `--bs-range-fill`（`0`–`1`）。其余变量定义在
`.form-range` 上，输入框与装饰元素都会继承，可在容器上覆盖任意变量。

| 属性                                   | 用途                         |
| -------------------------------------- | ---------------------------- |
| `--bs-range-fill`                      | 已填充轨道比例，由组件写入。 |
| `--bs-range-track-width`               | 轨道宽度。                   |
| `--bs-range-track-height`              | 轨道高度。                   |
| `--bs-range-track-cursor`              | 轨道上的鼠标指针样式。       |
| `--bs-range-track-bg`                  | 未填充部分的轨道背景。       |
| `--bs-range-track-border-radius`       | 轨道圆角。                   |
| `--bs-range-track-fill-bg`             | 已填充轨道的颜色。           |
| `--bs-range-track-disabled-bg`         | 禁用状态的轨道背景。         |
| `--bs-range-thumb-width`               | 滑块宽度。                   |
| `--bs-range-thumb-height`              | 滑块高度，默认等于宽度。     |
| `--bs-range-thumb-bg`                  | 滑块背景。                   |
| `--bs-range-thumb-border`              | 滑块边框简写。               |
| `--bs-range-thumb-border-radius`       | 滑块圆角。                   |
| `--bs-range-thumb-box-shadow`          | 滑块阴影。                   |
| `--bs-range-thumb-active-bg`           | 拖动中的滑块背景。           |
| `--bs-range-thumb-disabled-bg`         | 禁用状态的滑块背景。         |
| `--bs-range-thumb-transition-property` | 滑块过渡属性。               |
| `--bs-range-thumb-transition-duration` | 滑块过渡时长。               |
| `--bs-range-thumb-transition-timing`   | 滑块过渡缓动函数。           |
| `--bs-range-tick-width`                | 刻度线宽度。                 |
| `--bs-range-tick-height`               | 刻度线高度。                 |
| `--bs-range-tick-bg`                   | 刻度线颜色。                 |

## API

### Range

默认渲染 `div` 容器，内部包含原生 `<input type='range'>`。Box 属性作用于容器，
原生滑块属性由内部输入框接收。

| 属性           | 类型                        | 说明                                        |
| -------------- | --------------------------- | ------------------------------------------- |
| `min`          | `number`                    | 最小值，默认 `0`。                          |
| `max`          | `number`                    | 最大值，默认 `100`。                        |
| `step`         | `number \| 'any'`           | 吸附步长；`'any'` 表示不吸附。              |
| `value`        | `number`                    | 受控值。                                    |
| `defaultValue` | `number`                    | 非受控初始值。                              |
| `disabled`     | `boolean`                   | 禁用输入框。                                |
| `bubble`       | `boolean`                   | 在滑块上方显示数值气泡。                    |
| `format`       | `(value: number) => string` | 格式化气泡文本。                            |
| `ticks`        | `readonly RangeTick[]`      | 按数值渲染刻度。                            |
| `validation`   | `'valid' \| 'invalid'`      | 为输入框添加 `.is-valid` 或 `.is-invalid`。 |
| `component`    | `ElementType`               | 更换容器元素，默认 `div`。                  |
| `...props`     | `BoxProps<C>`               | Box 工具类属性及其余容器属性。              |

`RangeTick` 为 `{ value: number; label?: string }`。

`id`、`name`、`list`、`required`、`onChange`、`onInput` 和 `aria-*` 等属性会透传给
内部输入框而非容器，因此可以用它们为输入框关联标签或 datalist。

## 无障碍

每个滑块都需要可访问名称：使用 `htmlFor` 绑定的可见 `FormLabel`，没有可见标签时
使用 `aria-label`。数值气泡和刻度都是装饰性的（`aria-hidden`），屏幕阅读器朗读的是
输入框自身的值。

滑块保留原生键盘行为：方向键按 `step` 调整数值，Page Up 和 Page Down 以更大步长移动，
Home 和 End 分别跳到最小值与最大值。
