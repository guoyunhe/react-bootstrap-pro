# Range

Native range inputs cannot show a filled track consistently, because CSS cannot
read an input's value. `Range` renders the `.form-range` track with an inner
`.form-range-input` and keeps the `--bs-range-fill` custom property in sync, so
the fill, value bubble, and tick marks render in every browser. Bootstrap uses a
JavaScript plugin for this; the component implements the same behavior in React,
so no plugin is required.

`Range` forwards the native range attributes to the input and applies Box
utility props to the track wrapper. Like native inputs, `min` defaults to `0` and
`max` to `100`.

## API

### Range

Renders a `div` by default. Its own props are `min`, `max`, `step`, `value`,
`defaultValue`, `disabled`, `id`, `name`, `list`, `required`, `bubble`,
`format`, `ticks`, `validation`, `onChange`, `onInput`, `aria-label`,
`aria-describedby`, and `aria-labelledby`. It inherits native props for the
selected element and [`Box`](../box/README.mdx#api) utility props, except
`children`.

| Prop           | Type                           | Description                                     |
| -------------- | ------------------------------ | ----------------------------------------------- |
| `min`          | `number`                       | Minimum value; defaults to `0`.                 |
| `max`          | `number`                       | Maximum value; defaults to `100`.               |
| `step`         | `number \| 'any'`              | Snapping increment.                             |
| `value`        | `number`                       | Controlled value.                               |
| `defaultValue` | `number`                       | Initial value for uncontrolled usage.           |
| `disabled`     | `boolean`                      | Disables the input.                             |
| `bubble`       | `boolean`                      | Shows the value bubble above the thumb.         |
| `format`       | `(value: number) => string`    | Formats the bubble label.                       |
| `ticks`        | `readonly { value, label? }[]` | Renders tick marks positioned by value.         |
| `component`    | `ElementType`                  | Changes the track element; defaults to a `div`. |
| `...props`     | `BoxProps<C>`                  | Box utility props and remaining native props.   |

Native input attributes such as `id`, `name`, `list`, `required`, `onChange`,
`onInput`, and `aria-*` are forwarded to the inner input.

## Accessibility

Every range needs an accessible name. Use a visible `FormLabel` bound with
`htmlFor`, or `aria-label` when no visible label fits. The value bubble is
decorative (`aria-hidden`), so screen readers announce the input's own value.
