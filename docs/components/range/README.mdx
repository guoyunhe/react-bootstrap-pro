# Range

Native range inputs cannot show a filled track consistently, because CSS cannot
read an input's value. `Range` renders the `.form-range` wrapper with an inner
`.form-range-input` and keeps the `--bs-range-fill` custom property in sync, so
the fill, value bubble, and tick marks render in every browser. Bootstrap uses a
JavaScript plugin for this; the component implements the same behavior in React,
so no plugin is required.

`Range` forwards native range attributes to the inner input and applies Box
utility props to the wrapper. Like native inputs, `min` defaults to `0` and `max`
to `100`.

## CSS

### Variables

The component writes `--bs-range-fill` (`0`–`1`) on the wrapper from the input's
current value. The remaining variables are defined on `.form-range`, so the
input and decorations inherit them; override any of them on the wrapper.

| Variable                               | Purpose                                            |
| -------------------------------------- | -------------------------------------------------- |
| `--bs-range-fill`                      | Filled portion of the track, set by the component. |
| `--bs-range-track-width`               | Track width.                                       |
| `--bs-range-track-height`              | Track height.                                      |
| `--bs-range-track-cursor`              | Cursor over the track.                             |
| `--bs-range-track-bg`                  | Unfilled track background.                         |
| `--bs-range-track-border-radius`       | Track corner radius.                               |
| `--bs-range-track-fill-bg`             | Filled track color.                                |
| `--bs-range-track-disabled-bg`         | Track background when disabled.                    |
| `--bs-range-thumb-width`               | Thumb width.                                       |
| `--bs-range-thumb-height`              | Thumb height; defaults to the thumb width.         |
| `--bs-range-thumb-bg`                  | Thumb background.                                  |
| `--bs-range-thumb-border`              | Thumb border shorthand.                            |
| `--bs-range-thumb-border-radius`       | Thumb corner radius.                               |
| `--bs-range-thumb-box-shadow`          | Thumb shadow.                                      |
| `--bs-range-thumb-active-bg`           | Thumb background while dragging.                   |
| `--bs-range-thumb-disabled-bg`         | Thumb background when disabled.                    |
| `--bs-range-thumb-transition-property` | Thumb transition property.                         |
| `--bs-range-thumb-transition-duration` | Thumb transition duration.                         |
| `--bs-range-thumb-transition-timing`   | Thumb transition timing function.                  |
| `--bs-range-tick-width`                | Tick mark width.                                   |
| `--bs-range-tick-height`               | Tick mark height.                                  |
| `--bs-range-tick-bg`                   | Tick mark color.                                   |

## API

### Range

Renders a `div` wrapper by default with a native `<input type='range'>` inside.
Box props apply to the wrapper; the input receives the native range attributes.

| Prop           | Type                        | Description                                     |
| -------------- | --------------------------- | ----------------------------------------------- |
| `min`          | `number`                    | Minimum value; defaults to `0`.                 |
| `max`          | `number`                    | Maximum value; defaults to `100`.               |
| `step`         | `number \| 'any'`           | Snapping increment; `'any'` disables snapping.  |
| `value`        | `number`                    | Controlled value.                               |
| `defaultValue` | `number`                    | Initial value for uncontrolled usage.           |
| `disabled`     | `boolean`                   | Disables the input.                             |
| `bubble`       | `boolean`                   | Shows the value bubble above the thumb.         |
| `format`       | `(value: number) => string` | Formats the bubble label.                       |
| `ticks`        | `readonly RangeTick[]`      | Renders tick marks positioned by value.         |
| `validation`   | `'valid' \| 'invalid'`      | Adds `.is-valid` or `.is-invalid` to the input. |
| `component`    | `ElementType`               | Changes the wrapper element; defaults to `div`. |
| `...props`     | `BoxProps<C>`               | Box utility props and remaining wrapper props.  |

`RangeTick` is `{ value: number; label?: string }`.

The `id`, `name`, `list`, `required`, `onChange`, `onInput`, and `aria-*` props
are forwarded to the inner input rather than the wrapper, so a label or a
datalist can be associated with it.

## Accessibility

Every range needs an accessible name. Use a visible `FormLabel` bound with
`htmlFor`, or `aria-label` when no visible label fits. The value bubble and tick
marks are decorative (`aria-hidden`), so assistive technology reads the input's
own value.

Range inputs keep native keyboard behavior: Arrow keys change the value by
`step`, Page Up and Page Down move in larger increments, and Home and End jump
to the minimum and maximum.
