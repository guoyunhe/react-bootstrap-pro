# 堆叠布局

`Stack` 封装 Bootstrap 的 `.hstack` 和 `.vstack` 辅助类，`StackContainer` 封装
`.stack-container`，用于响应式堆叠变体。它们默认渲染为 `div`，并接受全部
[`Box`](../box/) 属性。

## 方向

将 `direction` 设为 `horizontal` 可使子元素水平排列并垂直居中，子元素默认只占用所需宽度。
默认方向为 `vertical`，子元素会拉伸至可用宽度。使用 `gap` 设置元素间距。

```tsx
<Stack direction='horizontal' gap={3}>
  <button type='button'>第一项</button>
  <button type='button'>第二项</button>
</Stack>
<Stack gap={2}>
  <button type='button'>保存更改</button>
  <button type='button'>取消</button>
</Stack>
```

## 响应式方向

Bootstrap 的响应式堆叠变体使用容器查询。使用 `StackContainer` 包裹堆叠布局，并为
`direction` 设置断点映射：

```tsx
<StackContainer>
  <Stack direction={{ xs: 'vertical', md: 'horizontal' }} gap={2}>
    <button type='button'>保存更改</button>
    <button type='button'>取消</button>
  </Stack>
</StackContainer>
```

## API

| 属性        | 类型                            | 默认值       | 说明                                 |
| ----------- | ------------------------------- | ------------ | ------------------------------------ |
| `direction` | `BoxResponsive<StackDirection>` | `'vertical'` | 基础尺寸或各响应式断点下的堆叠方向。 |
| `component` | `ElementType`                   | `'div'`      | 更改渲染的元素。                     |
| `className` | `string`                        | —            | 额外类名。                           |
| `...props`  | `BoxProps<C>`                   | —            | 原生属性及全部 Box 工具类属性。      |
