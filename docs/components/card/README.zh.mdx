# Card 卡片

`Card` 是灵活的内容容器，可放置文本、图片、列表及其他内容。卡片默认没有固定宽度和内边距；
可使用主体区域添加内边距，并通过工具类或网格布局调整尺寸。

<DemoContainer>
  <CardBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

## 工作方式

- 卡片使用 Flexbox 容器，可配合 Flex 和网格工具类布局。
- `.card` 默认没有内边距。使用 `CardBody` 创建带内边距的区域，并可组合页眉、页脚、
  图片等结构。
- 卡片默认没有外边距；按需添加外边距或间距工具类。
- 选择与内容相符的语义 HTML。`Card` 默认渲染为 `<div>`，也可以渲染为
  `<section>` 或 `<article>` 等元素。

## API

### Card

| 属性        | 类型                        | 默认值  | 说明                            |
| ----------- | --------------------------- | ------- | ------------------------------- |
| `variant`   | `'subtle' \| 'translucent'` | —       | 选择卡片表面样式。              |
| `component` | `C extends ElementType`     | `'div'` | 要渲染的原生元素或 React 组件。 |

继承当前渲染元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardBody

默认渲染为 `<div>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardHeader

默认渲染为 `<div>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardFooter

默认渲染为 `<div>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardTitle

默认渲染为 `<h5>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardSubtitle

默认渲染为 `<h6>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardText

默认渲染为 `<p>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### CardImage

| 属性        | 类型                    | 默认值  | 说明                                               |
| ----------- | ----------------------- | ------- | -------------------------------------------------- |
| `placement` | `'top' \| 'bottom'`     | —       | 应用顶部或底部图片样式；未设置时使用 `.card-img`。 |
| `component` | `C extends ElementType` | `'img'` | 要渲染的原生元素或 React 组件。                    |

继承当前渲染元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 工具类属性。信息性图片应提供
有意义的 `alt` 文本；装饰性图片的 `alt` 应为空字符串。

### CardImageOverlay

默认渲染为 `<div>`。继承当前渲染元素的原生属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

包入口导出 `Card`、`CardProps`、`CardBody`、`CardBodyProps`、`CardHeader`、
`CardHeaderProps`、`CardFooter`、`CardFooterProps`、`CardTitle`、`CardTitleProps`、
`CardSubtitle`、`CardSubtitleProps`、`CardText`、`CardTextProps`、`CardImage`、
`CardImageProps`、`CardImageOverlay` 和 `CardImageOverlayProps`。

## 无障碍访问

当卡片表示独立内容时，选择 `<article>` 或 `<section>` 等有意义的根元素。信息性图片应提供
有用的替代文本，覆盖在图片上的文字应确保有足够的对比度。
