# Card

`Card` is a flexible content container for text, images, lists, and other
content. Cards have no fixed width or padding by default; add a body for padded
content and use utilities or grid layouts to size them.

<DemoContainer>
  <CardBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

## How it works

- Cards are flexbox containers and work with flex and grid utilities.
- `.card` has no default padding. Use `CardBody` for a padded section alongside
  optional headers, footers, images, and other content.
- Cards have no default margin. Add margin or gap utilities as needed.
- Choose semantic HTML that matches the content. `Card` renders a `<div>` by
  default and can render elements such as `<section>` or `<article>`.

## API

### Card

| Prop        | Type                        | Default | Description                                  |
| ----------- | --------------------------- | ------- | -------------------------------------------- |
| `variant`   | `'subtle' \| 'translucent'` | —       | Selects a card surface treatment.            |
| `component` | `C extends ElementType`     | `'div'` | Native element or React component to render. |

Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardBody

Renders a `<div>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardHeader

Renders a `<div>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardFooter

Renders a `<div>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardTitle

Renders an `<h5>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardSubtitle

Renders an `<h6>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardText

Renders a `<p>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

### CardImage

| Prop        | Type                    | Default | Description                                                              |
| ----------- | ----------------------- | ------- | ------------------------------------------------------------------------ |
| `placement` | `'top' \| 'bottom'`     | —       | Applies the top or bottom image treatment. Without it, uses `.card-img`. |
| `component` | `C extends ElementType` | `'img'` | Native element or React component to render.                             |

Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props. Provide useful `alt` text for
informative images; use an empty `alt` for decorative images.

### CardImageOverlay

Renders a `<div>` by default. Accepts native props for the selected element and
[`Box`](../box/README.mdx#api) utility props.

`Card`, `CardProps`, `CardBody`, `CardBodyProps`, `CardHeader`, `CardHeaderProps`,
`CardFooter`, `CardFooterProps`, `CardTitle`, `CardTitleProps`, `CardSubtitle`,
`CardSubtitleProps`, `CardText`, `CardTextProps`, `CardImage`, `CardImageProps`,
`CardImageOverlay`, and `CardImageOverlayProps` are exported from the package
entry point.

## Accessibility

Choose a meaningful root element such as `<article>` or `<section>` when a card
represents standalone content. Give informative images useful alternative text,
and ensure overlaid text has sufficient contrast.
