# Popover

`Popover` provides Bootstrap's styled popover surface. It does not initialize
Bootstrap JavaScript or provide trigger, positioning, dismissal, or arrow
behavior. The examples below use React state and Floating UI for those
interactions.

## API

### Popover

Renders a `div` by default. Its own props are listed below; it inherits native
props for the selected element and [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`, including the polymorphic `component` prop.

| Prop        | Type                                    | Default | Description                                                                    |
| ----------- | --------------------------------------- | ------- | ------------------------------------------------------------------------------ |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | `'top'` | Adds the matching Bootstrap placement class; it does not position the popover. |
| `show`      | `boolean`                               | `false` | Adds `.show` to make the surface visible.                                      |
| `instant`   | `boolean`                               | `false` | Disables the fade transition.                                                  |

When `show` is `false`, the element remains mounted and Bootstrap styles make
it transparent; it is not automatically removed from the accessibility tree or
made inert. Conditionally render hidden content or manage its accessibility and
interactivity in your React state.

### PopoverHeader

Renders an `h3` by default and has no own props. It inherits native props for
the selected heading and [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`, including the `component` prop.

### PopoverBody

Renders a `div` by default and has no own props. It inherits native `div` props
and [`Box`](../box/README.mdx#api) props through `BoxProps<C>`, including the
`component` prop.

## Accessibility

Keep essential information available outside a transient popover. Use a
keyboard-operable trigger and connect it to the content with appropriate ARIA
attributes, such as `aria-expanded` and `aria-labelledby`. Do not rely only on
hover. `Popover` does not manage focus; for interactive content, provide
appropriate focus behavior or use a dialog component.

The fade transition uses CSS. Browsers without `@starting-style` still display
the popover, but may not animate its initial appearance.
