# Popover

`Popover` renders Bootstrap's styled popover surface and manages its interaction
with Floating UI. Pass a trigger element to get positioning, arrow rendering,
dismissal, and keyboard focus handling in React; Bootstrap's JavaScript plugin
is not needed.

## Overview

Click the button to toggle the popover. Click outside it or press Escape to
dismiss it.

## CSS variables

Popover surfaces expose local CSS variables for their background, border,
header, body, arrow, and transition styles. The custom example overrides the
surface and header colors:

```css
.custom-popover {
  --bs-popover-bg: #f0f7ff;
  --bs-popover-border-color: #9ec5fe;
  --bs-popover-header-bg: #cfe2ff;
  --bs-popover-header-color: #052c65;
}
```

## API

### Popover

Renders a `div` by default. Without `trigger`, it renders only the styled
surface and `show` adds `.show` for manual positioning. With `trigger`, it
renders the trigger and a portal-mounted popover whose placement, arrow, and
dismissal are managed by Floating UI.

Its own props are listed below; it inherits native props for the selected
element and [`Box`](../box/README.mdx#api) props through `BoxProps<C>`,
including the polymorphic `component` prop.

| Prop           | Type                                                                | Default     | Description                                                       |
| -------------- | ------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------- |
| `trigger`      | `ReactElement`                                                      | —           | Trigger element; enables the interactive Floating UI popover.     |
| `placement`    | `PopoverPlacement \| Partial<Record<Breakpoint, PopoverPlacement>>` | `'right'`   | Preferred placement or responsive placements.                     |
| `triggers`     | `PopoverTrigger[]`                                                  | `['click']` | Interactions that open the popover: `click`, `hover`, or `focus`. |
| `show`         | `boolean`                                                           | —           | Controlled visibility; adds `.show` in static mode.               |
| `onShowChange` | `(show: boolean) => void`                                           | —           | Called when an interaction requests a visibility change.          |
| `delay`        | `number \| { open?: number; close?: number }`                       | `0`         | Hover delay in milliseconds.                                      |
| `container`    | `HTMLElement \| null`                                               | —           | Element that receives the popover portal.                         |
| `instant`      | `boolean`                                                           | `false`     | Disables the fade transition.                                     |

The interactive popover is associated with its trigger through
`aria-describedby`. Clicking inside the popover does not dismiss it, so links
and controls in the content remain usable.

### PopoverHeader

Renders an `h3` by default and has no own props. It inherits native props for
the selected heading and [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`, including the `component` prop.

### PopoverBody

Renders a `div` by default and has no own props. It inherits native `div` props
and [`Box`](../box/README.mdx#api) props through `BoxProps<C>`, including the
`component` prop.

## Accessibility

Use a trigger that is keyboard-focusable and has a clear accessible name. The
trigger opens the popover on click by default; do not rely on hover alone.
Popovers use `role='tooltip'` and are connected to the trigger with
`aria-describedby`, matching Bootstrap.

Popovers do not manage keyboard focus order. When you need interactive content
such as forms or links, prefer a dialog so focus is trapped and the content is
reachable. Keep essential information available outside a transient popover.

The fade transition uses CSS. Browsers without `@starting-style` still display
the popover, but may not animate its initial appearance.
