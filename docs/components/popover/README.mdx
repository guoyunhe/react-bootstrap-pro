# Popover

`Popover` provides the styled popup surface. `show` controls its rendered
visibility; Bootstrap's JavaScript plugin can independently create and position
popovers from trigger elements.

## Placement

Set `placement` to `top`, `end`, `bottom`, or `start`.

## API

| Prop        | Type                                    | Description                             |
| ----------- | --------------------------------------- | --------------------------------------- |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | Selects the placement style.            |
| `show`      | `boolean`                               | Adds `.show`; false by default.         |
| `instant`   | `boolean`                               | Disables the fade transition.           |
| `component` | `ElementType`                           | Changes the root element.               |
| `...props`  | `BoxProps<C>`                           | Native props and all Box utility props. |

`PopoverHeader` and `PopoverBody` style the title and content regions.

## Accessibility

Keep essential information available outside a transient popover. Ensure
trigger controls are keyboard-operable and provide an accessible relationship
between a trigger and its content when managing the popover in React.
