# Popover 弹出框

`Popover` 提供弹出内容的表面样式。触发交互和 Floating UI 定位需要 Bootstrap
JavaScript bundle。

<DemoContainer>
  <Popover show placement='top'>
    <PopoverHeader>弹出框标题</PopoverHeader>
    <PopoverBody>弹出框内容</PopoverBody>
  </Popover>
</DemoContainer>

## API

| 属性        | 类型                                    | 说明                            |
| ----------- | --------------------------------------- | ------------------------------- |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | 选择放置方向样式。              |
| `show`      | `boolean`                               | 添加 `.show`；默认关闭。        |
| `instant`   | `boolean`                               | 禁用淡入淡出动画。              |
| `component` | `ElementType`                           | 更换根元素。                    |
| `...props`  | `BoxProps<C>`                           | 原生属性及所有 Box 工具类属性。 |

`PopoverHeader` 和 `PopoverBody` 分别设置标题和内容区域样式。

### Popover

默认渲染为 `div`。自有属性为 `instant?: boolean`、
`placement?: 'top' | 'end' | 'bottom' | 'start'`（默认值：`'top'`）和
`show?: boolean`（默认值：`false`）；继承所选元素的原生属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

### PopoverHeader

默认渲染为 `h3`，没有自有属性。继承原生标题属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

### PopoverBody

默认渲染为 `div`，没有自有属性。继承原生 `div` 属性及通过 `BoxProps<C>` 继承的
全部 [`Box`](../box/README.zh.mdx#api) 属性。
