# Popover 弹出框

`Popover` 渲染 Bootstrap 弹出框的表面样式，并使用 Floating UI 管理交互。传入触发器
元素即可在 React 中获得定位、箭头渲染、关闭和键盘焦点处理；无需 Bootstrap JavaScript
插件。

## 概览

点击按钮可切换弹出框；点击外部区域或按 Escape 键可关闭。

## CSS 变量

Popover 表面提供局部 CSS 变量，可设置背景、边框、标题、内容、箭头和过渡样式。自定义
示例覆盖了表面和标题的颜色：

```css
.custom-popover {
  --bs-popover-bg: #f0f7ff;
  --bs-popover-border-color: #9ec5fe;
  --bs-popover-header-bg: #cfe2ff;
  --bs-popover-header-color: #052c65;
}
```

## API

### Popover

默认渲染为 `div`。未传入 `trigger` 时，仅渲染表面样式，可通过 `show` 添加 `.show`
类以便手动定位。传入 `trigger` 时，会渲染触发器以及挂载到 portal 的弹出框，其放置
位置、箭头和关闭行为由 Floating UI 管理。

下表列出自有属性；此外继承所选元素的原生属性及通过 `BoxProps<C>` 继承的
[`Box`](../box/README.zh.mdx#api) 属性，包括多态 `component` 属性。

| 属性           | 类型                                                                | 默认值      | 说明                                            |
| -------------- | ------------------------------------------------------------------- | ----------- | ----------------------------------------------- |
| `trigger`      | `ReactElement`                                                      | —           | 触发器元素；启用 Floating UI 交互弹出框。       |
| `placement`    | `PopoverPlacement \| Partial<Record<Breakpoint, PopoverPlacement>>` | `'right'`   | 首选放置位置或响应式放置位置。                  |
| `triggers`     | `PopoverTrigger[]`                                                  | `['click']` | 打开弹出框的交互：`click`、`hover` 或 `focus`。 |
| `show`         | `boolean`                                                           | —           | 受控可见状态；静态模式下添加 `.show` 类。       |
| `onShowChange` | `(show: boolean) => void`                                           | —           | 交互请求更改可见状态时调用。                    |
| `delay`        | `number \| { open?: number; close?: number }`                       | `0`         | 悬停延迟，单位为毫秒。                          |
| `container`    | `HTMLElement \| null`                                               | —           | 接收弹出框 portal 的元素。                      |
| `instant`      | `boolean`                                                           | `false`     | 禁用淡入淡出过渡。                              |

交互式弹出框通过 `aria-describedby` 与触发器关联。点击弹出框内部不会关闭，因此其中
的链接和控件仍可使用。

### PopoverHeader

默认渲染为 `h3`，没有自有属性。继承所选标题元素的原生属性及通过 `BoxProps<C>` 继承的
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component` 属性。

### PopoverBody

默认渲染为 `div`，没有自有属性。继承原生 `div` 属性及通过 `BoxProps<C>` 继承的
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component` 属性。

## 无障碍访问

请使用可通过键盘聚焦且具有明确无障碍名称的触发器。默认点击触发器打开弹出框，不要只
依赖悬停交互。弹出框使用 `role='tooltip'`，并通过 `aria-describedby` 与触发器关联，
与 Bootstrap 保持一致。

弹出框不管理键盘焦点顺序。若内容包含表单或链接等交互元素，建议改用对话框，以便焦点
被限制在内容内并可到达。请确保重要信息在临时弹出框之外也可获取。

淡入淡出动画由 CSS 实现。不支持 `@starting-style` 的浏览器仍会显示弹出框，但初次
出现时可能没有动画。
