# Popover 弹出框

`Popover` 提供 Bootstrap 弹出框的表面样式，不会初始化 Bootstrap JavaScript，也不负责
触发、定位、关闭或绘制箭头。以下示例使用 React state 和 Floating UI 实现这些交互。

## API

### Popover

默认渲染为 `div`。下表列出自有属性；此外继承所选元素的原生属性及通过
`BoxProps<C>` 继承的 [`Box`](../box/README.zh.mdx#api) 属性，包括多态 `component`
属性。

| 属性        | 类型                                    | 默认值  | 说明                                                |
| ----------- | --------------------------------------- | ------- | --------------------------------------------------- |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | `'top'` | 添加对应的 Bootstrap 放置方向类，不负责定位弹出框。 |
| `show`      | `boolean`                               | `false` | 添加 `.show` 使表面可见。                           |
| `instant`   | `boolean`                               | `false` | 禁用淡入淡出过渡。                                  |

`show` 为 `false` 时，元素仍保留在 DOM 中，Bootstrap 样式会使其透明；它不会自动从
无障碍树中移除，也不会设为 inert。请在 React 状态中按需卸载隐藏内容，或管理其无障碍
属性和交互状态。

### PopoverHeader

默认渲染为 `h3`，没有自有属性。继承所选标题元素的原生属性及通过 `BoxProps<C>` 继承的
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component` 属性。

### PopoverBody

默认渲染为 `div`，没有自有属性。继承原生 `div` 属性及通过 `BoxProps<C>` 继承的
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component` 属性。

## 无障碍访问

请确保重要信息在临时弹出框之外也可获取。使用可通过键盘操作的触发器，并通过
`aria-expanded`、`aria-labelledby` 等合适的 ARIA 属性关联触发器和内容。不要只依赖
悬停交互。`Popover` 不管理焦点；若内容包含交互控件，请自行提供恰当的焦点行为，或
改用 Dialog 组件。

淡入淡出动画由 CSS 实现。不支持 `@starting-style` 的浏览器仍会显示弹出框，但初次
出现时可能没有动画。
