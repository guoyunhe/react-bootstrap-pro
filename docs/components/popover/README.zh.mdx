# Popover 弹出框

`Popover` 提供弹出内容的表面样式。触发交互和 Floating UI 定位需要 Bootstrap
JavaScript bundle。

<DemoContainer>
  <Popover show placement='top'>
    <PopoverHeader>弹出框标题</PopoverHeader>
    <PopoverBody>弹出框内容</PopoverBody>
  </Popover>
</DemoContainer>

## API

| 属性        | 类型                                    | 说明                            |
| ----------- | --------------------------------------- | ------------------------------- |
| `placement` | `'top' \| 'end' \| 'bottom' \| 'start'` | 选择放置方向样式。              |
| `show`      | `boolean`                               | 添加 `.show`；默认关闭。        |
| `instant`   | `boolean`                               | 禁用淡入淡出动画。              |
| `component` | `ElementType`                           | 更换根元素。                    |
| `...props`  | `BoxProps<C>`                           | 原生属性及所有 Box 工具类属性。 |

`PopoverHeader` 和 `PopoverBody` 分别设置标题和内容区域样式。
