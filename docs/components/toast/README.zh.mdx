# Toast 轻提示

`Toast` 使用 `.toast` 渲染轻量级通知，并配合 `ToastContainer`、`ToastHeader` 与
`ToastBody` 组成整体布局。未设置 `show` 时轻提示保持隐藏，因此其显示由 React 控制；
这些组件不会加载 Bootstrap JavaScript。轻提示默认作为实时区域，带有
`role='alert'`、`aria-live='assertive'` 与 `aria-atomic='true'`。

## API

### Toast

默认渲染带 `.toast` 的 `div`。自有属性为 `show`、`instant` 与 `translucent`；继承所选
元素的原生属性，以及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/#api) 工具类属性。未设置 `show` 时轻提示保持隐藏。

| 组件属性      | 类型      | 说明                                                  |
| ------------- | --------- | ----------------------------------------------------- |
| `show`        | `boolean` | 添加 `.show` 以显示轻提示。                           |
| `instant`     | `boolean` | 添加 `.toast-instant` 并移除淡入淡出过渡。            |
| `translucent` | `boolean` | 添加 `.toast-translucent`，应用模糊与饱和度背景效果。 |

轻提示默认设置 `role='alert'`、`aria-live='assertive'` 与 `aria-atomic='true'`；
传入同名属性可覆盖这些默认值。

### ToastContainer

默认渲染带 `.toast-container` 的 `div`，为堆叠的轻提示添加垂直间距。它没有自有属性，
默认设置 `role='region'` 与 `aria-live='polite'`。可通过 `position`、`top`、`end`、
`p` 等属性定位，并继承原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/#api) 工具类属性。

### ToastHeader

默认渲染带 `.toast-header` 的 `div`，采用 flex 布局。它没有自有属性，继承原生属性及
通过 `BoxProps<C>` 继承的全部 [`Box`](../box/#api) 工具类属性。

### ToastBody

默认渲染带 `.toast-body` 的 `div`。它没有自有属性，继承原生属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/#api) 工具类属性。

## 无障碍访问

将轻提示放入实时区域，使屏幕阅读器无需移动焦点即可朗读。`ToastContainer` 默认提供
`role='region'` 与 `aria-live='polite'`，`Toast` 则设置 `aria-atomic='true'`，确保整条
消息作为整体朗读。

请根据消息内容选择角色与礼貌级别：重要更新保留 `role='alert'` 与
`aria-live='assertive'`，常规信息使用 `role='status'` 与 `aria-live='polite'`。当信息
对任务至关重要（例如表单错误列表）时，请改用 [`Alert`](../alert/)。

在轻提示出现之前就应让实时区域存在于页面上；若同时创建区域与内容，通常不会被朗读。若
使用定时器自动隐藏，请留出足够的阅读时间。若不自动隐藏，必须提供关闭按钮；同时避免在
自动隐藏的轻提示中放置可聚焦控件，因为轻提示不会获得焦点。
