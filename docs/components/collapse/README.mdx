# Collapse

`Collapse` provides the `.collapse` panel classes. Control the `show` prop from
React, or use Bootstrap's JavaScript plugin and matching `data-bs-*` attributes.

## Trigger

Connect a button to the panel with matching IDs when using Bootstrap's plugin.

## API

| Prop         | Type          | Description                             |
| ------------ | ------------- | --------------------------------------- |
| `show`       | `boolean`     | Adds `.show` to display the panel.      |
| `horizontal` | `boolean`     | Uses the horizontal collapse modifier.  |
| `component`  | `ElementType` | Changes the root element.               |
| `...props`   | `BoxProps<C>` | Native props and all Box utility props. |

## Accessibility

Keep `aria-expanded` in sync with the panel state and connect the trigger to the
panel using `aria-controls`. Horizontal collapse also needs a width on its
immediate child.
