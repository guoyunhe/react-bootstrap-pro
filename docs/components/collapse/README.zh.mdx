# Collapse 折叠

`Collapse` 为面板应用 Bootstrap 的 `.collapse` 样式类。它不管理状态，也不会初始化
Bootstrap JavaScript 插件；可以通过 React 状态控制 `show`，或加载 Bootstrap 插件并使用
其数据属性。

## 工作原理

`.collapse` 隐藏面板，`.collapse.show` 显示面板。浏览器支持 `interpolate-size` 时，
Bootstrap 会为面板尺寸添加过渡动画。不支持该特性的浏览器仍会显示和隐藏面板，但没有尺寸
动画。Bootstrap 也会遵循减少动态效果偏好设置。

不要直接给 `.collapse` 元素添加内边距。请将它作为包装元素，并把内边距添加到内部元素，
这样尺寸过渡才能缩至零。

## 无障碍

触发器应使用原生按钮，并使其 `aria-expanded` 值与受控面板状态保持同步。使用
`aria-controls` 将触发器关联到面板。若使用锚点作为触发器，应添加 `role="button"` 并阻止
默认导航行为。Bootstrap 插件会自动更新触发器状态；React 控制的示例则应根据与 `show`
相同的状态更新该值。

Collapse 插件没有实现 ARIA Accordion 模式中所有可选的键盘交互。如需手风琴式分组行为，
请使用 [`Accordion`](../accordion/README.zh.mdx) 组件，或自行添加所需键盘行为。

## CSS

Bootstrap 提供以下折叠过渡变量。水平折叠会将过渡属性值改为 `inline-size, display`。

| CSS 变量                            | 默认值                | 说明             |
| ----------------------------------- | --------------------- | ---------------- |
| `--bs-transition-collapse-property` | `block-size, display` | 过渡使用的属性。 |
| `--bs-transition-collapse-duration` | `.35s`                | 过渡时长。       |
| `--bs-transition-collapse-timing`   | `ease`                | 过渡时间函数。   |

## Bootstrap JavaScript 插件

可以使用 Bootstrap 插件而不是 React 状态来控制面板。请单独加载 Bootstrap JavaScript，
为 `Collapse` 面板设置 `id`，并在触发器上添加 `data-bs-toggle="collapse"` 和
`data-bs-target="#panel-id"`。可使用选择器控制多个面板。`data-bs-parent` 选项可实现类似
手风琴的互斥行为。不要同时让插件和 React 控制同一个面板。

## API

### Collapse

默认渲染为 `div`。自有属性包括 `show`（添加 `.show` 类）和 `horizontal`（添加
`.collapse-horizontal` 类），默认值均为 `false`。这些属性仅设置 CSS 类，不管理状态，也不会
调用 Bootstrap JavaScript 插件。

`Collapse` 继承所选根元素的原生属性及全部 [`Box`](../box/README.zh.mdx#api) 属性。
继承的 `component` 属性可更换根元素；更换后，适用的原生属性和语义也会随之变化。

| 属性         | 类型      | 默认值  | 说明                      |
| ------------ | --------- | ------- | ------------------------- |
| `show`       | `boolean` | `false` | 添加 `.show` 以显示面板。 |
| `horizontal` | `boolean` | `false` | 为面板添加内联尺寸过渡。  |
