# Collapse 折叠

`Collapse` 提供 `.collapse` 面板样式。可在 React 中控制 `show` 属性，也可使用
Bootstrap JavaScript 插件及对应的 `data-bs-*` 属性。

<DemoContainer>
  <Collapse show>可折叠内容</Collapse>
</DemoContainer>

```tsx src='./demos/basic.tsx'
<Collapse horizontal show={expanded}>
  内容
</Collapse>
```

## API

### Collapse

默认渲染为 `div`。自有属性为 `horizontal`（应用水平折叠修饰类）和
`show`（应用显示状态类）。组件继承所选元素的原生属性及全部
[`Box`](../box/README.zh.mdx#api) 属性，包括 `component`、`className` 和
`classNameBefore`。

| 属性         | 类型          | 说明                            |
| ------------ | ------------- | ------------------------------- |
| `show`       | `boolean`     | 添加 `.show` 以显示面板。       |
| `horizontal` | `boolean`     | 使用水平折叠样式。              |
| `component`  | `ElementType` | 更换根元素。                    |
| `...props`   | `BoxProps<C>` | 原生属性及所有 Box 工具类属性。 |
