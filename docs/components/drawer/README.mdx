# Drawer

## How it works

`Drawer` renders a native `<dialog>` with Bootstrap drawer classes. It builds on
the same native dialog behavior as [`Dialog`](../dialog/README.mdx#how-it-works)
and uses React state for interactive examples. Pass `show` and `onShowChange`
to control it. Escape and backdrop clicks request closure, as does expansion
of a containing navbar. Bootstrap plugin data attributes and swipe gestures are
not implemented.

The default placement is `end`; use `start`, `top`, or `bottom` to select
another viewport edge. `start` and `end` follow the document's text direction.
Modal drawers open with `showModal()`, which places them in the top layer,
displays a backdrop, and traps focus. The `open` attribute alone opens a
non-modal dialog.

Do not apply
`margin` or `translate` directly to a drawer when it is animated; wrap it if
additional spacing or movement is needed. When a responsive drawer is inside a
navbar, React closes it as the navbar changes to its inline layout.

## Responsive

Responsive drawer classes show a drawer below their breakpoint and display its
contents inline at and above that breakpoint. Use a responsive display utility
to hide the toggle when the drawer is inline. When the drawer is inside a
`.navbar`, React observes the navbar and closes an open drawer as it
changes to the inline layout.

| Class        | Drawer layout below | Inline layout from |
| ------------ | ------------------- | ------------------ |
| `sm:drawer`  | `576px`             | `576px`            |
| `md:drawer`  | `768px`             | `768px`            |
| `lg:drawer`  | `1024px`            | `1024px`           |
| `xl:drawer`  | `1280px`            | `1280px`           |
| `2xl:drawer` | `1536px`            | `1536px`           |

## Accessibility

`Drawer` uses the native `<dialog>` element. Give each drawer a visible
`DrawerTitle` and point `aria-labelledby` to its `id`. Include a close button
with an accessible name or another clear dismiss action.

React opens modal drawers with `showModal()`, which provides
native focus management and makes the rest of the page inert. With
`scroll` and `backdrop={false}`, it uses `show()`;
focus is not trapped and the page remains interactive. The native Escape key
behavior can be disabled with `keyboard={false}`.

## CSS

### CSS variables

Override these variables on the drawer to customize its size and appearance.

| Variable                          | Default                                                   | Description                       |
| --------------------------------- | --------------------------------------------------------- | --------------------------------- |
| `--bs-drawer-inset`               | `var(--bs-spacer)`                                        | Distance from the viewport edge.  |
| `--bs-drawer-zindex`              | `var(--bs-z-drawer)`                                      | Drawer stacking order.            |
| `--bs-drawer-width`               | `400px`                                                   | Width of side drawers.            |
| `--bs-drawer-height`              | `30vh`                                                    | Height of top and bottom drawers. |
| `--bs-drawer-padding-x`           | `var(--bs-spacer)`                                        | Horizontal content padding.       |
| `--bs-drawer-padding-y`           | `var(--bs-spacer)`                                        | Vertical content padding.         |
| `--bs-drawer-color`               | `var(--bs-fg-body)`                                       | Text color.                       |
| `--bs-drawer-bg`                  | `var(--bs-bg-body)`                                       | Panel background.                 |
| `--bs-drawer-border-width`        | `var(--bs-border-width)`                                  | Border width.                     |
| `--bs-drawer-border-color`        | `var(--bs-border-color-translucent)`                      | Border color.                     |
| `--bs-drawer-border-radius`       | `var(--bs-radius-7)`                                      | Corner radius.                    |
| `--bs-drawer-box-shadow`          | `var(--bs-box-shadow-xl)`                                 | Panel shadow.                     |
| `--bs-drawer-transition-property` | `transform, visibility`                                   | Animated properties.              |
| `--bs-drawer-transition-duration` | `.3s`                                                     | Transition duration.              |
| `--bs-drawer-transition-timing`   | `var(--bs-transition-timing-overlay)`                     | Transition timing function.       |
| `--bs-drawer-title-line-height`   | `1.5`                                                     | Title line height.                |
| `--bs-drawer-backdrop-bg`         | `color-mix(in oklch, var(--bs-bg-body) 25%, transparent)` | Backdrop color.                   |
| `--bs-drawer-backdrop-blur`       | `8px`                                                     | Backdrop blur.                    |

The sheet uses `--bs-drawer-sheet-width` with a `760px` fallback on wide
viewports. Bootstrap's Sass token maps configure the drawer and its native
`::backdrop` separately.

## React behavior

`show` is controlled state; update it in `onShowChange` and provide an explicit
click handler for close buttons. By default the drawer is modal and locks page
scrolling. `scroll` permits scrolling, and `backdrop={false}` hides the backdrop.
Together these open a non-modal dialog; hiding the backdrop alone remains modal.
Plugin events, data APIs and swipe gestures are not implemented. The native
Invoker Commands example does not use these controlled options.

## API

### Drawer

Renders a native `<dialog>` by default. `component` can override the element;
when doing so, the replacement must support the dialog behavior you use.

| Prop           | Type                                    | Default | Description                                                                           |
| -------------- | --------------------------------------- | ------- | ------------------------------------------------------------------------------------- |
| `placement`    | `'start' \| 'end' \| 'top' \| 'bottom'` | `'end'` | Selects the viewport edge. `start` and `end` follow the text direction.               |
| `fullscreen`   | `boolean`                               | `false` | Expands the panel to the available viewport area.                                     |
| `sheet`        | `boolean`                               | `false` | Applies the bottom-sheet presentation.                                                |
| `translucent`  | `boolean`                               | `false` | Blurs and saturates content behind the panel.                                         |
| `instant`      | `boolean`                               | `false` | Disables drawer transitions.                                                          |
| `backdrop`     | `boolean \| 'static'`                   | `true`  | Controls backdrop visibility and dismissal.                                           |
| `keyboard`     | `boolean`                               | `true`  | Allow Escape to request closure.                                                      |
| `scroll`       | `boolean`                               | `false` | Allow page scrolling.                                                                 |
| `show`         | `boolean`                               | —       | Controls the native dialog when provided.                                             |
| `onShowChange` | `(show: boolean) => void`               | —       | Requests a state change on Escape, backdrop click, native close, or navbar expansion. |

Inherits native props for the selected element and all [`Box`](../box/README.mdx#api)
utility props, including `component` and `className`.

### DrawerHeader

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DrawerTitle

Renders an `h5` by default. It has no own props and inherits native heading
props and [`Box`](../box/README.mdx#api) utility props.

### DrawerBody

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.

### DrawerFooter

Renders a `div` by default. It has no own props and inherits native `div` props
and [`Box`](../box/README.mdx#api) utility props.
