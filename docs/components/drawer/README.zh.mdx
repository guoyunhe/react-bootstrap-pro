# Drawer 抽屉

`Drawer` 基于原生 `<dialog>`，并通过 Bootstrap JavaScript 插件实现遮罩、焦点管理
和按方向关闭。

<DemoContainer>
  <Drawer open placement='end'>
    <DrawerHeader>
      <DrawerTitle>导航</DrawerTitle>
    </DrawerHeader>
    <DrawerBody>抽屉内容</DrawerBody>
    <DrawerFooter>页脚</DrawerFooter>
  </Drawer>
</DemoContainer>

## API

### Drawer

默认渲染为 `dialog`。自有属性为
`placement?: 'start' | 'end' | 'top' | 'bottom'`（默认值：`'end'`）、
`fullscreen?: boolean`、`sheet?: boolean`、`translucent?: boolean` 和
`instant?: boolean`；继承所选元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

| 属性          | 类型                                    | 说明                                    |
| ------------- | --------------------------------------- | --------------------------------------- |
| `placement`   | `'start' \| 'end' \| 'top' \| 'bottom'` | 选择抽屉位置。                          |
| `fullscreen`  | `boolean`                               | 填满可用视口。                          |
| `sheet`       | `boolean`                               | 使用底部面板样式。                      |
| `translucent` | `boolean`                               | 添加半透明表面效果。                    |
| `instant`     | `boolean`                               | 禁用过渡动画。                          |
| `...props`    | `BoxProps<C>`                           | 原生 dialog 属性及所有 Box 工具类属性。 |

`DrawerHeader`、`DrawerTitle`、`DrawerBody` 和 `DrawerFooter` 提供对应的结构类名。
插件控制的模态行为需要 Bootstrap JavaScript bundle。

### DrawerHeader

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

### DrawerTitle

默认渲染为 `h5`。没有自有属性；继承原生标题属性及通过 `BoxProps<C>` 继承的
全部 [`Box`](../box/README.zh.mdx#api) 属性。

### DrawerBody

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

### DrawerFooter

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及通过 `BoxProps<C>`
继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。
