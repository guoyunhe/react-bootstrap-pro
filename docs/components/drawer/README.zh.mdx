# Drawer 抽屉

## 工作方式

`Drawer` 默认渲染带有 Bootstrap 抽屉类名的原生 `<dialog>`。它与
[`Dialog`](../dialog/README.zh.mdx#how-it-works) 使用相同的原生对话框行为，并通过
React 状态控制交互示例。通过 `show` 和 `onShowChange` 控制抽屉。Escape、点击背景
以及所在导航栏展开时会请求关闭；不实现插件数据属性或滑动关闭手势。

默认位置为 `end`；可设置 `start`、`top` 或 `bottom`。`start` 和 `end` 会根据文本方向
分别指向逻辑起始端和末端。模态抽屉通过 `showModal()` 打开，进入浏览器顶层、显示背景并
限制焦点。单独设置 `open` 属性会打开非模态对话框。

抽屉动画使用 `transform`；如需额外边距或位移，请将抽屉包在其他元素中，
不要直接对抽屉应用 `margin` 或 `translate`。响应式抽屉放在 navbar 中时，navbar 切换为
内联布局后，React 会关闭仍打开的抽屉。

## 响应式抽屉

响应式抽屉类会在对应断点以下显示为抽屉，在该断点及以上将内容作为普通内联内容显示。

若抽屉位于 `.navbar` 中，React 会监听 navbar 尺寸变化并关闭仍打开的抽屉。

## 无障碍访问

`Drawer` 使用原生 `<dialog>` 元素。为每个抽屉提供可见的 `DrawerTitle`，并通过
`aria-labelledby` 指向标题 ID。关闭按钮应有可访问名称，也可以提供其他明确的关闭操作。

React 使用 `showModal()` 打开模态抽屉，由浏览器管理焦点并阻止页面其他内容交互。
设置 `scroll` 和 `backdrop={false}` 时，会改用 `show()`；
此时不会限制焦点，页面仍可交互。可通过 `keyboard={false}` 禁用原生 Escape
关闭行为。

### CSS 变量

可在抽屉上覆盖以下变量以自定义尺寸和外观。

| 变量                              | 默认值                                                    | 说明                 |
| --------------------------------- | --------------------------------------------------------- | -------------------- |
| `--bs-drawer-inset`               | `var(--bs-spacer)`                                        | 与视口边缘的距离。   |
| `--bs-drawer-zindex`              | `var(--bs-z-drawer)`                                      | 抽屉堆叠顺序。       |
| `--bs-drawer-width`               | `400px`                                                   | 侧边抽屉宽度。       |
| `--bs-drawer-height`              | `30vh`                                                    | 顶部和底部抽屉高度。 |
| `--bs-drawer-padding-x`           | `var(--bs-spacer)`                                        | 水平内边距。         |
| `--bs-drawer-padding-y`           | `var(--bs-spacer)`                                        | 垂直内边距。         |
| `--bs-drawer-color`               | `var(--bs-fg-body)`                                       | 文字颜色。           |
| `--bs-drawer-bg`                  | `var(--bs-bg-body)`                                       | 面板背景。           |
| `--bs-drawer-border-width`        | `var(--bs-border-width)`                                  | 边框宽度。           |
| `--bs-drawer-border-color`        | `var(--bs-border-color-translucent)`                      | 边框颜色。           |
| `--bs-drawer-border-radius`       | `var(--bs-radius-7)`                                      | 圆角。               |
| `--bs-drawer-box-shadow`          | `var(--bs-box-shadow-xl)`                                 | 面板阴影。           |
| `--bs-drawer-transition-property` | `transform, visibility`                                   | 动画属性。           |
| `--bs-drawer-transition-duration` | `.3s`                                                     | 过渡时长。           |
| `--bs-drawer-transition-timing`   | `var(--bs-transition-timing-overlay)`                     | 过渡时间函数。       |
| `--bs-drawer-title-line-height`   | `1.5`                                                     | 标题行高。           |
| `--bs-drawer-backdrop-bg`         | `color-mix(in oklch, var(--bs-bg-body) 25%, transparent)` | 背景颜色。           |

token map 分别配置抽屉面板和原生 `::backdrop`。

## React 行为

`show` 是受控状态；请在 `onShowChange` 中更新状态，并为关闭按钮设置点击处理函数。
默认显示模态背景并锁定页面滚动；`scroll` 允许滚动，`backdrop={false}` 隐藏背景。
两者同时设置时使用非模态对话框；只隐藏背景时仍是模态对话框。组件不实现插件的
事件、data API 或滑动手势。原生 Invoker Commands 示例不使用这些受控选项。

## API

### Drawer

默认渲染原生 `<dialog>`。`component` 可以覆盖默认元素；替换后的元素需要支持所使用的
对话框行为。

| 属性           | 类型                                    | 默认值  | 说明                                                   |
| -------------- | --------------------------------------- | ------- | ------------------------------------------------------ |
| `placement`    | `'start' \| 'end' \| 'top' \| 'bottom'` | `'end'` | 选择视口边缘。`start` 和 `end` 会根据文本方向调整。    |
| `fullscreen`   | `boolean`                               | `false` | 扩展面板以填满可用视口区域。                           |
| `sheet`        | `boolean`                               | `false` | 应用底部 sheet 样式。                                  |
| `translucent`  | `boolean`                               | `false` | 模糊并增强面板后方内容的色彩饱和度。                   |
| `instant`      | `boolean`                               | `false` | 禁用抽屉过渡动画。                                     |
| `backdrop`     | `boolean \| 'static'`                   | `true`  | 背景显示及点击关闭行为。                               |
| `keyboard`     | `boolean`                               | `true`  | 是否允许 Escape 请求关闭。                             |
| `scroll`       | `boolean`                               | `false` | 允许页面滚动。                                         |
| `show`         | `boolean`                               | —       | 提供时控制原生对话框。                                 |
| `onShowChange` | `(show: boolean) => void`               | —       | Escape、点击背景、原生关闭或导航栏展开时请求更新状态。 |

继承所选元素的原生属性及全部 [`Box`](../box/README.zh.mdx#api) 工具类属性，包括
`component` 和 `className`。

### DrawerHeader

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DrawerTitle

默认渲染为 `h5`。没有自有属性；继承原生标题属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DrawerBody

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。

### DrawerFooter

默认渲染为 `div`。没有自有属性；继承原生 `div` 属性及
[`Box`](../box/README.zh.mdx#api) 工具类属性。
