# IconLink 图标链接

`IconLink` 渲染带有 Bootstrap `.icon-link` 辅助类的链接，使用行内 Flex 布局对齐文本
和图标，并设置下划线样式。Bootstrap 将带有 `.bi` 类的直接子图标设置为 `1em` 并使用
链接颜色。也可使用其他图标或图片，但可能需要自行设置尺寸和样式。

## API

### IconLink

默认渲染为 `a` 元素。自有属性为 `hover`，用于添加悬停修饰类。组件继承原生
锚点属性及全部 [`Box`](../box/README.zh.mdx#api) 工具类属性；`component`
可更换渲染元素。

| 属性    | 类型      | 说明                                         |
| ------- | --------- | -------------------------------------------- |
| `hover` | `boolean` | 添加 `.icon-link-hover` 悬停和焦点变换效果。 |

## 无障碍

装饰性图标应设置 `aria-hidden='true'`。传递信息的图标应提供无障碍名称，例如在 SVG
上设置 `role='img'` 和 `aria-label`。链接文本应清楚描述目标或操作。Bootstrap 会根据
`prefers-reduced-motion` 禁用图标的过渡动画，但焦点或悬停变换仍可能生效。
