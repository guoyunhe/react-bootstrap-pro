# IconLink

`IconLink` renders an anchor with Bootstrap's `.icon-link` helper, which uses
inline flex layout to align text and icons and adds underline styling. Bootstrap
sizes direct child icons with the `.bi` class to `1em` and uses the link color.
Other icons or images can be used, but may need their own sizing and styling.

## API

### IconLink

Renders an `a` element by default. Its own prop is `hover`, which adds the
hover modifier class. It inherits native anchor props and all
[`Box`](../box/README.mdx#api) utility props; `component` can change the
rendered element.

| Prop    | Type      | Description                                              |
| ------- | --------- | -------------------------------------------------------- |
| `hover` | `boolean` | Adds `.icon-link-hover` for hover and focus transitions. |

## Accessibility

Hide decorative icons with `aria-hidden='true'`. For icons that convey
information, provide an accessible name, such as `role='img'` and `aria-label`
on an SVG. The link text should describe its destination or action. Bootstrap
respects `prefers-reduced-motion` by disabling the icon's transition; the
focus or hover transform can still apply.
