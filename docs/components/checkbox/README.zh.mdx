# Checkbox 复选框

`Checkbox` 默认渲染原生 `<input type='checkbox'>`，并将 Bootstrap 6 的 `.check`
类直接添加到输入框。

## 基础复选框

`.check` 类会替换浏览器默认外观，显示带主题色的控件。它通过输入框
`::before` 伪元素上的 CSS mask 绘制选中与不确定标记，因此无需内联 SVG。
可覆盖 `--bs-check-icon-checked` 和 `--bs-check-icon-indeterminate` 来替换 mask 图像。

  <CheckboxBasicDemo />
</DemoContainer>

```tsx src='./demos/basic.tsx'

```

## 不确定状态

原生输入框可以设置为不确定状态，但 HTML 没有对应属性，因此请使用
`indeterminate` 属性。该状态独立于 `checked`，不会改变表单提交的值。用户激活复选框时
会清除混合状态；如果该状态表示一组项目的选中情况，请根据应用状态计算此属性。

## CSS

### 自定义属性

复选框通过 CSS 自定义属性公开尺寸、颜色和标记配置。可在输入框或其祖先元素上覆盖这些属性。

| 属性                              | 用途                           |
| --------------------------------- | ------------------------------ |
| `--bs-check-size`                 | 复选框宽度和高度。             |
| `--bs-check-margin-block`         | 复选框上下间距。               |
| `--bs-check-bg`                   | 未选中状态的背景色。           |
| `--bs-check-border-color`         | 未选中状态的边框颜色。         |
| `--bs-check-checked-bg`           | 选中和不确定状态的背景色。     |
| `--bs-check-checked-border-color` | 选中和不确定状态的边框颜色。   |
| `--bs-check-icon-checked`         | 选中标记的 CSS mask 图像。     |
| `--bs-check-icon-indeterminate`   | 混合状态标记的 CSS mask 图像。 |
| `--bs-check-disabled-bg`          | 禁用状态的背景色。             |
| `--bs-check-disabled-opacity`     | 禁用且已选中控件的不透明度。   |

## API

### Checkbox

默认渲染为 `input` 元素，设置 `type='checkbox'` 并添加 `.check` 类。自有属性包括
`indeterminate`、`size` 和 `validation`。

`Checkbox` 还继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。更换 `component` 根元素或 input 的 `type` 可能会失去原生
复选框行为；`indeterminate` 仅对原生复选框输入生效。

| 属性            | 类型                   | 默认值  | 说明                              |
| --------------- | ---------------------- | ------- | --------------------------------- |
| `indeterminate` | `boolean`              | `false` | 设置原生复选框的混合状态。        |
| `size`          | `'sm' \| 'lg'`         | —       | 添加 `.check-sm` 或 `.check-lg`。 |
| `validation`    | `'valid' \| 'invalid'` | —       | 添加对应的表单校验状态类。        |

当根元素为 `input` 时，`type` 默认为 `'checkbox'`。原生输入属性包括 `checked`、
`defaultChecked`、`disabled`、`name`、`required` 和 `type`。

## 无障碍

为每个复选框提供可访问名称。对于可见文本，使用 `htmlFor` 和唯一的输入框 `id` 关联
`<label>`；对于无可见标签的复选框，提供 `aria-label` 或 `aria-labelledby`。
原生混合状态是独立于选中状态的 DOM 属性；辅助技术可能会将其播报为“部分选中”。
切换按钮仍保留复选框语义。
