# Checkbox

`Checkbox` renders a native `<input type='checkbox'>` by default and adds
Bootstrap 6's `.check` class directly to the input.

## Basic checkbox

The `.check` class replaces the browser's default appearance with a themed
control. It draws checked and indeterminate marks with CSS masks on the input's
`::before` pseudo-element, so no inline SVG is needed. Override
`--bs-check-icon-checked` and `--bs-check-icon-indeterminate` to provide different
mask images.

## Indeterminate

Checkboxes can be indeterminate when the state is set on the native input.
HTML has no attribute for this state, so use the `indeterminate` prop. The mixed
state is independent of `checked` and does not change the value submitted with
a form. Activating the checkbox clears it; derive the prop from application state
when it represents a group selection.

## CSS

### Variables

The checkbox exposes CSS custom properties for its dimensions, colors, and
marks. Override these properties on the input or an ancestor.

| Variable                          | Purpose                                  |
| --------------------------------- | ---------------------------------------- |
| `--bs-check-size`                 | Checkbox width and height.               |
| `--bs-check-margin-block`         | Vertical spacing around the checkbox.    |
| `--bs-check-bg`                   | Unchecked background color.              |
| `--bs-check-border-color`         | Unchecked border color.                  |
| `--bs-check-checked-bg`           | Checked and indeterminate background.    |
| `--bs-check-checked-border-color` | Checked and indeterminate border.        |
| `--bs-check-icon-checked`         | CSS mask image for the check mark.       |
| `--bs-check-icon-indeterminate`   | CSS mask image for the mixed-state mark. |
| `--bs-check-disabled-bg`          | Disabled background color.               |
| `--bs-check-disabled-opacity`     | Opacity for disabled checked controls.   |

## API

### Checkbox

Renders an `input` element by default, sets `type='checkbox'`, and adds the
`.check` class. Its own props are `indeterminate`, `size`, and `validation`.

`Checkbox` also inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`. Changing
the root with `component` or changing the input `type` may remove native
checkbox behavior; `indeterminate` only applies to a native checkbox input.

| Prop            | Type                   | Default | Description                              |
| --------------- | ---------------------- | ------- | ---------------------------------------- |
| `indeterminate` | `boolean`              | `false` | Sets the native checkbox mixed state.    |
| `size`          | `'sm' \| 'lg'`         | —       | Adds `.check-sm` or `.check-lg`.         |
| `validation`    | `'valid' \| 'invalid'` | —       | Adds the corresponding validation class. |

When the selected root is an `input`, `type` defaults to `'checkbox'`. Native
input props include `checked`, `defaultChecked`, `disabled`, `name`, `required`,
and `type`.

## Accessibility

Give each checkbox an accessible name. For visible text, associate a `<label>`
using `htmlFor` and a unique input `id`; for an unlabeled checkbox, provide
`aria-label` or `aria-labelledby`. The native mixed state is a DOM property,
independent of the checked state; assistive technology may announce it as
partially checked. Toggle buttons retain checkbox semantics.
