# Checkbox

`Checkbox` renders a `.check` input. The class replaces the native appearance with
themed colors and draws the checked and indeterminate marks with a CSS mask, so
the icons inherit the contrast color without inline SVG. Labels and layout come
from `FormField`.

## Indeterminate

There is no HTML attribute for the indeterminate state, so set the DOM property
through a `ref`. `Checkbox` forwards refs to the underlying input.

To replace the built-in marks, override the `--bs-check-icon-checked` and
`--bs-check-icon-indeterminate` custom properties with your own `mask-image`.

## With form field

The `FormField` grid places the checkbox and its label side by side. Nested
fields work the same way, so a group of checkboxes can share one wrapper and
label.

## API

### Checkbox

Renders an `input` element by default and sets `type='checkbox'` unless another
native input type is supplied. Its own props are `size` and `validation`;
`theme` is inherited from `Box`.

`Checkbox` also inherits native props for the selected element and
[`Box`](../box/README.mdx#api) utility props, including `component`, `theme`,
`className`, and `classNameBefore`. `component` defaults to `'input'`; when the
selected component is an input, the default `type` is `'checkbox'`.

| Prop        | Type                    | Description                                    |
| ----------- | ----------------------- | ---------------------------------------------- |
| `size`      | `'sm' \| 'lg'`          | Scales the checkbox and its label.             |
| `theme`     | Bootstrap theme literal | Sets the checked color via `.theme-*`.         |
| `component` | `ElementType`           | Renders an `input type='checkbox'` by default. |
| `...props`  | `BoxProps<C>`           | Native props and all Box utility props.        |

## Accessibility

Give every checkbox an accessible name with a `<label for>` bound through
`htmlFor`. When several checkboxes belong to one question, group them in a
nested `FormField` with a shared label.
