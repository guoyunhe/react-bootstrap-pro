# Pagination

`Pagination` composes a list of page links. Wrap it in a `nav` with a
descriptive label, especially when the page contains more than one navigation
landmark. The links use native browser navigation; these examples use
placeholder fragment URLs, which should be replaced with real page URLs.

## Active

Set `active` on `PageLink` to style the current page and add
`aria-current='page'`. Alternatively, set `active` on `PaginationItem`; it
styles the child and adds `aria-current` to the list item. Avoid marking both
elements as current.

## Disabled

`PaginationItem disabled` adds a disabled class and `aria-disabled`, but does
not prevent navigation or remove a nested link from the tab order. Use a
non-interactive `PageLink component='span'` for unavailable destinations, as
shown here. If an anchor must remain, remove its `href` or explicitly prevent
activation, remove it from the tab order, and mark the link itself disabled.
CSS `pointer-events` alone does not prevent keyboard activation.

## CSS

### CSS variables

Override these Bootstrap variables on `Pagination` to customize its appearance.
Theme colors can override the corresponding link and active colors.

| Variables                                                                                                           | Purpose                         |
| ------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `--bs-pagination-min-height`, `--bs-pagination-padding-x`, `--bs-pagination-padding-y`, `--bs-pagination-font-size` | Link dimensions and typography. |
| `--bs-pagination-color`, `--bs-pagination-bg`                                                                       | Default link colors.            |
| `--bs-pagination-border-width`, `--bs-pagination-border-color`, `--bs-pagination-border-radius`                     | Borders and corner radius.      |
| `--bs-pagination-hover-color`, `--bs-pagination-hover-bg`, `--bs-pagination-hover-border-color`                     | Hover colors.                   |
| `--bs-pagination-active-color`, `--bs-pagination-active-bg`, `--bs-pagination-active-border-color`                  | Active page colors.             |
| `--bs-pagination-disabled-color`, `--bs-pagination-disabled-bg`, `--bs-pagination-disabled-border-color`            | Disabled page colors.           |

## API

### Pagination

Renders a `ul` by default.

| Own prop | Type           | Default | Description                      |
| -------- | -------------- | ------- | -------------------------------- |
| `size`   | `'sm' \| 'lg'` | —       | Selects the small or large size. |

Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) utility props, including `component` and `theme`.

### PaginationItem

Renders an `li` by default.

| Own prop   | Type      | Default | Description                                                                 |
| ---------- | --------- | ------- | --------------------------------------------------------------------------- |
| `active`   | `boolean` | `false` | Adds the active class and defaults `aria-current` to `'page'`.              |
| `disabled` | `boolean` | `false` | Adds the disabled class and `aria-disabled`; does not disable a child link. |

Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) utility props. An explicit `aria-current`
overrides the active default.

### PageLink

Renders an `a` by default.

| Own prop | Type      | Default | Description                                                    |
| -------- | --------- | ------- | -------------------------------------------------------------- |
| `active` | `boolean` | `false` | Adds the active class and defaults `aria-current` to `'page'`. |

Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) utility props, including `component`. An
explicit `aria-current` overrides the active default. Anchor destinations
require an `href`; use `component='span'` for non-interactive content.

## Accessibility

Give each navigation landmark a distinct, descriptive label and identify the
current page with `aria-current='page'`. Give symbol-only links accessible names.
For unavailable pages, prefer non-interactive content; visual disabled styling
and `aria-disabled` do not themselves block navigation.
