# Pagination

`Pagination` uses list markup inside a labeled navigation landmark. Mark the
current page with `active` and provide an accessible name for the navigation.

## Sizes

Use `size='sm'` or `size='lg'` to change the pagination control size.

## Previous and next links

Use descriptive labels when replacing text with symbols or icons.

## API

### Pagination

Renders a `ul` by default. Its own prop is `size?: 'sm' | 'lg'`; it inherits
native props for the selected element and all [`Box`](../box/README.mdx#api)
props through `BoxProps<C>`.

| Prop        | Type           | Description                             |
| ----------- | -------------- | --------------------------------------- |
| `size`      | `'sm' \| 'lg'` | Selects pagination sizing.              |
| `component` | `ElementType`  | Changes the list root element.          |
| `...props`  | `BoxProps<C>`  | Native props and all Box utility props. |

`PaginationItem` supports `active` and `disabled`; use `PageLink` for the
interactive link and its optional `active` state.

### PaginationItem

Renders an `li` by default. Its own props are `active?: boolean` and
`disabled?: boolean`; it updates `aria-current`/`aria-disabled` accordingly.
It inherits native props and all [`Box`](../box/README.mdx#api) props through
`BoxProps<C>`.

### PageLink

Renders an `a` by default. Its own prop is `active?: boolean`, which defaults
`aria-current` to `page`; it inherits native anchor props and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Give the navigation landmark a descriptive label, mark the current page with
`aria-current='page'`, and ensure disabled links cannot be activated.
