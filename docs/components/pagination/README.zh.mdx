# Pagination 分页

`Pagination` 在带有名称的导航区域中使用列表结构。用 `active` 标识当前页，并为
导航区域提供无障碍名称。

<DemoContainer>
  <nav aria-label='搜索结果页'>
    <Pagination>
      <PaginationItem>
        <PageLink href='/page/1'>1</PageLink>
      </PaginationItem>
      <PaginationItem active>
        <PageLink href='/page/2' active>
          2
        </PageLink>
      </PaginationItem>
      <PaginationItem>
        <PageLink href='/page/3'>3</PageLink>
      </PaginationItem>
    </Pagination>
  </nav>
</DemoContainer>

## API

### Pagination

默认渲染为 `ul`。自有属性为 `size?: 'sm' | 'lg'`；继承所选元素的原生属性及通过
`BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。

| 属性        | 类型           | 说明                            |
| ----------- | -------------- | ------------------------------- |
| `size`      | `'sm' \| 'lg'` | 设置分页尺寸。                  |
| `component` | `ElementType`  | 更换列表根元素。                |
| `...props`  | `BoxProps<C>`  | 原生属性及所有 Box 工具类属性。 |

`PaginationItem` 支持 `active` 和 `disabled`；使用 `PageLink` 渲染交互链接，并可设置
`active` 状态。

### PaginationItem

默认渲染为 `li`。自有属性为 `active?: boolean` 和 `disabled?: boolean`；会相应设置
`aria-current` 和 `aria-disabled`。继承原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

### PageLink

默认渲染为 `a`。自有属性为 `active?: boolean`；激活时默认设置
`aria-current="page"`。继承原生链接属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。
