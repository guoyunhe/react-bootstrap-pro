# CSS Grid

Bootstrap CSS Grid 是基于 Flexbox 的 [`Row` 和 `Col`](../grid/) 的可选替代方案。它使用
`.grid`、`.g-col-*` 和 `.g-start-*` 工具类；`Grid` 和 `GridItem` 通过 React 属性提供这些
功能。设置 `$enable-cssgrid: true` 并重新编译 Bootstrap Sass，即可启用 CSS Grid。若要完全
替代标准网格类，还需设置 `$enable-grid-classes: false`。

## 工作原理

- `.grid` 会创建 CSS Grid 容器，并通过 CSS 变量控制行、列和间距。
- `Grid` 使用 `columns` 和 `rows` 属性设置 `--bs-columns` 和 `--bs-rows`。
  `GridItem` 则将 `span` 和 `start` 映射为 `.g-col-*` 和 `.g-start-*` 类。
- 响应式 `span` 和 `start` 值使用容器查询，根据最近的 `.grid` 宽度响应，而不是根据视口宽度响应。
- 如果编译后的 Bootstrap 样式表未启用 CSS Grid，这些组件仍会渲染，但网格布局样式不会生效。

## 主要区别

- Flexbox 对齐工具类对 CSS Grid 列的影响方式有所不同。
- CSS Grid 的 `gap` 替代了 Flexbox 网格的 gutter。CSS Grid 没有负外边距，外边距工具类也不会改变其间距。
- 通过 CSS 变量设置列数和间距，而不是使用 Flexbox 的 `row-cols-*` 类。
- 嵌套网格是独立的网格容器。需要指定列数或间距时，应在每个嵌套网格上单独设置；Bootstrap 会在每个 `.grid` 上声明网格变量默认值。

## 自定义

Bootstrap 使用 CSS 变量设置每个网格的模板和间距：

| 变量           | 回退值   | 说明               |
| -------------- | -------- | ------------------ |
| `--bs-rows`    | `1`      | 网格模板中的行数。 |
| `--bs-columns` | `12`     | 网格模板中的列数。 |
| `--bs-gap`     | `1.5rem` | 行和列之间的间距。 |

`Grid` 提供 `columns` 和 `rows` 属性设置前两个变量。`--bs-gap` 可通过 `style` 传入 CSS 值。

## API

### Grid

默认渲染为 `<div>`。

| 属性      | 类型           | 默认值 | 说明                                                           |
| --------- | -------------- | ------ | -------------------------------------------------------------- |
| `columns` | `number`       | —      | 设置 `--bs-columns`；优先于 `style` 中的同名变量。             |
| `rows`    | `number`       | —      | 设置 `--bs-rows`；优先于 `style` 中的同名变量。                |
| `style`   | `CssGridStyle` | —      | 支持 CSS 属性及 `--bs-columns`、`--bs-rows`、`--bs-gap` 变量。 |

继承所选元素的原生属性，以及 [`Box`](../box/README.mdx#api) 的全部工具类属性，包括
`component` 和 `className`。

### GridItem

默认渲染为 `<div>`。

| 属性    | 类型                                  | 默认值 | 说明                                                                              |
| ------- | ------------------------------------- | ------ | --------------------------------------------------------------------------------- |
| `span`  | `CssGridResponsive<CssGridItemSpan>`  | —      | 设置 `.g-col-*`（1–12）；响应式对象支持 `xs`、`sm`、`md`、`lg`、`xl` 和 `2xl`。   |
| `start` | `CssGridResponsive<CssGridItemStart>` | —      | 设置 `.g-start-*`（1–11）；响应式对象支持 `xs`、`sm`、`md`、`lg`、`xl` 和 `2xl`。 |

继承所选元素的原生属性，以及 [`Box`](../box/README.mdx#api) 的全部工具类属性，包括
`component` 和 `className`。

## 无障碍

CSS Grid 只改变视觉布局，不会改变 DOM 的阅读顺序。请确保 JSX 中的项目顺序对辅助技术仍然合理。
响应式修饰类依赖容器查询；不支持容器查询的浏览器仍会应用无前缀类，但不会应用响应式覆盖。
不支持 CSS Grid 的浏览器会按普通文档流显示子元素。
