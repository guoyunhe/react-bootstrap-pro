# CSS Grid

Bootstrap CSS Grid is an optional alternative to the Flexbox-based
[`Row` and `Col`](../grid/). It uses the `.grid`, `.g-col-*`, and `.g-start-*`
utilities; `Grid` and `GridItem` expose them through React props. Enable
`$enable-cssgrid: true` and recompile Bootstrap Sass. To replace the standard
grid classes entirely, also set `$enable-grid-classes: false`.

## How it works

- `.grid` creates a CSS Grid container. Its rows, columns, and gaps are
  controlled by CSS variables.
- `Grid` sets `--bs-columns` and `--bs-rows` through its `columns` and `rows`
  props. `GridItem` maps `span` and `start` to `.g-col-*` and `.g-start-*`
  classes.
- Responsive `span` and `start` values use container queries. They respond to
  the width of the nearest `.grid`, not the viewport.
- If CSS Grid is disabled in the compiled Bootstrap stylesheet, these
  components still render but the grid layout styles are not applied.

## Key differences

- Flexbox alignment utilities do not affect CSS Grid columns in the same way.
- Grid `gap` replaces the Flexbox grid's gutters. A CSS Grid has no negative row
  margins, and margin utilities do not change its gaps.
- Set the number of columns and gaps with CSS variables instead of Flexbox
  `row-cols-*` classes.
- Nested grids are separate grid containers. Set values on each nested grid
  that needs a specific column count or gap; Bootstrap declares default grid
  variables on each `.grid`.

## Customizing

Bootstrap uses CSS variables for each grid's template and spacing:

| Variable       | Fallback | Description                             |
| -------------- | -------- | --------------------------------------- |
| `--bs-rows`    | `1`      | Number of rows in the grid template.    |
| `--bs-columns` | `12`     | Number of columns in the grid template. |
| `--bs-gap`     | `1.5rem` | Gap between columns and rows.           |

`Grid` exposes `columns`, `rows`, and `gridGap` props for these variables. The
`gridGap` value accepts the CSS `gap` syntax, including separate row and column
values. You can also set the variables directly through `style`.

## API

### Grid

Renders a `<div>` by default.

| Prop      | Type           | Default | Description                                                                       |
| --------- | -------------- | ------- | --------------------------------------------------------------------------------- |
| `columns` | `number`       | —       | Sets `--bs-columns`; takes precedence over the same variable in `style`.          |
| `rows`    | `number`       | —       | Sets `--bs-rows`; takes precedence over the same variable in `style`.             |
| `gridGap` | `string`       | —       | Sets `--bs-gap`; takes precedence over the same variable in `style`.              |
| `style`   | `CssGridStyle` | —       | Accepts CSS properties and `--bs-columns`, `--bs-rows`, and `--bs-gap` variables. |

Inherits native props for the selected element and all [`Box`](../box/README.mdx#api)
utility props, including `component` and `className`.
The inherited `gap` prop remains the separate `Box` spacing utility.

### GridItem

Renders a `<div>` by default.

| Prop    | Type                                  | Default | Description                                                                                  |
| ------- | ------------------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `span`  | `CssGridResponsive<CssGridItemSpan>`  | —       | Sets `.g-col-*` (1–12); responsive objects accept `xs`, `sm`, `md`, `lg`, `xl`, and `2xl`.   |
| `start` | `CssGridResponsive<CssGridItemStart>` | —       | Sets `.g-start-*` (1–11); responsive objects accept `xs`, `sm`, `md`, `lg`, `xl`, and `2xl`. |

Inherits native props for the selected element and all [`Box`](../box/README.mdx#api)
utility props, including `component` and `className`.

## Accessibility

CSS Grid changes visual layout but does not change DOM reading order. Keep the
item order in JSX meaningful for assistive technology. Responsive modifier
classes rely on container queries; without container-query support, unprefixed
classes still apply but responsive overrides do not. Browsers without CSS Grid
support display the children in normal document flow.
