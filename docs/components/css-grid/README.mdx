# CSS Grid

Bootstrap's CSS Grid is opt-in. Enable `$enable-cssgrid: true` in your Bootstrap
Sass build and recompile the stylesheet before using these components.
`Grid` and `GridItem` wrap `.grid`, `.g-col-*`, and `.g-start-*` respectively.
This API is independent of the Flexbox-based [`Row` and `Col`](../grid/).

The `.grid` container uses CSS variables for its rows, columns, and gap.
Responsive item classes use container queries and respond to the width of the
nearest `.grid`, rather than the viewport.

### Responsive

Responsive classes use container-query prefixes. These items take half the
available columns at narrow widths and one-third at the `md` container size:

```tsx
<Grid className='text-center'>
  <GridItem span={{ xs: 6, md: 4 }}>.g-col-6 .md:g-col-4</GridItem>
  <GridItem span={{ xs: 6, md: 4 }}>.g-col-6 .md:g-col-4</GridItem>
  <GridItem span={{ xs: 6, md: 4 }}>.g-col-6 .md:g-col-4</GridItem>
</Grid>
```

For comparison, two `.g-col-6` items remain half-width at every container size:

```tsx
<Grid className='text-center'>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
</Grid>
```

The container-query breakpoints are based on the width of `.grid`, so a grid
nested in a narrow column changes layout independently of the viewport.

### Playground

Resize the grid container, rather than the browser window, to see responsive
items cross their container-query breakpoints.

## Wrapping

Items automatically move to the next row when the current row has no remaining
space. The gap applies horizontally and vertically.

```tsx
<Grid className='text-center'>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
</Grid>
```

## Starts

Use `start` with `span` to set the starting grid line for an item.

```tsx
<Grid className='text-center'>
  <GridItem span={3} start={2}>
    .g-col-3 .g-start-2
  </GridItem>
  <GridItem span={4} start={6}>
    .g-col-4 .g-start-6
  </GridItem>
</Grid>
```

Start values begin at `1`; `0` is not a valid grid line.

## Auto columns

Direct children of `Grid` are automatically sized to one column when no span is
provided:

```tsx
<Grid className='text-center'>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
</Grid>
```

Automatic sizing can be combined with an explicitly sized item:

```tsx
<Grid className='text-center'>
  <GridItem span={6}>.g-col-6</GridItem>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
  <div>1</div>
</Grid>
```

## Nesting

Nested grids inherit their parent's row, column, and gap settings unless a
nested grid sets its own values. This example uses three columns on the outer
grid, inherits that count in the first nested grid, and resets the second
nested grid to 12 columns:

```tsx
<Grid columns={3} className='text-center' overflowX='auto'>
  <div>
    First auto-column
    <Grid>
      <div>Auto-column</div>
      <div>Auto-column</div>
    </Grid>
  </div>
  <div>
    Second auto-column
    <Grid columns={12}>
      <GridItem span={6}>6 of 12</GridItem>
      <GridItem span={4}>4 of 12</GridItem>
      <GridItem span={2}>2 of 12</GridItem>
    </Grid>
  </div>
  <div>Third auto-column</div>
</Grid>
```

## Customizing

Set CSS variables on an individual grid to customize its template and spacing:

| Variable       | Fallback | Description                             |
| -------------- | -------- | --------------------------------------- |
| `--bs-rows`    | `1`      | Number of rows in the grid template.    |
| `--bs-columns` | `12`     | Number of columns in the grid template. |
| `--bs-gap`     | `1.5rem` | Gap between columns and rows.           |

`Grid` exposes `columns` and `rows` props for the first two variables. Pass a
CSS value for `--bs-gap` through `style`.

### No grid classes

Direct children are grid items even without `GridItem` or a `.g-col-*` class:

```tsx
<Grid columns={3} className='text-center'>
  <div>Auto-column</div>
  <div>Auto-column</div>
  <div>Auto-column</div>
</Grid>
```

### Columns and gaps

Set the column count and gap independently:

```tsx
<Grid columns={4} style={{ '--bs-gap': '5rem' }} className='text-center'>
  <GridItem span={2}>.g-col-2</GridItem>
  <GridItem span={2}>.g-col-2</GridItem>
</Grid>
```

```tsx
<Grid columns={10} style={{ '--bs-gap': '1rem' }} className='text-center'>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={4}>.g-col-4</GridItem>
</Grid>
```

### Adding rows

Configure explicit rows and place items on them with `style` and `start`:

```tsx
<Grid rows={3} columns={3} className='text-center'>
  <div>Auto-column</div>
  <GridItem start={2} style={{ gridRow: 2 }}>
    Auto-column
  </GridItem>
  <GridItem start={3} style={{ gridRow: 3 }}>
    Auto-column
  </GridItem>
</Grid>
```

### Gaps

Set `rowGap` or `columnGap` in `style` to change one direction only:

```tsx
<Grid className='text-center' style={{ rowGap: 0 }}>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
</Grid>
```

The `--bs-gap` variable also accepts separate row and column values:

```tsx
<Grid className='text-center' style={{ '--bs-gap': '.25rem 1rem' }}>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
  <GridItem span={6}>.g-col-6</GridItem>
</Grid>
```

## Sass

Bootstrap generates `.g-col-*` and `.g-start-*` classes based on its Sass
variables. Change those variables and recompile to generate more classes, or
combine inline CSS with the generated classes:

```tsx
<Grid columns={18} style={{ '--bs-gap': '.5rem' }} className='text-center'>
  <GridItem style={{ gridColumn: 'span 14' }}>14 columns</GridItem>
  <GridItem span={4}>.g-col-4</GridItem>
</Grid>
```

## API

### Grid

| Prop        | Type                    | Default | Description                                                                       |
| ----------- | ----------------------- | ------- | --------------------------------------------------------------------------------- |
| `columns`   | `number`                | —       | Sets `--bs-columns`, overriding the variable in `style` when both are supplied.   |
| `rows`      | `number`                | —       | Sets `--bs-rows`, overriding the variable in `style` when both are supplied.      |
| `style`     | `CssGridStyle`          | —       | Accepts CSS properties and `--bs-columns`, `--bs-rows`, and `--bs-gap` variables. |
| `component` | `C extends ElementType` | `'div'` | Native element or React component to render.                                      |
| `className` | `string`                | —       | Additional class names.                                                           |
| `...props`  | `BoxProps<C>`           | —       | Native props plus every [`Box`](../box/) utility prop.                            |

### GridItem

| Prop        | Type                                  | Default | Description                                                      |
| ----------- | ------------------------------------- | ------- | ---------------------------------------------------------------- |
| `span`      | `CssGridResponsive<CssGridItemSpan>`  | —       | Sets `.g-col-*`; omitted items use Bootstrap's automatic sizing. |
| `start`     | `CssGridResponsive<CssGridItemStart>` | —       | Sets `.g-start-*` to place the item at a grid column.            |
| `component` | `C extends ElementType`               | `'div'` | Native element or React component to render.                     |
| `className` | `string`                              | —       | Additional class names.                                          |
| `...props`  | `BoxProps<C>`                         | —       | Native props plus every [`Box`](../box/) utility prop.           |
