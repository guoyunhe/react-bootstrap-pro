# List group

`ListGroup` renders a semantic list by default. Use action items for links or
buttons, and use `active` to identify the current selection.

## Flush and numbered

Use `flush` to remove the outer border and rounding, or `numbered` to show CSS
counters.

## Horizontal

Set `horizontal` to display items in a row, or provide a breakpoint to switch
the layout responsively.

## API

### ListGroup

Renders a `ul` by default. Its own props are `flush?: boolean`,
`horizontal?: boolean | 'sm' | 'md' | 'lg' | 'xl' | '2xl'`, and
`numbered?: boolean`; it inherits native props for the selected element and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

| Prop         | Type                                               | Description                             |
| ------------ | -------------------------------------------------- | --------------------------------------- |
| `flush`      | `boolean`                                          | Removes the outer border and rounding.  |
| `horizontal` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Lays items out horizontally.            |
| `numbered`   | `boolean`                                          | Adds nested counters to list items.     |
| `component`  | `ElementType`                                      | Changes the root element.               |
| `...props`   | `BoxProps<C>`                                      | Native props and all Box utility props. |

`ListGroupItem` accepts `action` and `active` modifiers.

### ListGroupItem

Renders an `li` by default. Its own props are `action?: boolean` and
`active?: boolean`; it inherits native props for the selected element and all
[`Box`](../box/README.mdx#api) props through `BoxProps<C>`.

## Accessibility

Use native list semantics for static items. For links and buttons, preserve
their native interaction and use `active` to identify the current selection.
