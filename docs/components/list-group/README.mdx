# ListGroup

`ListGroup` groups related items in a list or other container. Use
`ListGroupItem` for each item.

## Links and buttons

Use `action` with a native link or button for interactive styling; do not use
standard button classes. For an unavailable link, remove `href`, add the
`disabled` class and set `aria-disabled`. A class or `aria-disabled` alone does
not prevent keyboard activation of a link that retains an `href`.

## Horizontal

Use `horizontal` for a row at all sizes, or a breakpoint from `sm` to `2xl`
to switch at that container width. Responsive variants require a parent with
`containerQuery='inline'`. Without container-query support or a matching
container, the list remains vertical. Do not combine horizontal and flush.
Use `flex='fill'` on items for equal widths.

## CSS

List groups expose local CSS variables for colors, borders, padding and states.
See the [Bootstrap variables](https://getbootstrap.com/docs/6.0/components/list-group/#variables).

## JavaScript behavior

`ListGroup` does not manage selection or switch content. For tabbed panels, see
the [Tab documentation](../tab/README.mdx) and the
[Bootstrap list-group tabs](https://getbootstrap.com/docs/6.0/components/tab/#list-groups);
use a tab implementation that also handles focus and keyboard interaction.

## API

### ListGroup

Renders `ul` by default. Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component`.

| Prop         | Type                                               | Description                                                     |
| ------------ | -------------------------------------------------- | --------------------------------------------------------------- |
| `flush`      | `boolean`                                          | Removes outer borders and rounding.                             |
| `horizontal` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | Uses horizontal layout, optionally from a container breakpoint. |
| `numbered`   | `boolean`                                          | Enables CSS counters.                                           |

### ListGroupItem

Renders `li` by default. Inherits native props for the selected element and
[`Box`](../box/README.mdx#api) props, including `component` and `theme`.

| Prop     | Type      | Description                                                          |
| -------- | --------- | -------------------------------------------------------------------- |
| `action` | `boolean` | Adds interactive hover and focus styling.                            |
| `active` | `boolean` | Applies active styling; does not set ARIA state or manage selection. |

## Accessibility

Preserve `ul`/`li` or `ol`/`li` semantics for lists, and use native links and
buttons for actions. Set `aria-current` where appropriate. Disabled buttons use
native `disabled`; disabled links require additional handling. Control labels
and non-color cues remain necessary regardless of styling.
