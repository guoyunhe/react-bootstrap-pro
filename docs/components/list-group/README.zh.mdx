# ListGroup 列表组

`ListGroup` 默认渲染语义化列表。链接或按钮应使用操作项，并通过 `active`
标识当前选择。

<DemoContainer>
  <ListGroup>
    <ListGroupItem active>当前条目</ListGroupItem>
    <ListGroupItem action component='a' href='/next'>
      下一条
    </ListGroupItem>
  </ListGroup>
</DemoContainer>

## API

### ListGroup

默认渲染为 `ul`。自有属性为 `flush?: boolean`、
`horizontal?: boolean | 'sm' | 'md' | 'lg' | 'xl' | '2xl'` 和
`numbered?: boolean`；继承所选元素的原生属性及通过 `BoxProps<C>` 继承的全部
[`Box`](../box/README.zh.mdx#api) 属性。

| 属性         | 类型                                               | 说明                            |
| ------------ | -------------------------------------------------- | ------------------------------- |
| `flush`      | `boolean`                                          | 移除外侧边框和圆角。            |
| `horizontal` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 设置横向排列。                  |
| `numbered`   | `boolean`                                          | 为列表项添加嵌套计数器。        |
| `component`  | `ElementType`                                      | 更换根元素。                    |
| `...props`   | `BoxProps<C>`                                      | 原生属性及所有 Box 工具类属性。 |

`ListGroupItem` 支持 `action` 和 `active` 修饰属性。

### ListGroupItem

默认渲染为 `li`。自有属性为 `action?: boolean` 和 `active?: boolean`；继承所选元素
的原生属性及通过 `BoxProps<C>` 继承的全部 [`Box`](../box/README.zh.mdx#api) 属性。
