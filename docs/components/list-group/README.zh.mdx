# ListGroup 列表组

`ListGroup` 将相关条目组织为列表或其他容器，使用 `ListGroupItem` 渲染各条目。

## 链接与按钮

`aria-disabled` 并不能阻止带有 `href` 的链接被键盘激活。

## 横向排列

使用 `horizontal` 在所有尺寸下横向排列，或指定 `sm` 至 `2xl` 断点以根据容器宽度
切换。响应式变体需要在父元素上设置 `containerQuery='inline'`。浏览器不支持容器查询
或没有匹配容器时，列表保持纵向。不要同时使用横向排列与 `flush`。为条目设置
`flex='fill'` 可使其等宽。

## CSS

列表组提供控制颜色、边框、内边距和状态的局部 CSS 变量，详见
[Bootstrap 变量文档](https://getbootstrap.com/docs/6.0/components/list-group/#variables)。

## JavaScript 行为

`ListGroup` 不管理选中状态或切换内容。选项卡面板请参见
[Tab 文档](../tab/README.zh.mdx)和
[Bootstrap 列表组选项卡](https://getbootstrap.com/docs/6.0/components/tab/#list-groups)；
应使用同时处理焦点和键盘交互的选项卡实现。

## API

### ListGroup

默认渲染为 `ul`。继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component`。

| 属性         | 类型                                               | 说明                       |
| ------------ | -------------------------------------------------- | -------------------------- |
| `flush`      | `boolean`                                          | 移除外侧边框和圆角。       |
| `horizontal` | `boolean \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | 横向排列，可指定容器断点。 |
| `numbered`   | `boolean`                                          | 启用 CSS 计数器。          |

### ListGroupItem

默认渲染为 `li`。继承所选元素的原生属性及 [`Box`](../box/README.zh.mdx#api) 属性，
包括 `component` 和 `theme`。

| 属性     | 类型      | 说明                                             |
| -------- | --------- | ------------------------------------------------ |
| `action` | `boolean` | 添加交互用的悬停和焦点样式。                     |
| `active` | `boolean` | 应用激活样式；不会设置 ARIA 状态或管理选中状态。 |

## 无障碍

列表应保留 `ul`/`li` 或 `ol`/`li` 语义，操作应使用原生链接和按钮。按需设置
`aria-current`。禁用按钮使用原生 `disabled`；禁用链接需要额外处理。样式不能代替
控件标签和非颜色提示。
